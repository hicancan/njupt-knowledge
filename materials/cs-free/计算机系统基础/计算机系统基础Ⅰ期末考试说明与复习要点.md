# 《计算机系统基础Ⅰ》期末考试说明与复习要点

原件经识别和整理；“参考解答”是我们补的。

# 关于期末考试的一些说明

本文是学长根据 2023-2024-2 学期《计算机系统基础Ⅰ》期末考试的回忆整理而成，因该课程为新开设、参考资料较少，内容仅供参考。

## 一、试卷构成

试卷由选择题、填空题、实验题、问答题和综合题构成。

## 二、实验题

此次实验题为 attacklab 的第一阶段，类似于 ctarget.l1，具体见 attacklab 的相关内容。

## 三、问答题

此次问答题涉及了以下主题：

- 计算机采用补码的好处
- C 程序源代码是如何一步一步形成最后的二进制可执行程序的（参考课本 P2 图 1-3）
- 如何对抗缓冲区溢出攻击（参考课本 P198 的 3.10.4 小节相关内容）

## 四、综合题

此次综合题的分值为 50 分（一道大题就占了整张卷子一半的分数 233），由一系列具体的小问题组成，需要根据提供的 C 源代码、`objdump -d` 生成的反汇编指令等信息解决一系列问题。难度低于 bomblab（毕竟 C 源代码都已经给你了）。

## 五、其他

- 此次考试允许带计算器，因为涉及到很多内存地址的计算，都是十六进制计算，所以买个好点的、支持直接以不同进制计算的计算器带着比较好。
- 很多同学前面的题型花了很多时间，结果来不及认真分析最后一道综合题了；但最后一题其实比前面零碎的东西要更好拿分一些，可以合理安排一下做题顺序。
