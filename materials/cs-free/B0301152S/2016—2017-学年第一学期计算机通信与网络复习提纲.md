### 填空 1

题干：若码元周期 $T = 2 \times 10^{-4}$ 秒，且传送8电平信号，则传码速率为 \_\_\_\_ Bd、传信速率为 \_\_\_\_ b/s。

参考解答：
1. 传码速率（波特率）$R_B = 1/T = 1 / (2 \times 10^{-4}) = 5000$ Bd。
2. 每个码元携带的信息量 $\log_2(8) = 3$ bit。
3. 传信速率 $R_b = R_B \times \log_2(M) = 5000 \times 3 = 15000$ b/s。

答案：5000；15000。

### 选择 2

题干：一个带宽为4kHz的理想低通信道，若一个码元携带3bit的信息量，则最高信息传送速率为（）kb/s。
- A. 6
- B. 12
- C. 24
- D. 48

参考解答：
根据奈氏准则，理想低通信道的最高码元传输速率 $R_B = 2W \log_2 V$？不，这里给出的是“一个码元携带3bit信息”，即 $M=2^3=8$ 电平。
奈氏公式计算最高码元速率：$R_{Bmax} = 2W = 2 \times 4000 = 8000$ Baud。
最高信息速率 $R_{bmax} = R_{Bmax} \times \log_2 M = 8000 \times 3 = 24000$ b/s = 24 kb/s。

答案：C。

### 选择 3

题干：已知待传送的数据M=10011，若采用CRC技术进行检错，生成多项式为 $x^{3}+x^{2}+1$ ，则冗余码为()。
- A. 011
- B. 100
- C. 101
- D. 010

参考解答：
1. 生成多项式 $G(x) = x^3 + x^2 + 1$，对应二进制除数：1101。
2. 数据 M = 10011，阶数 n=3，在 M 后补 3 个 0，得到被除数：10011000。
3. 进行模2除法运算：
   ```text
             1100
           ________
    1101 ) 10011000
           1101
           ----
            10010
            1101
            ----
             10000
             1101
             ----
              1010
              1101
              ----
               111
   ```
   余数为 111？
   让我们重新仔细计算一遍模2除法（异或运算）：
   
   被除数：10011000
   除数：1101
   
   Step 1: 1001 ^ 1101 = 0100 -> 落下下一位1 -> 1001
   Step 2: 1001 ^ 1101 = 0100 -> 落下下一位0 -> 1000
   Step 3: 1000 ^ 1101 = 0101 -> 落下下一位0 -> 1010
   Step 4: 1010 ^ 1101 = 0111 -> 落下下一位0 -> 1110
   Step 5: 1110 ^ 1101 = 0011 -> 无位可落，余数即为 011。
   
   余数是 011。

答案：A。

知识点：[电子邮件系统（SMTP、POP3、IMAP、MIME）](../../../topics/计算机网络/email_protocols.md)

### 计算 1

题干：局域网采用CSMA/CD 协议，传输介质是长度为 $1000 \mathrm{~m}$ 长的电缆，电缆中的信号传播速度是 $2 \times 10^{8} \mathrm{~m} / \mathrm{s}$ 。若最短帧长为1000 bit，请求出该局域网的最大传输速率。

参考解答：
1. CSMA/CD协议要求争用期（碰撞检测时间）内必须能发送完最短帧。
2. 往返时延 $RTT = 2 \times \frac{\text{距离}}{\text{速度}} = 2 \times \frac{1000}{2 \times 10^8} = 10^{-5}$ 秒 = 10 $\mu$s。
3. 最短帧长 $L_{min} = R \times RTT$，其中 $R$ 为数据传输速率。
4. $1000 \text{ bit} = R \times 10^{-5} \text{ s}$。
5. $R = \frac{1000}{10^{-5}} = 10^8 \text{ bps} = 100 \text{ Mbps}$。

答案：100 Mbps。

### 填空 2

题干：CIDR地址块202.15.64.0/21中，包含有\_\_\_\_个IP地址，其中，最大的IP地址是\_\_\_\_。

参考解答：
1. CIDR前缀长度 /21，主机号位数 $32 - 21 = 11$ 位。
2. IP地址总数 $2^{11} = 2048$ 个。
3. 起始地址：202.15.64.0。
4. 第三个字节 64 的二进制是 01000000。/21 意味着前 21 位固定。
   第三字节的前 5 位固定（因为 $21-16=5$）。
   64 = 010**00000**。
   最后 3 位变化，加上第四字节 8 位变化，共 11 位变化。
   最大地址的主机部分全为1。
   第三字节最后3位为111 -> 010**111** = 32+16+8 = 56? 不对。
   64 的二进制：`0100 0000`
   /21 掩码：`1111 1111.1111 1111.1111 1000.0000 0000`
   网络地址：`202.15.0100 0000.0000 0000` (202.15.64.0)
   广播地址（最大IP）：主机位全1。
   第三字节变为 `0100 0111` = 64 + 7 = 71。
   第四字节全1 = 255。
   所以最大IP是 202.15.71.255。

答案：2048；202.15.71.255。

### 综合 1

题干：设有A、B、C、D四台主机都处于同一个网络中，它们的IP地址分别是193.155.12.112, 193.155.12.120, 193.155.12.176, 193.155.12.222, 共同的子网掩码是255.255.255.224。请问：

1）这四台主机哪些可以直接通信，哪些需要通过路由器才能通信？

2）若要加入第五台主机E，使其能与D主机直接通信，则E主机IP地址范围是什么？

参考解答：
1. **子网分析**：
   - 子网掩码 255.255.255.224 即 /27。
   - 块大小（Block Size）= $256 - 224 = 32$。
   - 子网划分如下：
     - 子网1: 193.155.12.0 ~ 193.155.12.31
     - 子网2: 193.155.12.32 ~ 193.155.12.63
     - ...
     - 子网N: 193.155.12.x * 32 ~ 193.155.12.x * 32 + 31
     
   - 计算各主机所在子网：
     - A: 112 / 32 = 3.5 -> 属于第4个子网（从0开始计数是索引3），起始地址 $3 \times 32 = 96$。范围：96-127。
       - 112 在 [96, 127] 之间。网络地址 193.155.12.96，广播地址 193.155.12.127。
     - B: 120 / 32 = 3.75 -> 同样属于 [96, 127] 子网。
     - C: 176 / 32 = 5.5 -> 属于第6个子网（索引5），起始地址 $5 \times 32 = 160$。范围：160-191。
       - 176 在 [160, 191] 之间。网络地址 193.155.12.160，广播地址 193.155.12.191。
     - D: 222 / 32 = 6.93 -> 属于第7个子网（索引6），起始地址 $6 \times 32 = 192$。范围：192-223。
       - 222 在 [192, 223] 之间。网络地址 193.155.12.192，广播地址 193.155.12.223。

2. **问题1回答**：
   - A (112) 和 B (120) 在同一子网 [96, 127]，可以直接通信。
   - C (176) 在子网 [160, 191]，D (222) 在子网 [192, 223]。
   - A/B 与 C/D 不同子网，需路由器。
   - C 与 D 不同子网，需路由器。
   - **结论**：A和B可以直接通信；其余任意两台之间均需通过路由器通信。

3. **问题2回答**：
   - E要与D直接通信，必须在同一子网。
   - D所在的子网范围是 193.155.12.192 ~ 193.155.12.223。
   - 可用主机地址范围：网络地址(192)除外，广播地址(223)除外。
   - 有效主机IP范围：193.155.12.193 ~ 193.155.12.222。
   - E不能与D同IP，即 E $\neq$ 193.155.12.222。
   - **结论**：E主机IP地址范围是 193.155.12.193 ~ 193.155.12.221。

### 综合应用题（Wireshark报文分析）

题干：使用Wireshark采集访问南邮的网站服务器时所传输的报文，其中有个报文数据的内容如下图所示（16进制表示），请回答：

<table><tr><td>0000:</td><td>f0 1f af 67 52 a7 00 19</td><td>e0 38 12 e4 08 00 45 00</td></tr><tr><td>0010:</td><td>00 34 00 00 40 00 3b 06</td><td>0b 76 ca 77 e0 c9 c0 a8</td></tr><tr><td>0020:</td><td>c8 64 00 50 c5 74 13 0b</td><td>52 0c 53 fa d8 8c 80 12</td></tr><tr><td>0030:</td><td>16 d0 cc 7f 00 00 02 04</td><td>05 b4 01 01 04 02 01 03</td></tr></table>

①数据报首部长度为多少字节？
②数据报的协议字段是多少，表示什么协议？
③源站和目的站IP地址分别是什么？
④已知初始TTL=64，从当前主机到南邮的网站服务器，经过几个路由器的转发？

参考解答：
我们需要解析IP头部。IP头部从偏移量 `08 00` 之后开始（前8字节是MAC头，再前4字节可能是其他，但在以太网帧中，IP头从EtherType `08 00` 后开始）。
看偏移 `000e` (14) 处是 `08 00`，说明后面是IP头。
IP头起始位置：偏移 `0010` 行的第3个字节开始？
让我们对齐一下：
Offset 0000: f0 1f af 67 52 a7 (Dst MAC)
Offset 0006: 00 19 e0 38 12 e4 (Src MAC)
Offset 000c: 08 00 (EtherType, IPv4)
Offset 000e: 45 00 (Start of IP Header)

IP Header Bytes:
Byte 0 (000e): `45` -> Version 4, IHL (Header Length in 32-bit words) = 5.
   - 首部长度 = $5 \times 4 = 20$ 字节。
Byte 1 (000f): `00` -> Type of Service
Byte 2-3 (0010): `00 34` -> Total Length = 52 bytes.
Byte 4-5 (0012): `00 00` -> Identification
Byte 6-7 (0014): `40 00` -> Flags & Fragment Offset. `40` = 0100 0000. Don't Fragment set.
Byte 8 (0016): `3b` -> TTL = 59 (十进制).
Byte 9 (0017): `06` -> Protocol. 6 represents TCP.
Byte 10-11 (0018): `0b 76` -> Header Checksum.
Byte 12-15 (001a): `ca 77 e0 c9` -> Source IP Address.
   - CA = 202, 77 = 119, E0 = 224, C9 = 201.
   - Src IP: 202.119.224.201
Byte 16-19 (001e): `c0 a8 c8 64` -> Destination IP Address.
   - C0 = 192, A8 = 168, C8 = 200, 64 = 100.
   - Dst IP: 192.168.200.100

Question 1: 首部长度 20 字节。
Question 2: 协议字段 6，表示 TCP 协议。
Question 3: 源IP 202.119.224.201，目的IP 192.168.200.100。
Question 4: 
   - 当前 TTL = 59。
   - 初始 TTL = 64。
   - 经过的路由器跳数 = $64 - 59 = 5$。
   - 注意：题目问“经过几个路由器的转发”。每经过一个路由器，TTL减1。
   - 如果初始是64，现在是59，说明减少了5。这意味着数据包经过了5个路由器（或者设备）。
   - 答案：5个。

答案：
① 20字节。
② 6，TCP。
③ 源站：202.119.224.201；目的站：192.168.200.100。
④ 5个。
