# 《编译原理》第12次作业答案：LL(1)分析表构造

原件经识别和整理；“参考解答”是我们补的。

## 一、LL(1)分析表构造

### 计算 1

构造下面文法的LL(1)分析表（表结构已给出）：

$$
\begin{aligned}
A &::= BCc \mid gDB \\
B &::= \varepsilon \mid bCDE \\
C &::= DaB \mid ca \\
D &::= \varepsilon \mid dD \\
E &::= gAf \mid c
\end{aligned}
$$

| | a | b | c | d | f | g | # |
|---|---|---|---|---|---|---|---|
| **A** | $A::=BCc$ | $A::=BCc$ | $A::=BCc$ | $A::=BCc$ | | $A::=gDB$ | |
| **B** | $B::=\varepsilon$ | $B::=bCDE$ | $B::=\varepsilon$ | $B::=\varepsilon$ | $B::=\varepsilon$ | $B::=\varepsilon$ | $B::=\varepsilon$ |
| **C** | $C::=DaB$ | | $C::=ca$ | $C::=DaB$ | | | |
| **D** | $D::=\varepsilon$ | $D::=\varepsilon$ | $D::=\varepsilon$ | $D::=dD$ | $D::=\varepsilon$ | $D::=\varepsilon$ | $D::=\varepsilon$ |
| **E** | | | $E::=c$ | | | $E::=gAf$ | |

参考解答：该表已正确构造，无需修改。

计算各非终结符的 FIRST 集与 FOLLOW 集：

- **FIRST 集**：
  - $\mathrm{FIRST}(A)=\{a,b,c,d,g\}$，$\mathrm{FIRST}(B)=\{\varepsilon,b\}$，$\mathrm{FIRST}(C)=\{a,c,d\}$，
  - $\mathrm{FIRST}(D)=\{\varepsilon,d\}$，$\mathrm{FIRST}(E)=\{c,g\}$。

- **FOLLOW 集**（由产生式右部相邻关系及首尾符号继承）：
  - $\mathrm{FOLLOW}(A)=\{f,\#\}$（来自 $E\to gAf$ 与开始符号），
  - $\mathrm{FOLLOW}(B)=\{a,c,f,\#\}$（来自 $A\to BCc$、$C\to DaB$、$E\to gAf$），
  - $\mathrm{FOLLOW}(C)=\{c\}$（来自 $A\to BCc$ 与 $B\to bCDE$），
  - $\mathrm{FOLLOW}(D)=\{a,b,c,d,f,g,\#\}$（来自 $A\to gDB$、$C\to DaB$、$D\to dD$），
  - $\mathrm{FOLLOW}(E)=\{a,c,f,\#\}$（来自 $B\to bCDE$）。

**填表规则**：对产生式 $X\to\alpha$，若终结符 $t\in\mathrm{FIRST}(\alpha)$，则表 $[X,t]=\alpha$；若 $\varepsilon\in\mathrm{FIRST}(\alpha)$，则对 $\forall t\in\mathrm{FOLLOW}(X)$ 填 $\alpha$。

逐行验证：
- **$A$**：两候选首符集 $\{b,c,d,a\}$（即 $\mathrm{FIRST}(BCc)$，因 $B,C$ 均可空，含 $a$）与 $\{g\}$ 不相交，故在 $a,b,c,d$ 列填 $BCc$，$g$ 列填 $gDB$。
- **$B$**：$bCDE$ 首符为 $b$；$\varepsilon$ 产生式填 $\mathrm{FOLLOW}(B)=\{a,c,f,\#\}$（注意 $b\notin$ FOLLOW($B$)，避免冲突）。
- **$C$**：$ca$ 首符 $c$；$DaB$ 因 $D$ 可空，首符为 $\{d,a\}$，故填 $a,d$ 列。
- **$D$**：$dD$ 填 $d$；$\varepsilon$ 填 $\mathrm{FOLLOW}(D)$ 全列（含 $b,g$ 等，因 $D$ 后随 $B$ 或 $C$ 可空）。
- **$E$**：$gAf$ 填 $g$，$c$ 填 $c$。

各列均无多重定义，故该文法为 LL(1) 文法，所给表即为正确的 LL(1) 分析表。

知识点：[LL(1)分析法（FIRST/FOLLOW集、分析表构造）](../../../topics/编译原理/LL1分析法.md)

### 计算 2

对下列文法，构造LL(1)分析表：

$$
\begin{aligned}
S &::= aAd \\
A &::= BC \\
B &::= b \mid \varepsilon \\
C &::= c \mid \varepsilon
\end{aligned}
$$

**FIRST集与FOLLOW集计算：**

*   $\text{FIRST}(S) = \{a\}$
*   $\text{FIRST}(A) = \{b, c, \varepsilon\}$
*   $\text{FIRST}(B) = \{b, \varepsilon\}$
*   $\text{FIRST}(C) = \{c, \varepsilon\}$
*   $\text{FOLLOW}(S) = \{\#\}$
*   $\text{FOLLOW}(A) = \{d\}$
*   $\text{FOLLOW}(B) = \{d, c\}$ （注：因 $A \to BC$，且 $C \to \varepsilon$，故 $\text{FOLLOW}(A)$ 中的 $d$ 加入 $\text{FOLLOW}(B)$；又因 $C \to c$，故 $c$ 也加入 $\text{FOLLOW}(B)$）
*   $\text{FOLLOW}(C) = \{d\}$

**LL(1)分析表：**

| | a | b | c | d | # |
|---|---|---|---|---|---|
| **S** | $S::=aAd$ | | | | |
| **A** | | $A::=BC$ | $A::=BC$ | $A::=BC$ | |
| **B** | | $B::=b$ | $B::=\varepsilon$ | $B::=\varepsilon$ | |
| **C** | | | $C::=c$ | $C::=\varepsilon$ | |

参考解答：**结论：该文法是 LL(1) 文法，分析表如下（产生式均按给定文法原文填写）：**

|  | a | b | c | d | # |
|---|---|---|---|---|---|
| **S** | $S ::= aAd$ | | | | |
| **A** | | $A ::= BC$ | $A ::= BC$ | $A ::= BC$ | |
| **B** | | $B ::= b$ | $B ::= \varepsilon$ | $B ::= \varepsilon$ | |
| **C** | | | $C ::= c$ | $C ::= \varepsilon$ | |

**推理过程：**

1. **FIRST 集**

$$
\begin{aligned}
\text{FIRST}(B) &= \{b, \varepsilon\} \\
\text{FIRST}(C) &= \{c, \varepsilon\} \\
\text{FIRST}(A) &= \text{FIRST}(BC) = (\text{FIRST}(B) - \{\varepsilon\}) \cup \text{FIRST}(C) = \{b, c, \varepsilon\} \\
\text{FIRST}(S) &= \{a\}
\end{aligned}
$$

2. **FOLLOW 集**

- $S$ 是开始符号，$\text{FOLLOW}(S) = \{\#\}$。
- 由 $S \to aAd$，$d \in \text{FOLLOW}(A)$，故 $\text{FOLLOW}(A) = \{d\}$。
- 由 $A \to BC$：
  - $\text{FIRST}(C) - \{\varepsilon\} = \{c\}$ 加入 $\text{FOLLOW}(B)$；
  - $C \to \varepsilon$，故 $\text{FOLLOW}(A) = \{d\}$ 加入 $\text{FOLLOW}(B)$。
  
  因此 $\text{FOLLOW}(B) = \{c, d\}$。
- 由 $A \to BC$，$\text{FOLLOW}(A) = \{d\}$ 加入 $\text{FOLLOW}(C)$，故 $\text{FOLLOW}(C) = \{d\}$。

3. **分析表构造规则与逐项填写**

对每个产生式 $A \to \alpha$：

- 若 $a \in \text{FIRST}(\alpha)$，填 $M[A, a] = A \to \alpha$；
- 若 $\varepsilon \in \text{FIRST}(\alpha)$，对每个 $b \in \text{FOLLOW}(A)$，填 $M[A, b] = A \to \alpha$。

逐条产生式：

- $S \to aAd$：$\text{FIRST}(aAd) = \{a\}$，填 $M[S, a] = S \to aAd$。
- $A \to BC$：$\text{FIRST}(BC) = \{b, c, \varepsilon\}$（因 $B \to \varepsilon, C \to \varepsilon$ 均可），故填 $M[A, b], M[A, c]$；又 $\varepsilon \in \text{FIRST}(BC)$，$\text{FOLLOW}(A) = \{d\}$，故再填 $M[A, d] = A \to BC$。
- $B \to b$：填 $M[B, b] = B \to b$。
- $B \to \varepsilon$：$\text{FOLLOW}(B) = \{c, d\}$，填 $M[B, c] = M[B, d] = B \to \varepsilon$。
- $C \to c$：填 $M[C, c] = C \to c$。
- $C \to \varepsilon$：$\text{FOLLOW}(C) = \{d\}$，填 $M[C, d] = C \to \varepsilon$。

4. **验证 LL(1)**

所有单元格至多填一条产生式（$B \to b$ 与 $B \to \varepsilon$ 无冲突，因 $b \notin \text{FOLLOW}(B)$；$C \to c$ 与 $C \to \varepsilon$ 无冲突，因 $c \notin \text{FOLLOW}(C)$），故该文法是 LL(1) 文法。
