### 习题 2

已知文法
$$
\begin{array} { r } { Z : = b M b } \\ { M : = ( L \mid a } \\ { L : = M a } \end{array}
$$
利用简单优先分析法分析符号串 `((aa)a)#`

给定简单优先关系表如下：

|   | Z | b | M | L | a | ( | ) |
|---|---|---|---|---|---|---|---|
| **Z** |   |   |   |   |   |   |   |
| **b** |   |   | I |   | < | < |   |
| **M** |   | I |   |   | I |   |   |
| **L** |   | > |   |   | > |   |   |
| **a** |   | > |   |   | > |   | I |
| **(** |   |   | < | I | < | < |   |
| **)** |   | > |   |   | > |   |   |

注：表中 `I` 表示相等关系（=），`<` 表示优先于（<），`>` 表示大于（>）。
