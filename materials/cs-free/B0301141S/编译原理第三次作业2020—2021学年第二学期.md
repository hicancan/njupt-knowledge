# 编译原理第三次作业（2020—2021 学年第二学期）

本资料为《编译原理》课程第三次作业的习题部分，由识别工具读取并整理。

## 一、必做题

### 选择 1

试分别构造产生下列语言的文法：

（1）$\{ \mathsf { a } ^ { n } \mathsf { b } ^ { m } \mathsf { c } ^ { p } \mid n , m , p \geq 0 \}$

（2）写一个文法使其语言为 $L(G) = \{ \mathsf { a } ^ { m } \mathsf { b } ^ { n } \mathsf { c } ^ { n } \mid m \text{ 为奇数}, n \text{ 为偶数且 } |n| > 0 \}$

（3）设文法 $G$ 规则为：
$$
\mathrm{B} := \mathrm{a} \mid \mathrm{Sb}
$$
$$
\mathrm{A} := \mathrm{Aa} \mid \mathrm{bB}
$$
对句型 $\mathrm{bBABb}$ 给出推导语法树，并求出其句型短语，简单短语和句柄。

答案：无（需自行解答）
