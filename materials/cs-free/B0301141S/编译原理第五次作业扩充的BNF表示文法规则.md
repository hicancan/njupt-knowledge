# 《编译原理》第五次作业（扩充的BNF表示文法规则）

原件经识别和整理；“参考解答”是我们补的。

用扩充的 BNF 表示以下文法规则：

$$
Z ::= A B \mid A C \mid A
$$

$$
Z := A [ B \mid C ]
$$

$$
A ::= B C \mid B C D \mid A X Z \mid A X Y
$$

$$
A := B C [ D ] \mid \{ X ( Z \mid Y ) \}
$$

$$
A ::= a A B b \mid a b
$$

$$
A ::= A a b \mid \varepsilon
$$

$$
A := a [ A B ] b
$$

$$
A := \{ a b \}
$$

### 解 1

$$
Z ::= A ( B \mid C \mid \varepsilon ) ::= A [ B \mid C ]
$$

参考解答：该变换**不正确**。

原式 $Z ::= A ( B \mid C \mid \varepsilon )$ 表示 $A$ 后必须跟随 $B$、$C$ 或 $\varepsilon$ 三者之一，即语言为 $\{AB, AC, A\}$；而变换后的 $Z ::= A [ B \mid C ]$ 中，方括号 $[B \mid C]$ 仅表示可选的 $B$ 或 $C$，等价于 $(B \mid C \mid \varepsilon)$，看似相同，但问题在于 **EBNF 中方括号内不允许直接使用“|”作为选择运算符嵌套在可选结构中而不加括号分组**，标准 EBNF 语法要求可选项内部若含选择需显式括起，即应写作 $A [(B \mid C)]$。原变换省略了内层括号，导致语法歧义或不符合 EBNF 规范，因此不是合法的等价变换。

知识点：[文法的其他表示法（扩充BNF、语法图）](../../../topics/编译原理/文法其他表示法.md)、[文法产生式、推导与规约](../../../topics/编译原理/文法产生式与推导.md)、[字母表与符号串的基本概念](../../../topics/编译原理/字母表与符号串.md)

### 解 2

$$
A ::= B C ( \varepsilon \mid D ) \{ X ( Z \mid Y ) \} ::= B C [ D ] \{ X ( Z \mid Y ) \}
$$

参考解答：**结论：** 该文法等价于：

$$
A ::= BC[D]\{X(Z\mid Y)\}
$$

其中，`[]` 表示可选一次，`{}` 表示重复零次或多次。

**推理与计算：**

原产生式中的各部分含义为：

- $\varepsilon\mid D$：可选择空串或 $D$，即：

  
$$
\varepsilon\mid D \;\Rightarrow\; [D]
$$

- $\{X(Z\mid Y)\}$：表示重复零次或多次，每次为 $X(Z\mid Y)$，保持不变。

因此：

$$
A ::= BC(\varepsilon\mid D)\{X(Z\mid Y)\}
$$

可改写为：

$$
A ::= BC[D]\{X(Z\mid Y)\}
$$

即：

$$
\boxed{A ::= BC[D]\{X(Z\mid Y)\}}
$$

这里的扩展 BNF 记法中：

- $[D]$ 等价于 $\varepsilon\mid D$；
- $\{X(Z\mid Y)\}$ 等价于 $(X(Z\mid Y))^*$，即零次或多次重复。

知识点：[文法产生式、推导与规约](../../../topics/编译原理/文法产生式与推导.md)、[语法树、最左/最右推导与文法的二义性](../../../topics/编译原理/语法树与二义性.md)、[乔姆斯基文法分类（0型、1型、2型、3型）](../../../topics/编译原理/文法分类.md)

### 解 3

$$
S ::= a ( ( A B \mid \varepsilon ) b ) ::= a [ A B ] b
$$

参考解答：好的，我们先看题目给的形式：

$$
S ::= a ( ( A B | \varepsilon ) b ) ::= a [ A B ] b
$$

这实际上是在用扩展 BNF 记号（方括号表示可选项）重写一个文法产生式。

---

**结论**  
扩展后的产生式为：

$$
S \to a \, [AB] \, b
$$

表示 S 可以产生 `a b` 或者 `a A B b`。

---

**推理过程**  

1. 原始形式中的 `( ( A B | ε ) b )` 表示：  
   - 先出现 `A B` 或者什么都不出现（即 ε），  
   - 然后一定出现终结符 `b`。

2. 用方括号表示可选项时，`[AB]` 就等价于 `( A B | ε )`。

3. 所以，整个右部可以简写为 `a [AB] b`。

---

**选项判断**（假设有类似选择题）  
- 正确项：`a [AB] b` —— 准确表达了 ε 或 AB 的二选一，且 b 必须出现。  
- 其他项如果写成 `a (AB)? b` 也可以等价，但如果写成 `a A? B? b` 则不对，因为那允许只出现 A 或只出现 B，而原文法要求 A、B 同时出现或同时不出现。

知识点：[文法的其他表示法（扩充BNF、语法图）](../../../topics/编译原理/文法其他表示法.md)、[字母表与符号串的基本概念](../../../topics/编译原理/字母表与符号串.md)

### 解 4

$$
A ::= \{ a b \mid \varepsilon \} ::= \{ a b \}
$$

补充：

- `[ t ]`：$t$ 或 $\varepsilon$（$t$ 可出现可不出现）
- `{ t }`：$t$ 不出现或出现任意多次
- `( )`：提取因子

所谓超前读字符（也称超前搜索），是指仅向前读取字符，判别该字符是什么，不做别的处理工作。当判明情况以后，再回过头来处理已读过的字符。

参考解答：**结论：** 该文法描述的语言为 $\{ (ab)^n \mid n \geq 0 \}$，即由空串 $\varepsilon$ 或任意多次重复的 $ab$ 构成的集合。原文法写法存在冗余，可简化为 $A ::= \{ab\}$。

**推理过程：**

1. **符号语义分析**
   - $\{ab\}$ 表示 $ab$ 出现零次或多次，即 $(ab)^*$，对应语言 $\{\varepsilon, ab, abab, \ldots\}$。
   - $\mid \varepsilon$ 表示“或为空串”，但 $\varepsilon$ 已包含在 $\{ab\}$ 的语义中（当重复次数为 $0$ 时）。

2. **冗余性说明**
   - 原式 $A ::= \{ab \mid \varepsilon\}$ 中，$\varepsilon$ 的显式列出是多余的，因为 $\{ab\}$ 本身已涵盖空串情况。
   - 因此 $A ::= \{ab \mid \varepsilon\}$ 与 $A ::= \{ab\}$ 等价，均生成 $(ab)^*$。

3. **关于超前读字符**
   - 若题目涉及超前读（lookahead），其作用是**仅预读字符以判断后续推导方向**，不消耗或处理字符。例如，在解析 $ab$ 的重复结构时，可通过超前读判断下一个字符是否为 $a$，以决定是否继续匹配 $ab$ 或结束推导。
