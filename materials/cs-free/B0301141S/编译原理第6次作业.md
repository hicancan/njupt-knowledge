## 一、综合题

### 综合 1

题干：设右线性文法 $\mathrm { \bf G } { = } ( \{ \mathrm { S } , \mathrm { \bf A } , \mathrm { \bf B } \} , \{ \mathrm { \bf a } , \mathrm { \bf b } \} , \mathrm { \bf S } , \mathrm { \bf P } )$ ，其中P组成如下：
S::=bA
A::=bB
A::=aA
A::=b
B::=a
画出该文法的状态转换图。

答案：无。

参考解答：
根据给定的右线性文法产生式规则，我们可以构建对应的有限自动机（状态转换图）。

1.  **确定状态集合**：
    非终结符为 $\{S, A, B\}$，通常将开始符号 $S$ 对应初始状态，其他非终结符对应中间状态。由于是右线性文法，当推导结束时（即产生式右侧为非终结符或终结符），我们需要引入一个接受状态（终态），记为 $f$ 或 $Z$。
    
    *   观察产生式：
        *   $S ::= bA$
        *   $A ::= bB$
        *   $A ::= aA$
        *   $A ::= b$ （注意：这里 $A$ 可以直接推导出终结符 $b$，意味着从状态 $A$ 读入 $b$ 后进入接受状态）
        *   $B ::= a$ （同理，从状态 $B$ 读入 $a$ 后进入接受状态）

2.  **构建状态转换**：
    设初始状态为 $S$，增加一个终态 $f$。

    *   由 $S ::= bA$：在状态 $S$ 下，输入 $b$，转移到状态 $A$。
        *   边：$S \xrightarrow{b} A$
    *   由 $A ::= bB$：在状态 $A$ 下，输入 $b$，转移到状态 $B$。
        *   边：$A \xrightarrow{b} B$
    *   由 $A ::= aA$：在状态 $A$ 下，输入 $a$，转移到状态 $A$（自环）。
        *   边：$A \xrightarrow{a} A$
    *   由 $A ::= b$：在状态 $A$ 下，输入 $b$，结束推导，进入终态 $f$。
        *   边：$A \xrightarrow{b} f$
    *   由 $B ::= a$：在状态 $B$ 下，输入 $a$，结束推导，进入终态 $f$。
        *   边：$B \xrightarrow{a} f$

3.  **状态转换图描述**：
    *   节点：$S$ (初始), $A$, $B$, $f$ (终态，可用双圈表示)。
    *   有向边：
        *   $S \to A$，标记为 $b$
        *   $A \to A$，标记为 $a$
        *   $A \to B$，标记为 $b$
        *   $A \to f$，标记为 $b$
        *   $B \to f$，标记为 $a$
