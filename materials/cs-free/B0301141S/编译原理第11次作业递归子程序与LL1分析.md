# 《编译原理》第11次作业（递归子程序与LL(1)分析）

原件经识别和整理；“参考解答”是我们补的。

## 一、作业

### 综合 1

用框图法描述识别下面文法句子的递归子程序。

文法 G[A]：

$$A ::= [B$$

$$B ::= X] \mid BA$$

$$X ::= Xa \mid Xb \mid a \mid b$$

参考解答：## 结论

递归子程序的结构图如下，其中 `B` 的递归调用用于识别任意多个由 `X` 生成的子串：

```text
                ┌──────────────┐
                │     main     │
                │              │
                │  调用 B      │
                └──────┬───────┘
                       │
                       ▼
                ┌──────────────┐
                │  proc_B      │
                │              │
                │  读入 X      │
                │  递归调用 B  │
                │  读入 A      │
                └──────────────┘
```

更准确地表示各子程序之间的调用关系：

```text
main
 └── B
      ├── X
      │    ├── X
      │    │    ├── ...
      │    │    └── a | b
      │    └── a | b
      └── A
```

对应的递归子程序示意框图可写成：

```text
             ┌───────────┐
             │    B      │
             └─────┬─────┘
                   │
          ┌────────┴────────┐
          ▼                 ▼
     ┌─────────┐       ┌─────────┐
     │    X    │       │    A    │
     └────┬────┘       └─────────┘
          │
     ┌────┴─────┐
     ▼          ▼
  ┌──────┐   ┌──────┐
  │  X   │   │ a|b  │
  └──┬───┘   └──────┘
     │
   ┌─┴─┐
   │...│
   └─┬─┘
     ▼
  ┌──────┐
  │ a|b  │
  └──────┘
```

## 子程序设计

### `proc_B`

```text
proc_B:
    调用 proc_X
    若输入串当前符号属于 FIRST(A) = {a, b}，则
        调用 proc_B
    否则
        返回
```

由于


$$
FIRST(A)=\{a,b\},
$$


因此 `B` 的识别过程可以表述为：

1. 先识别一个 `X`；
2. 如果后面还有 `a` 或 `b`，说明这些符号可以继续构成下一个 `X`，递归识别；
3. 直到不能继续时结束。

### `proc_X`

```text
proc_X:
    若当前符号为 a 或 b，则
        读入一个符号
        返回
    否则
        调用 proc_X
        读入一个 a 或 b
        返回
```

这里利用了


$$
X ::= Xa \mid Xb \mid a \mid b
$$


的左递归形式。实际递归子程序通常改写为等价的右递归形式：


$$
X ::= aX' \mid bX'
$$



$$
X' ::= aX' \mid bX' \mid \varepsilon.
$$


### `proc_A`

```text
proc_A:
    读入一个符号
    返回
```

因为


$$
A ::= [B,
$$


所以 `A` 负责读入左方括号 `[`，之后由 `B` 完成剩余识别。

## 关键说明

文法可理解为：


$$
A ::= [B,
$$


而


$$
B ::= X] \mid BA
$$


表示 `B` 由一个或多个 `X` 组成，最后以 `]` 结束：


$$
B ::= X^+].
$$


因此，识别时先读入 `[`，然后连续识别一个或多个 `X`，最后读入 `]`。

例如，输入串

```text
[abba]
```

的识别过程为：

```text
A 读入 '['
B 识别 X = "abba"
B 识别结束
A 读入 ']'
```

其中 `X` 的识别利用递归：

```text
X -> Xa -> Xb -> a
```

对应实际读入顺序为：

```text
a, b, b, a
```

故该递归子程序能够识别该文法生成的所有句子。

知识点：[递归下降分析法](../../../topics/编译原理/递归下降分析法.md)、[文法产生式、推导与规约](../../../topics/编译原理/文法产生式与推导.md)、[语法树、最左/最右推导与文法的二义性](../../../topics/编译原理/语法树与二义性.md)

### 综合 2

利用下面分析表分析符号串 `(i+)` 是否为文法所定义的句子。

有文法 G[E]：

$$E \rightarrow TE'$$

$$E' \rightarrow +TE' \mid \varepsilon$$

$$T \rightarrow FT'$$

$$T' \rightarrow *FT' \mid \varepsilon$$

$$F \rightarrow (E) \mid i$$

LL(1) 分析表如下：

|    | i | + | * | ( | ) | # |
|----|---|---|---|---|---|---|
| E  | $E \rightarrow TE'$ |  |  | $E \rightarrow TE'$ |  |  |
| E' |  | $E' \rightarrow +TE'$ |  |  | $E' \rightarrow \varepsilon$ | $E' \rightarrow \varepsilon$ |
| T  | $T \rightarrow FT'$ |  |  | $T \rightarrow FT'$ |  |  |
| T' |  | $T' \rightarrow \varepsilon$ | $T' \rightarrow *FT'$ |  | $T' \rightarrow \varepsilon$ | $T' \rightarrow \varepsilon$ |
| F  | $F \rightarrow i$ |  |  | $F \rightarrow (E)$ |  |  |

参考解答：结论：符号串 `(i+)` **不是**该文法定义的句子，LL(1) 分析过程报错。

分析过程如下。

输入串为：


$$
(i+)
$$


初始分析栈为：


$$
\# E
$$


输入指针指向最左符号 `(`。

---

**第 1 步**

栈顶：`E`  
当前输入符号：`(`

查表：


$$
M[E, (] = E \rightarrow TE'
$$


栈变为：


$$
\# E' T
$$


---

**第 2 步**

栈顶：`T`  
当前输入符号：`(`

查表：


$$
M[T, (] = T \rightarrow FT'
$$


栈变为：


$$
\# E' T' F
$$


---

**第 3 步**

栈顶：`F`  
当前输入符号：`(`

查表：


$$
M[F, (] = F \rightarrow (E)
$$


栈变为：


$$
\# E' T' ) E (
$$


匹配栈顶 `(` 与当前输入符号 `(`，弹栈，输入指针前进到 `i`。

栈：


$$
\# E' T' ) E
$$


---

**第 4 步**

栈顶：`E`  
当前输入符号：`i`

查表：


$$
M[E, i] = E \rightarrow TE'
$$


栈变为：


$$
\# E' T' ) E' T
$$


---

**第 5 步**

栈顶：`T`  
当前输入符号：`i`

查表：


$$
M[T, i] = T \rightarrow FT'
$$


栈变为：


$$
\# E' T' ) E' T' F
$$


---

**第 6 步**

栈顶：`F`  
当前输入符号：`i`

查表：


$$
M[F, i] = F \rightarrow i
$$


栈变为：


$$
\# E' T' ) E' T' i
$$


匹配栈顶 `i` 与当前输入符号 `i`，弹栈，输入指针前进到 `+`。

栈：


$$
\# E' T' ) E' T'
$$


---

**第 7 步**

栈顶：`T'`  
当前输入符号：`+`

查表：


$$
M[T', +] = T' \rightarrow \varepsilon
$$


弹栈。

栈：


$$
\# E' T' ) E'
$$


---

**第 8 步**

栈顶：`E'`  
当前输入符号：`+`

查表：


$$
M[E', +] = E' \rightarrow +TE'
$$


栈变为：


$$
\# E' T' ) E' T +
$$


匹配栈顶 `+` 与当前输入符号 `+`，弹栈，输入指针前进到 `)`。

栈：


$$
\# E' T' ) E' T
$$


---

**第 9 步**

栈顶：`T`  
当前输入符号：`)`

查表：


$$
M[T, )] = \text{空}
$$


即分析表中 `T` 行、`)` 列没有产生式可用。

因此 LL(1) 分析失败。

---

所以 `(i+)` 不能由该文法推出，不是该文法定义的句子。
