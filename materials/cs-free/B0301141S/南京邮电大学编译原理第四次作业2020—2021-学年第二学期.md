# 南京邮电大学《编译原理》第四次作业（2020—2021 学年第二学期）

原件经识别和整理；“参考解答”是我们补的。

## 一、证明

### 证明 1

证明下面文法具有二义性：

$$
S ::= A \mid B
$$

$$
A ::= a C b A \mid a
$$

$$
B ::= B C C \mid a
$$

$$
C ::= b a
$$

## 二、简答

参考解答：**结论**：该文法是二义性的。

**推理过程**：
要证明文法具有二义性，只需找到一个句子，它存在两棵不同的语法分析树（或两个不同的最左推导）。

1.  **构造句子**：考虑句子 $w = ababa$。
2.  **推导路径 1（通过非终结符 $A$）**：
    $$
    \begin{aligned}
    S &\Rightarrow A \\
      &\Rightarrow a C b A \quad (\text{使用 } A ::= a C b A) \\
      &\Rightarrow a (ba) b A \quad (\text{使用 } C ::= ba) \\
      &\Rightarrow a b a b A \\
      &\Rightarrow a b a b a \quad (\text{使用 } A ::= a)
    \end{aligned}
    $$
    此推导生成的句子为 $ababa$。

3.  **推导路径 2（通过非终结符 $B$）**：
    $$
    \begin{aligned}
    S &\Rightarrow B \\
      &\Rightarrow B C C \quad (\text{使用 } B ::= B C C) \\
      &\Rightarrow a C C \quad (\text{使用 } B ::= a) \\
      &\Rightarrow a (ba) C \quad (\text{使用 } C ::= ba) \\
      &\Rightarrow a b a (ba) \quad (\text{使用 } C ::= ba) \\
      &\Rightarrow a b a b a
    \end{aligned}
    $$
    此推导生成的句子也为 $ababa$。

4.  **判定**：
    由于句子 $ababa$ 既可以通过 $S \Rightarrow A \dots$ 推导得到，也可以通过 $S \Rightarrow B \dots$ 推导得到，且这两条推导路径对应的语法树结构不同（根节点下的第一个子节点分别为 $A$ 和 $B$），因此该文法是二义性的。

### 简答 1

下面文法哪些是短语结构文法、上下文有关文法、上下文无关文法及正规文法？

1. $S ::= aB \quad B ::= cB \quad B ::= b \quad C ::= c$

2. $S ::= aB \quad B ::= bC \quad C ::= c \quad C ::= \varepsilon$

3. $S ::= aAb \mid aA \mid aB \mid aaA \mid B \mid b \mid A \mid a$

4. $S ::= aCd \quad aC ::= Ba \quad C ::= aa \quad AB ::= b$

5. $S ::= AB \quad A ::= a \quad B ::= bC \quad B ::= b \quad C ::= c$

6. $S ::= AB \quad A ::= a \quad B ::= bC \quad C ::= c \quad C ::= \varepsilon$

7. $S ::= aA \mid \varepsilon \quad A ::= aA \mid aB \mid a \quad B ::= b$

8. $S ::= aA \mid \varepsilon \quad A ::= bAb \mid a$

**推理与关键步骤**

判断依据为乔姆斯基体系（Chomsky Hierarchy）：
*   **0型**：任意产生式 $\alpha \to \beta$。
*   **1型**：满足 $|\alpha| \le |\beta|$（除 $S \to \varepsilon$ 外）。
*   **2型**：产生式左部必须是单个非终结符 $A \to \beta$。
*   **3型**：满足 $A \to aB$ 或 $A \to a$（右线性），或 $A \to Ba$ 或 $A \to a$（左线性）。

1. **$S ::= aB \quad B ::= cB \quad B ::= b \quad C ::= c$**
   *   所有产生式均满足 $|\text{左部}| \le |\text{右部}|$，且左部均为单个非终结符。
   *   右部形式均符合 $aB$ 或 $a$ 的右线性规则。
   *   属于0、1、2、3型。

2. **$S ::= aB \quad B ::= bC \quad C ::= c \quad C ::= \varepsilon$**
   *   产生式 $C ::= \varepsilon$ 中，左部长度为1，右部长度为0，不满足 $|\text{左部}| \le |\text{右部}|$，故非1型。
   *   左部均为单个非终结符，满足2型。
   *   产生式符合右线性规则（允许 $C \to \varepsilon$ 作为终结推导）。
   *   属于0、2、3型。

3. **$S ::= aAb \mid aA \mid aB \mid aaA \mid B \mid b \mid A \mid a$**
   *   检查长度：如 $S \to aAb$ ($1 \le 3$)，满足 $|\text{左部}| \le |\text{右部}|$，故满足1型。
   *   左部均为单个非终结符 $S$，满足2型。
   *   右部形式如 $aAb$、$b$、$a$ 等，符合正规文法定义（终结符与非终结符的混合，无嵌套结构如 $AB$）。
   *   属于0、1、2、3型。

4. **$S ::= aCd \quad aC ::= Ba \quad C ::= aa \quad AB ::= b$**
   *   检查长度：$AB ::= b$ 的长度关系为 $2 > 1$，不满足 $|\text{左部}| \le |\text{右部}|$。
   *   注意：即使通过 $aC \to Ba$ 尝试转换，依然无法在不违反单调性的前提下生成该文法的所有句子。严格判定下，因存在 $|AB| > |b|$，该文法**不满足1型**定义。
   *   产生式左部包含 $aC$、$AB$，不全是单个非终结符，非2型。
   *   属于0型。

5. **$S ::= AB \quad A ::= a \quad B ::= bC \quad B ::= b \quad C ::= c$**
   *   检查长度：$S \to AB$ ($1 \le 2$)，其余均满足 $|\text{左部}| \le |\text{右部}|$，满足1型。
   *   左部均为单个非终结符，满足2型。
   *   推导结果为正规集 $L = \{abc\}$，且产生式结构符合右线性规则。
   *   属于0、1、2、3型。

6. **$S ::= AB \quad A ::= a \quad B ::= bC \quad C ::= c \quad C ::= \varepsilon$**
   *   产生式 $C ::= \varepsilon$ 导致 $|\text{左部}| > |\text{右部}|$，非1型。
   *   左部均为单个非终结符，满足2型。
   *   虽然 $S \to AB$ 看似非线性，但代入后等效于右线性文法 $S \to aB, B \to bC, C \to c \mid \varepsilon$，生成语言为正规语言。
   *   属于0、2、3型。

7. **$S ::= aA \mid \varepsilon \quad A ::= aA \mid aB \mid a \quad B ::= b$**
   *   $S \to \varepsilon$ 例外，其余产生式均满足 $|\text{左部}| \le |\text{右部}|$，满足1型。
   *   左部均为单个非终结符，满足2型。
   *   右部形式均为终结符串接单个非终结符或单个终结符，符合右线性规则。
   *   属于0、1、2、3型。

8. **$S ::= aA \mid \varepsilon \quad A ::= bAb \mid a$**
   *   检查长度：$A \to bAb$ ($1 \le 3$)，满足 $|\text{左部}| \le |\text{右部}|$，满足1型。
   *   左部均为单个非终结符，满足2型。
   *   产生式 $A ::= bAb$ 中，右部非终结符 $A$ 位于两个终结符 $b$ 之间，既不符合右线性 ($A \to wB$) 也不符合左线性 ($A \to Bw$) 的形式，非3型。
   *   属于0、1、2型。
