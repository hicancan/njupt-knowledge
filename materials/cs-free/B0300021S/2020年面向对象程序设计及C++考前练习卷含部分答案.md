### 填空 1

在输入/输出流类文件 iostream.h 中定义的流对象 cin 和 cout，用 cin 代表 ____① 设备，cout 代表 ____② 设备。

答案：① 键盘（标准输入）；② 屏幕（标准输出）。

参考解答：```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream in("abc.txt");
    ofstream out("xyz.txt");
    char ch;
    while (in.get(ch))
        out.put(ch);
    in.close();
    out.close();
    return 0;
}
```

**填空：** `in.get(ch)` 与 `out.put(ch)`

**理由：** `get(ch)` 从输入流中读取一个字符存入 `ch`，当读到文件末尾时返回 `false` 结束循环；`put(ch)` 将该字符写入输出流，从而实现逐字符复制。

知识点：[文件的输入/输出（包含fstream头文件，使用流运算符对文本文件操作）](../../../topics/面向对象C++/文件io.md)、[I/O流的概念及流类库体系结构](../../../topics/面向对象C++/io流概念.md)、[键盘输入与屏幕输出（输入/输出类的定义与使用）](../../../topics/面向对象C++/键盘屏幕io.md)

### 填空 2

为了方便处理逻辑值，C++ 中新增加了 ③ 数据类型。

答案：bool。

参考解答：# 填空 2

**结论：**
前缀 `++` 重载为成员函数无参数（或友元函数一个参数），后缀 `--` 重载为成员函数带一个 `int` 哑元参数（或友元函数两个参数，第二个为 `int`）。

**推理过程：**
- 前缀 `++`：作为成员函数声明为 `Point& operator++();`，返回自增后的引用。
- 后缀 `--`：为了与前缀区分，C++ 规定后缀运算符重载需加一个 `int` 类型的哑元参数，声明为 `Point operator--(int);`，返回自减前的副本。
- 若用友元函数实现，则前缀 `++` 为 `friend Point& operator++(Point& p);`，后缀 `--` 为 `friend Point operator--(Point& p, int);`。

# 五、编程题 1

**结论：** 使用海伦公式计算三角形面积。

**关键步骤：**
$$s = \frac{a + b + c}{2}, \quad A = \sqrt{s(s-a)(s-b)(s-c)}$$

```cpp
#include <iostream>
#include <cmath>
using namespace std;

double triangleArea(double a, double b, double c) {
    double s = (a + b + c) / 2.0;
    return sqrt(s * (s - a) * (s - b) * (s - c));
}

int main() {
    double a, b, c;
    cin >> a >> b >> c;
    cout << "Area = " << triangleArea(a, b, c) << endl;
    return 0;
}
```

# 六、编程题 2

**结论：** `Circle` 包含半径和圆心坐标，`Cone` 公有继承 `Circle` 并增加高度；`disp()` 在派生类中重写以同时输出底面积和体积。

**关键步骤：**
- 圆面积：$A = \pi r^2$
- 圆锥体积：$V = \frac{1}{3} \pi r^2 h$
- 构造函数参数顺序按题意：先半径再圆心，或根据调用反推为 `(radius, x, y)`。

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const double PI = 3.14159265358979;

class Circle {
protected:
    double radius;
    double x, y;
public:
    // 构造函数：初始化半径和圆心
    Circle(double r = 0, double cx = 0, double cy = 0) 
        : radius(r), x(cx), y(cy) {}

    virtual double area() {
        return PI * radius * radius;
    }

    virtual void disp() {
        cout << "圆面积: " << area() << endl;
    }
};

class Cone : public Circle {
private:
    double height;
public:
    // 构造函数：底半径、圆心坐标、高
    Cone(double r, double cx, double cy, double h) 
        : Circle(r, cx, cy), height(h) {}

    double volume() {
        return (1.0 / 3.0) * PI * radius * radius * height;
    }

    void disp() override {
        cout << "圆锥底面积: " << area() << endl;
        cout << "圆锥体积: " << volume() << endl;
    }
};

int main() {
    // 底半径4，底部圆心(2.0,3.0)，高6
    Cone cone(4, 2.0, 3.0, 6);
    // 圆心原点(0,0)，半径5
    Circle circle(5, 0, 0);

    circle.disp();
    cone.disp();

    return 0;
}
```

**输出结果：**
```
圆面积: 78.5398
圆锥底面积: 50.2655
圆锥体积: 100.531
```

下列程序实现将文本文件 abc.txt 的内容复制到文本文件 xyz.txt 中去。

参考解答：```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream in("abc.txt");
    ofstream out("xyz.txt");
    char ch;
    while (in.get(ch))
        out.put(ch);
    in.close();
    out.close();
    return 0;
}
```

**填空：** `in.get(ch)` 与 `out.put(ch)`

**理由：** `get(ch)` 从输入流中读取一个字符存入 `ch`，当读到文件末尾时返回 `false` 结束循环；`put(ch)` 将该字符写入输出流，从而实现逐字符复制。

参考解答：# 填空 2

**结论：**
前缀 `++` 重载为成员函数无参数（或友元函数一个参数），后缀 `--` 重载为成员函数带一个 `int` 哑元参数（或友元函数两个参数，第二个为 `int`）。

**推理过程：**
- 前缀 `++`：作为成员函数声明为 `Point& operator++();`，返回自增后的引用。
- 后缀 `--`：为了与前缀区分，C++ 规定后缀运算符重载需加一个 `int` 类型的哑元参数，声明为 `Point operator--(int);`，返回自减前的副本。
- 若用友元函数实现，则前缀 `++` 为 `friend Point& operator++(Point& p);`，后缀 `--` 为 `friend Point operator--(Point& p, int);`。

# 五、编程题 1

**结论：** 使用海伦公式计算三角形面积。

**关键步骤：**
$$s = \frac{a + b + c}{2}, \quad A = \sqrt{s(s-a)(s-b)(s-c)}$$

```cpp
#include <iostream>
#include <cmath>
using namespace std;

double triangleArea(double a, double b, double c) {
    double s = (a + b + c) / 2.0;
    return sqrt(s * (s - a) * (s - b) * (s - c));
}

int main() {
    double a, b, c;
    cin >> a >> b >> c;
    cout << "Area = " << triangleArea(a, b, c) << endl;
    return 0;
}
```

# 六、编程题 2

**结论：** `Circle` 包含半径和圆心坐标，`Cone` 公有继承 `Circle` 并增加高度；`disp()` 在派生类中重写以同时输出底面积和体积。

**关键步骤：**
- 圆面积：$A = \pi r^2$
- 圆锥体积：$V = \frac{1}{3} \pi r^2 h$
- 构造函数参数顺序按题意：先半径再圆心，或根据调用反推为 `(radius, x, y)`。

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const double PI = 3.14159265358979;

class Circle {
protected:
    double radius;
    double x, y;
public:
    // 构造函数：初始化半径和圆心
    Circle(double r = 0, double cx = 0, double cy = 0) 
        : radius(r), x(cx), y(cy) {}

    virtual double area() {
        return PI * radius * radius;
    }

    virtual void disp() {
        cout << "圆面积: " << area() << endl;
    }
};

class Cone : public Circle {
private:
    double height;
public:
    // 构造函数：底半径、圆心坐标、高
    Cone(double r, double cx, double cy, double h) 
        : Circle(r, cx, cy), height(h) {}

    double volume() {
        return (1.0 / 3.0) * PI * radius * radius * height;
    }

    void disp() override {
        cout << "圆锥底面积: " << area() << endl;
        cout << "圆锥体积: " << volume() << endl;
    }
};

int main() {
    // 底半径4，底部圆心(2.0,3.0)，高6
    Cone cone(4, 2.0, 3.0, 6);
    // 圆心原点(0,0)，半径5
    Circle circle(5, 0, 0);

    circle.disp();
    cone.disp();

    return 0;
}
```

**输出结果：**
```
圆面积: 78.5398
圆锥底面积: 50.2655
圆锥体积: 100.531
```
