## 五、编程题（共 15 分）

下面是一个图书类的定义：

```cpp
class book {
public:
    book(char *t="unknown", int n=0);   // 构造函数
    ~book();                            // 析构函数
    void settitle(char *b);             // 设置书名
    void lend();                        // 借书，判断是否可借，可借则数量减一
    void ret();                         // 还书，数量加一
    void print();                       // 显示信息
private:
    char *title;                        // 书名
    int number;                         // 数量
};
```

（1）根据以上提示实现该类的成员函数；

（2）编写 main 函数，定义一个 book 类的对象，分别完成设置书名、借书、还书以及显示信息操作。

（3）main 函数已给出：

```cpp
#include <iostream>
#include <cstring.h>
using namespace std;

class book {
public:
    book(char *t="unknown", int n=0);   // 构造函数
    ~book();
    void settitle(char *b);
    void lend();
    void ret();
    void print();
private:
    char *title;                        // 书名
    int number;                         // 数量
};

book::book(char *t, int n)              // 构造函数
{
    title=new char[strlen(t)+1];
    strcpy(title,t);
    number=n;
}

book::~book()                           // 析构函数
{
    if(title) delete [] title;
}

void book::settitle(char *t)            // 设置书名
{
    if(!t) return;
    if(title) delete[]title;
    title=new char[strlen(t)+1];
    strcpy(title,t);
}

void book::lend()                       // 借书
{
    if(number==0)
        cout<<"不可借!" <<endl;
    else number--;
}

void book::print()                      // 显示图书的信息
{
    cout<<"title: "<<title<<endl;
    cout<<"number: "<<number<<endl;
}

int main()
{
    book a;
    a.settitle("C Programming");
    a.lend();
    a.ret();
    a.print();
    return 0;
}

参考解答：## 读程（复数类）

**结论：**

```cpp
#include <iostream>
using namespace std;

class Complex {
public:
    Complex(double r = 0, double i = 0) : real(r), image(i) {}
    friend Complex operator+(const Complex& c1, const Complex& c2);
    void print() const {
        cout << real << " + " << image << "i" << endl;
    }
private:
    double real;
    double image;
};

Complex operator+(const Complex& c1, const Complex& c2) {
    return Complex(c1.real + c2.real, c1.image + c2.image);
}
```

**推理过程：**

- 数据成员 `real`、`image` 均为 `double` 类型。
- 构造函数使用默认参数 `r=0, i=0`，满足"默认都为 0"的要求。
- `operator+` 声明为 `friend`，在类外定义时不加作用域限定符，直接访问两个对象的私有成员完成实部与虚部分别相加。

## 五、编程题

**结论：** 题目代码中缺少 `ret()` 函数的实现，补充如下：

```cpp
void book::ret()    // 还书
{
    number++;
}
```

**关键步骤说明：**

1. **构造函数**：用 `new char[strlen(t)+1]` 动态分配内存，再用 `strcpy` 拷贝字符串，`number` 直接赋值。
2. **析构函数**：判断 `title` 非空后 `delete[] title` 释放堆内存，防止内存泄漏。
3. **`settitle`**：先释放旧内存，再重新分配并拷贝新字符串；对空指针做防御性检查。
4. **`lend`**：判断 `number == 0` 时输出不可借，否则 `number--`。
5. **`ret`**：还书只需 `number++`。
6. **`print`**：按格式输出 `title` 和 `number`。
7. **`main` 函数执行流程**：
   - `book a;` → 调用默认构造，`title="unknown"`, `number=0`
   - `a.settitle("C Programming");` → 书名改为 `"C Programming"`
   - `a.lend();` → `number==0`，输出 `不可借!`
   - `a.ret();` → `number` 变为 $1$
   - `a.print();` → 输出 `title: C Programming` 和 `number: 1`

**程序运行结果：**

```
不可借!
title: C Programming
number: 1
```
