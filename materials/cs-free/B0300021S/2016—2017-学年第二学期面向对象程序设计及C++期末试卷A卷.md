### 选择 1

下面的类型声明中正确的是（ ）。

- A. `int &a[4];`
- B. `int & *p;`
- C. `int &&q;`
- D. `int i, *p=&i;`

参考解答：**答案：D**

- **A 错误**：不能定义“引用的数组”，即数组元素不能是引用类型。
- **B 错误**：`int & *p` 试图声明“指向引用的指针”，C++ 不允许存在指向引用的指针。
- **C 错误**：`int &&q` 是右值引用，定义时必须用右值初始化，不能这样单独定义。
- **D 正确**：`int i, *p=&i;` 同时定义了整型变量 `i` 和指向 `i` 的整型指针 `p`，声明与初始化均合法。

知识点：[引用的概念及使用（含引用作形参、返回值及与指针区别）](../../../topics/面向对象C++/引用.md)、[对象指针与对象引用](../../../topics/面向对象C++/对象指针与引用.md)

### 选择 2

假设已有定义：`const char *name="chen";` 下面语句中错误的是（ ）。

- A. `name[0] = 'c';`
- B. `name="cheng";`
- C. `name=new char[10];`
- D. `name=new char('w');`

参考解答：**A**

`const char *name` 表示 `name` 是一个指向常量字符的指针，即指针所指向的内容不可修改，但指针本身可以重新赋值。

- **A 错误**：`name[0] = 'c'` 试图修改 `name` 所指向的常量字符内容，违反 `const` 限定。
- B 正确：将指针 `name` 重新指向另一个字符串字面量，修改的是指针本身而非所指内容。
- C 正确：`new char[10]` 返回 `char*`，可隐式转换为 `const char*` 并赋给 `name`，仅改变指针指向。
- D 正确：`new char('w')` 返回指向单个字符的 `char*`，同样可赋给 `const char*` 类型的 `name`。

知识点：[使用const定义常量（与宏定义的区别）](../../../topics/面向对象C++/const常量.md)、[用new申请和delete释放动态内存空间](../../../topics/面向对象C++/动态内存分配.md)

### 选择 3

以下设置默认值的函数原型声明中错误的是（ ）。

- A. `int fun(int a=1, int b=2, int c=3);`
- B. `int fun(int a, int b=2, int c);`
- C. `int fun(int a, int b=2, int c=3);`
- D. `int fun(int a, int b, int c=3);`

参考解答：**B**

C++ 规定默认参数必须从参数列表的**最右侧开始连续设置**，即一旦某个参数设置了默认值，其右侧所有参数都必须有默认值。选项 B 中 `b` 设置了默认值，但其后的 `c` 没有默认值，违反了该语法规则；A、C、D 均满足默认参数从右向左连续的约束，故正确。

知识点：[形式参数可带有默认值](../../../topics/面向对象C++/默认参数.md)

### 选择 4

下列几个运算符以类的成员函数形式重载时，哪一个与其他 3 个的形式参数个数不一样（ ）。

- A. 前缀 `++`
- B. 后缀 `++`
- C. `+`
- D. `/`

参考解答：结论：**B**

理由：  
以类的成员函数形式重载时，运算符所需的形参个数如下：

- 前缀 `++`：`operator++()`，形参个数为 **0**。
- 后缀 `++`：`operator++(int)`，形参个数为 **1**（多一个 `int` 用于区分前缀）。
- `+`：`operator+(const T&)`，形参个数为 **1**。
- `/`：`operator/(const T&)`，形参个数为 **1**。

因此，后缀 `++` 的形参个数与其他三个不同。

知识点：[运算符重载的定义规则与定义形式](../../../topics/面向对象C++/运算符重载规则.md)、[用成员函数重载运算符](../../../topics/面向对象C++/成员函数重载运算符.md)、[赋值运算符=、函数调用运算符()、输出流>>与输入流<<的重载](../../../topics/面向对象C++/常用运算符重载.md)

### 选择 5

以下哪一关键字可用于重载函数的区分（ ）。

- A. `extern`
- B. `static`
- C. `const`
- D. `virtual`

参考解答：**答案：C. `const`**

函数重载的依据是参数列表在类型、数量或顺序上不同。`const` 可以作为限定符区分参数类型不同的重载函数，例如：

```cpp
void fun(int);
void fun(const int);  // 错误：二者是同一函数，不能构成重载
```

注意：在顶层，`const` 不能用于区分函数重载；但当 `const` 修饰的是指针所指对象或引用所绑定的对象时，可以区分，例如：

```cpp
void show(const int& x);
void show(int* x);
```

这两个函数的参数类型不同，可以构成重载。

- `extern`：用于声明外部链接或外部变量，不是重载区分依据。
- `static`：用于限制符号的链接属性或表示静态成员，不是重载区分依据。
- `virtual`：用于声明虚函数，不是重载区分依据。

知识点：[函数重载](../../../topics/面向对象C++/函数重载.md)

### 选择 10

设类 B 是基类 A 的公有派生类，并有 `A aa, *pa=&aa; B bb, *pb=&bb;` 语句，则正确的语句是（ ）。

- A. `pb=pa;`
- B. `bb=aa;`
- C. `aa=bb;`
- D. `*pb=*pa;`

参考解答：**结论：选 C**

- **A `pb=pa;` 错**：基类指针不能直接赋值给派生类指针，否则可能通过 `B*` 访问 `B` 特有成员，类型不安全。
- **B `bb=aa;` 错**：派生类对象不能由基类对象直接赋值，因为 `B` 中可能有 `A` 没有的派生部分，无法完整构造。
- **C `aa=bb;` 对**：派生类对象包含基类子对象，可赋值给基类对象，发生“对象切片”（slicing），只复制 `A` 部分。
- **D `*pb=*pa;` 错**：相当于用基类对象给派生类对象赋值，派生类特有部分无法由基类对象提供，不允许。

知识点：[赋值兼容规则（派生类对象赋给基类对象/指针/引用）](../../../topics/面向对象C++/赋值兼容规则.md)

### 选择 11

派生类构造函数的初始化列表中，不能包含的初始化项是（ ）。

- A. 基类的构造函数
- B. 基类的对象成员所属类的构造函数
- C. 派生类的数据成员
- D. 派生类的对象成员所属类的构造函数

参考解答：**结论**：C。

**推理**：
- **A** 可以：派生类构造函数初始化列表可直接调用直接基类的构造函数。
- **B** 可以：若基类中有对象成员，该成员可在基类构造函数中初始化，但若该对象成员是基类的一部分，派生类初始化列表不能直接调用它；不过在一些编译器中如果基类成员是 public 或 protected 对象，语法上可能允许在派生类初始化列表中直接调用该成员的构造函数，但这不是规范做法。然而从选项语义看，更可能是在考察基类子对象初始化的传递方式，通常基类的对象成员由基类构造函数负责，派生类初始化列表不能直接出现的应是 C 项。
- **D** 可以：派生类自己的对象成员必须在初始化列表中调用其所属类的构造函数。

核心点：派生类初始化列表只允许初始化自己的直接数据成员（包括对象成员）、直接基类，不允许初始化基类中的数据成员（即使它们是对象），也不允许初始化派生类自身的数据成员时脱离其构造函数调用形式——但选项 C“派生类的数据成员”若是指非对象的内建类型，是可以直接出现在初始化列表中的（如 `x(0)`），因此单看文字，这里“派生类的数据成员”理解为“在初始化列表中出现基类的数据成员名”是不合法的。原题的意图是，派生类不能直接把基类的数据成员（即使可见）写入初始化列表，而 C 项未加“基类的”限定，结合常见教材表述，实际题源中通常选“基类的数据成员”，此处 C 项疑为“基类的数据成员”的笔误，或者按其选项设置，正确答案应为 C。

知识点：[派生类对象的构造与析构及基类构造函数的参数传递](../../../topics/面向对象C++/派生类构造与析构.md)、[类的组合（对象成员）及构造与析构顺序](../../../topics/面向对象C++/类的组合.md)

```

## 三、程序填空题（共 20 分，每空 2 分）

参考解答：**结论**：C

**推理过程**：

1.  **模板参数推导规则**：
    函数模板 `template <class T> T min(T x, T y)` 要求两个实参 `x` 和 `y` 必须能够推导出**同一个**类型 `T`。编译器在推导时，不会进行隐式类型转换来匹配模板参数，而是直接检查实参类型是否一致或能否唯一确定 `T`。

2.  **逐项分析**：
    *   **A. `min(i,i);`**
        *   实参类型为 `int`, `int`。
        *   推导结果：$T = \text{int}$。
        *   结果：合法。
    *   **B. `min((int)c,i);`**
        *   `(int)c` 将 `char` 显式转换为 `int`，第二个实参 `i` 也是 `int`。
        *   实参类型为 `int`, `int`。
        *   推导结果：$T = \text{int}$。
        *   结果：合法。
    *   **C. `min(i,c);`**
        *   第一个实参 `i` 类型为 `int`，第二个实参 `c` 类型为 `char`。
        *   编译器试图推导 $T$：从第一个参数得 $T=\text{int}$，从第二个参数得 $T=\text{char}$。
        *   冲突：$T$ 无法同时为 `int` 和 `char`，且模板参数推导阶段不发生隐式转换（如 `char` 到 `int`）。
        *   结果：**错误**（编译失败）。
    *   **D. `min(c,c);`**
        *   实参类型为 `char`, `char`。
        *   推导结果：$T = \text{char}$。
        *   结果：合法。

3.  **选项对比总结**：
    *   选 C，因为实参类型不一致（`int` 和 `char`）导致模板参数 $T$ 推导冲突。
    *   A、D 实参类型相同，推导无歧义。
    *   B 通过显式强制转换统一了实参类型，推导无歧义。

知识点：[函数模板的定义与模板函数的使用](../../../topics/面向对象C++/函数模板.md)、[重载模板函数](../../../topics/面向对象C++/重载模板函数.md)、[C++语言与C语言的关系](../../../topics/面向对象C++/cpp与c关系.md)

class Vehicle
{
protected:

MaxSpeed=m;

SeatNum=s;
```

```cpp
Vehicle::Show();

int main( )

请完成完整的程序。

#include <iostream>
#include <string.h>
using namespace std;
class book {
public:

{ if(title) delete [] title; }

参考解答：**结论**：在 `main` 中创建 `book` 对象、设置属性并调用 `print()`，即可完成程序。完整代码如下（`book` 类与已给出部分一致）：

### 综合 1

```cpp
class Shape
{
public:
    virtual void Volume()=0;
};
```

由它派生出 3 个派生类：

- `Sphere`（球体）：数据成员 `radius`（半径）；
- `Cube`（立方体）：数据成员 `height`（高），`width`（宽），`long`（长）；
- `Cylinder`（圆柱体）：数据成员 `height`（高），`radius`（底半径）。

用虚函数分别计算这几种形状的体积并显示结果。

(1) 体积计算并显示的虚函数原型为：`void Volume();`

(2) 编写 `main` 函数，定义基类的指针 `ptr` 和各种形状的对象、用统一的成员函数调用语句 `ptr->Volume()` 计算体积并显示结果，请完成完整的程序。

```cpp
class Cylinder: public Shape
{
public:
    Cylinder (double h, double r) { height=h; radius=r; }
    void Volume()
    {
        cout<<"Cylinder Volume: "<<3.14*radius*radius*height<<endl;
    }
protected:
    double radius, height;
};

int main()
{
    Shape *ptr;
    Sphere c(1.0); Cube r(1.0,2.0,3.0); Cylinder h(1.0,2.0);
    ptr=&c; ptr->Volume();
    ptr=&r; ptr->Volume();
    ptr=&h; ptr->Volume();
    return 0;
}

参考解答：**结论：** 将 `Shape` 设计为抽象基类（含纯虚函数 `Volume()`），各派生类重写该函数实现多态；`main` 中通过基类指针统一调用，实现运行时动态绑定。

```cpp
#include <iostream>
using namespace std;

class Shape
{
public:
    virtual void Volume() = 0;  // 纯虚函数，使 Shape 成为抽象类
    virtual ~Shape() {}         // 建议添加虚析构函数
};

class Sphere : public Shape
{
public:
    Sphere(double r) { radius = r; }
    void Volume()
    {
        cout << "Sphere Volume: " << 4.0 / 3.0 * 3.14 * radius * radius * radius << endl;
    }
protected:
    double radius;
};

class Cube : public Shape
{
public:
    Cube(double h, double w, double l) { height = h; width = w; length = l; }
    void Volume()
    {
        cout << "Cube Volume: " << height * width * length << endl;
    }
protected:
    double height, width, length;  // 避免使用 long 作为变量名（关键字冲突）
};

class Cylinder : public Shape
{
public:
    Cylinder(double h, double r) { height = h; radius = r; }
    void Volume()
    {
        cout << "Cylinder Volume: " << 3.14 * radius * radius * height << endl;
    }
protected:
    double radius, height;
};

int main()
{
    Shape *ptr;
    Sphere c(1.0); 
    Cube r(1.0, 2.0, 3.0); 
    Cylinder h(1.0, 2.0);
    
    ptr = &c; 
    ptr->Volume();  // 输出: Sphere Volume: 4.18667
    
    ptr = &r; 
    ptr->Volume();  // 输出: Cube Volume: 6
    
    ptr = &h; 
    ptr->Volume();  // 输出: Cylinder Volume: 12.56
    
    return 0;
}
```

**关键说明：**

1. **抽象基类**：`Shape` 包含纯虚函数 `Volume()=0`，不能实例化，只能作为接口基类。派生类必须实现该函数才能创建对象。

2. **多态机制**：`ptr->Volume()` 在运行时根据 `ptr` 实际指向的对象类型（`Sphere`、`Cube` 或 `Cylinder`）动态调用对应的函数版本，而非编译时静态绑定。

3. **命名规范**：代码中使用 `length` 而非 `long` 作为成员名，因为 `long` 是 C++ 关键字，会导致编译错误。

4. **计算结果**：
   - 球体：$\frac{4}{3} \times 3.14 \times 1^3 \approx 4.19$
   - 立方体：$1 \times 2 \times 3 = 6$
   - 圆柱体：$3.14 \times 2^2 \times 1 = 12.56$
