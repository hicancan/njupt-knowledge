#### （2）函数重载

**特征**：函数名相同，函数参数类型或个数（参数列表）不同。与函数返回类型无关。

**练习**：下列重载函数定义错误的是？
- A. `int print( int x);` 与 `void print(float x);`
- B. `int disp(Myclass A);` 与 `char * disp(Myclass A);`
- C. `int show( int x);` 与 `int show( char *s);`
- D. `int view(int x , int y);` 与 `int view( int x);`

*注：选项B中两个函数的参数列表完全相同（均为 `Myclass A`），仅返回类型不同，因此不能构成重载，定义错误。*

### 2. 知识要点

#### （1）运算符重载

分为成员函数和友元函数两种方式。

**示例代码：**

```cpp
class X {
public:
    // 成员函数，双目运算 +、-、*、/
    X operator+(X a);
    
    // 友元函数，双目运算
    friend X operator+(X a, X b);
    
    // 成员函数，单目运算 -
    X operator-(); 
    
    // 友元函数，单目运算
    friend X operator-(X a);
    
    // 成员函数，前缀 ++、--
    X operator++(); 
    
    // 友元函数，前缀 ++、--
    friend X operator++(X& a);
    
    // 成员函数，后缀 ++、-- (int 参数用于区分)
    X operator++(int); 
    
    // 友元函数，后缀 ++、--
    friend X operator++(X& a, int);
    
    // 友元函数, 输出运算符 <<
    friend ostream& operator<<(ostream & out, const X &obj);
    
    // 友元函数, 输入运算符 >>
    friend istream& operator>>(istream & in, X &obj);
};
```

参考教材例 6.8、实验三。
