# 图像与视频处理基础伴读：从光到采样网格

为什么屏幕上标成同样灰度的两块看起来不一样亮？为什么视频可以少存一部分颜色样点，却不能把同样比例的灰度样点随意删掉？中间有三个不同的世界：物理光、观看者的感受、文件里的样值。本文按历史课件实际内容串起它们，并补齐原件末页八题的参考解答，不代表现行考核。

## 到达平面的光，与从平面向眼睛来的光，不是同一个量

光具有波与粒子的两种描述，根据问题可用波长或光子能量讨论。可见波段的边界是约定范围，不是所有人的感知硬开关。到达相机或眼睛的光可以来自物体自身，也可以来自其他光源照射后经物体反射或透射；像素值因此不能只当物体材质。一帧表示某时刻一定投影下的空间样本，还可用不同颜色分量描述，视频再加时间轴。

辐射功率用瓦计；明视觉光通量把谱功率密度按标准视效率 $V(\lambda)$ 加权，常写 $\Phi_v=K_m\int V(\lambda)\Phi_{e,\lambda}(\lambda)\,d\lambda$。教材近似用 $555\,\mathrm{nm}$ 的光把归一化峰值与约 $683\,\mathrm{lm/W}$ 联系起来；同样辐射瓦数换一个波长，不一定测得同样流明。系统输入电功率到流明的发光效率又是另一回事，不能拿单一波长系数直接估灯具耗电。

| 量 | 问的问题 | 常见单位 |
| --- | --- | --- |
| 光通量 | 总共有多少按明视觉加权的光？ | 流明（lm） |
| 发光强度 | 光源向这个方向每单位立体角发出多少光通量？ | 坎德拉（cd） |
| 照度 | 受光表面每单位实际面积收到了多少？ | 勒克斯（lx） |
| 亮度 | 表面朝观察方向每单位投影面积呈现多少发光强度？ | 坎德拉每平方米（cd/m²） |

**补充（自编算例）。** 60 lm 均匀入射到 $2\,\mathrm{m}^2$ 平面，照度为 30 lx；若无其他变化而均匀落在 $0.5\,\mathrm{m}^2$，则为 120 lx。==给的是入射流明和受光面积，应算照度，不是亮度。== 要算反射表面朝某方向的亮度，还需反射与方向信息。色温描述近似黑体的色度，非黑体常用相关色温。原件第 14 页先写 2527 K 再加 273；已经以 K 给出的数不得再换算，若起值是 2527 °C，才约为 2800 K。同一相关色温不意味着两者光谱相同。

## 三个分量可以还原视觉上的颜色，不等于复原光谱

常见颜色描述要分亮暗、色调及饱和程度；红和蓝主要差在色调，某种红掺入中性分量可以降低饱和度。饱和度依颜色空间的定义，不能把所有光谱色与屏幕编码的一个固定百分比机械对应。不同光谱可能在人眼产生相同或相近的颜色匹配。三种锥体对宽而重叠的波段有不同响应，不是各只接收一个 RGB 波长。给定显示基色及白点，可以用三基色相加生成设备色域内的颜色；不能据此声称任何三基色都能用非负比例生成全部可见色。近邻子像素由眼睛空间整合，逐时发光也可能被时间整合；印刷或滤色片通过减去一部分光谱得到颜色，实际墨水一般还用黑版改善中性暗色和重现。

| 表示 | 它分开了什么 | 常见误会 |
| --- | --- | --- |
| RGB、CMY／CMYK | 红绿蓝分量，或印刷控制量 | $C=1-R$ 等理想归一化补色模型不等于任意印刷色彩管理 |
| YUV、YIQ | 光亮信息与两路色度；历史模拟系统采用不同定义与轴 | 坐标和权重不能挪用到任何数字视频 |
| $Y^{\prime}C_bC_r$ | 数字信号中的亮度信息与色差 | 要先确定色彩矩阵、偏移和数值范围 |
| HSV／HSB、HSL、HSI | 色调、饱和度和某种亮度轴 | HSV 的 $V$ 常取最大分量，HSL 的 $L$ 常取最大最小平均，HSI 的 $I$ 则取三分量平均，三个数不互换 |

以归一化分量 $(0.9,0.3,0.3)$ 为例，HSV 的 $V=0.9$，HSL 的 $L=0.6$，HSI 的 $I=0.5$。对于相等的 RGB 分量，Hue 无物理意义，程序可约定填 0；不可把这个 0 解释成红色。数字色差的另一个验算：在原件第 50 页给的全幅示例中，$C_b$ 是对 $B^{\prime}-Y^{\prime}$ 的缩放加偏移，$C_r$ 则对应 $R^{\prime}-Y^{\prime}$；因此逆式红分量应加 $1.402(C_r-128)$、蓝分量应加 $1.772(C_b-128)$，原件逆矩阵的红行色差列应订正。不要把此全幅示例的偏移直接用于后面演播室的码值范围。

## 眼睛的背景适应、分辨力和时间响应

角膜和晶状体成像到视网膜；视觉响应还与观察时的适应状态有关。白天条件下锥体提供分辨色彩的能力，暗环境以杆体为主，色彩感知减弱，光视效率峰值也移向较短波长。以 $B$ 表示给定背景亮度，则可觉察的最小亮度差为 $\Delta B_{\min}$；在一定范围内 $\Delta B_{\min}/B$ 近似稳定，极暗、极亮或不同环境下不能用固定比值外推。相同灰块旁边放较亮或较暗背景，观察者会给出不同的明暗判断，Mach 带也表明边界附近的主观变化不等于物理亮度真有过冲。

分辨精细图案首先受视角和对比度影响，常见观看条件下对亮度细节更敏感，为色差降采样提供加工余地；对彩色细线、文字或后续测量，仍可能看见色边。亮度反应有时间积分，临界闪烁频率随亮度、刺激和视野等条件而变。电影重复投影一帧可提高闪烁频率，但不会让原始运动多出一帧，不能把刷新频率和新画面帧率混为一谈。“数字视网膜”在课件是借感知启发摄像与处理的应用引子，不是数字化步骤。

## 采样选位置，量化选数值，编码给它编号

把二维连续图像变成 $M$ 行 $N$ 列的离散数组，是空间采样；**订正（原件第 81 页）**，在矩形带限与理想重建约定下，两个方向分别需大于对应最高空间频率的两倍，而不只是大于最高频率。降采样前若有超过新带宽的内容，应先[平滑或限带](../../../topics/图像与视频处理/空域平滑.md)，否则高频会混成看似真实的低频。量化才把每点幅度限制到有限级数；均匀量化时，未过载且取最近级的样值误差在半步长内。色带或假轮廓不一定是像素太少，可能是亮度级太粗。编码是为量化级分配数字，若不考虑行补齐、尺寸元数据或压缩，单通道 $k$ 位样本总计 $MNk$ 比特，$k$ 位可标出至多 $2^k$ 个不同码字。

**补充（自编算例）。** 在采样间隔相同的线上，归一化频率 $0.6$ 与 $0.4$ 周期／样点的余弦产生相同离散序列：$\cos(2\pi\cdot0.6n)=\cos(2\pi\cdot0.4n)$。把每样点从 8 位加到 10 位，并不能辨认缺失的高频。相反，若只是灰度轴有太少层次，提高空间采样率也不是提高层次数的直接手段。==先判断失真在采样位置还是样值轴。==

## 兼容彩色电视如何兼顾旧黑白机

模拟系统会传一条黑白机可用的亮度信号，把两路色差信息另行调制，使彩色机能还原颜色。扫描行、场频、带宽与是否隔行属于另一组参数；同一幅画面可由两个不同时刻的场构成，场率与完整帧率不能直接等同。

- **NTSC** 的两路色度在同一副载波上作正交调制；同步解调乘相应本振，低通留下所需分量，去掉两倍副载波附近部分。参考相位有误会让两路色度混合，色调会偏。用教学信号 $A\cos\omega t+B\sin\omega t$ 时，乘 $2\cos\omega t$ 后低通得 $A$，交叉项没有直流；判断相角象限须用带符号的两分量，不能只看一个比值。
- **PAL** 逐行反相的是其中一路色度的符号，接收端利用相邻行抵消一定的相位误差；不等于轮流把两路都关闭，也不保证所有失真消失。**SECAM** 用逐行交替传送并以行存储补全两路色差；利用调频和时间上的错开，代价包括存储及相邻行相关性的要求。

彩色视频数字化还要按时间取帧、按行列取空间样点；原件对比直接采复合波形与先分开各分量再采样。分量处理避开部分重复解码的损伤，也利于统一后续采样和量化；不能说数字化等于已做压缩。ITU-R 的演播室分量约定解决的是设备如何对同一组样值达成一致，不是猜某个文件一定能解的依据。

## 原件末页八题：参考解答

1. **彩色的三要素。** 亮暗描述视觉上明暗程度，色调说接近哪类颜色，饱和度度量偏离中性程度；分别比较同色调浅深、不同色调以及中性灰，避免把“饱和度高”写成“亮度高”。彩色模型里的强度量不自动等同物理亮度。
2. **三基色如何用于电视。** 摄像与显示约定三分量的色度和基色，接收端通过相加使观察者产生近似的三刺激匹配，不必传每个像素的光谱。历史兼容方案也可由三分量生成一条亮度和两条色差，而不是三路都直接按 RGB 调制。
3. **RGB 与 HSI 怎样描述颜色。** RGB 用三个基色的幅值；HSI 把同样的颜色描述为环上的色调、从中性轴偏离的程度和平均强度 $I=(R+G+B)/3$。表示变了，信息不一定丢；在灰轴上色调不可辨。最大分量不是 HSI 的强度定义。
4. **PAL 相对于 NTSC。** 二者都能兼容亮度通道；NTSC 的正交色度对本振相位误差较敏感，PAL 的一条色度逐行交替相位，并借助行间处理抵消一部分色调偏差，代价是解码结构和对行间相关性的要求，不是消除一切色差。
5. **BT.601 包含什么。** [ITU-R BT.601](https://www.itu.int/rec/R-REC-BT.601/en) 给出演播室数字电视的分量编码参数，包含分量关系、采样结构、频率、有效行样值数和量化电平。以表 3 的 4:2:2 为例，亮度、每路色差取样频率分别是 13.5 和 6.75 MHz，有效行分别有 720 和 360 个样值；8 位标称亮度黑白为 16、235，色差以 128 为零。按 [BT.601-7 表 3](https://www.itu.int/dms_pubrec/itu-r/rec/bt/R-REC-BT.601-7-201103-I!!PDF-E.pdf)，色差标称端点 16、240，相差 224 个步长、含端点共有 225 个级；原件第 107 页写作 224 级，须区分步长和级数。统一编码有利于设备交换同样解释的分量样值。
6. **分量接口和参数标准如何区分。** [BT.656](https://www.itu.int/rec/R-REC-BT.656/en) 定义 525／625 行电视系统中采用 BT.601 4:2:2 的数字分量接口；[BT.709](https://www.itu.int/rec/R-REC-BT.709/en) 给高清制作与交换的参数，[BT.1120](https://www.itu.int/rec/R-REC-BT.1120/en) 则给出相应 1920×1080 演播室信号的数字接口办法；[BT.1120-9 正文](https://www.itu.int/dms_pubrec/itu-r/rec/bt/R-REC-BT.1120-9-201712-I!!PDF-E.pdf)也引用 BT.2100，不能说接口只用于 BT.709。两组都可用“先统一样值表示，再统一如何在接口上送出去”记忆；接口不是又一种图像压缩算法。
### 第 7 题：编写 RGB 与 HSI 的转换

下列独立 MATLAB 参考程序按一个归一化像素实现，可对数组中每个像素应用同一规则。第一方向用带象限的角度，反向先转到 $0^\circ$ 至 $120^\circ$ 的基段，再按色调轮转通道。原件第 56 页最后一段将本应由总和约束求出的剩余红通道写成了蓝通道，下面用轮转规避重复推导的笔误。不是把 HSV 函数改名；输入任意 HSI 三元组也不保证生成的 RGB 落在正方体内。

```matlab
function hsi = rgb_to_hsi_one(rgb)
    rgb = reshape(double(rgb), 1, []);
    assert(numel(rgb) == 3 && all(isfinite(rgb)) && ...
           all(rgb >= 0 & rgb <= 1));
    r = rgb(1); g = rgb(2); b = rgb(3);
    light = mean(rgb);
    if light == 0 || max(rgb) == min(rgb)
        hsi = [0, 0, light];  % 中性灰的色调按约定填写
        return
    end
    h = mod(atan2d(sqrt(3)*(g-b), 2*r-g-b), 360);
    s = 1 - min(rgb)/light;
    hsi = [h, s, light];
end
```

```matlab
function rgb = hsi_to_rgb_one(hsi)
    hsi = reshape(double(hsi), 1, []);
    assert(numel(hsi) == 3 && all(isfinite(hsi)) && ...
           all(hsi(2:3) >= 0 & hsi(2:3) <= 1));
    h = mod(hsi(1), 360); s = hsi(2); light = hsi(3);
    if s == 0 || light == 0
        rgb = [light, light, light];
        return
    end
    sector = floor(h/120);
    theta = h - 120*sector;
    c = light*(1-s);
    a = light*(1 + s*cosd(theta)/cosd(60-theta));
    b = 3*light-a-c;
    base = [a, b, c];
    rgb = circshift(base, [0, sector]);
    tol = 1e-12;
    assert(all(rgb >= -tol & rgb <= 1+tol), 'HSI outside RGB gamut');
    rgb = min(1, max(0, rgb));  % 只消除浮点舍入余量
end
```

**复算点。** 纯红返回 $(0^\circ,1,1/3)$；正绿、正蓝的色调为 $120^\circ$ 与 $240^\circ$。对 $(0.6,0.3,0.3)$，$I=0.4$、$S=0.25$、色调为零，回算 $(0.6,0.3,0.3)$。历史实验页另列出图像的读取、显示、写出和视频帧的读取、写出接口；动手测时先确认数组通道顺序、类型和取值范围，再做往返误差测试，避免把 8 位整数直接当成这里的归一化浮点输入。

### 第 8 题：解释 4:2:0

对常见的偶数尺寸画面，亮度每个像素位置一份，两个色差平面各在水平、垂直减半；在一个 $2\times2$ 亮度网格对应四个亮度样值及各一个色差样值，0 不表示某个色差完全没传。4:4:4 三平面同密度；4:2:2 是色差水平减半、垂直不变；4:1:1 是色差水平方向约四分之一、垂直不变。两种同为平均每亮度像素 1.5 个样值的取法也会牺牲不同方向的细节，色差样点相位和边界规则仍由具体约定决定。以 $1920\times1080$、每样值 8 位为例，4:2:0 有 3,110,400 个样值、每帧像素纯数据 24,883,200 比特；相同尺寸的 4:4:4 为其两倍。

> [!TIP]
> 做彩色视频题，先写采样网格和亮度平面的尺寸，再数每个色差平面的样值；如果题问码率，还要乘样值位深与帧率，分开计算封装和编码开销。
