# 《计算机组成与结构》期末复习提纲（课件）

原件经识别和整理；“参考解答”是我们补的。

## 第一章

### 计算机性能指标与基本结构

- 了解计算机性能指标——吞吐量、CPI、MIPS、FLOPS 等
- 了解计算机软件硬件基本结构
  - 冯·诺依曼体系结构设计思想、组成部分、特点
  - 编译—汇编—链接

## 第二章

知识点：[计算机组成五大部件（运算器、控制器、存储器、输入设备、输出设备）](../../../topics/计算机组成/computer-five-parts.md)、[CPU执行时间与性能计算公式](../../../topics/计算机组成/cpu-time.md)、[CPI（每条指令平均时钟周期数）](../../../topics/计算机组成/cpi.md)、[MIPS速率与有效CPI计算](../../../topics/计算机组成/mips-rate.md)

### 数据表示与运算

- 了解定点数、浮点数的表示方法
- IEEE754 浮点数（例如：32 位的最大规格化正数）
- 了解原码、反码、补码的概念（例如：零的表示方法）
- 掌握补码加减法、乘法；溢出的概念及检测
- 掌握 ALU 的基本思想与工作原理
  - FA 加法器 + 函数发生器

## 第三章

知识点：[数制与码制（原码、反码、补码、移码表示法及相互关系）](../../../topics/计算机组成/number-systems.md)、[定点加减法运算与基本的二进制加法/减法器（全加器逻辑电路）](../../../topics/计算机组成/fixed-point-add-sub.md)、[溢出及其判定（双符号位法、最高位进位与次高位进位的异或值）](../../../topics/计算机组成/overflow-detect.md)

### 存储器与 Cache

- 了解 SRAM、DRAM 的基本概念
- 掌握 Cache 存储器的目的、工作原理——例如：CPU 中引入 Cache 主要为了解决什么问题？
- 掌握命中率的计算，主存与 Cache 地址映射的三种方式（要求能画图说明）

## 第四章

知识点：[Cache基本原理（命中率、访问效率、容量与块长对命中率的影响）](../../../topics/计算机组成/cache-basic.md)、[Cache地址映射与变换（全相联映射、直接映射、组相联映射）](../../../topics/计算机组成/cache-mapping.md)、[SRAM与DRAM的比较（工作原理、读写周期、时序信号）](../../../topics/计算机组成/sram-dram.md)

### 指令系统

- 了解 CISC、RISC 的基本概念——了解 RISC 系统的特点
- 掌握零、一、二、三地址指令的基本格式
- 掌握基本的寻址方式（直接寻址、变址寻址、寄存器寻址）
- 掌握指令设计的基本方法
  - 指令条数与指令码位数的关系
  - 寻址宽度与地址字段位数的关系

## 第五章

知识点：[MIPS32 I型指令格式与功能（面向运算、访存、条件转移分支等类型）](../../../topics/计算机组成/mips-i-type.md)、[寻址方式（寄存器直接寻址、立即数寻址、基准地址寻址等）](../../../topics/计算机组成/addressing-mode.md)、[MIPS32 R型指令格式与功能（Register，由op配合func字段确定操作）](../../../topics/计算机组成/mips-r-type.md)

### CPU 与微程序

- 了解 CPU 的基本构成
- 掌握微程序基本原理
  - 相容性、互斥性微操作的概念
- 掌握微指令、微程序设计相关内容
  - 微程序控制器组成原理框图
  - 能写出一条简单汇编指令的微程序（例如 `ADD AX, [100];`）
- 掌握 CPU 流水线结构
  - 掌握 CPU 流水线时空图
  - 掌握造成 CPU 流水断流的三种相关和例子代码

## 第六章

知识点：[CPU基本部件选型（PC、IR、MAR、MDR、ALU、通用寄存器堆、多路选择器）](../../../topics/计算机组成/cpu-components.md)、[微程序控制系统的组成与优点](../../../topics/计算机组成/microprogram-control.md)、[MIPS五级流水线方式（IF、ID、EX、MEM、WB）与流水线寄存器](../../../topics/计算机组成/pipeline-basic.md)

### 总线

- 了解系统总线内部结构
  - 例如：数据线、控制线、地址线的功能
- 掌握总线的仲裁
  - 三种集中仲裁的工作方式、优缺点（例如：哪种方式对电路故障敏感）

## 第七章

知识点：[总线的基本概念、特性、标准化与结构形态](../../../topics/计算机组成/bus-concept.md)、[集中式总线仲裁方式（链式查询方式、计数器定时查询方式、独立请求方式的优缺点）](../../../topics/计算机组成/bus-arbitration.md)

### 磁盘存储系统

- 了解磁盘存储系统的基本工作原理——磁盘系统的框架图
- 掌握磁盘存储系统的基本技术指标——存储密度、容量、平均存取时间、数据传输率
- 掌握存储系统的基本计算
  - 磁盘柱面、存储容量、传输率等指标的计算

## 第八章

知识点：[磁盘存储设备（磁性材料物理特性、磁表面存储器读写原理、盘片分类）](../../../topics/计算机组成/disk-storage.md)、[磁盘存储器的技术指标（平均存取时间、数据传输率、总存储容量计算）](../../../topics/计算机组成/disk-metrics.md)、[磁盘上信息的分布与记录格式（柱面、磁道、扇区编号、扇标脉冲）](../../../topics/计算机组成/disk-format.md)

### 外围设备与中断

- 了解 CPU 管理外围设备的几种基本方式——哪些由硬件实现，哪些由软件实现
- 了解计算机系统响应中断和恢复执行的流程——例如：响应中断过程中，CPU 对标志位的操作
- 了解常见的中断事件
- 掌握单级中断和多级中断，及其优缺点
