# 《Java软件开发》第3次作业：创建多源文件项目与setXXX/getXXX方法练习

原件经识别和整理；“参考解答”是我们补的。

本资料为南京邮电大学计算机学院《Java软件开发》课程第3次实验作业，主要涉及Netbeans多源文件项目创建及封装性（setter/getter）的练习。

## 一、实验内容

### 练习 1

参照课件第 4章第 4.1 节的例子，学习创建包含多个源代码文件的项目并完成编译和运行。

具体要求和提示:

1. 参考课程视频讲解，在 Netbeans中创建 1个项目，在项目中分别创建 3 个源文件：`CreateObjectDemo.java`, `Point.java`和 `Rectangle.java`。
2. 完成项目的编译和运行。
3. 参考课件上的示例，修改项目源代码，在 `Point`类为其成员变量 x，y，以及在 `Rectangle` 类中为其成员变量 width, height增加 set XXX/getXXX 方法对，并在 `CreatObjectDemo` 类中，找出采用限定性命名方式直接访问 Point对象以及 Rectangle对象中的成员变量的语句，将它们更换为采用 setXXX/getXXX方法进行访问的语句。
4. 再次完成项目的编译和运行。

补充：2021年3月，计算机学院，南京邮电大学
