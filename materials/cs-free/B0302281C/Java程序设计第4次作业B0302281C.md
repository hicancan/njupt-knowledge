# 《Java程序设计》第4次作业（B0302281C）

原件经识别和整理；“参考解答”是我们补的。

练习：已有字符串 “hello1234”，试写程序将其转换为 “HELLO2345”。

### 提示

1. 下面是课堂上举例的回文程序代码（参见第 4 章课件），可以在编写程序时作为参考。

2. 学习查阅 Java 文档，在文档中找出 Character 类中合适的方法，可以用于区分一个字符是数字还是字母，以便进行相应的转换。

3. 字符串 “hello1234” 直接在程序中定义，转换后得到的字符串 “HELLO2345” 在文本命令行窗口输出。

参考解答：```markdown
### 结论

输出结果为：

```text
HELLO2345
```

### 推理过程

1. 定义字符串 `s = "hello1234"`。
2. 遍历 `s` 中的每个字符 `c`：
   - 若 `c` 是字母（`Character.isLetter(c)` 为 `true`），则转换为大写字母，即 `Character.toUpperCase(c)`；
   - 若 `c` 是数字（`Character.isDigit(c)` 为 `true`），则将该数字字符对应的数值加 1。
     - 例如 `'1'` 变为 `'2'`，`'4'` 变为 `'5'`。
     - 可用 `(char)(c + 1)` 实现。
3. 拼接转换后的字符，得到新字符串：
   - `h → H`
   - `e → E`
   - `l → L`
   - `l → L`
   - `o → O`
   - `1 → 2`
   - `2 → 3`
   - `3 → 4`
   - `4 → 5`
4. 最终结果：`"HELLO2345"`。

```java
String s = "hello1234";
String result = "";
for (char c : s.toCharArray()) {
    if (Character.isLetter(c)) {
        result += Character.toUpperCase(c);
    } else if (Character.isDigit(c)) {
        result += (char)(c + 1);
    }
}
System.out.println(result);  // HELLO2345
```
