# 《Java程序设计》第4次作业：逐字符判断与转换

原件要求程序内定义 `hello1234`，用字符分类和转换得到 `HELLO2345` 并输出。原件的回文示例可借鉴如何逐个访问字符，不代表也要倒序。第 2 页另有历史提交说明，第 3 页为空。以下程序是自编参考解答。

## 一次只改当前位置，不要重新解释整段数字

**参考解答**：把字母变成大写，数字逐个加一，原有顺序不变。把后缀当作整数 `1234` 加一会得到 `1235`，不是题目的转换。原题只给定固定字符，本例把可处理范围明确为 ASCII 字母和数字 `0` 至 `8`，不自行规定 `9` 要变成什么。

```java
public class CharacterTransform {
    static String transform(String input) {
        StringBuilder out = new StringBuilder(input.length());
        for (int i = 0; i < input.length(); i++) {
            char ch = input.charAt(i);
            if (ch > 0x7f) {
                throw new IllegalArgumentException("ASCII only");
            }
            if (Character.isLetter(ch)) {
                out.append(Character.toUpperCase(ch));
            } else if (Character.isDigit(ch) && ch != '9') {
                out.append((char) (ch + 1));
            } else {
                throw new IllegalArgumentException("Unexpected character");
            }
        }
        return out.toString();
    }

    public static void main(String[] args) {
        System.out.println(transform("hello1234"));
    }
}
```

每轮开始时，输出缓冲区已经保存前 `i` 个字符的转换结果。本轮只检查第 `i` 个字符、添加一个新字符，最后的字符串因此保持原顺序。先分别试字母、数字，再试混合输入：

| 输入 | 输出或动作 | 要检查什么 |
| --- | --- | --- |
| `aZ` | `AZ` | 小写被转成大写，原有大写不变 |
| `08` | `19` | 逐个字符变换，不把带前导零的后缀当作整数 |
| `hello1234` | `HELLO2345` | 题目给定的输出 |
| `9` 或全角数字 `１` | 明确拒绝 | 定义域不是所有 Unicode 字母、数字 |

> [!WARNING]
> ==加一得到的表达式类型是 int==。若直接写 `out.append(ch + 1)`，例如处理 `'1'` 时会追加文本 `50` 而不是字符 `'2'`；强制转回 `char` 后才选中字符版本。参见 [StringBuilder 的重载文档](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/StringBuilder.html)和[数据类型转换](../../../topics/Java开发/数据类型转换.md)。

[Character 文档](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html)中的分类方法并不限于 ASCII。扩展到任意 Unicode 文本时，字符分类适用的范围与“编码加一恰好仍是下一位数字”不是同一个问题，且逐个 `char` 也不能遍历所有 Unicode 码点。本题只用 ASCII，不把示例推成通用字符串算法。对应[基本数据类型](../../../topics/Java开发/基本数据类型.md)、[流程控制](../../../topics/Java开发/流程控制语句.md)和[终端输出](../../../topics/Java开发/输入输出基础.md)。
