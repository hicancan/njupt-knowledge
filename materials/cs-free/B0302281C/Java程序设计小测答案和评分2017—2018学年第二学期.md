## 一、选择题（每小题 10 分，共 70 分）

### 选择 1

类 A 定义如下，可正确的是替换//here 的选项是 ( )
```java
public class A{
    public void amethod(int i){ }
    //here 
}
```
- A. `public int amethod(int z){ }`
- B. `public int amethod(int i, int j){return 99;}`
- C. `protected void amethod(long l){ }`
- D. `private void anothermethod(){ }`

答案：BCD。
参考解答：本题考查方法重载与访问修饰符。A选项返回类型不同但参数相同且未构成重载规则中的合法重写/重载混淆（此处主要考察重载，A中参数名z不影响，但返回类型int与原void不同，若视为重载则合法，但在Java中仅返回类型不同不能构成重载，故A错误）；B选项参数列表不同，构成重载，合法；C选项参数类型不同，构成重载，合法；D选项方法名不同，属于新成员，合法。注意题目问的是“替换//here”，即在该位置添加代码。A选项会导致编译错误（仅返回类型不同），B、C、D均合法。

### 选择 2

下面正确的语句是( )
- A. `System.out.println(1 + 1);`
- B. `int i = 2 + ‘2’;`
- C. `String s = “on” + ‘one’;`
- D. `int z = 025;`

答案：ABD。
参考解答：A选项输出整数2，正确；B选项中字符'2'的ASCII值为50，2+50=52，赋值给int正确；C选项中字符常量不能用单引号包裹多个字符'one'，应使用双引号字符串"one"或单个字符，故错误；D选项025是八进制字面量，合法，正确。

- B. `boolean b2 = false;`

### 选择 4

“result” 是一个布尔变量，下面表达式正确的是 ( )
- A. `result=true;`
- B. `if(result){ …}`
- C. `if(result!=0){ …}`
- D. `result=1;`

答案：A。
参考解答：A选项为布尔变量赋值，正确；B选项if条件需要布尔表达式，正确；C选项result是boolean类型，不能与int 0比较，编译错误；D选项不能将int 1直接赋给boolean变量，编译错误。

### 选择 5

程序片段代码如下当 m 取何值时仅输出 Default ( )
```java
switch(m){
case 0:System.out.println(“Case 0”);
case 1:
default:System.out.println(“Default”); 
}
```
- A. 0
- B. 1
- C. 2
- D. 3

答案：BCD。
参考解答：switch语句中，若没有break，会发生穿透。
- m=0：执行case 0打印"Case 0"，然后穿透到case 1/default，打印"Default"。输出两行。
- m=1：执行case 1（无代码），穿透到default，打印"Default"。仅输出Default。
- m=2：无匹配case，直接跳到default，打印"Default"。仅输出Default。
- m=3：无匹配case，直接跳到default，打印"Default"。仅输出Default。
因此，m取1, 2, 3时仅输出Default。

知识点：[if-else、switch、while、do-while、for语句及break/continue/return分支控制](../../../topics/Java开发/流程控制语句.md)、[算术、关系、逻辑、位运算、移位、条件及复合赋值运算符与优先级](../../../topics/Java开发/运算符与表达式.md)、[Java标识符命名规则与保留关键字](../../../topics/Java开发/标识符与关键字.md)

### 选择 6

下面的哪些声明是不合法的（ ）
- A. `public protected amethod(int i)`
- B. `public void amethod(int i)`
- C. `public void amthod(void)`
- D. `void public amethod(int i)`

答案：ACD。
参考解答：A选项同时使用public和protected修饰符，非法；B选项合法的方法声明；C选项方法参数列表中不能有void类型，非法；D选项返回类型void必须在修饰符之后，参数列表之前，此处顺序错误，非法。

### 选择 7

某程序如下, 对其运行结果描述正确的是（ ）
```java
public class PainOrGain{
    private static Random rnd = new Random();
    public static void main(String[] args){
        StringBuffer word = null;
        switch(rnd.nextInt(2)){
            case 1: word = new StringBuffer('P');
            case 2: word = new StringBuffer('G');
        }
        word.append('a');word.append('i');word.append('n');
        System.out.println(word);
    }
}
```
- A. 随机输出 Pain 或 Gain
- B. 总是输出 Gain
- C. 总是输出 Pain
- D. 以上都不正确

答案：D。
参考解答：`rnd.nextInt(2)` 生成 0 或 1。
- 如果结果是 0：switch 没有匹配的 case，word 保持为 null。后续调用 `word.append(...)` 会抛出 `NullPointerException`。
- 如果结果是 1：进入 case 1，word 初始化为 "P"。由于没有 break，继续执行 case 2，word 被重新初始化为 "G"。然后追加 "ain"，输出 "Gain"。
- 如果结果是 2：nextInt(2) 不会生成 2，所以此情况不存在。
综上，要么抛出异常，要么输出 Gain。选项A、B、C描述均不准确或不完整（B说“总是”错误，因为可能异常）。因此选D。

知识点：[if-else、switch、while、do-while、for语句及break/continue/return分支控制](../../../topics/Java开发/流程控制语句.md)、[基本数据类型（整型、浮点型、字符型、布尔型）及Unicode编码](../../../topics/Java开发/基本数据类型.md)

### 选择 8

某程序如下, 对其描述正确的是（ ）
```java
class B{
    public static void main(String args[]){ 
        int p; 
        int j = 10; 
        j = p; 
    } 
}
```
- A. 程序编译时出现 1处错误
- B. 程序编译时出现 2处错误
- C. 程序运行时出现错误
- D. 程序编译和运行都没有错误

答案：A。
参考解答：局部变量 `p` 声明后未被初始化就直接赋值给 `j` (`j = p`)，Java编译器会报错“variable p might not have been initialized”。这是一处编译错误。
