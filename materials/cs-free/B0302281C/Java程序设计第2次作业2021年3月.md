# 《Java程序设计》第2次作业：整数求和

两页原件只有一道编程题：求 $1$ 至 $1000$ 的整数和，并向终端输出。第 2 页是历史提交说明的续页，不是另一道练习。下文的代码和验算是补充解答，不是原件答案。

## 每一轮结束时，已经加到了哪里

**参考解答**：要把整个区间加一次，可让循环计数器表示==下一项要加的数==，累加器表示==已经处理的前缀之和==。

```java
public class SumToThousand {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 1000; i++) {
            sum += i;
        }
        System.out.println(sum);
    }
}
```

输出为 `500500`。每轮开始时，`sum` 等于从 $1$ 到 $i-1$ 的和。第一轮之前还没加任何数，故初值是 $0$；轮中加上 $i$，令下一轮的同一关系依然成立。当 $i$ 变成 $1001$ 时停止，最后一项 $1000$ 确实已纳入。可另把首尾两项配成 $1001$，共 $500$ 对，得到同一结果。

> [!TIP]
> 如果一时拿不准应写 `<` 还是 `<=`，先让上限等于 $1$。从 $1$ 加到 $1$ 应输出 $1$；误写成严格小于会让循环一次也不跑。

练习对应[流程控制](../../../topics/Java开发/流程控制语句.md)、[变量的作用域与初始化](../../../topics/Java开发/变量的作用域与初始化.md)和 [Java 程序入口](../../../topics/Java开发/HelloWorld程序结构.md)。

## 能放下答案，还要能放下中间结果

**补充**：本题所有部分和都是非负且不超过 $500500$，所以可用 `int`。若推广到更大的 $n$，先区分循环累加和直接写 `n * (n + 1) / 2`：后者先算乘积，中间值可能比答案早溢出。比如 $n=50000$ 的正确和为 $1250025000$，仍在 `int` 范围内，但乘积 $2500050000$ 已超界。把算完的结果赋给 `long` 无法补救已经发生的溢出；当 `n` 是非负 `int` 时，可在运算前写成 `n * (n + 1L) / 2`。先用 long 的 $1$，既保证加一也在 `long` 中求值，也让乘积提升到 `long`。

| $n$ | 正确的和 | `int` 累加能否容纳 |
| --- | --- | --- |
| $65535$ | $2147450880$ | 能 |
| $65536$ | $2147516416$ | 不能 |

> [!WARNING]
> 变量类型要看==运算发生时的类型==，不能只看最后接收结果的变量。参见[基本数据类型](../../../topics/Java开发/基本数据类型.md)和[数据类型转换](../../../topics/Java开发/数据类型转换.md)。
