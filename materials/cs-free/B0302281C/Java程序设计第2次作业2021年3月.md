## 练习

### 练习 1

计算从 1 到 1000 的所有整数的和，并输出结果。

提示：

1. 在程序中正确选择合适的变量类型。
2. 采用和 HelloWorld 程序相同的方式，在文本命令行窗口中输出计算结果。

参考解答：**结论：** 从 1 到 1000 的所有整数之和为 **500500**。在 Java 中，可以使用 `int` 类型存储循环变量及最终结果（500500 远小于 `int` 的最大值 2147483647），通过 `for` 循环累加，并使用 `System.out.println` 输出。

**计算过程（等差数列求和）：**
$$S = \frac{n(a_1 + a_n)}{2} = \frac{1000 \times (1 + 1000)}{2} = 500 \times 1001 = 500500$$

**参考代码：**

```java
public class SumCalculator {
    public static void main(String[] args) {
        int sum = 0; // 用于存储累加结果，初始化为0
        
        // 循环从1遍历到1000，进行累加
        for (int i = 1; i <= 1000; i++) {
            sum += i;
        }
        
        // 在命令行窗口输出结果
        System.out.println("1到1000的所有整数之和为：" + sum);
    }
}
```

**运行结果：**
```text
1到1000的所有整数之和为：500500
```
