### 简答 1

（Reviews Questions 5.2）How are HTML elements and attributes represented in the JavaScript binding to DOM?

答案：HTML elements are represented as objects, and their attributes are represented as properties of those objects.

知识点：[文档对象模型（DOM）概念与结构](../../../topics/Web开发技术/dom-model.md)、[基于对象的概念与JavaScript内置对象](../../../topics/Web开发技术/js-objects.md)、[JavaScript中的元素访问方式（forms数组、name属性、id属性、隐式数组implicit arrays）](../../../topics/Web开发技术/element-access.md)

### 简答 2

（Reviews Questions 5.6）What are the two ways in which an event handler can be associated with an event generated by a specific HTML element in the DOM 0 event model?

答案：
1. By assigning a function to the corresponding `on` property of the element object (e.g., `element.onclick = handlerFunction`).
2. By specifying the handler code directly in the HTML attribute of the element (e.g., `<button onclick="handlerCode">`).

知识点：[事件与事件处理（Events、Attributes、Tags、注册处理程序Registering a Handler及方法比较）](../../../topics/Web开发技术/event-handling.md)、[文档对象模型（DOM）概念与结构](../../../topics/Web开发技术/dom-model.md)、[HTML文档结构（head、body、meta元素）](../../../topics/Web开发技术/html-doc-structure.md)

### 简答 3

（Reviews Questions 5.14）Why is it good to use JavaScript to check the validity of form inputs before the form data is sent to the server?

答案：It reduces server load and network traffic by catching invalid input early on the client side, providing immediate feedback to the user without requiring a round-trip to the server.

### 代码 1

（Exercise 5.1）Modify the radio_click.html example to have five buttons, labeled red, blue, green, yellow, and orange. The event handlers for these buttons must produce messages stating the chosen favorite color. The event handler must be implemented as a function whose name must be assigned to the onclick attribute of the radio button elements. The chosen color must be sent to the event handler as a parameter.

JavaScript 代码：

```html
<!DOCTYPE html>
<html>
<head>
    <title>Favorite Color</title>
    <script type="text/javascript">
        function showColor(color) {
            alert("Your favorite color is " + color);
        }
    </script>
</head>
<body>
    <h3>Select your favorite color:</h3>
    <input type="radio" name="color" value="red" onclick="showColor('red')"> Red<br>
    <input type="radio" name="color" value="blue" onclick="showColor('blue')"> Blue<br>
    <input type="radio" name="color" value="green" onclick="showColor('green')"> Green<br>
    <input type="radio" name="color" value="yellow" onclick="showColor('yellow')"> Yellow<br>
    <input type="radio" name="color" value="orange" onclick="showColor('orange')"> Orange<br>
</body>
</html>
```

参考解答：**结论**

以上代码即为满足题目所有要求的完整参考实现。

**推理与关键说明**

1. **五个按钮**：使用 5 个 `<input type="radio">`，`name` 属性统一设为 `"color"` 以保证互斥单选，标签文本分别为 red、blue、green、yellow、orange。
2. **事件处理函数**：在 `<script>` 中定义命名函数 `showColor(color)`，内部通过 `alert()` 弹出包含所选颜色的提示信息。
3. **onclick 绑定与传参**：每个 radio 元素的 `onclick` 属性被赋值为函数调用表达式（如 `onclick="showColor('red')"`），将对应颜色字符串作为参数直接传入，符合“函数名赋给 onclick 属性”且“颜色作为参数发送”的要求。

知识点：[复选框（Checkboxes）与单选按钮（Radio Buttons）的事件处理](../../../topics/Web开发技术/checkbox-radio-events.md)、[事件与事件处理（Events、Attributes、Tags、注册处理程序Registering a Handler及方法比较）](../../../topics/Web开发技术/event-handling.md)、[屏幕输出与键盘输入（alert、confirm、prompt方法）](../../../topics/Web开发技术/js-io.md)

### 代码 2

（Exercise 5.3）Develop and test an HTML document that has checkboxes for apple (59 cents each), orange (49 cents each), and banana (39 cents each), along with a Submit button. Each of the checkboxes should have its own onclick event handler. These handlers must add the cost of their fruit to a total cost. An event handler for the Submit button must produce an alert window with the message Your total cost is $xxx, where xxx is the total cost of the chosen fruit, including 5 percent sales tax. This handler must return false (to avoid actual submission of the form data).

JavaScript 代码：

```html
<!DOCTYPE html>
<html>
<head>
    <title>Fruit Order</title>
    <script type="text/javascript">
        var totalCost = 0;

        function updateTotal(cost) {
            // Note: This simple logic adds cost every time clicked. 
            // A robust solution would track checked state or recalculate from scratch.
            // Based on typical textbook exercise intent for "add to total":
            totalCost += cost;
        }

        function calculateAndSubmit() {
            var tax = totalCost * 0.05;
            var finalTotal = totalCost + tax;
            alert("Your total cost is $" + finalTotal.toFixed(2));
            return false; // Prevents form submission
        }
    </script>
</head>
<body>
    <form action="#" method="post">
        <h3>Select fruits:</h3>
        <!-- Apple: 59 cents -->
        <input type="checkbox" name="apple" value="0.59" onclick="updateTotal(0.59)"> Apple ($0.59)<br>
        
        <!-- Orange: 49 cents -->
        <input type="checkbox" name="orange" value="0.49" onclick="updateTotal(0.49)"> Orange ($0.49)<br>
        
        <!-- Banana: 39 cents -->
        <input type="checkbox" name="banana" value="0.39" onclick="updateTotal(0.39)"> Banana ($0.39)<br>
        
        <br>
        <input type="submit" value="Submit" onclick="return calculateAndSubmit()">
    </form>
</body>
</html>

参考解答：**结论**  
该代码能实现“点击复选框累加水果价格、提交时弹出含 5% 税的总价并阻止表单实际提交”的基本功能，但在“重复点击同一复选框”时会出现重复计价的逻辑缺陷。

---

**推理过程**

1. **累加逻辑**  
   `updateTotal(cost)` 每次点击都执行 `totalCost += cost`。  
   - 首次勾选苹果：`totalCost = 0.59`  
   - 再次点击同一苹果复选框（无论取消勾选还是再次勾选）：`totalCost` 再次增加 `0.59`，导致重复计价。

2. **提交计算**  
   `calculateAndSubmit()` 中：
   
$$
\text{tax} = 0.05 \times \text{totalCost}
$$

   
$$
\text{finalTotal} = \text{totalCost} + \text{tax}
$$

   弹出金额用 `toFixed(2)` 保留两位小数，符合美元显示格式。

3. **阻止提交**  
   提交按钮的 `onclick` 返回 `false`，因此表单不会真正向 `action="#"` 提交，页面不会跳转或刷新。

4. **代码缺陷**  
   复选框的 `onclick` 只做加法，未判断 `checked` 状态，因此：
   - 取消勾选不会减少总价  
   - 反复点击同一复选框会无限累加  
   - 若用户先勾选再取消，总价仍然包含已取消水果的费用

---

**选择题说明（若本题有选项）**  
该实现的核心错误在于：**没有根据复选框当前状态更新总价，而是盲目累加**。  
因此，正确做法应是每次点击时重新计算所有被选中水果的总和，或在 `updateTotal` 中检查 `this.checked`，若为 `false` 则减去对应价格。
