### 简答 4
简述静态库和共享库的创建过程，并介绍二者的优缺点。

参考解答：
**静态库：**
*   **创建过程**：
    1. 编译 C 语言文件，生成目标文件：`gcc -c wang.c`
    2. 生成静态库：`ar cr libwang.a wang.o`
*   **优点**：运行时无需外部库支持；程序执行速度快。
*   **缺点**：可执行文件体积较大；不易更新维护。

**共享库（动态库）：**
*   **创建过程**：
    1. 编译生成位置无关的目标文件：`gcc -c -fpic wang.c`
    2. 生成共享库：`gcc -shared wang.o -o libwang.so`
*   **优点**：可执行文件体积小；容易维护，多个程序可共享同一份库。
*   **缺点**：不能离开动态库独立运行；运行时加载库有一定开销，速度相对较慢。

知识点：[GCC编译器的使用与编译过程（预处理、编译、汇编、链接）](../../../topics/Linux系统编程/GCC编译器.md)

### 程序 3
在一个空目录下，以 king 用户（属于组 admin）运行下列命令，并写出管道文件中的内容。
```bash
$ mkfifo -m 644 mypipe
$ ls -a > mypipe
$ ls -l
$ echo * >> mypipe
```

参考解答：
此题考察命名管道（FIFO）。
1. `mkfifo` 创建管道。
2. `ls -a > mypipe` 尝试将输出重定向到管道。如果没有读取端，`ls` 会阻塞等待。
3. 题目问“写出管道文件中的内容”。通常 FIFO 文件本身不存储内容，内容是流式的。
4. 如果后续有读取操作，才会得到内容。
5. 识别答案中有 `mypipe -> 这两段目操` (可能是“这两个操作”)。
6. 实际上，`ls -a` 的输出包括 `.`, `..`, `mypipe`。
7. `echo * >> mypipe` 会将当前目录下的非隐藏文件列表追加。
8. 由于没有展示读取命令（如 `cat mypipe`），严格来说管道里是“正在传输的数据流”。
9. 但若必须写出“预期被读取的内容”，则是 `ls -a` 的输出加上 `echo *` 的输出。
   内容大致为：
   ```text
   .
   ..
   mypipe
   mypipe
   ```
   *(注：`echo *` 会展开为当前可见文件，此时只有 mypipe)*

知识点：[有名管道FIFO的创建与无亲缘关系进程通信](../../../topics/Linux系统编程/有名管道FIFO.md)

### 编程 1
编写 shell 脚本，提示用户输入起始数字 A 和终止数字 B。要求：
1. 计算从 A 到 B 的和；
2. 在用户输入完 A 和 B 两个值后，通过调用函数 check() 判断 A，B 哪个值比较大；
3. 在主程序中，如果 A<B 则计算 A 的阶乘，否则输出 B 的阶乘。

参考解答：
```bash
#!/bin/bash

check() {
    if [ $1 -lt $2 ]; then
        return 1
    else
        return 2
    fi
}

echo "Enter the first integer:"
read A
echo "Enter the second integer:"
read B

# 判断大小
check $A $B
result=$?

if [ $result -eq 1 ]; then
    # A < B, 计算 A 的阶乘
    m=1
    mul=1
    while [ $m -le $A ]
    do
        mul=`expr $mul \* $m`
        m=`expr $m + 1`
    done
    echo "Factorial of A ($A) is: $mul"
else
    # A >= B, 计算 B 的阶乘
    m=1
    mul=1
    while [ $m -le $B ]
    do
        mul=`expr $mul \* $m`
        m=`expr $m + 1`
    done
    echo "Factorial of B ($B) is: $mul"
fi

# 计算从 A 到 B 的和 (注意区间方向，若 A>B 则交换或处理范围)
# 题目要求计算从 A 到 B 的和，通常指 min(A,B) 到 max(A,B) 或者就是 A 到 B 步进。
# 假设 A <= B 的情况已在上面分支考虑，这里补充求和逻辑
sum=0
start=$A
end=$B
if [ $A -gt $B ]; then
    start=$B
    end=$A
fi

m=$start
while [ $m -le $end ]
do
    sum=`expr $sum + $m`
    m=`expr $m + 1`
done
echo "Sum from $A to $B is: $sum"
```

### 编程 2
在 Linux 环境下，分别用 shell 脚本和 C 语言将九九乘法表输出到文件 99table.txt 中。同时，分别写出两种程序编写完成后付诸运行所需的所有命令。

参考解答：

**Shell 脚本 (`99table.sh`)**
```bash
#!/bin/bash
for ((i=1; i<=9; i++))
do
    for ((j=1; j<=i; j++))
    do
        printf "%d*%d=%-4d" $j $i $(($i*$j))
    done
    echo ""
done > 99table.txt
```
**运行命令：**
```bash
chmod +x 99table.sh
./99table.sh
```

**C 语言 (`99table.c`)**
```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("99table.txt", "w");
    if (fp == NULL) {
        printf("Cannot open file\n");
        return 1;
    }
    
    int i, j;
    for (i = 1; i <= 9; i++) {
        for (j = 1; j <= i; j++) {
            fprintf(fp, "%d*%d=%-4d", j, i, i*j);
        }
        fprintf(fp, "\n");
    }
    
    fclose(fp);
    return 0;
}
```

```bash
gcc -o 99table 99table.c
./99table
