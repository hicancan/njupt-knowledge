## 四、查询表达（每小题3分，共15分）

学生成绩管理系统中有三张表：

- S(学号，姓名，性别，年龄)
- C(课号, 课名, 学分, 先修课号)
- SC(学号, 课号, 成绩, 学期)

使用 SQL 语言实现以下查询要求，注意每小题限用一条 SQL 语句实现具体要求。

### 选择 1

题干：求 05061 学期学生数学课的最低分

```sql
SELECT MIN(成绩) AS 最低分
FROM SC
WHERE 课号 = '数学课' AND 学期 = '05061';
```

答案：见上。
参考解答：原件识别混乱，根据题意重构标准 SQL。原题中“如图 2”及后续乱码已修正为符合逻辑的 SQL 语句。

### 选择 2

题干：查找学习了学号为 S1 的学生选修的全部课程的学生姓名

```sql
SELECT DISTINCT S.姓名
FROM S, SC SC1
WHERE S.学号 = SC1.学号
AND NOT EXISTS (
    SELECT *
    FROM SC SC2
    WHERE SC2.学号 = 'S1'
    AND NOT EXISTS (
        SELECT *
        FROM SC SC3
        WHERE SC3.学号 = S.学号
        AND SC3.课号 = SC2.课号
    )
);
```

答案：见上。
参考解答：原件识别严重错误（如 `w H z R Z`），此处提供标准的“除法”运算 SQL 写法（双重否定）。若采用集合相减思路也可行，但双重否定更通用。

知识点：[码（候选码、主码、外码）](../../../topics/数据库系统/码.md)、[范式（1NF、2NF、3NF、BCNF）](../../../topics/数据库系统/范式.md)、[函数依赖（平凡/非平凡、完全/部分、传递函数依赖）](../../../topics/数据库系统/函数依赖.md)

## 五、判断每个模式的主码及所属的范式级别，并说明原因（每小题3分，共15分）

知识点：[自主存取控制（GRANT、REVOKE、数据库角色）](../../../topics/数据库系统/自主存取控制.md)

### 选择 1

题干：$R(X,Y,Z)$，$F = \{Y \rightarrow Z, XZ \rightarrow Y\}$

**分析：**
1. **求候选码**：
   - $X$ 不出现在任何依赖的右部，必为候选码成员。
   - $Z$ 不出现在任何依赖的左部（注意 $XZ \rightarrow Y$ 中 $Z$ 是部分），需结合其他属性。
   - 计算 $(X)^+$：$X \rightarrow ?$ 无直接依赖，无法推导。
   - 计算 $(XZ)^+$：$XZ \rightarrow Y$，得到 $\{X, Z, Y\}$。即 $XZ$ 是超码。
   - 检查 $X$ 是否为候选码？$X^+ = \{X\}$，不是。
   - 检查 $Z$ 是否为候选码？$Z^+ = \{Z\}$，不是。
   - 检查 $XY$？$(XY)^+ = \{X, Y, Z\}$（因 $Y \rightarrow Z$）。所以 $XY$ 也是候选码。
   - 实际上，通常此类题目考察最小覆盖。让我们重新严谨推导：
     - 属性分类：
       - L类（只出现在左边）：无
       - R类（只出现在右边）：$Z$ ($Y \rightarrow Z$)
       - LR类（两边都出现）：$X, Y$ ($XZ \rightarrow Y$, $Y \rightarrow Z$)
       - N类（都不出现）：无
     - 候选码必然包含 L类和 N类，这里没有。
     - 尝试组合：
       - $X$: $X^+ = X$
       - $Y$: $Y^+ = YZ$
       - $Z$: $Z^+ = Z$
       - $XY$: $(XY)^+ = XYZ$ (因为 $Y \rightarrow Z$)。所以 $XY$ 是候选码。
       - $XZ$: $(XZ)^+ = XYZ$ (因为 $XZ \rightarrow Y$)。所以 $XZ$ 是候选码。
       - $YZ$: $(YZ)^+ = YZ$
     - 候选码为 $XY$ 和 $XZ$。
   - **主属性**：$X, Y, Z$（所有属性都是主属性，因为它们都属于某个候选码）。
   - **非主属性**：无。

2. **范式判断**：
   - **1NF**：满足。
   - **2NF**：不存在非主属性，故自动满足 2NF（或者说没有非主属性对码的部分依赖）。
   - **3NF**：不存在非主属性，故自动满足 3NF。
   - **BCNF**：检查每一个决定因素是否包含码。
     - $Y \rightarrow Z$：$Y$ 不是码（$Y^+ = YZ \neq XYZ$）。所以不满足 BCNF。
   
   **结论**：
   - 主码：$XY, XZ$
   - 范式：3NF

答案：主码为 $XY$ 和 $XZ$；属于 3NF。
参考解答：原件识别为“不存在部分依赖... R(X,Y,Z) ∈ 2NF”，这是错误的。因为存在 $Y \rightarrow Z$，而 $Y$ 不是超码，所以不满足 BCNF。但由于没有非主属性，所以满足 3NF。

知识点：[范式（1NF、2NF、3NF、BCNF）](../../../topics/数据库系统/范式.md)、[函数依赖（平凡/非平凡、完全/部分、传递函数依赖）](../../../topics/数据库系统/函数依赖.md)、[码（候选码、主码、外码）](../../../topics/数据库系统/码.md)

### 选择 2

题干：$R(C,T,S,N,G)$，$F = \{C \rightarrow T, CS \rightarrow G, S \rightarrow N\}$

**分析：**
1. **求候选码**：
   - L类（只出现在左边）：$C, S$（$C$ 在 $C \rightarrow T$ 和 $CS \rightarrow G$ 左边；$S$ 在 $S \rightarrow N$ 左边。注意 $S$ 也出现在 $CS$ 中，但它是单独出现的左部属性之一，需看整体闭包）。
   - 更准确分类：
     - $C$: 出现在左边 ($C \rightarrow T, CS \rightarrow G$)，不出现在右边。-> L类
     - $S$: 出现在左边 ($S \rightarrow N, CS \rightarrow G$)，不出现在右边。-> L类
     - $T$: 出现在右边 ($C \rightarrow T$)。-> R类
     - $N$: 出现在右边 ($S \rightarrow N$)。-> R类
     - $G$: 出现在右边 ($CS \rightarrow G$)。-> R类
   - 候选码必须包含所有 L类属性：$C, S$。
   - 计算 $(CS)^+$：
     - $C \rightarrow T$
     - $S \rightarrow N$
     - $CS \rightarrow G$
     - 结果：$\{C, S, T, N, G\}$。
   - 所以，唯一候选码是 $CS$。

2. **范式判断**：
   - **主属性**：$C, S$。
   - **非主属性**：$T, N, G$。
   - **2NF 检查**（是否存在非主属性对码的部分函数依赖）：
     - 码是 $CS$。
     - 存在 $C \rightarrow T$。$T$ 是非主属性，$C$ 是码的真子集。这是**部分依赖**。
     - 存在 $S \rightarrow N$。$N$ 是非主属性，$S$ 是码的真子集。这是**部分依赖**。
     - 因此，不满足 2NF。
   - **结论**：属于 1NF。

答案：主码为 $CS$；属于 1NF。
参考解答：原件识别出“存在部分依赖”、“至强性C、S”、“E·INF”（可能是想写 1NF 或 2NF 的错误标记）。根据分析，因存在 $C \rightarrow T$ 和 $S \rightarrow N$，明显违反 2NF，故为 1NF。
