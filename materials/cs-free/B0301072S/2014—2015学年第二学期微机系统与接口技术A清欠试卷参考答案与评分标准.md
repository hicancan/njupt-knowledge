## 三、简答题（共 25 分，每题 5 分）

知识点：[真值数与补码的相互转换及补码计算](../../../topics/微机接口/zhenzhi-buma.md)、[标志寄存器中的状态标志位与控制标志位](../../../topics/微机接口/zhuangtai-biaozhi.md)

### 简答 1

（1）INTR 引脚有中断请求，系统没有 DMA 请求，没有 NMI 请求。

（2）CPU 当前指令执行完毕。

知识点：[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)

### 简答 2

一帧数据有四部分，分别是：

（1）起始位，1 位，逻辑 0；

（2）数据位，5～8 位，逻辑 0/1；

（3）奇偶校验位，0～1 位，逻辑 0/1；

（4）停止位，1～2 位，逻辑 1。

知识点：[接口电路的作用和基本功能](../../../topics/微机接口/jiekou-gongneng.md)、[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)

### 简答 3

接口电路中能与 CPU 直接进行信息交换的寄存器就叫端口。分为：数据端口、状态端口和控制端口。

知识点：[接口电路的作用和基本功能](../../../topics/微机接口/jiekou-gongneng.md)、[端口的概念与分类（数据端口、状态端口、控制端口）](../../../topics/微机接口/duankou-gainian.md)、[端口的编址方式（统一编址与独立编址）](../../../topics/微机接口/duankou-bianzhi.md)

### 简答 4

硬件中断和软件中断有四个不同：中断的引发方式不同；获取中断类型码的方式不同；CPU 响应的条件不同；中断处理程序的结束方式不同。

知识点：[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)、[总线的基本概念与分类（内部总线、系统总线、外部总线）](../../../topics/微机接口/zongxian-gainian.md)

### 简答 5

有 A、B、C 三个数据端口。A 口：方式 0、方式 1 和方式 2；B 口：方式 0 和方式 1；C 口：方式 0。

知识点：[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)、[最常用的I/O指令（IN、OUT的直接寻址与DX间址）](../../../topics/微机接口/io-zhiling.md)、[查询方式输入输出编程模式与流程](../../../topics/微机接口/chaxun-fangshi.md)

### 综合 1

段结构 2 分。

```asm
DATA SEGMENT USE16
ICOUNT DB 10
DATA ENDS

CODE SEGMENT USE16
ASSUME CS:CODE,DS:DATA
BEG:  MOV AX,DATA
      MOV DS,AX          ; 1 分
      CLI                ; 1 分
      CALL I8255
      CALL WRITE1C
      STI                ; 1 分
SCAN: MOV AH,1
      INT 16H            ; 1 分
      JZ SCAN
      MOV AH,4CH         ; 1 分
      INT 21H

SERVICE PROC             ; 6 分
      PUSHA
      PUSH DS
      MOV AX,DATA
      MOV DS,AX
      DEC ICOUNT
      JNZ EXIT
      MOV ICOUNT,10
      MOV AL,0
      MOV DX,231H
      OUT DX,AL
      MOV CX,2000
LAST: NOP
      LOOP LAST
      MOV AL,0FFH
      MOV DX,231H
      OUT DX,AL
EXIT: POP DS
      POPA
      IRET
SERVICE ENDP

I8255 PROC               ; 3 分
      PUSHA
      MOV AL,1XXXX00XB
      MOV DX,233H
      OUT DX,AL
      RET
I8255 ENDP

WRITE1C PROC             ; 3 分
      PUSH DS
      MOV AX,CODE
      MOV DS,AX
      MOV DX,OFFSET SERVICE
      MOV AX,251CH
      INT 21H
      POP DS
      RET
WRITE1C ENDP

CODE ENDS
END BEG
