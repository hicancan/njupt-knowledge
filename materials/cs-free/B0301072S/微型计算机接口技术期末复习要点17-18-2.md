### 选择 1

**知识点：补码与溢出判断**

1. **补码特性**
   - 没有 `-0` 的补码。在 8 位二进制中，`-128` 的补码是 `1000 0000`。
   - 补码的补码等于原码。
   - $(x+y)_{\text{补}} = x_{\text{补}} + y_{\text{补}}$。

2. **溢出概念与判断**
   - **定义**：运算结果超出了运算器所能表示的范围。
   - **CPU 判溢**：如加数与被加数的最高位相同，却与结果的最高位相异，则将溢出标志置为 1。
   - **程序员判溢**：
     - 若参与运算的数是**无符号数**，则判进位标志（CF），`CF=1` 表示出错。
     - 若参与运算的数是**有符号数**，则判溢出标志（OF），`OF=1` 表示出错。

3. **寻址与指令限制**
   - 变址寻址中，比例因子只能是 1、2、4、8 中的一个数。
   - 对于 `MOV` 指令：
     - 立即数不能直接送段寄存器。
     - 不允许在两个段寄存器之间传送数据。

**知识点：指令对标志位的影响总结**

| 指令类型 | 具体指令示例 | 影响标志位情况 |
| :--- | :--- | :--- |
| **传送指令** | MOV, LEA 等 | 不影响任何标志位 |
| **堆栈指令** | PUSH, POP | POPF 影响，其他不影响 |
| **算术指令** | 加法 (ADD/ADC) | 影响 6 个标志（INC 不影响 CF） |
| | 减法 (SUB/SBB) | 影响 6 个标志（DEC 不影响 CF） |
| | 求补 (NEG) | 影响 6 个标志 |
| | 比较 (CMP) | 影响 6 个标志 |
| | 乘法 (MUL/IMUL) | 影响 OF, CF 标志 |
| | 除法 (DIV/IDIV) | 不影响标志位 |
| | BCD 调整指令 | 影响特定标志位（见下文详细表） |
| **逻辑运算指令** | AND, OR, XOR, TEST | 影响 OF, SF, ZF, AF, PF, CF (除 NOT 外) |
| | 移位 (SHL, SAL, SHR, SAR) | 影响 OF, SF, ZF, AF, PF, CF (除 OF 外，OF 状态不定或置 0) |
| | 循环移位 (ROL, ROR, RCL, RCR) | 仅影响 OF, CF 标志 |
| **转移和调用指令** | JMP, CALL, RET | 不影响标志位 |

### 选择 3

**知识点：常用指令集详解**

#### 一、传送类指令
1. **通用传送**
   - **MOV**: 数据传送。
   - **LEA**: 地址传送（取有效地址）。
   - **XCHG**: 交换指令。
   - **XLAT**: 查表指令。查找数据段中的字节表，`EBX/BX` = 表头有效地址，`AL` = 元素对表头的偏移地址。
2. **堆栈指令**
   - 操作数必须是字或者双字。
   - `SP` 指向最后推入堆栈信息的所在单元。进栈时 `SP` 向低位移动（低地址方向延伸）。
   - 入栈顺序：先入高位后入低位；出栈顺序相反。
   - **PUSH**: 进栈。
   - **POP**: 出栈。
   - **PUSHF/POPF**: 标志寄存器出入栈。
   - **PUSHA/POPA**: 通用寄存器保护现场。

#### 二、算术运算指令
1. **加法**: `ADD`, `ADC`, `INC`（`INC` 将操作数视为无符号数，不影响 CF 标志）。
2. **减法**: `SUB`, `SBB`, `DEC`（同上，`DEC` 不影响 CF）。
3. **求补**: `NEG`（即求负数）。
4. **比较**: `CMP`（同 `SUB`，但不保存结果）。
5. **乘法**:
   - `MUL`: 无符号乘法。隐含目的操作数 `DX:AX`，源操作数不能是立即数。
   - `IMUL`: 带符号乘法。隐含目的操作数 `DX:AX`，源操作数不能是立即数。
6. **除法**:
   - `DIV`: 无符号除法。
   - `IDIV`: 有符号除法。
7. **BCD 码调整指令**:
   - **加法**:
     - `DAA`: 组合 BCD，影响除 OF 外的标志位。
     - `AAA`: 未组合 BCD，只影响 AF, CF 标志位。
   - **减法**:
     - `DAS`: 组合 BCD，影响除 OF 外的标志位。
     - `AAS`: 未组合 BCD，只影响 AF, CF 标志位。
   - **乘法**: `AAM` (未组合 BCD)，只影响 PF, SF, ZF 标志位。
   - **除法**: `AAD` (未组合 BCD)，只影响 PF, SF, ZF 标志位。

#### 三、逻辑运算指令
1. **基本逻辑**: `AND` (与), `OR` (或), `NOT` (非), `XOR` (异或), `TEST` (测试，执行 AND 运算但结果不送入目标操作数)。
2. **移位指令**: 详见教材 P101。

#### 四、转移和调用指令
1. **无条件转移**: `JMP`。
2. **条件转移** (括号内为转移条件):
   - **单个条件标志**: `JZ/JNZ`, `JS/JNS`, `JO/JNO`, `JP/JNP`, `JCXZ` (CX=0 转移)。
   - **无符号数大小比较** (前跟 CMP):
     - `JC` (小于) / `JNC` (不小于)
     - `JA` (大于) / `JNA` (不大于)
   - **有符号数大小比较** (前跟 CMP):
     - `JL` (小于) / `JLE` (不小于)
     - `JG` (大于) / `JGE` (不大于)
3. **循环控制转移**:
   - `LOOP`: CX ≠ 0 转移。
   - `LOOPZ` / `LOOPE`: CX ≠ 0 且 ZF=1 转移。
   - `LOOPNZ` / `LOOPNE`: CX ≠ 0 且 ZF=0 转移。
4. **子程序调用**: `CALL` / `RET` (注意子程序定义格式 `PROC`/`ENDP`)。
   - 调用时可以间接转移，如 `BX` 存储转移地址。
   - 调用时将 IP 存于堆栈段。
   - `RET EXP`: 带返回参数，释放多余的参数占用的堆栈空间。

#### 五、串操作指令
1. **串传送**: `DS:[SI]` → `ES:[DI]`。
   - 指令：`MOVSB` (字节), `MOVSW` (字), `MOVSD` (双字)。
   - 机制：传送一个元素后 CPU 自动修改 SI、DI。DF=0 时自增，DF=1 时自减。
   - 重复前缀：`REP MOVSB` 等，以 CX 为计数器。
2. **串装入**:
   - `LODSB`: `DS:[SI]` → AL
   - `LODSW`: `DS:[SI]` → AX
   - `LODSD`: `DS:[SI]` → EAX
   - 根据 DF 标志决定方向。
3. **串存储**:
   - `STOSB`: AL → `ES:[DI]` (1 单元)
   - `STOSW`: AX → `ES:[DI]` (2 单元)
   - `STOSD`: EAX → `ES:[DI]` (4 单元)
   - 同样有 `REP STOSB` 等重复前缀，CX 为计数器。
4. **串比较**:
   - 源串地址 → `DS:[SI]`，目串地址 → `ES:[DI]`。
   - 指令：`CMPSB` (字节), `CMPSW` (字), `CMPSD` (双字)。
   - 结果：相等则 ZF=1，不等 ZF=0。
   - 重复前缀：`REPE` (相等继续), `REPNE` (不等继续)。
5. **串搜索**:
   - 在 `ES:[DI]` 的目标区搜索关键字。
   - 关键字 → AL/AX/EAX。
   - 指令：`SCASB`, `SCASW`, `SCASD`。
   - 结果：找到关键字 ZF=1，否则 ZF=0。
   - 重复前缀：`REPE` / `REPNE`。

#### 六、处理机控制指令
1. **标志处理指令**:
   - `CLC`/`STC`: CF 置 0/1。
   - `CMC`: CF 取反。
   - `CLD`/`STD`: DF 置 0/1。
   - `CLI`/`STI`: IF 置 0/1。
2. **其他处理指令**:
   - `WAIT`: 处理器等待。
   - `ESC`: 处理器交权。
   - `LOCK`: 封锁总线。
   - `HLT`: 处理器暂停。
   - `NOP`: 空操作指令。

### 选择 4

**知识点：汇编程序结构与 DOS/BIOS 调用**

1. **完整的段定义格式**
   ```assembly
   .586
   DATA SEGMENT USE16
       ; 数据定义
   DATA ENDS
   CODE SEGMENT USE16
       ASSUME CS:CODE, DS:DATA
   START:
       MOV AX, DATA
       MOV DS, AX
       MOV AH, 4CH
       INT 21H
   CODE ENDS
   END START
   ```
   - **说明**:
     - `USE16`: 表示单元有效地址为 16 位。
     - `ORG`: 定位伪指令，通知汇编程序将下一条指令或数据存放在表达式给出的偏移地址。
     - `AT`: 表达式，表示段基址，常配合 `ORG` 使用。
     - 堆栈段链接属性应为 `STACK`，分类名为 `'STACK'` 且不能省略。EXE 文件必须有堆栈段。
     - COM 文件编程要求使用 `ORG` 将启动指令放在代码段偏移地址 `100H`。

2. **DOS 调用格式**
   - 格式：`MOV AH, 功能号` ... `INT 21H` ...
   - **常见功能**:
     - **01H**: 等待键入字符并回显，响应 Ctrl+C。出口：`AL`=ASCII 码。
     - **02H**: 显示一个字符，响应 Ctrl+C (破坏 AL)。入口：`DL`=ASCII 码。
     - **07H**: 等待键入字符无回显，不响应 Ctrl+C。出口：`AL`=ASCII 码。
     - **08H**: 等待键入字符无回显，响应 Ctrl+C。出口：`AL`=ASCII 码。
     - **09H**: 显示字符串，响应 Ctrl+C (破坏 AL)。入口：`DS:DX`=字符串首地址 (必须以 `$` 结束)。
     - **0AH**: 等待输入一串字符串到缓冲区。
       - 入口：`DS:DX`=缓冲区首地址。
       - 缓冲区格式：[最大容量] [实际接收长度] [接收内容...]

3. **BIOS 调用**
   - 格式：`MOV AH, 功能号` ... `INT n` (如 10H, 16H) ...
   - **键盘输入 (INT 16H)**:
     - **00H**: 读取字符，无回显，响应 Ctrl+C。出口：`AL`=ASCII 码。
     - **01H**: 查询缓冲区。出口：ZF=0(有)/1(无)。
   - **屏幕功能 (INT 10H)**:
     - **0EH**: 显示字符 (等价于 DOS 02H)。入口：`AL`=ASCII 码。
     - **13H**: 显示字符串。
       - 入口：`AL`=0~3, `BH`=页号, `BL`=属性字, `CX`=长度, `DH/DL`=起始行列, `ES:BP`=字符串首地址。

4. **宏指令**
   - 格式：
     ```assembly
     宏名 MACRO 哑元表
         LOCAL 标号表
         宏体
     ENDM
     ```
   - `LOCAL`: 局部标号，允许与源程序重名。
   - **区别**: 子程序由 CPU 完成调用；宏指令由汇编程序在汇编过程中展开。
   - 哑元是无值符号，调用时需对应实元表。

### 选择 5

**知识点：存储器与接口基础**

1. **总线分类**: 地址总线、数据总线、控制总线。
2. **存储器扩展计算**:
   - **例 1**: 若干片 128KB SRAM 构成 512KB 存储器。
     - 需要片数：$512 \div 128 = 4$ 片。
     - 若起始地址为 `10000H`，则最后一个单元地址为 `8FFFFH` (512KB = $2^{19}$ 字节，$10000H + 2^{19} - 1 = 8FFFFH$)。
   - **例 2**: 用 32K×8 芯片构成 `A0000H` 至 `EFFFFH` 空间。
     - 总容量：`EFFFFH` - `A0000H` + 1 = `50000H` = 320KB。
     - 所需片数：$320 \text{KB} \div 32 \text{KB} = 10$ 片。
3. **接口电路功能**:
   - 数据缓冲、联络、寻址、数据转换、中断管理。
4. **端口定义**: 接口电路中能与 CPU 交换信息的寄存器。
   - 类型：数据端口 (必选)、状态端口、控制端口。
5. **端口编址方式**:
   - **统一编址**: I/O 端口作为存储器单元看待。
   - **独立编址**: PC 机采用，端口地址不分段，不占用存储空间，需专用 I/O 指令。

### 选择 6

**知识点：I/O 指令与数据传输方式**

1. **I/O 指令**:
   - 可用寄存器：`AL`, `AX`, `EAX`。
   - **直接寻址** (端口地址 8 位):
     - `IN AL, PORT` (PORT 可为立即数)
     - `OUT PORT, AL`
   - **DX 间址** (端口地址 16 位，必须在 DX 中，不可用 `[]`):
     - `IN AL, DX`
     - `OUT DX, AL`
2. **微机系统与外设交换信息的方式**:
   - **无条件传送**: 假设外设已准备好。
   - **查询方式**: 确认具备条件后才传送。
     - 示例代码:
       ```assembly
       RSCAN: MOV DX, 200H
              IN AL, DX
              TEST AL, 80H
              JZ RSCAN
              MOV DX, 201H
              IN AL, DX
       ```
   - **中断方式**:
     - 特点：外设没准备好时 CPU 可执行其他任务；外设准备好后主动请求；CPU 暂停当前程序转去服务程序；服务完自动返回。
   - **DMA 方式**:
     - 特点：硬件实现外设与内存直接交换，不通过 CPU，速度快；速度上限取决于存储器工作速度。

### 选择 7

**知识点：8254 可编程定时器/计数器**

1. **内部结构**: 三个 16 位计数器。CLK 下降沿计数减 1。
   - 计数公式：$N = f_{clk} / f_{out}$，范围 $0 \sim 65536$。
2. **端口地址**: 最后两位 `A1A0` 选择寄存器。
   - `00`: 计数器 0
   - `01`: 计数器 1
   - `10`: 计数器 2
   - `11`: 控制字寄存器
3. **工作方式**:
   - **启动方式**: 软件启动 (GATE=1) 或 硬件启动 (GATE: 0→1)。
   - **方式 2 (分频器/脉冲发生器)**:
     - 软件启动，输出周期脉冲。
     - 初值自动重装：计数到 1 时 OUT 变低，经一个 CLK 周期变高，初值重装。
   - **方式 3 (方波发生器)**:
     - 软件启动，自动重装。
     - 初值为偶数：每 CLK 减 2，减到 0 变极性，输出 1:1 方波，脉宽均为 $N/2$。
     - 初值为奇数：正脉宽 $T(CLK) \times (N+1)/2$，负脉宽 $T(CLK) \times (N-1)/2$。
     - 实际装入初值 = 写入初值 - 1。
4. **方式控制字格式**:
   - **D7 D6 (计数器选择)**: 00(0#), 01(1#), 10(2#), 11(读回控制字)。
   - **D5 D4 (读写方式)**:
     - 00: 锁存当前值。
     - 01: 只写低 8 位。
     - 10: 只写高 8 位。
     - 11: 先低后高。
   - **D3 D2 D1 (工作方式)**:
     - 000: 方式 0
     - 001: 方式 1
     - X10: 方式 2
     - X11: 方式 3
     - 100: 方式 4
     - 101: 方式 5
   - **D0 (数值选择)**: 0=二进制，1=BCD。

### 选择 8

**知识点：中断系统**

1. **中断源**:
   - **外部中断 (硬件)**:
     - `INTR`: 可屏蔽硬件中断。
     - `NMI`: 非屏蔽硬件中断。
   - **内部中断 (软件)**: BIOS 中断、DOS 中断。
2. **中断向量**:
   - 前 2 字节：偏移地址 (IP)。
   - 后 2 字节：段基址 (CS)。
   - **中断向量表**: 位于系统存储器最低 1KB (地址 $00000H \sim 003FFH$)。每个向量 4 字节，共 256 个 ($4 \times n \sim 4 \times n+3$)。
3. **写入中断向量方法**:
   - **方法 1**: 自己编写程序直接修改向量表。
   - **方法 2**: DOS 功能调用。
     - **35H (读取)**: `AH=35H`, `AL`=类型码。出口：`ES:BX`=向量。
     - **25H (写入)**: `AH=25H`, `AL`=类型码。入口：`DS:DX`=新向量 (`DS`=段基址, `DX`=偏移)。
4. **中断处理细节**:
   - 非屏蔽中断：CPU 自动产生类型码 2。
   - 可屏蔽中断：开中断状态下，由中断控制器送入类型码。
   - 返回指令：`IRET`。
5. **中断系统基本功能**:
   - 屏蔽/开放控制。
   - 中断判优。
   - 中断嵌套。
   - 自动转入处理及返回断点。

### 传输速率与串行异步通信

1. 传输速率：并行 > 串行同步 > 串行异步。

2. 串行异步通信时数据是从低位到高位传输的。串行异步通信格式（PPT 第 7 页）：无数据传送时，通信线长时间为逻辑 1。

3. 数据信号速率：每秒传送信号的个数（波特率）。数据通信速率：每秒传送二进制比特的个数（比特率）。当采用二进制信号传输时二者相等。

4. 异步通信中，收发双方必须约定通信速率与数据帧格式，且必须一致。

5. RS232 采用负逻辑电平，在串行接口芯片与 RS232 之间存在电平转换，然后再传输至 MODEM。转换芯片：MC1488（发送方）、MC1489（接收方）。

### 8250 串行异步通信接口芯片

能实现数据串并转换、全双工异步通信，内部有 MODEM 控制器可直接和 MODEM 相连。PC 有两个串口：主串口 COM1（3FXH）、辅串口 COM2（2FXH）。

#### 一、10 个寄存器

（1）发送保持寄存器：只有它空闲时，CPU 才能写入下一个数据。

（2）接收缓冲寄存器：只有它满的时候，CPU 才能用 IN 读取内容。

（3）通信线状态寄存器：提供数据传输状态信息。

- D0：接收数据准备好（接收缓冲器满）标志位，D0=1 表示已接收一帧完整数据并放入接收缓冲器。
- D1~D4：错误标志，只要有一位为 1，在中断允许的情况下，8250 内部将产生“接收数据错”中断，读取状态寄存器后自动复位。
- D5：发送保持寄存器空闲标志位，D5=1 表示它空闲，CPU 可以写入新数据。
- D6：发送移位寄存器空闲标志位，D6=1 表示一帧数据发送完毕（数据由发送保持寄存器移入发送移位寄存器时置 0）。
- D7：恒为 0。

只有当 D0=1 时，CPU 才能读数；只有当 D5=1 或 D6=1 时（一般只用 D5），CPU 才能写数据。

寄存器各位置 1 时，相应的中断允许位也为 1：

- D0=1：产生接收中断
- D5=1：产生发送中断
- D1~D4=1：产生“字符错”中断

（4）中断允许寄存器：

- D0=1：允许接收到一帧数据后，内部提出“接收中断请求”
- D1=1：允许发送保持寄存器空时，提出“发送中断请求”
- D2=1：允许接收出错时，提出“接收数据错中断请求”
- D3=1：允许 MODEM 状态改变时，提出“MODEM 中断请求”
- D4~D7 恒为 0

优先级：接收数据错 > 接收中断 > 发送中断 > MODEM 中断。

（5）中断识别寄存器：识别是哪个中断源引起的中断。转入中断服务程序之后，读取中断识别寄存器的内容进行判断，然后再转入相应的处理程序。

- D0：中断指示位，D0=1 表示无中断待处理（注意！！！）
- D2 D1：中断识别码
  - 00：MODEM 状态改变
  - 01：发送保持器空
  - 10：接收数据准备好
  - 11：接收数据错
- D3~D7 恒为 0，可用于检测 8250 是否存在。

（6）MODEM 控制寄存器：

- D0&D1=1：使 DTR&RTS=0，为 8250 收发作准备
- D2=0：PC 机用不着
- D3=1：8250 能送出中断请求
- D4：通常置 0，设置 8250 工作在正常收发方式；若置 1，则工作在内环自检方式（外环检测是人为将 2、3 端口接起，D4=0）
- D5~D7 恒为 0

8250 中断方式编程措施：

1）设置中断允许寄存器相应位为 1

2）MODEM 控制寄存器 D3 置 1

3）8259 相应屏蔽字置 0（主 8259 的 IR3、IR4）

4）写入中断向量

5）STI

（7）除数寄存器（高/低）：设置通信速率。只有当通信线控制寄存器的 D7=1，才可访问除数寄存器（见 8 号寄存器）。通信速率查表。

（8）通信线控制寄存器：设置数据格式。

- D7：寻址位，为 1 访问除数寄存器，为 0 访问合用端口地址的非除数寄存器
- D6：中止位设置，为 1 输出长时间中止信号 0，为 0 正常通信，一般为 0
- D5 D4 D3：校验位选择
  - 000：无校验位
  - 001：奇校验
  - 011：偶校验
  - 101：校验位恒为 1
  - 111：校验位恒为 0
- D2：停止位选择
  - 0：1 位
  - 1（D1 D0=00）：1.5 位
  - 1（D1 D0≠00）：2 位
- D1 D0：数据位选择
  - 00：5 位
  - 01：6 位
  - 10：7 位
  - 11：8 位

（9）MODEM 状态寄存器：反映 8250 与通信设备之间联络信号的当前状态以及变化情况，编程用不到。

#### 二、初始化编程

（1）设置通信线控制寄存器寻址位为 1。

（2）将除数高/低 8 位写入除数寄存器，确定通信速率。

（3）将 D7=0 的控制字写入通信线控制寄存器，确定数据格式。

（4）设置中断允许寄存器。

（5）设置 MODEM 控制寄存器：

- 中断方式：D3=1
- 查询方式：D3=0
- 内环自检：D4=1（应采用查询方式）
- 正常通信：D4=0

### 8255A 并行接口芯片

#### （1）组成

分为 A、B 两组：

- PA7~PA0：A 组 A 口
- PC7~PC4：A 组 C 口上半部
- PB7~PB0：B 组 B 口
- PC3~PC0：B 组 C 口下半部

A 口地址：60H；B 口地址：61H；C 口地址：62H；控制口地址：63H。

#### （2）工作方式

- 方式 0：基本型入/出，适用于 A、B、C 口
- 方式 1：选通型入/出，适用于 A、B 口
- 方式 2：双向传输，适用于 A 口

A 口：方式 0、1、2；B 口：方式 0、1；C 口：方式 0。

1）选通型

①选通型输入

A 口定义为选通型时，端口和外设有数据线 PA7~PA0、联络线 IBF（A）和 STB（A）。

- IBF：输入缓冲器满，状态线
- STB：选通信号输入

当 STB 为一个负脉冲时完成数据锁存，通过 IBF 状态告知 CPU 可读。只有 IBF 为 0 时外设才能写入数据，为 1 时通知外设不要再送数据。

②选通型输出

B 口定义为选通型输出时，端口和外设有数据线 PB7~PB0、联络线 OBF（B）、ACK（B）。

- OBF：输出缓冲器满，状态线
- ACK：确认应答

OBF 为负脉冲时，通知外设输出缓冲器已满。外设取走数据后，使 ACK 为负脉冲，告知 CPU 数据已取走。

2）基本型（即无联络信号）

①基本型输入：B 口定义为基本型输入时，对 B 口执行 IN 指令，输入数据→CPU。

②基本型输出：A 口定义为基本型输出时，对 A 口执行 OUT 指令，把数据锁存在端口。

1）控制字（必须写入控制口）

①方式选择控制字 D7=1

A 组：

- D6 D5：方式选择
  - 00：方式 0
  - 01：方式 1
  - 1X：方式 2
- D4：A 口 1：输入 0：输出
- D3：C 口 PC7~PC4 1：输入 0：输出

B 组：

- D2：方式选择 0：方式 0 1：方式 1
- D1：B 口 1：输入 0：输出
- D0：C 口 PC3~PC0 1：输入 0：输出

注：C 口上下半部可以选择不同的入/出（都是方式 0，也因此无需控制 C 口方式）。

②C 口按位置 0/1 命令字 D7=0

- D6 D5 D4 未用
- D3 D2 D1：位选择
  - 0 0 0：PC0
  - 0 0 1：PC1
  - 0 1 0：PC2
  - 0 1 1：PC3
  - 1 0 0：PC4
  - 1 0 1：PC5
  - 1 1 0：PC6
  - 1 1 1：PC7
- D0：PCX 置位 1：PCX 置 1 0：PCX 置 0

2）初始化编程步骤

方式选择命令字→控制口，选择某一口的工作方式；根据需要，C 口置 0/1 命令字→控制口，禁止/允许某一口提出中断。

#### （3）时序

一、方式 1 输入

1）A 口选通型输入

①方式字 B0H 写入控制口后，A 口工作在选通型输入：

- PA7~PA0：输入线
- PC4：自动定义为入线，STB（A）
- PC5：自动定义为出线，IBF（A）
- PC3：自动定义为出线，INTR（A）

它们不再受方式字 D3、D0 控制；PC7、PC6 空闲，受方式字 D3 控制。

②中断管理

INTE（A）为 A 口中断允许触发器：

- C 口置 0/1 命令字使 PC4=1 时，INTE（A）=1，允许 A 口中断
- C 口置 0/1 命令字使 PC4=0 时，INTE（A）=0，禁止 A 口中断

当 INTE（A）=1 后，若 IBF（A）=1，则 A 口提出中断请求。

2）B 口选通型输入

①方式字 86H 写入控制口后，B 口工作在选通型输入：

- PB7~PB0：输入线
- PC2：自动定义为入线，STB（B）
- PC1：自动定义为出线，IBF（B）
- PC0：自动定义为出线，INTR（B）

②中断管理

INTE（B）为 B 口中断允许触发器：C 口置 0/1 命令字使 PC2 控制 INTE（B）为 0/1。

方式 1 输入时，CPU 与 8255 信息交换的方式：可用中断方式、查询方式（查询 IBF）。

二、方式 1 输出

1）A 口方式 1 输出

①方式字 A0H 写入控制字：

- PA7~PA0：输出线
- PC6：自动定义为入线，ACK（A）
- PC7：自动定义为出线，OBF（A）
- PC3：自动定义为出线，INTR（A）

②中断管理

C 口置 0/1 命令字使 PC6 控制 INTE（A）。INTE（A）=1 后，若 OBF（A）=1，则 A 口提出中断。

2）B 口方式 1 输出

①方式字 84H：

- PB7~PB0：输出线
- PC2：自动定义为入线，ACK（B）
- PC1：自动定义为出线，OBF（B）
- PC0：自动定义为出线，INTR（B）

C 口置 0/1 命令字使 PC2 控制 INTE（B）。INTE（B）=1 后，若 OBF=1，则 INTR（B）=1，B 口提出中断。

方式 1 输出时，查询 OBF=1（不满）时可送下一个。

三、双向方式

①控制字：11XXXD1 D1 D0

PA7~0 是双向的数据线，可以分时完成数据输入/出：

- PC3 自动定义为出线：INTRA
- PC7 自动定义为出线：OBFA
- PC6 自动定义为入线：ACKA
- PC4 自动定义为入线：STBA
- PC5 自动定义为出线：IBFA
- PC2~0 空闲

②中断管理

INTE1 为双向方式中的输出中断允许触发器：

- 用 C 口置 0/1 命令字使 PC6 置 0，则 INTE1=0
- 用 C 口置 0/1 命令字使 PC6 置 1，则 INTE1=1

INTE1 置 1 后，若 OBFA=1，则 INTRA=1，提出中断请求。

INTE2 为双向方式（方式 2）下的输入中断允许触发器，可通过 C 口置 0/1 命令字设置为 0 或 1；置 1 后，当 IBFA=1 时 INTRA=1，向 CPU 提出中断请求。CPU 与 8255 交换信息时，方式 0 用无条件传送，方式 1、2 用查询或中断方式；8255 不能回送中断向量，须由 8259 IR1 管理中断。中断允许触发器与引脚的对应关系为：A 口方式 1 入 INTEA--PC4、A 口方式 1 出 INTEA--PC6、B 口方式 1 入 INTEB--PC2、B 口方式 1 出 INTEB--PC2、A 口双向入 INTE1--PC4、A 口双向出 INTE2--PC6。初始化编程分两步：方式选择命令字送控制口，方式 1、2 时再送允许中断命令字到控制口。
INTE2 为双向方式（方式 2）下的输入中断允许触发器，可通过 C 口置 0/1 命令字设置为 0 或 1；置 1 后，当 IBFA=1 时 INTRA=1，向 CPU 提出中断请求。CPU 与 8255 交换信息时，方式 0 用无条件传送，方式 1、2 用查询或中断方式；8255 不能回送中断向量，须由 8259 IR1 管理中断。中断允许触发器与引脚的对应关系为：A 口方式 1 入 INTEA--PC4、A 口方式 1 出 INTEA--PC6、B 口方式 1 入 INTEB--PC2、B 口方式 1 出 INTEB--PC2、A 口双向入 INTE1--PC4、A 口双向出 INTE2--PC6。初始化编程分两步：方式选择命令字送控制口，方式 1、2 时再送允许中断命令字到控制口。
