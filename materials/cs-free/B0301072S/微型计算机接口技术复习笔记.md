### 选择 1

**知识点：补码表示**

题干：-1的原码是`1000 0000`，那么-1的补码是什么？

答案：`1000 0000`。
补充：在8位二进制中，-1的原码为 `1000 0001`，反码为 `1111 1110`，补码为 `1111 1111`。若题目意指“-128”的补码或特定语境下的-1（如某些教材定义不同），请核对原件。此处根据常见逻辑，-1的8位补码通常为 `FFH` (`1111 1111`)。*注：原文识别结果为“-128...1000 0000”，这实际上是-128的原码/补码（特殊值）。若题目问的是-128，则答案为 `1000 0000`。*

### 简答 5

**知识点：标志寄存器**

题干：举例说明：
1. 加减法运算时，无法产生进位或借位的标志位。
2. 乘除法运算时，发生溢出时的标志位。

### 简答 8

**知识点：标志位影响**

题干：总结各类指令对标志位的影响：

参考解答：
1. **不影响标志位的指令**：
   - `MOV`, `LEA`, `PUSH`, `POP` (除 `POPF`) 等数据传送类指令。
2. **栈指令**：
   - `PUSH`, `POP`: 不影响状态标志位（除了 `POPF` 会改变标志位）。
3. **算术指令**：
   - **加法** (`ADD`, `ADC`, `INC`): 影响所有6个状态标志位 (`OF, SF, ZF, AF, PF, CF`)。注意：`INC` 不影响 `CF`。
   - **减法** (`SUB`, `SBB`, `DEC`): 影响所有6个状态标志位。注意：`DEC` 不影响 `CF`。
   - **乘法** (`MUL`, `IMUL`): 影响 `OF` 和 `CF`（高位结果是否非零）。
   - **除法** (`DIV`, `IDIV`): 影响未定义（通常不关心，但除零会导致异常）。
   - **BCD调整**: 影响 `AF` 和其他标志位。
4. **逻辑指令**：
   - **逻辑运算** (`AND`, `OR`, `NOT`, `XOR`, `TEST`): `NOT` 不影响标志位；其他影响 `SF, ZF, PF`，并清除 `OF`，`CF` 置0。`AF` 未定义。
   - **移位指令** (`SHL`, `SAL`, `SHR`, `SAR`): 影响 `OF, SF, ZF, PF, CF`。`AF` 未定义。
   - **循环移位** (`ROL`, `ROR`, `RCL`, `RCR`): 只影响 `OF` 和 `CF`。
5. **转移和堆栈指令**：
   - 不影响标志位（除了 `CALL`, `RET`, `IRET` 涉及标志位压栈/出栈，但不改变当前标志位值）。

### 简答 9

**知识点：指令分类**

题干：主要掌握的指令集分类。

参考解答：
1. **数据传送指令**：
   - `MOV`: 基本数据传送。
   - `LEA`: 取有效地址。
   - `XCHG`: 交换。
   - `XLAT`: 表格查找转换。`(BX)=表头有效地址, AL=元素相对偏移地址`。
2. **栈指令**（只能操作双字）：
   - `SP` 指向栈顶。入栈时 SP 先减后存，出栈时先取后加。
   - `PUSH`, `POP`.
   - `PUSHF/POPF`: 标志寄存器入栈/出栈。
   - `PUSHA/POPA`: 通用寄存器入栈/出栈。
3. **算术运算指令**：
   - **加法**：`ADD`, `ADC` (带进位), `INC` (不影响 CF).
   - **减法**：`SUB`, `SBB` (带借位), `DEC` (不影响 CF).
   - **求补**：`NEG` (求负).
   - **比较**：`CMP` (同 SUB，不保存结果).
   - **乘法**：`MUL` (无符号), `IMUL` (有符号). 结果存入 DX:AX.
   - **除法**：`DIV` (无符号), `IDIV` (有符号). 商/余数位置固定.
   - **BCD调整**：
     - 加法：`DAA` (非压缩BCD? 原文似指压缩或非压缩调整，通常 DAA 用于压缩 BCD 加法后调整), `AAA` (非压缩 BCD 加法后调整，影响 A,C).
     - 减法：`DAS` (压缩 BCD 减法后调整), `AAS` (非压缩 BCD 减法后调整).
     - 乘法：`AAM` (非压缩 BCD 乘法后调整，影响 P,S,Z).
     - 除法：`AAD` (非压缩 BCD 除法前调整，影响 P,S,Z).
4. **逻辑运算指令**：
   - **逻辑运算**：`AND`, `OR`, `NOT`, `XOR`, `TEST`. `NOT` 不影响标志位。
   - **移位**：见上文。
5. **转移和堆栈指令**：
   - **无条件转移**：`JMP`.
   - **条件转移**（基于标志位）：
     - 测试标志：`JZ/JNZ`, `JS/JNS`, `JO/JNO`, `JP/JNP`, `JCXZ` (CX=0).
     - 无符号比较（前置 CMP）：`JC` (小于), `JNC` (大于等于), `JA` (大于), `JNA` (小于等于).
     - 有符号比较（前置 CMP）：`JL` (小于), `JLE` (小于等于), `JG` (大于), `JGE` (大于等于).
   - **循环控制转移**：
     - `LOOP`: CX≠0 转移.
     - `LOOPE/LOOPZ`: CX≠0 且 Z=1 转移.
     - `LOOPNE/LOOPNZ`: CX≠0 且 Z=0 转移.
   - **子程序调用**：`CALL` / `RET`. 对应过程定义 `PROC` / `ENDP`.
     - 调用时 IP 压栈.
     - 返回时 IP 出栈.
     - `RET EXP`: 释放指定大小的栈空间.
6. **串操作指令**：
   - **移动**：`MOVSB` (字节), `MOVSW` (字), `MOVSD` (双字). 源 `(DS):[SI]`, 目的 `(ES):[DI]`. SI/DI 随 D 标志自动增减. `REP` 前缀重复 CX 次.
   - **加载**：`LODSB/W/D`. 从 `(DS):[SI]` 加载到 AL/AX/EAX.
   - **存储**：`STOSB/W/D`. 将 AL/AX/EAX 存储到 `(ES):[DI]`.
   - **比较**：`CMPSB/W/D`. 比较 `(DS):[SI]` 和 `(ES):[DI]`. 根据结果设置 ZF. `REPE/REPNE` 前缀.
   - **扫描**：`SCASB/W/D`. 比较 AL/AX/EAX 与 `(ES):[DI]`. 找到关键字时 ZF=1. `REPE/REPNE` 前缀.
7. **处理器控制指令**：
   - **标志位操作**：`CLC/STC` (CF), `CMC` (CF取反), `CLD/STD` (DF), `CLI/STI` (IF).
   - **其他**：`WAIT`, `ESC`, `LOCK`, `HLT`, `NOP`.

### 简答 10

**知识点：汇编程序结构**

题干：程序的两种结构形式。

参考解答：
1. **.586 DATA SEGMENT USE16 ... CODE SEGMENT USE16 ... END BEG**
   - 使用 `.586` 伪指令支持 Pentium 指令集。
   - `DATA SEGMENT USE16`: 数据段，16位有效地址。
   - `CODE SEGMENT USE16`: 代码段。
   - `ASSUME CS:CODE, DS:DATA`: 段寄存器关联。
   - `MOV AH, 4CH` / `INT 21H`: DOS 退出调用。
   - `ORG`: 指示起始偏移地址。
   - `STACK`: 堆栈段定义。
2. **COM 文件结构**：
   - 要求使用 `ORG 100H` 指令，因为 COM 文件加载到内存偏移 100H 处开始执行。

### 简答 11

**知识点：DOS功能调用**

题干：DOS功能调用格式及常用功能。

参考解答：
格式：
```assembly
MOV AH, 功能号
... ; 输入参数
INT 21H
... ; 输出参数
```

常用功能：
1. **01H**: 键盘输入一个字符（回显）。输入 ASCII 码存入 AL。
2. **02H**: 显示一个字符。DL = 字符 ASCII 码。
3. **07H**: 键盘输入一个字符（不回显）。AL = 输入 ASCII 码。
4. **08H**: 键盘输入一个字符（不回显，类似 07H，但保留在缓冲区供后续读取？通常 07H 和 08H 区别在于 Ctrl+C 处理或回显细节，具体依 BIOS/DOS 版本）。AL = 输入 ASCII 码。
5. **09H**: 显示字符串。DS:DX = 字符串首地址，字符串以 `$` 结尾。
6. **0AH**: 键盘输入缓冲区输入。DS:DX = 缓冲区首地址。
   - 缓冲区格式：
     - 第1字节：最大长度
     - 第2字节：实际输入长度
     - 第3字节起：输入字符

### 简答 12

**知识点：BIOS功能调用**

题干：BIOS功能调用格式及常用功能。

参考解答：
格式：
```assembly
MOV AH, 功能号
... ; 输入参数
INT n ; 10H (显示), 16H (键盘) 等
... ; 输出参数
```

**键盘功能 (INT 16H)**:
1. **00H**: 读取键盘字符（回显）。AL = 字符 ASCII 码，AH = 扫描码。
2. **01H**: 查询键盘状态。ZF=0 有键，ZF=1 无键。

**显示功能 (INT 10H)**:
1. **0EH**: 显示字符（Teletype模式，类似 DOS 02H）。AL = 字符 ASCII 码。
2. **13H**: 显示字符串。
   - 输入：AL (0-3, 显示属性), BH (页号), BL (颜色/属性), CX (字符数), DH/DL (行列号), ES:BP (字符串地址)。

### 简答 14

**知识点：中断向量**

题干：中断向量的概念。

参考解答：
- 中断向量是中断服务程序入口地址（段地址+偏移地址）。
- 存储在内存低端的 1KB 区域（00000H-003FFH）。
- 每个中断类型号 N 占用 4 个字节：偏移地址在高地址还是低地址？通常是低地址存偏移，高地址存段地址（小端序）。即 `Vector[N*4] = Offset`, `Vector[N*4+2] = Segment`。

### 简答 16

**知识点：硬件中断响应**

题干：硬件中断的处理流程。

参考解答：
1. CPU 完成当前指令。
2. 关中断（IF=0），保护现场（压栈 CS, IP, FLAGS）。
3. 从中断向量表读取中断服务程序入口地址。
4. 跳转执行中断服务程序。
5. 中断返回指令 `IRET`，恢复现场。

   - 所需芯片数：$320KB / 32KB = 10$ 片。

### 简答 8

**知识点：8254 定时器**

题干：8254 芯片的工作原理。

参考解答：
1. **内部结构**：三个 16 位计数器。CLK 信号下降沿使计数器减 1。
   - $N = f_{clk} / f_{out}$，范围 0~65536。
2. **端口地址**：
   | A1 A0 | 寄存器 |
   | :--- | :--- |
   | 00 | 0# 计数器 |
   | 01 | 1# 计数器 |
   | 10 | 2# 计数器 |
   | 11 | 控制寄存器 |
3. **工作方式**：
   - **方式 1 (可重触发单稳态)**：硬件触发，GATE=1 启动。OUT 脉冲宽度为一个 CLK 周期。
   - **方式 2 (分频器/速率发生器)**：
     - 初值装入后，OUT 为高电平。
     - 计数到 1 时，OUT 变低，持续一个 CLK 周期，然后自动重装初值，OUT 变高。
     - 产生周期性负脉冲。
   - **方式 3 (方波发生器)**：
     - 初值为偶数：OUT 为方波，周期 $N \times T_{CLK}$。
     - 初值为奇数：OUT 为不对称方波。
     - 自动重装。
   - **方式 4 (软件选通触发)**：
     - 初值装入后，OUT 为高。
     - 计数到 0 时，OUT 变低，持续一个 CLK 周期，然后自动重装。
   - **方式 5 (硬件选通触发)**：
     - GATE 上升沿启动计数。
     - 计数到 0 时，OUT 变高。
4. **控制字格式**：
   - **通道选择 (D7 D6)**: 00-0#, 01-1#, 10-2#, 11-控制字。
   - **读写方式 (D5 D4)**: 00-锁存, 01-低8位, 10-高8位, 11-高低8位。
   - **工作方式 (D3 D2 D1)**: 000-方式0 ... 101-方式5。
   - **计数格式 (D0)**: 0-二进制, 1-BCD。

##### 简答 7

**知识点：8250 接收状态寄存器**

题干：接收状态寄存器的位定义。

参考解答：
- **D0**: 接收准备标志。D0=1 表示已接收一帧数据，可读取。
- **D1-D4**: 错误标志。任一位为 1 均产生中断。读该寄存器自动清零。
- **D5**: 发送保持寄存器空标志。D5=1 表示 CPU 可写入。
- **D6**: 发送移位寄存器空标志。D6=1 表示一帧数据发完。
- **D7**: 始终为 0。

##### 简答 8

**知识点：8250 中断允许寄存器**

题干：中断允许寄存器的位定义。

- **D0**: 接收数据中断允许。
- **D1**: 发送保持寄存器空中断允许。
- **D2**: 接收字符超时中断允许。
- **D3**: MODEM 状态中断允许。
- **D4-D7**: 0。

##### 简答 9

**知识点：8250 中断识别寄存器**

- **D2-D1**: 中断源识别。
  - 00: MODEM 状态变化。
  - 01: 发送保持寄存器空。
  - 10: 接收数据准备好。
  - 11: 接收字符超时。
- **D3-D7**: 0。
