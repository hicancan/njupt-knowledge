8253 的计数器 1 端口地址由 A1A0 决定：  
- 计数器 0：A1A0 = 00  
- 计数器 1：A1A0 = 01  
- 计数器 2：A1A0 = 10

**其他选项不对的原因**  
- A：82H 最低两位是 `10`，对应计数器 2，不是计数器 1。  
- B：83H 无误，但题目要求选计数器 1，没有排除它的理由，这个就是正确选项。  
- D：84H 最低两位是 `00`，对应计数器 0，不对。

### 选择 2

B

参考解答：**结论**  
选择 **B**。

**推理过程**  
设 EPROM 芯片容量为 $2^n \times 8$ 位（$n$ 为地址线条数），则其内部地址线为 $n$ 条。  
需扩展的存储系统容量为 $2^{16} \times 8$ 位，即共有 16 条系统地址线。  
字扩展时，高位地址线用于片选，剩余低位地址线直接连到所有芯片的片内地址。  
若系统地址线为 16，片内地址线为 $n$，则片选地址线数为 $16 - n$。  
已知译码器输出端接 8 个芯片的 $\overline{CE}$，即芯片数为 $8 = 2^3$，故片选地址线数为 3。  
因此 $16 - n = 3$，得 $n = 13$，即 EPROM 芯片内部地址线为 13 条，容量为 $2^{13} \times 8$ 位 = 8K×8 位。

**选项分析**  
- **A**：4K×8 位片内地址 12 条，片选需 4 条，译码器需接 16 片，与题设 8 片矛盾。  
- **B**：8K×8 位符合上述计算。  
- **C**：16K×8 位片内地址 14 条，片选需 2 条，对应 4 片，不符。  
- **D**：8K×4 位需位扩展后再字扩展，组合后片选要求不同，不符。

参考解答：这三个数值相等，分别表示同一数值的二进制、十进制和 BCD 码形式。

- **二进制 $10010011_2$**：按权展开计算 $1 \times 2^7 + 0 \times 2^6 + 0 \times 2^5 + 1 \times 2^4 + 0 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 128 + 16 + 2 + 1 = 147_{10}$。
- **十进制 $93$**：若题目本意为三数相等，则此处应为 $147$；若 $93$ 为独立给定值，则 $93_{10} = 01011101_2$，与第一个数不等。但结合第三项 BCD 码验证：$0001\,0100\,0111_{\text{BCD}}$ 按每 4 位一组对应十进制数字 $1$、$4$、$7$，即 $147_{10}$，与二进制 $10010011_2$ 完全一致。

## 三、简答题

参考解答：**结论**：无条件、查询、中断、DMA

**推理过程**：
微型计算机与外设之间的数据传送方式主要依据 CPU 参与程度及控制机制的不同，分为以下四种基本类型：

1.  **无条件传送（同步传送）**：CPU 不检查外设状态，直接进行读写。适用于简单、慢速且状态固定的外设。
2.  **程序查询方式**：CPU 通过程序不断读取状态寄存器，判断外设是否就绪。若未就绪则循环等待，直至就绪才进行数据传送。CPU 效率较低。
3.  **中断传送方式**：外设在准备好后向 CPU 发出中断请求，CPU 暂停当前程序，转去执行中断服务程序进行数据传送。实现了 CPU 与外设的并行工作，提高了 CPU 利用率。
4.  **DMA（直接存储器访问）方式**：由 DMA 控制器接管总线，在外设与内存之间直接进行大批量数据传送，无需 CPU 干预每个字节的传输。适用于高速、大批量数据传输。

知识点：[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)

**推理过程**  
- 对于 **DMA 请求**：DMA 请求通常需要 CPU 在当前总线周期结束后释放总线控制权。如果 CPU 当前一条指令未执行完毕，则总线周期可能仍在进行中，CPU 无法立即交出总线，因而不会立即响应 DMA。

参考解答：① 结论：描述有误，8086 的中断响应/返回流程中，**FLAGS 先压栈后弹栈，但中断向量写入顺序是先 IP 后 CS，返回时用 IRET 一次弹出 IP、CS、FLAGS，不存在“弹出两个分量”的说法，且“返回断点”是由 IRET 自动完成的，不是额外的第③步后续动作。**

**推理/订正过程：**
- **第①步正确**：8086 在响应中断时，先执行 `PUSH FLAGS`（F 寄存器），然后清除 IF、TF，再依次 `PUSH CS`、`PUSH IP`。题中只写了“将 F 寄存器、CS 和 IP 的当前值压入堆栈”，顺序未强调，但可以接受。
- **第②步错误**：中断类型码为 21H，中断向量表地址为 $4 \times 21\text{H} = 84\text{H}$。从 `00084H`、`00085H` 中取出的字装入 **IP**，从 `00086H`、`00087H` 中取出的字装入 **CS**。题目说“写入 IP、CS 中”，虽然顺序未指明，但若理解为任意顺序则会出错，应为 **先 IP 后 CS**。
- **第③步错误**：中断服务程序末尾的返回指令是 `IRET`。它从栈顶**一次**弹出 3 个字（6 字节），依次恢复 **IP、CS、FLAGS**。题目说“弹出两个分量到 IP、CS 还包括 F 寄存器内容”措辞模糊，容易误解为只弹出两个分量加上 F；实际是连续弹出 IP、CS、F。若有单独的 F 弹出步骤描述，则完全混淆了 IRET 的原子操作。
- “返回断点”本身就由 `IRET` 将 CS:IP 指向被中断指令的下一条指令实现，**不应作为独立于③的额外给分点**。

**结论**：原流程描述将 `IRET` 的恢复过程拆解不当，且向量装载顺序缺失关键约束，需按 8086 实际硬件动作修正。

参考解答：**结论**
汇编语言源程序的开发过程主要包含三个步骤：**编辑**生成 `.ASM` 文件、**汇编**生成 `.OBJ` 文件、**链接**生成 `.EXE` 或 `.COM` 可执行文件。

**推理与过程**
1.  **编辑（Editing）**：
    使用文本编辑器编写汇编源代码，保存为扩展名为 `.ASM` 的ASCII文本文件。此阶段仅进行语法层面的文字录入，不涉及机器码转换。

2.  **汇编（Assembling）**：
    调用汇编程序（如 MASM、TASM）对 `.ASM` 文件进行处理。
    -   **功能**：检查语法错误，将助记符指令翻译成机器码，处理伪指令，生成目标文件。

3.  **链接（Linking）**：
    调用链接程序（如 LINK）对一个或多个 `.OBJ` 文件及库文件进行处理。
    -   **功能**：合并段地址，解析外部引用（重定位），分配最终的内存地址空间。
    -   **结果**：生成可执行文件。
        -   **.EXE**：可重定位的可执行文件，适用于较大程序，支持多段结构。
        -   **.COM**：简单的二进制可执行文件，通常限制在 64KB 以内，单一段结构，加载速度快。

## (2) 查询接收一个字符

**结论：** 该程序段通过**查询方式**从 COM1 接收一个字节数据，结果存入 `AL`。

**关键步骤分析：**

```assembly
SCAN: MOV DX, 3FDH      ; 指向线路状态寄存器（LSR）
      IN AL, DX          ; 读 LSR
      TEST AL, 01H       ; 测试 D₀（数据就绪 DR 位）
      JZ SCAN            ; D₀=0 表示接收缓冲区空，跳转继续查询
      MOV DX, 3F8H       ; D₀=1 表示数据已就绪，指向接收缓冲寄存器（RBR）

```

- $3\text{FDH}$ 是 COM1 的 LSR 端口地址；其 $D_0$ 位为"接收数据就绪"标志。
