## 二、填空

### 填空 1

间址、DX

参考解答：## 结论

**间址**、**DX**

## 推理

在 8086/8088 指令系统中，I/O 端口寻址只有两种方式：

- **直接端口寻址**：指令中直接给出 8 位端口号，可寻址 $0 \sim 255$（即 $00\text{H} \sim \text{FFH}$）。
- **间接端口寻址（间址）**：端口号事先放入寄存器 **DX**，可寻址全部 $64\text{K}$ 个端口（$0000\text{H} \sim \text{FFFFH}$）。

因此，当端口号大于 255 时，必须采用**间址**方式，并将端口号送入 **DX** 寄存器。

典型指令形式：

```asm
MOV DX, 03F8H   ; 端口号送入 DX
IN  AL, DX      ; 间接读端口
OUT DX, AL      ; 间接写端口
```

### 填空 2

$\overline{OBF}$、$\overline{ACK}$

参考解答：**结论：** $\overline{OBF}$ 和 $\overline{ACK}$ 是 **8255A 可编程并行接口芯片工作在方式 1（选通 I/O）输出模式**下的两个联络（握手）信号。

---

### 推理过程

在 8255A 的方式 1 输出模式中，CPU 与外设之间采用应答式（握手）方式进行数据传送，需要专用的联络信号来协调：

1. **$\overline{OBF}$（Output Buffer Full，输出缓冲器满）**
   - **方向**：8255A → 外设（输出信号，低电平有效）。
   - **作用**：当 CPU 将数据写入 8255A 的输出端口后，8255A 自动使 $\overline{OBF}$ 变为低电平，通知外设"输出缓冲器中已有新数据，可以取走"。

2. **$\overline{ACK}$（Acknowledge，响应/应答）**
   - **方向**：外设 → 8255A（输入信号，低电平有效）。
   - **作用**：外设接收到数据后，向 8255A 发出低电平有效的 $\overline{ACK}$ 信号，表示"数据已被取走"。该信号的下降沿会使 $\overline{OBF}$ 恢复为高电平（缓冲器空），其上升沿可触发中断请求信号 $\overline{INTR}$ 变高，向 CPU 申请下一次输出。

> **补充**：这两个信号配合 $\overline{WR}$（CPU写信号）和 $\overline{INTR}$（中断请求），共同构成方式 1 输出的完整握手时序。

### 填空 4

通信线状态

参考解答：**结论：** 通信线状态对应 **Modem 状态寄存器（MSR，Modem Status Register）**。

**推理过程：**

在微机接口技术中，串行通信接口芯片（如 INS 8250 / 16550 UART）通过一组内部寄存器来管理和监测通信过程：

- **LSR（Line Status Register，线路状态寄存器）**：反映的是**数据链路层**的状态，如接收数据就绪、溢出错误、奇偶校验错误、帧错误等。
- **MSR（Modem Status Register，Modem 状态寄存器）**：反映的是**通信线（调制解调器控制线）**的状态，即 DCD（载波检测）、RI（振铃指示）、DSR（数据设备就绪）、CTS（清除发送）等硬件握手信号的电平变化。

因此，“通信线状态”由 **MSR（Modem 状态寄存器）** 来读取和反映。

② 半双工方式：要求收发双方均具备接收和发送数据的能力，由于只有一条信道，数据不能在两个方向上同时传送。

### 简答 3

无条件传送，查询方式，中断控制方式，DMA 方式

参考解答：这四种方式是微型计算机接口中 CPU 与外设进行数据传送的控制方式，按控制复杂度和传输效率递增排列。

-   **无条件传送**：适用于外设状态固定或响应速度极快的简单设备（如开关、LED），CPU 直接执行 I/O 指令读写，无需检测外设状态；优点是硬件简单，缺点是可靠性差、适用范围窄。
-   **查询方式（程序控制）**：CPU 在传送前循环读取外设状态寄存器，确认“就绪”后才执行数据传送；解决了无条件传送的可靠性问题，但 CPU 大量时间浪费在等待和测试状态上，效率低且无法处理突发事件。
-   **中断控制方式**：外设在准备好数据后主动向 CPU 发中断请求，CPU 暂停当前任务转而处理 I/O，完成后返回原程序；实现了 CPU 与外设的并行工作，提高了系统效率，但每次传送仍需 CPU 参与数据搬运，不适合大批量高速传输。
-   **DMA 方式**：由专用 DMA 控制器接管总线，在外设与内存之间直接成块传送数据，仅在开始和结束时通知 CPU；传输速率接近存储器存取速度，CPU 开销最小，适用于磁盘、网卡等高速大数据量设备，但硬件成本最高。

### 推理

这三个条件同时满足时，CPU 会在当前指令执行结束后响应可屏蔽中断：

1. **有可屏蔽中断请求**：说明存在可通过 INTR 引脚向 CPU 提出、且能被 IF 屏蔽的中断请求。
2. **CPU 一条指令执行完毕**：CPU 通常在一条指令执行完成后才响应可屏蔽中断，以保证当前指令的完整性。
3. **$IF=1$**：中断允许标志开放，允许 CPU 响应可屏蔽中断。

因此，CPU 将暂停当前程序，转入相应的中断服务程序。

### 简答 5

中断向量是实模式下，中断服务子程序的入口地址。它由 2 部分组成：

① 服务程序所在代码段的段基址。

② 服务程序所在代码段的偏移地址。

## 四、综合应用

参考解答：中断向量在实模式中断向量表中占用 **4 个字节**：

- **高 16 位**：中断服务子程序所在代码段的**段基址**
- **低 16 位**：中断服务子程序所在代码段内的**偏移地址**

CPU 响应中断时，用中断类型号 $n$ 计算向量地址：


$$
\text{向量地址} = n \times 4
$$


从该地址起连续读取 4 个字节，先取低 16 位装入 IP，再取高 16 位装入 CS，从而转去执行中断服务子程序。

### 综合 2

3FBH、80H、3F9H、00H、3F8H、60H

3FBH、0AH、3F9H、00H、3FCH、00H

参考解答：### 结论
该序列为 **8251A 可编程串行接口芯片** 的初始化程序片段（基于 x86 I/O 端口操作）。

第一组数据配置了 **方式字** 和 **命令字**，将 8251A 设置为异步通信、波特率因子 16、7 位数据、偶校验、2 位停止位，并允许发送/接收。
第二组数据通常用于进一步的状态检查或特定的控制命令设置（如复位错误标志或调整流控），具体取决于上下文，但核心在于识别出这是针对 8251A 的端口读写操作。

### 推理与分析过程

#### 1. 端口地址分析
在典型的 IBM PC/XT 系统或教学实验箱中，8251A 的端口地址分配如下：
- **数据端口**：$3F8H$
- **状态/命令端口**：$3F9H$
- **方式/命令端口**：$3FBH$ (注：不同教材或硬件设计可能略有差异，常见的是 $3F8H$ 为数据，$3F9H$ 为状态/命令。但在本题给出的序列中，出现了 $3FBH$ 和 $3FCH$，这更符合某些特定实验箱的地址映射，或者题目暗示的是 **8250/16450 UART** 与 **8251** 的混合考察，但根据 `80H` 和 `0AH` 这种典型的方式字特征，主要指向 **8251A**)。

*修正分析*：让我们重新审视标准的 8251A 连接。通常 8251A 有两个端口地址：
- 偶地址（如 $3F8H$）：数据寄存器
- 奇地址（如 $3F9H$）：状态/命令寄存器
- 有些设计会将 $3FAH$ 或 $3FBH$ 用于其他控制。

然而，观察题目给出的数据对：
1. `3FBH, 80H`：向端口 $3FBH$ 写入 $80H$
2. `3F9H, 00H`：向端口 $3F9H$ 写入 $00H$
3. `3F8H, 60H`：向端口 $3F8H$ 写入 $60H$

这看起来更像是 **8250/16550 UART** 的初始化流程，或者是特定实验平台的 8251 映射。让我们尝试用 **8251A** 的标准方式字来验证数据内容。

**假设是 8251A：**
8251A 的方式字格式（D7-D0）：
- D7,D6: 波特率因子 (01=x1, 10=x16, 11=x64)
- D5: 停止位 (0=1位, 1=2位; 若同步则无关)
- D4: 奇偶使能 (1=允许)
- D3: 奇偶选择 (0=偶, 1=奇)
- D2,D1: 字符长度 (00=5, 01=6, 10=7, 11=8)
- D0: 同步/异步 (0=同步, 1=异步)

分析数据 `80H` ($1000\ 0000_2$)：
- D7,D6 = 10 $\rightarrow$ 波特率因子 x16
- D5 = 0 $\rightarrow$ 1 位停止位
- D4 = 0 $\rightarrow$ 无奇偶校验
- D2,D1 = 00 $\rightarrow$ 5 位数据
- D0 = 0 $\rightarrow$ 同步模式
*这与常见的异步通信初始化不太吻合（通常 D0=1）。*

分析数据 `60H` ($0110\ 0000_2$)：
- 如果这是方式字：
- D7,D6 = 01 $\rightarrow$ x1
- D5 = 1 $\rightarrow$ 2 位停止位
- D4 = 0 $\rightarrow$ 无校验
- D2,D1 = 00 $\rightarrow$ 5 位
- D0 = 0 $\rightarrow$ 同步
*也不太像标准配置。*

**重新假设：这是 8250 UART (COM1 端口基址 3F8H)**
8250 的端口定义：
- $3F8H$: RBR/THR/DLL (读/写数据 / 除数锁存低字节)
- $3F9H$: IER/DLM (中断使能 / 除数锁存高字节)
- $3FAH$: IIR/FIFO
- $3FBH$: LCR (线路控制寄存器)
- $3FCH$: MCR (调制解调器控制寄存器)

**验证第一组数据：**
1. **`3FBH, 80H`**: 向 LCR ($3FBH$) 写入 $80H$ ($1000\ 0000_2$)。
   - LCR 的 D7 是 **DLAB** (Divisor Latch Access Bit)。
   - D7=1 表示允许访问除数锁存器 (DLL 和 DLM)。这是设置波特率的第一步。
2. **`3F9H, 00H`**: 向 DLM ($3F9H$) 写入 $00H$。
   - 设置除数高字节为 0。
3. **`3F8H, 60H`**: 向 DLL ($3F8H$) 写入 $60H$ ($96_{10}$)。
   - 设置除数低字节为 96。
   - **计算波特率**：对于 8250，波特率 = $\frac{\text{基准时钟}}{16 \times \text{除数}}$。
   - 标准基准时钟为 $1.8432 \text{ MHz}$。
   - 波特率 = $\frac{1843200}{16 \times 96} = \frac{1843200}{1536} = 1200 \text{ bps}$。

**验证第二组数据：**
1. **`3FBH, 0AH`**: 向 LCR ($3FBH$) 写入 $0AH$ ($0000\ 1010_2$)。
   - D7=0: 禁用 DLAB，恢复数据/中断寄存器访问。
   - D5,D4,D3 = 000: 无校验? 不，LCR 格式：
     - D1,D0: 字长。$10_2$ = 7 位? 不，$00$=5, $01$=6, $10$=7, $11$=8。这里 D1=1, D0=0 $\rightarrow$ **7 位数据**。
     - D2: 停止位。$0$ = 1 位停止位 (若字长=5则为1.5)。
     - D3: 奇偶使能。$0$ = 禁用? 等等，$0AH = 0000\ 1010_2$。
       - D0=0, D1=1 $\rightarrow$ 6 位数据? (通常 8N1 是 03H)。
       - 让我们仔细看 $0AH$ 的二进制：$0000\ 1010$。
       - D0=0, D1=1 $\rightarrow$ 6 位数据长度。
       - D2=0 $\rightarrow$ 1 位停止位。
       - D3=0 $\rightarrow$ 无奇偶校验。
       - *或者*，如果是 $0BH$ ($0000\ 1011$) 则是 7 位。如果是 $03H$ ($0000\ 0011$) 则是 8 位。
       - 许多教材中 $0AH$ 可能对应 **7位数据，偶校验**？
       - LCR 格式：D3(Parity Enable), D4(Even/Odd), D5(Stick), D6(Break), D7(DLAB).
       - $0AH = 0000\ 1010_2$.
       - D0=0, D1=1 $\rightarrow$ **6 位数据**。
       - D2=0 $\rightarrow$ **1 位停止位**。
       - D3=0 $\rightarrow$ **无校验**。
       - *注：有些题目可能是 $0BH$ (7位) 或 $03H$ (8位)。如果题目确实是 0AH，那就是 6 位数据。*
2. **`3F9H, 00H`**: 向 IER ($3F9H$) 写入 $00H$。
   - 禁用所有中断。
3. **`3FCH, 00H`**: 向 MCR ($3FCH$) 写入 $00H$。
   - 调制解调器控制寄存器清零，DTR/RTS 等信号无效。

### 最终综合解答

这是一段针对 **8250 UART**（兼容 16450/16550）的初始化代码，端口基址为 $3F8H$（即 COM1）。

#### 第一组：设置波特率为 1200 bps
1.  **`OUT 3FBH, 80H`**：访问线路控制寄存器 (LCR)，置 D7 (DLAB) 为 1，以访问除数锁存器。
2.  **`OUT 3F9H, 00H`**：写入除数锁存高字节 (DLM) 为 0。
3.  **`OUT 3F8H, 60H`**：写入除数锁存低字节 (DLL) 为 $60H$ ($96D$)。
    *   **计算**：波特率 $B = \frac{1.8432 \text{ MHz}}{16 \times 96} = 1200 \text{ bps}$。

#### 第二组：设置通信格式与控制
1.  **`OUT 3FBH, 0AH`**：再次访问 LCR，DLAB=0，设置通信格式。
    *   $0AH = 0000\ 1010_2$。
    *   D1,D0 = $10$ $\rightarrow$ **6 位数据位**。
    *   D2 = $0$ $\rightarrow$ **1 位停止位**。
    *   D3 = $0$ $\rightarrow$ **无奇偶校验**。
    *   *(注：若题目意为常见配置，可能是印刷错误或特定要求，标准 8N1 为 03H，7E1 为 0BH 等。此处严格按 0AH 解析为 6 位数据)*。
2.  **`OUT 3F9H, 00H`**：写入中断使能寄存器 (IER)，**禁止所有中断**。
3.  **`OUT 3FCH, 00H`**：写入调制解调器控制寄存器 (MCR)，**复位所有控制线** (DTR, RTS 等为低电平)。

（1）

- 结论：使用 8253 通道 0 的方式 3 产生 $4\ \text{kHz}$ 方波。

- 推理 / 计算：
  - 方式控制字 $01110110B$ 表示：通道 0、先低字节后高字节写入计数初值、方式 3、二进制计数。
  - 计数初值写入 $500$，因此输出频率为
    $$
    f = \frac{f_{\text{CLK}}}{N} = \frac{2\ \text{MHz}}{500} = 4000\ \text{Hz} = 4\ \text{kHz}.
    $$
  - 由于方式 3 为方波方式，故在 OUT0 端得到 $4\ \text{kHz}$ 的方波输出。

（2）

- 结论：清除 8259A 主片 IRQ2 和从片 IRQ1 对应的中断屏蔽位，允许这两个中断请求。

- 推理 / 计算：
  - 主片端口 $21\text{H}$ 为 OCW1（中断屏蔽寄存器）。原屏蔽字与 $11111011B$ 相与，清除 $D_2$ 位，因此开放 IRQ2。
  - 从片端口 $0\text{A}1\text{H}$ 为从片 8259A 的 OCW1。原屏蔽字与 $11111101B$ 相与，清除 $D_1$ 位，因此开放 IRQ1。
  - 从片的中断请求经主片 IRQ2 引入，故综合效果是允许 IRQ2 与 IRQ9（即从片的 IRQ1）中断。
