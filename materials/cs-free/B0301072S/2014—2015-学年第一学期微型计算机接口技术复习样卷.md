知识点：[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)

### 简答 1
字长=8， $X=-75, Y=+86$，求 $[X]_{补}$ 和 $[Y]_{补}$，并用补码计算 $X+Y$。要求有运算过程并对结果是否溢出进行分析。

解：
$X = -75$，原码 $11001011$，反码 $10110100$，补码 $10110101$。
$Y = +86$，原码 $01010110$，补码 $01010110$。

$$
\begin{array}{r}
   10110101 \\ (+) \quad 01010110 \\ \hline
  100001011
\end{array}
$$

结果为 9 位，舍去最高位进位，得 $00001011$。
$C_n = 1$（最高位进位），$O_n = 0$（符号位无进位与数值位进位异或为 0，即 $1 \oplus 0 = 1$? 不对，重新检查溢出判断）。

**重新分析溢出：**
$X = -75 (10110101)$
$Y = +86 (01010110)$
加法：
```text
  10110101
+ 01010110
----------
 100001011
```
结果低 8 位为 $00001011$（即 $+11$）。
符号位运算：$1+0=1$（无进位到第 9 位？不对，第 7 位向第 8 位有进位吗？
第 6 位（1）+ 第 6 位（1）= 0 进 1。
第 7 位（0）+ 第 7 位（0）+ 进位 1 = 1。
符号位（第 7 位）：$1+0=1$。
实际上：
$10110101$
$01010110$
--------
$100001011$
第 7 位（符号位）相加：$1+0=1$，没有产生向第 8 位的进位？
让我们逐位加：
Bit 0: 1+0=1
Bit 1: 0+1=1
Bit 2: 1+1=0 (c1)
Bit 3: 0+0+c1=1
Bit 4: 1+1=0 (c1)
Bit 5: 1+0+c1=0 (c1)
Bit 6: 0+1+c1=0 (c1)
Bit 7: 1+0+c1=0 (c1) -> 这里错了，1+0+1=0，进位 1。
所以结果是 $00001011$，进位 $C_7=1$。
符号位 $S_x=1, S_y=0$，不同号相加不会溢出。
或者用 $O_n = C_7 \oplus C_6$。
$C_6$ (Bit 6 向 Bit 7 的进位): Bit 6 是 0+1+1(carry from bit 5)=0，进位 1。所以 $C_6=1$。
$C_7$ (Bit 7 向 Bit 8 的进位): Bit 7 是 1+0+1(carry from bit 6)=0，进位 1。所以 $C_7=1$。
$O_n = 1 \oplus 1 = 0$。无溢出。

结果：$+11$。
答案：$[X]_{补}=10110101B$, $[Y]_{补}=01010110B$, $X+Y=00001011B$ ($+11$)，无溢出。

知识点：[真值数与补码的相互转换及补码计算](../../../topics/微机接口/zhenzhi-buma.md)、[算术运算与逻辑运算指令（ADD、SUB、MUL、AND、OR、NOT等）](../../../topics/微机接口/suanlu-yunsuan.md)

### 简答 2
简述 CPU 响应非屏蔽中断和可屏蔽中断的条件。

解：
**CPU 响应可屏蔽中断（INTR）的条件：**
1. INTR 引脚有中断请求，NMI 引脚没有中断请求，系统没有 DMA 请求。
2. CPU 当前指令执行完毕。
3. CPU 处于开中断状态，即标志寄存器的中断允许标志（IF）置 1。

**CPU 响应非屏蔽中断（NMI）的条件：**
1. NMI 引脚有中断请求，系统没有 DMA 请求。
2. CPU 当前指令执行完毕。
（注：非屏蔽中断不受 IF 标志影响，只要 NMI 有效且当前指令结束即可响应，但通常要求不处理 DMA 请求时响应，具体视架构而定，一般教材强调前两点）。

知识点：[标志寄存器中的状态标志位与控制标志位](../../../topics/微机接口/zhuangtai-biaozhi.md)、[微机系统与I/O端口的信息交换方式（无条件、查询、中断、DMA）](../../../topics/微机接口/xinxi-jiaohuan.md)

### 简答 3
设 8255A 的方式选择命令字为 80H，说明各个数据口的工作方式和输入/输出方向。
*(注：原文识别为 808，根据 8255 控制字格式，80H 为二进制 1000 0000，符合方式选择命令字格式)*

控制字 $80H = 10000000B$。

- D0=0：C 口低 4 位输出。

### 简答 4
系统启动后，设内存地址 184H～187H 的四个单元中的内容依次为 12H, 34H, 56H, 78H，请问该四个单元存放的是哪一型中断向量？该型中断服务程序的入口物理地址是多少？

解：
中断向量表起始地址为 0000H:0000H。
每个中断向量占 4 个字节（2 字节偏移 IP，2 字节段基 CS）。
地址范围 184H～187H。
中断向量编号 $n = 184H / 4 = 61H$。
所以存放的是 **61H** 型中断向量。

向量内容：
CS (高地址): 187H 单元内容 = 78H
IP (低地址): 186H 单元内容 = 56H
CS (低地址): 185H 单元内容 = 34H
IP (高地址): 184H 单元内容 = 12H
*(注意：x86 是小端序，低地址存低位)*
- 偏移量 IP = (185H 单元) 34H, (184H 单元) 12H -> $1234H$?
不对，顺序是：
184H: 12H (IP 低)
185H: 34H (IP 高) -> IP = $3412H$
186H: 56H (CS 低)
187H: 78H (CS 高) -> CS = $7856H$

逻辑地址：$7856H:3412H$。
物理地址 = $7856H \times 10H + 3412H = 78560H + 3412H = 7B972H$。

*修正：* 题目中给出的数据是 12, 34, 56, 78。
如果是 184H(12), 185H(34), 186H(56), 187H(78)。
IP = 3412H (小端：12 是低，34 是高)
CS = 7856H (小端：56 是低，78 是高)
物理地址 = $78560H + 3412H = 7B972H$。

答案：61H 型中断向量。入口物理地址是 7B972H。

### 应用 1
编写一程序段，把 AL 低四位和 AH 低四位拼装成一个字节（AL 低四位为拼装后的高四位）→ AH。（6 分）

解：
```assembly
SHL AL, 4      ; AL 左移 4 位，低四位移至高四位
AND AH, 0FH    ; AH 保留低四位，清除高四位
ADD AH, AL     ; 将移位后的 AL 加到 AH 上
; 结果在 AH 中
```

知识点：[移位与循环移位指令（SHL、SHR、ROL、ROR等）](../../../topics/微机接口/yiwei-xunhuan.md)、[算术运算与逻辑运算指令（ADD、SUB、MUL、AND、OR、NOT等）](../../../topics/微机接口/suanlu-yunsuan.md)

### 应用 2
设堆栈段寄存器 SS=2000H, SP=0100H, 阅读下面程序片段，完成相应空格。(4 分)
```assembly
(1) MOV AX, 1234H
(2) MOV BX, 5678H
(3) PUSH AX
(4) PUSH BX
(5) POP AX
(6) ADD AH, AL
(7) MOV BL, AH
```

执行完第 (4) 条指令后 SP=\_\_\_\_H，执行完第 (5) 条指令后 AX=\_\_\_\_H，SS=\_\_\_\_H。执行完第 (7) 条指令后 BX=\_\_\_\_H。

解：
初始 SP = 0100H。
(3) PUSH AX: SP = 0100H - 2 = 00FEH。
(4) PUSH BX: SP = 00FEH - 2 = 00FC H。
此时栈顶内容为 BX (5678H)。
(5) POP AX: 弹出栈顶数据给 AX。AX = 5678H。SP = 00FC H + 2 = 00FEH。
SS 始终不变，为 2000H。
(6) ADD AH, AL: AH=56H, AL=78H。AH = 56H + 78H = CEH。AX = 5CEH。
(7) MOV BL, AH: BL = CEH。BX = 56CEH。

答案：
SP = **00FC** H
AX = **5678** H
SS = **2000** H
BX = **56CE** H

### 应用 3
PC 系统外扩使用了一片可编程定时/计数器 8254，8254 的输入时钟是 8MHz。（10 分）
（1）下列是 CPU 对 8254 的初始化程序段，根据要求完成相关内容。
```assembly
MOV AL, 01110110B
MOV DX, 207H
OUT DX, AL
MOV AX, 2000
MOV DX, 205H
OUT DX, AL
MOV AL, AH
OUT DX, AL
```
由上述程序段可知，设计时使用了 8254 的\_\_\_\_号计数器，其口地址是\_\_\_\_H，工作在方式\_\_\_\_，使用了\_\_\_\_进制计数，计数初值是\_\_\_\_，输出信号的频率是\_\_\_\_Hz。（6 分）。

解：
控制字 $01110110B = 76H$。
- D7-D6=01：选择计数器 1。
- D5-D4=11：读写低 8 位和高 8 位（先低后高）。
- D3-D1=110：方式 6（方波发生器）。
- D0=0：二进制计数。

程序细节：
- 写控制字到 207H（对应计数器 1 的控制口）。
- 写计数初值 2000 到 205H（对应计数器 1 的数据口）。
- 计数初值 2000（十进制）。
- 输入时钟 $f_{clk} = 8 \text{ MHz} = 8,000,000 \text{ Hz}$。
- 输出频率 $f_{out} = f_{clk} / N = 8,000,000 / 2000 = 4000 \text{ Hz}$。

答案：
计数器：**1**
口地址：**205**
工作方式：**6**
进制：**二进制**
计数初值：**2000**
输出频率：**4000**

（2）不改变输入时钟的频率，想使该计数器的输出信号周期变大，初始化时应采取什么措施？输出周期最大是多少？（4 分）。

解：
措施：加大计数初值 $N$。
公式：$T_{out} = T_{clk} \times N = \frac{1}{f_{clk}} \times N$。
要使周期变大，需增大 $N$。
8254 最大计数值为 65536（16 位二进制）。
$f_{clk} = 8 \text{ MHz}$，周期 $T_{clk} = \frac{1}{8 \times 10^6} = 0.125 \mu s$。
最大周期 $T_{max} = 65536 \times 0.125 \mu s = 8192 \mu s = 8.192 \text{ ms}$。
或者：$f_{min} = 8 \text{ MHz} / 65536 \approx 122.07 \text{ Hz}$。
$T_{max} = 1 / 122.07 \approx 0.008192 \text{ s} = 8.192 \times 10^{-3} \text{ s}$。

答案：采取的措施是**加大计数初值**。输出周期最大是 **8.192 ms** (或 $8.192 \times 10^{-3}$ 秒)。

### 应用 4
利用甲、乙两台计算机的主串口直接相连进行单工通信，甲发送，乙接收。双方通信前约定：8 位数据位，1 位停止位，无校验，通信速率为 2400 bps (分频系数为 0018H)，双方均采用查询方式进行数据的发送和接收。(20 分)

（1）求每秒能传输多少个字符？如果需要传送一个字符"A"，要求画出串行异步通信的一帧字符格式，并标出各部分的逻辑电平（TTL）和位数。（4 分）

解：
波特率 2400 bps。
一帧数据：1 起始位 + 8 数据位 + 0 校验位 + 1 停止位 = 10 位。
每秒传输字符数 = $2400 / 10 = 240$ 个。

字符 "A" 的 ASCII 码为 $41H$ (二进制 01000001)。
帧格式（发送端）：
- 空闲态：高电平 (1)
- 起始位：低电平 (0)，1 位
- 数据位：从低位到高位，01000001
- 停止位：高电平 (1)，1 位

图示描述：
```text
时间轴 ->
电平：  1  0  0 1 0 0 0 0 0 1  1
       |  |-----------------------|
       |   起始位                 | 停止位
       |                          |
       |--- 数据位 (LSB->MSB) ---|
```
具体波形：
空闲：高
起始：低 (1 位)
数据：0 (LSB), 1, 0, 0, 0, 0, 0, 1 (MSB)
停止：高 (1 位)

（2）请将下列甲机用查询方式发送字符 'A' 的程序段补充完整。(6 分)
```assembly
SCANT: MOV DX, ① ______
       ② ______
       TEST AL, ③ ______
       ④ ______ SCANT
       MOV DX, ⑤ ______
       MOV AL, ⑥ ______
       OUT DX, AL
```

解：
查询发送步骤：
1. 读取状态寄存器，检查发送缓冲区是否为空（TXE 位）。
2. 若为空，则跳出循环；否则继续等待。
3. 发送数据。

假设 8250 端口分配（常见配置）：
- 数据口：3F8H (或 3F0H 等，根据题目上下文推断)
- 状态口：3FDH (或 3F5H 等)
- 控制口：3FEH (或 3F4H 等)

观察题目中给出的代码结构：
`MOV DX, ①` -> 应该是状态寄存器地址。
`IN AL, DX` (隐含) -> 读状态。
`TEST AL, ③` -> 测试 TXE 位。8250 状态寄存器中，TXE 通常是位 5 (0x20)。
`JZ SCANT` -> 如果为 0 (忙)，跳转回 SCANT。
`MOV DX, ⑤` -> 切换到数据寄存器地址。
`MOV AL, ⑥` -> 加载字符 'A'。
`OUT DX, AL` -> 发送。

根据常见题目答案：
① 3FDH (状态口)
② IN AL, DX
③ 20H (TXE 位)
④ JZ SCANT (或者 JNZ EXIT, 但这里是循环等待，所以是 JZ SCANT，意为如果没准备好就跳回去)
⑤ 3FH (数据口，假设基址 3F8H，数据口 3F8H，状态口 3FDH? 或者是 3F0H 等。题目中后面出现了 3FEH 作为控制口，3FDH 作为状态口，那么数据口可能是 3F8H。但看后面的填空，⑤ 处填了 3FEH? 不对，3FEH 通常是控制口。

`① 3FDH`, `② IN AL, DX`, `③ 20H`, `④ JZ SCANT`, `⑤ 3FEH` (这里可能是题目印刷错误或特定板卡地址，通常数据口是 3F8H，但如果是 3FEH 可能是数据口？或者题目中 3FEH 是数据口？)
再看题目下方给出的完整代码：
`MOV DX, ① 3FDH`
`② IN AL, DX`
`TEST AL, ③ 20H`
`④ JZ SCANT`

`MOV AL, ⑥ 'A'`
`OUT DX, AL`

根据题目提供的最终答案行：
① 3FDH
② IN AL, DX
③ 20H
④ JZ SCANT

（3）请完成对甲计算机的 8250 初始化程序段。（10 分）

解：
参数：
- 波特率：2400 bps
- 分频系数：0018H (即 24)
- 数据位：8
- 停止位：1
- 校验：无
- 模式：查询

初始化步骤：
1. 设置除数锁存器（波特率发生器）。
   - 写 DLL (低字节) = 18H
   - 写 DLM (高字节) = 00H
2. 设置线路控制寄存器 (LCR)。
   - 8 位数据，无校验，1 停止位 -> LCR = 0x03 (00000011B)。
   - 需先置 1 (Divisor Latch Access Bit) 才能访问除数锁存器。

程序段：
```assembly
; 假设基址 3F8H
MOV DX, 3FEH        ; 控制口 (LCR)
MOV AL, 80H         ; 置位除数锁存器访问位 (DLAB=1)
OUT DX, AL

MOV DX, 3F8H        ; 数据口 (DLL)
MOV AL, 18H
OUT DX, AL

MOV DX, 3F9H        ; 数据口 (DLM) (假设基址+1)
MOV AL, 00H
OUT DX, AL

MOV DX, 3FEH        ; 控制口 (LCR)
MOV AL, 03H         ; 8 数据，无校验，1 停止，DLAB=0
OUT DX, AL

; 设置中断控制寄存器 (ICR) 关闭中断 (查询方式)
MOV DX, 3FAH        ; 中断使能寄存器 (IER)
MOV AL, 00H
OUT DX, AL

; 设置 FIFO 控制寄存器 (FCR)
MOV DX, 3FCH        ; FCR
MOV AL, 06H         ; 启用 FIFO，清收发缓冲区
OUT DX, AL
```
*(注：具体端口地址需根据题目上下文，通常 8250 基址 3F8H，端口分别为 3F8~3FF)*
