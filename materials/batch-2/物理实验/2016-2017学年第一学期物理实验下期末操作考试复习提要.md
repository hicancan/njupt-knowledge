## 一、声速测量

### 1. 实验要求

1. 掌握共振干涉法、相位比较法测声速的原理和方法；
2. 掌握示波器主要功能键的调节和使用；
3. 掌握信号发生器信号参数调节和寻找共振频率的方法；
4. 会用逐差法处理数据，计算声速，结果要正确表达。

知识点：[实验报告的内容（含实验内容与步骤等）](../../../topics/大学物理实验/实验报告内容.md)、[有效数字的概念与定义](../../../topics/大学物理实验/有效数字概念.md)

### 2. 公式与数据处理示例

**公式：**

$$
\left\{ \begin{array}{l} {v _ {0} = 3 3 1. 4 5 \sqrt {\frac {t + 2 7 3 . 1 5}{2 7 3 . 1 5}} \text{ m/s}} \\ {\overline {{v}} = f \cdot \overline {{\lambda}} = f \cdot \frac {2}{5} \overline {{\Delta L}}} \\ {u _ {v} = \overline {{v}} \sqrt {\left(\frac {u _ {0 L}}{\Delta L}\right) ^ {2} + \left(\frac {u _ {f}}{f}\right) ^ {2}}} \\ {E = \frac {| \overline {{v}} - v _ {0} |}{v _ {0}} \times 1 0 0 \% } \end{array} \right.
$$

**求值示例：**

*   **理论值**：$V_0 = 342.84 \text{ m/s}$
*   **共振法**：$v = \overline { v } \pm M_{0} = (346.8 \pm 4.4) \text{ m/s}$，相对误差 $E = 1.2\%$
*   **相位法**：$v = \overline { v } \pm M_{0} = (346.10 \pm 0.48) \text{ m/s}$，相对误差 $E = 1.0\%$

### 1. 实验要求

知识点：[实验报告的内容（含实验内容与步骤等）](../../../topics/大学物理实验/实验报告内容.md)、[有效数字的概念与定义](../../../topics/大学物理实验/有效数字概念.md)

### 2. 公式与数据处理示例

**公式：**

*   分流电阻：$R _ { 1 } = \frac { R _ { g } } { n_1 - 1 }, \quad R _ { 2 } = \frac { R _ { g } } { n_2 - 1 }$ *(注：原文识别为具体数值比例，此处还原通用原理，原文示例中 $n$ 对应倍数)*
    *   原文示例逻辑：$R_1$ 对应大量程分流，$R_2$ 对应小量程分流。
*   绝对误差：$\Delta I = I _ { 0 } - I$ （$I_0$ 为标准表读数，$I$ 为改装表读数）
*   引用误差（精度）：$f = \frac { |\Delta I|_{max} } { I_m } \times 100\%$

**求值示例：**

*   表头内阻估算：$R_g \approx 100 \Omega$
*   1mA 电流表改装：
    *   精度 $f = 0.9\%$
    *   级别定为：1.0 级（通常向上取整至标准等级，原文“上级”意指取更高级别或标准等级）
*   10mA 电流表改装：
    *   精度 $f = 0.9\%$
    *   级别定为：1.0 级
