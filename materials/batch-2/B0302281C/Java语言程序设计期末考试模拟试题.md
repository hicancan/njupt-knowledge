### 填空 1

开发与运行 Java 程序需要经过的三个主要步骤为 ==编辑源程序==、==编译生成字节码== 和 ==解释运行字节码==。

参考解答：**结论**
编辑源程序、编译生成字节码、解释运行字节码。

**推理过程**
Java 程序的开发运行遵循“编写—编译—运行”的经典流程：
1. **编辑源程序**：使用文本编辑器或 IDE 编写 `.java` 文件，内容为符合 Java 语法的源代码。
2. **编译生成字节码**：通过 `javac` 编译器将 `.java` 文件编译成与平台无关的 `.class` 字节码文件（bytecode）。
3. **解释运行字节码**：通过 `java` 命令启动 JVM，由解释器（或 JIT 编译器）将字节码转换为机器码并执行。

知识点：[Java平台、JVM定义及编译解释执行原理](../../../topics/Java开发/Java平台与JVM.md)

### 填空 2

如果一个 Java Applet 源程序文件只定义有一个类，该类的类名为 MyApplet，则类 MyApplet 必须是 ==Applet== 类的子类并且存储该源程序文件的文件名为 ==MyApplet==。

参考解答：**结论**：`Applet`；`MyApplet.java`

**推理过程**：
1.  **继承关系**：Java Applet 程序必须继承自 `java.applet.Applet` 类（或其子类 `javax.swing.JApplet`），以便被浏览器或 Applet 查看器加载和执行生命周期方法（如 `init()`, `start()` 等）。题目语境通常指基础的 `Applet` 类。
2.  **文件命名规则**：根据 Java 语言规范，如果源文件中包含一个 `public` 类，则文件名必须与该类名完全一致（区分大小写），并以 `.java` 为扩展名。题目指出只定义有一个类且类名为 `MyApplet`，隐含该类为 public 或作为主类，因此源文件必须命名为 `MyApplet.java`。

知识点：[Java SE、Java EE、Java ME的区别与应用领域](../../../topics/Java开发/Java版本体系.md)、[第一个Java程序（源文件创建、javac编译、类定义、main方法）](../../../topics/Java开发/HelloWorld程序结构.md)

### 填空 3

如果一个 Java Applet 程序文件中定义有 3 个类，则使用 Sun 公司的 JDK 编译器 javac.exe 编译该源程序文件将产生 ==3== 个文件名与类名相同而扩展名为 ==.class== 的字节码文件。

参考解答：## 结论

产生 **3** 个扩展名为 **.class** 的字节码文件。

## 推理

Java 编译器 `javac` 在编译一个 `.java` 源文件时，会为源文件中定义的**每一个类**（包括外部类和内部类）各生成一个独立的字节码文件，文件名与对应类名相同，扩展名为 `.class`。

因此，3 个类就对应 3 个 `.class` 文件。

### 填空 4

在 Java 的基本数据类型中，char 型采用 Unicode 编码方案，每个 Unicode 码占用 ==2== 字节内存空间，这样，无论是中文字符还是英文字符，都是占用 ==2== 字节内存空间。

参考解答：两个空的答案都是 **2**。

**推理过程：**

1.  Java 语言规范明确指出，`char` 类型（基本数据类型之一）被定义为一个 16 位的 Unicode 码元（Code Unit）。因此，它在内存中占用 $16 / 8 = 2$ 字节。
2.  Java 采用 **UTF-16** 编码方案。在此方案中：
    *   **基本多文种平面（BMP）** 中的字符（包括绝大多数英文字符和中文字符）使用 **1 个** `char` 存储。
    *   因此，单个 `char` 的内存占用始终是 **2 字节**，无论字符的内容是什么。题目中“都是占用”的主语是“每个字符（在 `char` 类型表示下）”的固定存储单元，故填 2。

知识点：[基本数据类型（整型、浮点型、字符型、布尔型）及Unicode编码](../../../topics/Java开发/基本数据类型.md)、[Java标识符命名规则与保留关键字](../../../topics/Java开发/标识符与关键字.md)

### 填空 5

设 x = 2，则表达式 `(x++) / 3` 的值是 ==1==。

参考解答：0

**解析**：`(x++) / 3` 中 `x++` 先取 x 的当前值 2 参与计算，再自增。由于 `x` 和 `3` 都是 `int` 类型，执行整数除法：

$$
\frac{2}{3} = 0 \quad (\text{商为 } 0,\text{ 余数 } 2 \text{ 被舍去})
$$

故表达式值为 **0**；若误以为是先自增后计算（即 `(++x)/3 = 3/3 = 1`）才会得 1，这是常见陷阱。

知识点：[算术、关系、逻辑、位运算、移位、条件及复合赋值运算符与优先级](../../../topics/Java开发/运算符与表达式.md)、[基本数据类型（整型、浮点型、字符型、布尔型）及Unicode编码](../../../topics/Java开发/基本数据类型.md)、[成员变量与局部变量的作用范围、默认值及final终止变量](../../../topics/Java开发/变量的作用域与初始化.md)

### 填空 8

创建一个名为 MyPackage 的包的语句是 ==package MyPackage;==，该语句应该放在程序的位置为：==应该在程序第一句==。

参考解答：**结论**

- 创建包的语句：`package MyPackage;`
- 放置位置：源文件的**第一句**（即第一个非注释、非空行的语句）。

**推理过程**

1. Java 语言规范规定，`package` 声明用于指定当前类所属的包，必须出现在源文件中所有 `import` 语句和类/接口定义之前。
2. 文件开头的注释（如 `//` 或 `/* */`）和空行不计入"语句"，因此 `package` 语句必须是程序中的**第一条可执行声明语句**。
3. 若将 `package` 语句放在 `import` 或类定义之后，编译器会直接报错：`package declaration must be the first statement in a compilation unit`。

知识点：[第一个Java程序（源文件创建、javac编译、类定义、main方法）](../../../topics/Java开发/HelloWorld程序结构.md)

### 填空 9

设有数组定义：`int MyIntArray[] = { 10, 20, 30, 40, 50, 60, 70 };` 则执行以下几个语句后的输出结果是 ==120==。

**解析：**

```java
int sum = 0;
for (int i = 0; i < MyIntArray.length; i++)
    sum += MyIntArray[i];

```

若输出结果为 120，则对应语句应为：

```java
System.out.println(MyIntArray[1] + MyIntArray[3] + MyIntArray[5]);
```

即：


$$
20 + 40 + 60 = 120
$$


所以输出结果为 **120**。
