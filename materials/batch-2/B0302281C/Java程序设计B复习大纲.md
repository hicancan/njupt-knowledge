### 具体复习内容

1. 关键字和标识符

2. 基本数据类型：8个基本数据类型，所占字节数

3. 运算符，重点算术运算符

4. 基本结构（条件结构、循环结构，重点是for循环）

5. 数组：数组的定义、初始化、利用循环结构对数组的遍历、数组作为方法的输入参数

6. 方法的定义和调用，理解方法的输入参数和输出参数，关注返回值类型；理解方法的重载的概念，尤其是构造方法的重载；递归调用

7. 类的定义

   重点关注类的基本成员的定义，包括数据成员、构造方法、get方法、set方法、普通方法等。

   类的访问修饰符：public 和缺省

   类成员的访问修饰符：public，private，protected，缺省

8. 理解构造方法无返回值类型、默认构造方法、构造方法重载、this、super

9. 对象与类之间的关系

10. this 的三种用法

11. package 的作用，如何定义包？

12. 继承关系的理解（三个方面，重点理解“重写”）

13. 对象的创建语句注意多态，即父类的变量可以指向子类的对象，反之错误。

14. 接口的概念，理解其成员

15. 异常

    异常的概念：是指程序运行过程中出现的不正常情况。

    异常处理：try… catch… finally

    异常的抛出：throw 异常类的对象;

    异常的声明：在一个方法中可以不处理异常，而是交由调用该方法的方法来进行处理，这时需要声明异常，使用 throws 语句，例如：

    ```java
    void method() throws 异常类型 {
    }
    ```

16. 线程：是程序运行过程中的一条执行路径。

    多线程即在程序运行过程中存在着多条执行路径，这些路径同时执行，又称为并发执行。

17. 常见的包

    如 Math 类所在的包？Math 类的作用？包含的常量和方法？

    如输入输出的包

    如 Scanner 类所在的包

    如 Swing 组件的包

    如 GUI 中事件处理的包

18. GUI

    布局管理器有哪些？JFrame、JPanel 等的默认布局管理器？

    常见的组件、组件的添加（添加到内容面板中）

    菜单组件的层次关系

    常见组件的事件、事件监听接口？

    事件处理的方式？（实现接口、扩展适配器）
