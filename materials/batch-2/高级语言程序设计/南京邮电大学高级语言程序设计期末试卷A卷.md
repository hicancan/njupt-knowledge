### 编程 3

**题目**：某影院周末放映了 8 部电影。编写程序，从键盘上读入这 8 部电影的名称、票价及售出票数，计算并输出影院该周末的总票房收入，以及票房收入最高的电影名称及其票房收入。

**公式**：
$$ \text{某部电影的票房收入} = \text{该部电影的票价} \times \text{该部电影的售出票数} $$
$$ \text{总票房收入} = \sum \text{所有电影的票房收入} $$

**相关定义与原型声明要求**：

1.  **结构体定义**：
    ```c
    typedef struct film
    {
        char name[20];    /* 电影名称 */
        int ticket;       /* 售出票数 */
        int price;        /* 电影票价 */
        int income;       /* 票房收入 */
    } film;
    ```

2.  **函数原型**：
    *   `void input(film *a, int n);`
        *   功能：从键盘读入所有电影的名称、售出票数及票价，并计算出每部电影的票房收入。
    *   `int sum(film *a, int n);`
        *   功能：求出所有电影的票房收入总和，并返回该总和。
    *   `int max(film *a, int n);`
        *   功能：返回票房收入最高的电影的数组下标。

3.  **主程序要求**：
    *   调用上述函数。
    *   输出总票房收入。
    *   输出票房最高电影的名称和收入。

**参考代码框架**：
```c
#include <stdio.h>
#include <string.h>

typedef struct film {
    char name[20];
    int ticket;
    int price;
    int income;
} film;

void input(film *a, int n) {
    for(int i = 0; i < n; i++) {
        scanf("%s%d%d", a[i].name, &a[i].ticket, &a[i].price);
        a[i].income = a[i].ticket * a[i].price;
    }
}

int sum(film *a, int n) {
    int total = 0;
    for(int i = 0; i < n; i++) {
        total += a[i].income;
    }
    return total;
}

int max(film *a, int n) {
    int idx = 0;
    for(int i = 1; i < n; i++) {
        if(a[i].income > a[idx].income) {
            idx = i;
        }
    }
    return idx;
}

int main() {
    film movies[8];
    input(movies, 8);
    
    int total_income = sum(movies, 8);
    int top_idx = max(movies, 8);
    
    printf("总票房收入：%d\n", total_income);
    printf("票房最高电影：%s, 收入：%d\n", movies[top_idx].name, movies[top_idx].income);
    
    return 0;
}
```

## 七、编程题 3（10 分）

编写一个程序，为一个公司人力资源部门管理 30 名员工的通讯录。通讯录信息的内容包括：工号、姓名、电话号码等。要求从键盘读入每位员工的工号、姓名、电话号码后，按照员工的姓名升序进行排序，并输出至屏幕。排序使用选择法。相关定义与原型声明要求如下：

(1) 储存通讯录信息的结构体类型定义为

```c
struct employee
{
    int ID;          /* 工号 */
    char name[20];   /* 姓名 */
    char phone[20];  /* 电话号码 */
};

typedef struct employee employee;
```

(2) `void input( employee *pa, int n );`

其中，pa 为数组的首地址，n 为数组元素的个数。该函数的功能是：从键盘读入所有员工的工号、姓名和电话号码。

(3) `void sort( employee *pa, int n );`

其中，pa 为数组的首地址，n 为数组元素的个数。该函数的功能是：使用选择法，按姓名升序对 pa 数组进行排序。

(4) `void output( employee *pa, int n );`

其中，pa 为数组的首地址，n 为数组元素的个数。该函数的功能是：输出 pa 数组的所有内容。

编写完整的程序，实现上述功能与要求。
