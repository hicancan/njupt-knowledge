# 《高级语言程序设计》C语言知识点复习资料

原件经识别和整理；“参考解答”是我们补的。

本资料为《高级语言程序设计》C 语言课程的复习要点，涵盖程序结构、数据类型、运算符、控制流程、函数及指针数组等核心考点。

## 总体概念

1.  **程序结构**：C 语言程序结构分为三种：**顺序结构**、**循环结构**（包含 for、while、do-while 三种）、**选择结构**（if 和 switch）。
2.  **执行流程**：读程序必须从 `main()` 入口开始，然后从最上面顺序往下读。碰到循环做循环，碰到选择做选择。
3.  **数据存储**：计算机中的数据在内存中以**二进制**形式保存。数据存放的位置称为**地址**。
4.  **位与字节**：
    *   **bit (位)**：指 0 或者 1。
    *   **byte (字节)**：一个字节 = 8 个位。
5.  **进制转换**：务必掌握二进制如何转换成十进制。
6.  **函数分类**：C 语言中函数可分为**自定义函数**和**库函数**。
7.  **基本数据类型**：包括整型、字符型和浮点型（或实型）。

### 概念常考考点

1.  **编译预处理**：不是 C 语言的一部分，不在运行时执行。C 语言编译的程序称为源程序，以 ASCII 数值存放在文本文件中。
2.  **Main 函数**：每个 C 语言程序中 `main` 函数有且只有一个。
3.  **函数定义**：在函数中不可以再定义函数。
4.  **Break 语句**：可用于循环结构和 switch 语句。
5.  **逗号运算符**：优先级最低。

### 转义字符与进制表示

*   **十六进制**：`int a = 0x6d;` 是将十六进制数赋给变量 `a`，注意前缀 `0x` 必须存在。
*   **八进制**：`int a = 06d;` 是八进制形式。
    *   **非法情况**：`018` 是非法的，因为八进制中没有数字 8（逢 8 进 1）。
*   **转义字符**：
    *   `'\x6d'` 是合法的十六进制转义字符，`0` 不能省略，`x` 必须小写。
    *   `'\141'` 是合法的八进制转义字符，`0` 不能省略。
    *   `'\108'` 是非法的，因为八进制转义字符中不能出现 8。

### 强制类型转换

*   **语法格式**：必须是 `(int)a`，而不是 `int(a)`。类型名外面必须有括号。
*   **作用范围区别**：
    *   `(int)(a+b)`：先计算 `a+b`，再将结果转换为整型。
    *   `(int)a + b`：先将 `a` 转换为整型，再加上 `b`。

知识点：[强制类型转换的语法与应用](../../../topics/C语言程序设计/强制类型转换.md)、[算术运算符及其优先级说明](../../../topics/C语言程序设计/算术运算符.md)、[表达式中及赋值中的自动类型转换原则](../../../topics/C语言程序设计/自动类型转换.md)

### 表达式的考查

*   **赋值表达式**：表达式的值是最左边变量的值。例如 `a=b=5;`，该表达式的值为 5。**常量不可以被赋值**。
*   **自加/自减表达式**：假设 `a=5`。
    *   `++a`：值为 6。机理：先将 `a` 的值加 1 存入 `a`，然后表达式的值为 6。
    *   `a++`：值为 5。机理：先取 `a` 的当前值 5 作为表达式的值，然后将 `a` 的值加 1 变为 6 存入 `a`。
    *   **后续使用**：执行完 `++a` 或 `a++` 后，变量 `a` 中的值均为 6。
    *   **考试口诀**：++在前先加后用，++在后先用后加。
*   **逗号表达式**：
    *   优先级最低。
    *   表达式的值是逗号最右边那个表达式的值。
    *   例如 `(2, 3, 4)` 的值为 4。
*   **取模运算 `%`**：两边要求必须是整数，否则错误。
*   **取整方式**：以下三种情况都会丢弃小数部分：
    1.  `int a = 1.6;` (赋值时截断)
    2.  `(int)a;` (强制转换)
    3.  *(注：原文此处缺失第三种具体写法，通常指整数除法)*

*   表达式的值只能为 1（真）或 0（假）。

### 逻辑表达式

*   表达式的值只能为 1（真）或 0（假）。
*   **逻辑运算符**：`&&` (与), `||` (或), `!` (非)。
*   **优先级**：`!` > `&&` > `||`。
*   **短路现象**：考试常考点。
    *   `&&`：如果左边为假，右边不再计算。
    *   `||`：如果左边为真，右边不再计算。
*   **区间判断**：
    *   **错误写法**：`0 < x < 10`。这是先计算 `0 < x`，结果为 1 或 0；再用 1 或 0 与 10 比较，结果总是真（1）。
    *   **正确写法**：`(0 < x) && (x < 10)`。

### 条件表达式 (三目运算符)

*   **格式**：`表达式1 ? 表达式2 : 表达式3`
*   **规则**：当 `表达式1` 为非 0 (真) 时，结果为 `表达式2` 的值；当 `表达式1` 为 0 (假) 时，结果为 `表达式3` 的值。

### While 循环中的赋值与比较

*   **对比**：`while((c=getchar()) != '\n')` 与 `while(c=getchar() != '\n')`。
*   **原理分析**：
    *   `!=` 的优先级高于 `=`。
    *   `a = 3 != 2`：先算 `3 != 2` 得 1，再赋值给 `a`，所以 `a` 为 1。
    *   `(a = 3) != 2`：先算 `a = 3`，再算 `3 != 2`，此时 `a` 为 3。
*   **注意点**：括号在改变运算优先级中的重要性。

*   **实参与形参**：
    *   调用函数时传入的参数称为**实参**（如 `a`, `b`）。

### 参数传递方式 (考试重点)

1.  **传数值 (Pass by Value)**：
    *   形参是实参的副本。

2.  **传地址 (Pass by Reference/Pointer)**：
    *   传递的是变量的地址。
    *   通过指针操作，形参（指针）所指内容的变化**会**改变实参的值。

知识点：[函数的原型声明及其位置](../../../topics/C语言程序设计/函数原型声明.md)、[指针变量的概念、基类型与定义方法](../../../topics/C语言程序设计/指针的概念与定义.md)

### 指针运算符详解

*   `int *p` 中：
    *   `p`：当作地址使用。
    *   `*p`：解引用，取出地址 `p` 里面存储的数值，可以当变量用。
*   **`*p++` 与 `(*p)++` 的区别** (改错题重点)：
    *   `*p++`：由于 `++` 优先级高于 `*`，等价于 `*(p++)`。先取 `p` 指向的值，然后 `p` 的地址向后移动（指向下一个元素）。**地址变化**。
    *   `(*p)++`：先取 `p` 指向的值，将该值加 1。**数值变化**，地址不变。

1.  **数组名**：表示第一个元素的地址。

2.  **函数名**：表示该函数的入口地址。
3.  **字符串常量名**：表示第一个字符的地址。

### 一维数组的重要概念

以 `int a[10];` 为例：

1.  **a 的含义**：`a` 是数组名，表示第一个元素 `a[0]` 的地址。
2.  **a 的性质**：`a` 是地址常量。因此 `a++` 或 `a = a + 2` 都是错误的。
3.  **a 的类型**：`a` 是一维数组名，类型为指向元素的指针（列指针）。`a+1` 表示跳过 1 个元素的大小。

### 二维数组的重要概念

以 `int a[3][3];` 为例：

1.  **a 的含义**：`a` 是数组名，表示第一行 `a[0]` 的地址，即 `&a[0]`。
2.  **a 的性质**：`a` 是地址常量。`a++` 或 `a = a + 2` 都是错误的。
3.  **a 的类型**：`a` 是二维数组名，类型为指向行的指针（行指针）。`a+1` 表示跳过 1 行（即 3 个元素的大小）。
4.  **a[i] 的性质**：
    *   `a[0]`, `a[1]`, `a[2]` 也都是地址常量，不可赋值。
    *   它们都是列指针（指向该行第一个元素的指针）。
    *   `a[0]+1`, `a[1]+1` 等表示在该行内跳一列。
5.  **a 与 a[i] 的区别**：
    *   `a` 的类型是“指向含 3 个 int 的一维数组的指针”。
    *   `a[i]` 的类型是“指向 int 的指针”。
    *   基类型不同：前者步长是一行，后者步长是一个元素。

### 二维数组做题技巧

**题目示例**：`int a[3][3] = {1, 2, 3, 4, 5, 6, 7, 8, 9};`

**步骤一：可视化数组结构**

| | 第 0 列 | 第 1 列 | 第 2 列 |
| :--- | :---: | :---: | :---: |
| **a[0]** (第 0 行) | 1 | 2 | 3 |
| **a[1]** (第 1 行) | 4 | 5 | 6 |
| **a[2]** (第 2 行) | 7 | 8 | 9 |

**步骤二：解析指针表达式**

*   **`*(a[0]+1)`**：`a[0]` 指向第0行第0列，`+1` 移到第0行第1列，解引用得到 `a[0][1]`，值为 **2**。
*   **`*(a[1]+2)`**：从第1行第0列移到第1行第2列，解引用得到 `a[1][2]`，值为 **6**。

订正：原件把 `*(a[0]+1)` 的值写成了1；按所列数组，其值应为2。

*   **记忆法则**：凡是二维数组题目，先画出上述表格格式，再定位行列，即可简化计算。

### 数组初始化

*   **一维数组**：长度可以省略，编译器自动计算。
    *   `int a[] = {1, 2};` **合法**。
*   **二维数组**：第一维长度可以省略，但**第二维长度必须写明**。
    *   `int a[][4] = {2, 3, 4};` **合法**。
    *   `int a[4][] = {2, 3, 4};` **非法**。
