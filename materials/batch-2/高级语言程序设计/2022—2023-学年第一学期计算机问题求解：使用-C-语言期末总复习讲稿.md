## 模块一：基础知识部分

### 1. C 语言程序的组成

-   **文件结构**：由一个或多个文件组成，每个文件由一个或多个函数组成。
-   **基本单位**：函数是 C 程序的基本单位。
-   **入口函数**：一个程序有且只有一个 `main()` 函数，这是程序的入口。

知识点：[C语言程序的组成结构](../../../topics/C语言程序设计/C程序的组成.md)

### 2. 从源程序到可执行文件的全过程

全过程包括：**编辑** $\rightarrow$ **编译** $\rightarrow$ **链接** $\rightarrow$ **运行**。

各阶段生成的文件扩展名如下：
| 阶段 | 文件类型 | 扩展名 |
| :--- | :--- | :--- |
| 源文件 | .c | `.c` |
| 目标文件 | .obj | `.obj` |
| 可执行文件 | .exe | `.exe` |
| 头文件 | - | `.h` |

知识点：[C程序开发过程（源程序到可执行文件的全过程）](../../../topics/C语言程序设计/C程序开发过程.md)、[计算机硬件组成（CPU、存储器等）及工作过程](../../../topics/C语言程序设计/计算机组成及工作过程.md)、[程序模块的划分原则与方法](../../../topics/C语言程序设计/模块化程序设计.md)

### 3. C 程序中的六种符号

关键字、标识符、运算符、分隔符、其它符号、数据（包括常量和变量）。

#### (1) 常用关键字
需熟悉 C 语言所有常用关键字。

#### (2) 标识符
能正确定义标识符并判断其合法性。

#### (3) 运算符
掌握所有的运算符及其优先级、结合方向及特殊的运算规则。

#### (4) 常量
-   **定义**：值不可变化的量。
-   **表现形式**：字面常量和符号常量。
-   **定义方法**：C 语言定义符号常量只有一种方法：`#define 常量名 串`。

#### (5) 变量
-   **定义**：在程序运行过程中其值可变的量，需要先定义后使用。
-   **属性**：每一个变量都具有变量名、变量的当前值、变量的地址、变量的存储属性。
    -   指针变量中存的是地址。
    -   其余变量中存放的是值。

#### (6) 变量的作用域与存储属性

**全局变量**：
-   在所有函数之外定义的变量。
-   作用域：从定义点开始到程序结束（去掉含同名局部量的作用区域）。

**局部变量**：
-   在函数内部定义的变量（形式参数也是局部变量）。
-   分类：`auto`（默认）和 `static`。
    -   **auto 型**：函数被调用时分配空间，每次函数执行完毕后将不再存在。
    -   **static 型**：程序刚运行时便分配空间并做初始化（若未指定初值则默认为 0），初始化只做一次。每次函数执行完毕后继续存在，但只在本函数中起作用。

## 模块二：三种基本结构及流程控制

C 程序的三种基本结构是：**顺序结构**、**选择结构**、**循环结构**。

知识点：[C程序中的六种符号](../../../topics/C语言程序设计/C程序中的六种符号.md)、[常量与变量的概念](../../../topics/C语言程序设计/常量与变量.md)、[局部变量与全局变量的作用域范围](../../../topics/C语言程序设计/变量的作用域.md)

### 1. 顺序结构

-   **主要语句**：赋值语句和函数调用语句。
-   **常用输入输出函数**：`scanf()`, `printf()`, `getchar()`, `putchar()` 等。
-   **格式控制注意事项**：
    -   `scanf()` 输入时要严格按照格式控制串的形式要求输入。
    -   `printf()` 输出时需进行相应的格式控制。
    -   **常见格式转换说明符**：`%c`, `%s`, `%d`, `%f`, `%lf`。
        -   当变量为 `double` 类型时，在 `scanf` 中必须用 `%lf`，但在 `printf` 中用 `%f` 即可。
    -   **`%s` 的特殊性**：无论 `scanf` 还是 `printf` 中，与之对应的都是**地址**。
    -   **其他格式串**：如 `%d`, `%c`, `%lf`, `%f` 等，在 `scanf` 中用地址对应，但在 `printf` 中用值对应。

知识点：[printf函数的格式控制与使用](../../../topics/C语言程序设计/printf函数.md)、[scanf函数的格式控制与使用](../../../topics/C语言程序设计/scanf函数.md)、[顺序结构程序设计](../../../topics/C语言程序设计/顺序结构.md)

### 2. 选择结构

使用 `if...else`、`switch` 语句配合复合语句、`break` 语句控制实现。

#### (1) if 语句
-   **三种形式**：单分支 `if`、双分支 `if`、嵌套 `if`。
-   **匹配原则**：`else` 应与其前最靠近的未匹配过的 `if` 相对应，而与对齐的形式无关。
-   **条件表达式**：通常是关系或逻辑表达式，实际语法上可以是任何表达式。仅以该表达式是 `0`（假）或非 `0`（真）来判断。
-   **控制范围**：`if( )` 及 `else` 后面都只能控制一条语句，经常需要用到复合语句 `{ ... }`。

#### (2) switch 语句
特别注意事项：
1.  **表达式类型**：`switch` 后面的表达式类型应当为整型、字符型、枚举型，不可以是 `float` 或 `double` 型（因为表达式的取值必须是离散值）。
2.  **执行流程**：找到与表达式匹配的常量后开始执行，直到遇到 `break` 或 `switch` 语句结束才会停止。
    -   如果分支后没有及时用 `break`，则继续向下执行（穿透现象）。
    -   因此，`switch` 结构可以选择多个分支执行。
3.  **常量顺序**：这些常量的顺序调整不影响程序的正确性，只要每个分支执行的功能固定即可。
4.  **嵌套**：嵌套的 `switch` 在阅读时要注意每一层的起止位置。

> **练习思考**：
> 1. 下列程序段执行后，a、b 的值是？
> 2. 设有声明 `int a=1, b=2`，则下面程序段的输出结果是？如果是内层的每个 `case` 后有 `break`，而外层没有 `break`，输出结果是？

知识点：[if单分支与双分支选择语句](../../../topics/C语言程序设计/if语句.md)、[switch多分支选择语句及其说明](../../../topics/C语言程序设计/switch语句.md)、[if语句的嵌套及else就近配对原则](../../../topics/C语言程序设计/if嵌套与就近配对原则.md)

### 3. 循环结构

-   **常用语句**：`while`、`do...while`、`for`。
-   **类型区分**：
    -   `while` 和 `for` 属于**当型循环**。
    -   `do...while` 属于**直到型循环**。
    -   若循环条件为非 `0` 则继续循环，若为 `0` 则结束。
    -   三种循环是可以相互转化的。
-   **控制语句**：
    -   `break`：表示退出本层次循环。
    -   `continue`：表示忽略本次循环体中的后续语句，重新开始下一次循环条件的判断。
-   **退出的几个操作**：
    1.  在循环结构中用 `break` 结束本层循环；在 `switch` 语句中用 `break` 结束本层 `switch` 中当前分支的执行。
    2.  在函数体内的 `return` 语句结束本函数的调用，返回到调用点。
    3.  库函数 `exit` 结束程序的执行，返回到操作系统（该函数在 `<stdlib.h>` 头文件中）。

知识点：[while当型循环语句（含赋值与比较陷阱）](../../../topics/C语言程序设计/while循环.md)、[do-while直到型循环语句](../../../topics/C语言程序设计/do-while循环.md)、[for循环语句及表达式省略规则](../../../topics/C语言程序设计/for循环.md)、[break跳出循环与continue结束本次循环的区别](../../../topics/C语言程序设计/break与continue.md)

### 4. 经典算法回顾

#### (1) 质数问题
-   **判断整数是否为质数**：用一层循环解决。
    -   函数原型：`int prime(int n);`
    -   功能：判断参数 `n` 是否为质数，如果是返回 `1`，不是返回 `0`。
    -   要求：完全掌握教材例子，结合第 5 章掌握定义函数来实现。
-   **找出一定范围内所有的质数**：用两层循环解决。
    -   要求：结合实验题目，能按一定的格式输出。

#### (2) 求和问题
掌握求和问题中条件的控制方式、累加的方式及每一项的特点：
-   **根据项数求解**：例如求 100 项之和。
-   **根据精度求解**：例如求到这一项的绝对值小于 $1E-6$ 为止。
    -   循环控制步骤：
        1.  求当前项的语句。
        2.  将当前项累加到和里的语句。
        3.  根据求和要求改变分子、分母、符号位的语句。
-   **通项公式**：每一项通常表达成 $1.0 \times \text{分子} \times \text{符号位} / \text{分母}$（假设分子分母都是 int 型）。
    -   有的求和不存在正负项交替，则不需要考虑符号位。
    -   有的分子或分母是某一个常量，则上式更简化。
-   **累加器**：求和需要设一个累加器首先清零，然后在循环体内加上表示项的那个变量。
    -   参考教材求和示例及实验 1 中数列求和问题。

#### (3) 符合一定特征的数据寻找问题
-   **水仙花数**：一个三位数如果恰好等于它每一位数字的立方和。
    -   例如：$153 = 1^3 + 5^3 + 3^3$。
-   **完数**：一个数如果恰好等于它的因子（不包含自身）之和。
    -   例如：6 的因子为 1、2、3，而 $6 = 1 + 2 + 3$。

## 模块三：函数

知识点：[质数（素数）判断的经典算法实现](../../../topics/C语言程序设计/质数判断算法.md)、[累加和与阶乘等数列求和算法](../../../topics/C语言程序设计/数列求和算法.md)、[函数的定义格式与函数体](../../../topics/C语言程序设计/函数的定义.md)

### 1. 基本概念
-   **组成**：C 语言的源程序由一个或多个函数组成，其中必须有且只能有一个主函数 `main()`。
-   **执行流程**：程序执行总是从 `main` 函数开始，也是因 `main` 函数的结束而结束整个程序。
-   **嵌套规则**：C 函数只可以**嵌套调用**，而不能**嵌套定义**。
-   **递归**：C 函数可以在定义的时候调用自己，这就是直接递归方式。

知识点：[函数的定义格式与函数体](../../../topics/C语言程序设计/函数的定义.md)、[函数的调用形式与实际参数](../../../topics/C语言程序设计/函数的调用.md)

### 2. 函数相关核心问题

#### (1) 函数定义
-   **组成**：包括函数首部和函数体。
-   **首部要素**：函数返回值类型、函数名（形式参数表）。
-   **返回值**：函数只能返回一个值。如果一个函数需要返回多个信息，则要考虑其中的形式参数采用**指针参数**。
    -   *示例*：`int f(int a[], int n, int *max);`
    -   功能：由函数返回数组 `a` 的前 `n` 个元素之和，而元素的最大值通过设定 `max` 指针，在函数体内求 `*max` 实现。外部调用时，要用一个地址实参对应于形式参数 `max`。

#### (2) 函数原型
-   **定义顺序**：函数应当先定义后被调用。
-   **原型声明**：如果出现调用先于定义的情况，则必须对后定义的函数在调用点之前进行原型声明。
-   **写法**：函数原型就是函数定义的首部最后加一个分号。
-   **参数名**：在原型声明中形式参数名字可以缺省。

#### (3) 函数调用
-   **形式**：`函数名（实在参数表）`

#### (4) 形式参数类型
-   **值形式参数**：实在参数将值赋值到值形式参数变量中（单向传递）。
-   **指针形式参数**：将实参的地址赋值到指针形式参数中。虽然都是单向传递，但是可以通过在被调函数中修改指针所指向的内容达到修改实参变量的目的。

#### (5) 变量的作用域问题

| 变量类型 | 定义位置 | 作用域 | 生命周期 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| **全局变量** | 所有函数之外 | 定义点到程序结束处（去除同名局部量作用域） | 整个程序运行期间 | 初始化为 0 |
| **局部自动变量** | 函数内部（形参表、函数体开始、复合语句开始） | 本函数内的当前语句块 | 所在函数被调用时分配，结束时释放 | 下次调用重新分配 |
| **静态局部变量** | 函数内部（带 static 关键字） | 本函数内 | 整个程序运行期间 | 值保留，只初始化一次，不给定初值自动为 0 |

知识点：[函数的定义格式与函数体](../../../topics/C语言程序设计/函数的定义.md)、[值传递与地址传递（传址）的区别](../../../topics/C语言程序设计/参数传递方式.md)、[局部变量与全局变量的作用域范围](../../../topics/C语言程序设计/变量的作用域.md)

### 3. 重点函数功能
需掌握以下功能用函数实现：
-   判断一个整数是否质数。
-   一维数组中的生成所有元素、输出所有元素。
-   求和、求平均、最值求解、排序、查找。
-   **递归函数**：n!（阶乘）、最大公约数、Fibonacci 的第 n 项等。

## 模块四：数据类型

C 中数据类型分为：**基本类型**、**构造类型**、**指针类型**、**空类型**四大类。
-   **基本类型**：整型、实型、字符型。
-   **构造类型**：枚举型、数组类型、结构体类型、共同体类型。
-   **指针类型**：特殊性在于其变量中存放的是内存地址信息而不是内存中的值。

**本模块重点**：数组、结构体、指针类型、字符串处理、链表，以及与函数的综合使用。

知识点：[递归函数的定义与调用过程](../../../topics/C语言程序设计/函数的递归.md)、[一维数组的定义格式与内存存储方式](../../../topics/C语言程序设计/一维数组的定义与存储.md)、[质数（素数）判断的经典算法实现](../../../topics/C语言程序设计/质数判断算法.md)

### 1. 数组类型

#### (1) 基本知识
-   **定义**：一维及二维数组变量的定义。
    -   注意：方括号中必须是整型常量或常量表达式。例：`int a[4];`
    -   下标范围：有效下标范围为 $0 \sim 3$。**起始下标为 0**，不可以下标越界访问。
-   **初始化**：
    -   可以缺省元素个数。
    -   对于二维数组只能缺省行数。
    -   规则：从左至右依次初始化。当初值少于元素个数时，其余元素的默认初值为 0。
-   **访问元素**：
    -   两种等效表示：`a[i]` 和 `*(a+i)`。
    -   两种等效地址：`a+i` 或 `&a[i]`。
-   **一维字符数组操作字符串**：
    -   会正确输入输出数组的元素。
    -   正确输入输出字符串。
        -   例：`char str[20]="ABCDE";` 则 `printf("%s\n", str+2);` 的输出结果是 `CDE`。
        -   原理：与 `%s` 对应的是表示字符串的首地址，输出遇到 `\0` 结尾标志就结束。
-   **string.h 常用函数**：
    -   `strlen`：求长度（有效字符个数，不包括结尾标记）。
    -   字符串比较：不能用 `s1 > s2`，应该用 `strcmp(s1, s2) > 0`。
    -   字符串赋值、连接。
    -   编程实现：字符串逆置、删除空格、抽取指定形式字符（如只保留数字）。

#### (2) 二维数组
-   **基本方法**：按矩阵形式输出、转置、求主对角线或次对角线元素之和。
-   **算法理解**：
    -   理解一维数组名作实参和形式参数传地址的实质。
    -   理解 `void f(int a[])` 中的形式参数 `a` 实质上是一个指针形式参数，即函数首部可写成 `void f(int *a)`。
-   **一维数组常见算法**：
    -   输入/输出所有元素。
    -   寻找最大数、最小数。
    -   求和、求平均值。
    -   查找某一个值是否是数组中的元素。
    -   排序算法。
    -   插入和删除元素（需画图理解数组元素移位操作，如课本图 6.5, 6.6）。

### 2. 指针类型

-   **定义形式**：`数据类型 *指针变量名`，例：`int *p;`
-   **区别**：注意 `p` 与 `*p` 的区别。
-   **注意事项**：
    -   指针变量若未赋值，不能对 `*p` 操作。
    -   若对指针赋值为空值（NULL），也不能对 `*p` 操作。

#### 指针与数组的关系
-   熟练掌握对指针操作一维数组。
-   理解数组名是地址常量的概念。
-   **指针运算**：指针指向数组的时候执行 `p++`、`p--` 的意义。
-   **访问方法**：
    -   下标法：`p[2]`
    -   指针运算符：`*(p+2)`
    -   例：`int a[4]={1,2,3,4}, *p=a; ++p;`
        -   `p[2]` 或 `*(p+2)` 表示元素 `a[3]`。
        -   `p+1` 或 `a+2` 表示地址概念，都等于 `&a[2]`。
-   **易错点**：区别 `*p++` 和 `*(p++)` 这两个表达式的不同结果。
-   **指针减法**：指向同一数组空间中的指针可以做减法，表示二者之间相隔的元素个数。
-   **函数参数**：掌握数组做函数参数时的两种表达方式。
-   **字符指针 vs 字符数组**：
    -   用字符指针操作字符串比用字符数组具有更大的灵活性。
    -   例：`s=p;` 是正确的赋值。
    -   错误示例：`s=*p;` 或 `*s="AB";` 都是错误的。

### 3. 结构体类型

-   **定义**：会正确定义结构体类型，以及嵌套的结构体类型。

    1.  先定义类型再定义变量。
    2.  定义类型的同时定义变量（类型名可以缺省）。

    -   掌握用结构体指针正确访问结构体或结构体数组元素。
-   **typedef**：会用 `typedef` 给出一个类型的别名。
    -   语法：`typedef 原类型名 新类型名;`

### 2. C 文件打开的方式

-   **基本方式**：
    -   `r`：只读
    -   `w`：只写
    -   `a`：追加
-   **修饰符**：
    -   `+`：表示可读可写。
        -   打开一个新文件可读可写，一定是 `w+`。
        -   打开一个旧文件可读可写，可能是 `r+` 或 `a+`。
    -   `b`：表示打开二进制文件（否则默认是对文本文件操作）。

### 3. 文件的操作步骤

1.  **定义指针**：定义 `FILE*` 文件指针，一个文件对应一个指针。
2.  **打开文件**：利用文件指针打开文件 `fp = fopen(文件名，打开方式)`。
    -   注意：文件名要用双引号括起，路径之间用 `\\`。
    -   打开方式也要用双引号括起。
3.  **读写操作**：共四对函数。
    | 读写类型 | 函数对 |
    :--- | :--- |
    单字符读写 | `fgetc`, `fputc` |
    字符串读写 | `fgets`, `fputs` |
    格式化读写 | `fscanf`, `fprintf` |
    块数据读写 | `fread`, `fwrite` |
    -   **示例**：一般用 `fgetc(fp, c)` 来从已有文件中获取一个字符，用 `fputc(fp, c)` 向 `fp` 所对应的文件中写入一个字符。该操作往往要用循环条件控制执行。
4.  **关闭文件**：文件操作完成后要用 `fclose(fp)` 关闭文件。
