### 编程 8

编写一个程序，要求：

① 在 `main` 函数中定义一维整型数组 `arr`，调用 `input` 函数完成数组的 n 个元素的输入（n≤20），然后统计数组中质数元素的个数。最后输出质数的个数及所有的质数元素。

② 输入函数的原型为：`void input(int *ptr, int n);` 其中，`ptr` 为数组的首地址，`n` 为要输入元素的个数。

③ 将判断质数定义为一个函数，原型为：`int isPrime(int n);` 其中，`n` 为待判断的整数，如果是质数返回 1，不是质数返回 0。

### 编程 9

编程一个程序实现：

① 产生数组元素函数的原型为：`void input(int *ptr, int n);` 其中，`ptr` 为数组的首地址，`n` 为要输入元素的个数。要求产生 n 个数组元素，值在 [1,100] 区间（用随机函数产生，不是从键盘输入）。

② 输出函数的原型为：`void output(int *ptr, int n);` 其中，`ptr` 为数组的首地址，`n` 为要输入元素的个数。

③ 排序函数，原型为：`int sort(int *ptr, int n);`

④ 在 `main` 函数中定义一维整型数组 `arr`，调用 `input` 函数产生数组的 10 个元素，调用 `output` 依次输出数组元素；再对数组中的元素按由小到大的顺序排序调用 `sort` 函数，最后再调用 `output` 输出排序后的数组元素。

```c
int main() {
    int arr[N];
    srand(time(NULL));   // 调用系统时钟做种子
    input(arr, N);
    printf("The former array:\n");
    output(arr, N);
    sort(arr, N);
    printf("The latter array:\n");
    output(arr, N);
    return 0;
}
