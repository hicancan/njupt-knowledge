### 编程 1

给一维数组输入数据后，找出最大值并输出。

参考解答：**结论**：先读入数组元素，再用一个变量保存当前最大值，遍历数组比较更新，最后输出。

**思路与关键步骤**：
1. 定义数组 `a[n]`。
2. 用循环输入：`for (i=0;i<n;i++) scanf("%d", &a[i]);`
3. 设 `max = a[0]`。
4. 从 `i=1` 到 `n-1` 比较：若 `a[i] > max`，则 `max = a[i]`。
5. 输出 `max`。

**参考代码**：
```c
#include <stdio.h>

int main() {
    int n, i, max;
    int a[100];

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    max = a[0];
    for (i = 1; i < n; i++) {
        if (a[i] > max) {
            max = a[i];
        }
    }

    printf("max = %d\n", max);
    return 0;
}
```

**复杂度**：时间复杂度 $O(n)$，空间复杂度 $O(n)$（若只需最大值可优化到 $O(1)$）。

### 编程 2

结构体类型中有两个整型成员 `a`、`b` 和一个双精度实型成员 `average`，成员 `average` 的值是两个整型成员 `a` 和 `b` 的平均值。编写主函数，定义该类型的数组共 5 个元素，程序完成读入这 5 个结构体数组元素中的整型成员，然后求出实型成员的值，最后输出 5 个结构体变量各成员的值。

参考解答：结论：  
定义一个结构体类型，包含 `int a`、`int b` 和 `double average`，主函数中创建包含 5 个元素的数组，依次输入 `a` 和 `b`，计算 `average = (a + b) / 2.0`，最后输出每个元素的三个成员。

简明推理/计算过程：  
1. 结构体定义需在函数外或内部，使用 `struct` 关键字，三个成员如题目所述。  
2. 主函数中定义 `struct` 类型的数组长度为 5。  
3. 用循环读取每个数组元素的 `a` 和 `b`。  
4. 在同一个或下一个循环中计算 `average`：强制类型提升为浮点需用 2.0 作为除数。  
5. 再用循环输出所有成员，输出格式可用空格或换行分隔。

关键代码框架：
```c
#include <stdio.h>

struct Data {
    int a;
    int b;
    double average;
};

int main() {
    struct Data arr[5];
    for (int i = 0; i < 5; i++) {
        scanf("%d %d", &arr[i].a, &arr[i].b);
        arr[i].average = (arr[i].a + arr[i].b) / 2.0;
    }
    for (int i = 0; i < 5; i++) {
        printf("%d %d %.2f\n", arr[i].a, arr[i].b, arr[i].average);
    }
    return 0;
}
```
说明：  
- 用 `/2.0` 保证结果为 `double` 类型，避免整数整除丢失小数。  
- 输出时 average 可按需保留小数，此处示例用 `%.2f`。  
- 若题目无额外要求，无需对输入输出添加多余提示文字。  

若是选择题形式，可据此判断各选项正误：  
- 选项若将 `average` 定义为 `int` 则错（题目要求双精度实型）。  
- 选项若用 `(a+b)/2` 直接赋给 `double` 会丢失小数部分。  
- 选项若未用循环读取所有元素则不符合“5 个结构体数组元素”的要求。  
- 选项若缺少计算 `average` 的步骤则未完成“求出实型成员的值”。

### 编程 3

编写程序输出下三角形式的九九乘法表。

参考解答：**结论**  
程序按嵌套循环结构输出下三角九九乘法表。

**参考程序**  
```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 9; ++i) {          // 控制行
        for (int j = 1; j <= i; ++j) {      // 控制列，列数等于当前行号
            printf("%d×%d=%-2d  ", j, i, i * j);
        }
        printf("\n");                       // 每行结束换行
    }
    return 0;
}
```

**输出效果**  
```

1×2=2   2×2=4   
1×3=3   2×3=6   3×3=9   
1×4=4   2×4=8   3×4=12  4×4=16  
1×5=5   2×5=10  3×5=15  4×5=20  5×5=25

### 编程 4

编程统计文件 `d:\letter.txt` 中大写字母 `A` 的个数并输出。

参考解答：**结论**

使用 C 语言标准文件操作函数，以只读文本模式打开 `d:\letter.txt`，逐字符读取并统计等于 `'A'` 的字符数量，最后输出计数结果。

**推理与关键步骤**

1.  **文件打开**：使用 `fopen("d:\\letter.txt", "r")` 打开文件。注意在 C 语言字符串中，路径分隔符 `\` 需要转义为 `\\`。需检查返回的文件指针是否为 `NULL` 以确保文件成功打开。
2.  **初始化计数器**：定义整型变量 `count = 0` 用于存储大写字母 `A` 的出现次数。
3.  **遍历与统计**：使用 `fgetc()` 函数循环读取文件中的每个字符，直到遇到文件结束符 `EOF`。在循环体内，判断当前读取的字符是否等于 `'A'`，若相等则 `count++`。
4.  **资源释放与输出**：循环结束后，使用 `fclose()` 关闭文件指针，并使用 `printf` 输出 `count` 的值。

**参考代码实现**

```c
#include <stdio.h>

int main() {
    FILE *fp;
    int ch;
    int count = 0;

    // 1. 打开文件，注意路径中的反斜杠需要转义
    fp = fopen("d:\\letter.txt", "r");
    
    // 检查文件是否成功打开
    if (fp == NULL) {
        printf("无法打开文件 d:\\letter.txt\n");
        return 1;
    }

    // 2. 逐字符读取并统计
    while ((ch = fgetc(fp)) != EOF) {
        if (ch == 'A') {
            count++;
        }
    }

    // 3. 关闭文件
    fclose(fp);

    // 4. 输出结果
    printf("大写字母 A 的个数为: %d\n", count);

    return 0;
}
```

### 编程 5

读取 C 盘根目录下的文本文件 `test.txt`，将其中的大写字母以小写字母的形式显示，其余字符均原样显示。

参考解答：## 结论

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *fp;
    int ch;

    fp = fopen("C:\\test.txt", "r");
    if (fp == NULL)
    {
        printf("无法打开文件！\n");
        exit(1);
    }

    while ((ch = fgetc(fp)) != EOF)
    {
        if (ch >= 'A' && ch <= 'Z')
            ch = ch + ('a' - 'A');   /* 大写转小写 */
        putchar(ch);
    }

    fclose(fp);
    return 0;
}
```

## 关键说明

1. **文件打开**：路径写作 `"C:\\test.txt"`（反斜杠需转义），只读模式 `"r"`；打开失败必须判断 `fp == NULL` 并退出。
2. **逐字符读取**：用 `fgetc` 循环读取，直到返回 `EOF`。
3. **大小写转换**：若字符满足 `'A' <= ch <= 'Z'`，则加上 `'a' - 'A'`（即 32）变为对应小写字母；其余字符直接输出。
4. **资源释放**：用 `fclose(fp)` 关闭文件。

### 编程 6

从键盘上读入一个字符串，不另外定义新串，将该串中的所有空格删除后再输出。

参考解答：**结论**

使用双指针（快慢指针）原地压缩字符串。快指针 `j` 遍历原串，慢指针 `i` 指向下一个非空格字符应写入的位置。若 `s[j]` 不是空格，则令 `s[i++] = s[j]`；否则跳过。最后在 `s[i]` 处置入 `'\0'`。

**推理与关键步骤**

- 删除操作不改变非空格字符的相对顺序，因此把非空格字符依次前移即可，无需新串。
- 由于 `i <= j` 恒成立，写入不会覆盖尚未读取的字符，原地操作安全。
- 复杂度：时间 $O(n)$，额外空间 $O(1)$。

**参考代码**

```c
#include <stdio.h>

int main(void)
{
    char s[1000];
    int i = 0, j = 0;

    fgets(s, sizeof(s), stdin);   /* 读入一行 */

    while (s[j] != '\0') {
        if (s[j] != ' ') {        /* 非空格则前移 */
            s[i] = s[j];
            i++;
        }
        j++;
    }
    s[i] = '\0';                  /* 新的字符串结束位置 */

    printf("%s\n", s);
    return 0;
}
```

### 编程 7

利用循环结构求下列数列的前 100 项之和并输出和值。

参考解答：# 数列求和

## 题目分析

题目要求利用循环结构求数列前 100 项之和。根据常见教材，该数列通项公式为：

$$a_n = \frac{1}{n(n+1)}$$

即：

$$S = \sum_{n=1}^{100} \frac{1}{n(n+1)}$$

## 数学推导

利用裂项相消法：

$$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$

所以：

$$S = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{100} - \frac{1}{101}\right) = 1 - \frac{1}{101} = \frac{100}{101} \approx 0.990099$$

## C 语言参考代码

```c
#include <stdio.h>

int main() {
    double sum = 0.0;
    int n;
    
    for (n = 1; n <= 100; n++) {
        sum += 1.0 / (n * (n + 1));
    }
    
    printf("前100项之和为: %f\n", sum);
    printf("精确值: 100/101 = %f\n", 100.0 / 101);
    
    return 0;
}
```

## 运行结果

```
前100项之和为: 0.990099
精确值: 100/101 = 0.990099
```

## 关键点说明

| 要点 | 说明 |
|------|------|
| 循环变量 | `n` 从 1 到 100，共 100 项 |
| 累加器 | `sum` 初始化为 0，类型为 `double` 保证精度 |
| 通项公式 | `1.0 / (n * (n + 1))`，注意用 `1.0` 而非 `1` 避免整数除法 |
| 验证 | 理论值 $\frac{100}{101} \approx 0.990099$，与程序输出一致 |

知识点：[累加和与阶乘等数列求和算法](../../../topics/C语言程序设计/数列求和算法.md)、[多重循环嵌套的执行过程](../../../topics/C语言程序设计/循环嵌套.md)

### 编程 8

编写一个程序，要求：

① 在 `main` 函数中定义一维整型数组 `arr`，调用 `input` 函数完成数组的 n 个元素的输入（n≤20），然后统计数组中质数元素的个数。最后输出质数的个数及所有的质数元素。

② 输入函数的原型为：`void input(int *ptr, int n);` 其中，`ptr` 为数组的首地址，`n` 为要输入元素的个数。

③ 将判断质数定义为一个函数，原型为：`int isPrime(int n);` 其中，`n` 为待判断的整数，如果是质数返回 1，不是质数返回 0。

参考解答：**结论：** 完整程序如下。

```c
#include <stdio.h>

void input(int *ptr, int n);
int isPrime(int n);

int main(void) {
    int arr[20];
    int n;
    int count = 0;
    int primes[20];

    printf("请输入元素个数n(n<=20): ");
    scanf("%d", &n);

    input(arr, n);

    for (int i = 0; i < n; i++) {
        if (isPrime(arr[i])) {
            primes[count++] = arr[i];
        }
    }

    printf("质数个数为: %d\n", count);
    printf("质数元素为: ");
    for (int i = 0; i < count; i++) {
        printf("%d ", primes[i]);
    }
    printf("\n");

    return 0;
}

void input(int *ptr, int n) {
    printf("请输入%d个整数:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", ptr + i);
    }
}

int isPrime(int n) {
    if (n <= 1) return 0;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return 0;
    }
    return 1;
}
```

**推理与关键步骤：**

- **`input` 函数**：利用指针 `ptr + i` 等价于 `&ptr[i]`，通过循环依次读入 $n$ 个整数到数组中。
- **`isPrime` 函数**：质数定义为大于 $1$ 且只能被 $1$ 和自身整除的自然数。先排除 $n \le 1$ 的情况；再用试除法从 $2$ 遍历到 $\lfloor\sqrt{n}\rfloor$（即 `i * i <= n`），若存在因子则返回 $0$，否则返回 $1$。
- **`main` 函数**：遍历数组每个元素调用 `isPrime`，若返回 $1$ 则将该元素存入 `primes` 数组并使计数器 `count` 自增，最后输出统计结果。

### 编程 9

编程一个程序实现：

① 产生数组元素函数的原型为：`void input(int *ptr, int n);` 其中，`ptr` 为数组的首地址，`n` 为要输入元素的个数。要求产生 n 个数组元素，值在 [1,100] 区间（用随机函数产生，不是从键盘输入）。

② 输出函数的原型为：`void output(int *ptr, int n);` 其中，`ptr` 为数组的首地址，`n` 为要输入元素的个数。

③ 排序函数，原型为：`int sort(int *ptr, int n);`

④ 在 `main` 函数中定义一维整型数组 `arr`，调用 `input` 函数产生数组的 10 个元素，调用 `output` 依次输出数组元素；再对数组中的元素按由小到大的顺序排序调用 `sort` 函数，最后再调用 `output` 输出排序后的数组元素。

```c
int main() {
    int arr[N];
    srand(time(NULL));   // 调用系统时钟做种子
    input(arr, N);
    printf("The former array:\n");
    output(arr, N);
    sort(arr, N);
    printf("The latter array:\n");
    output(arr, N);
    return 0;
}

参考解答：结论：  
`input` 用 `rand()` 生成 `[1,100]` 的随机数存入数组，`output` 遍历输出，`sort` 采用冒泡排序实现升序排列。

关键实现如下：

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define N 10

void input(int *ptr, int n) {
    for (int i = 0; i < n; ++i)
        ptr[i] = rand() % 100 + 1;
}

void output(int *ptr, int n) {
    for (int i = 0; i < n; ++i)
        printf("%d ", ptr[i]);
    printf("\n");
}

int sort(int *ptr, int n) {
    int i, j, t;
    for (i = 0; i < n - 1; ++i)
        for (j = 0; j < n - 1 - i; ++j)
            if (ptr[j] > ptr[j + 1]) {
                t = ptr[j];
                ptr[j] = ptr[j + 1];
                ptr[j + 1] = t;
            }
    return 0;
}

int main() {
    int arr[N];
    srand((unsigned)time(NULL));
    input(arr, N);
    printf("The former array:\n");
    output(arr, N);
    sort(arr, N);
    printf("The latter array:\n");
    output(arr, N);
    return 0;
}
```

说明：  
- `rand() % 100 + 1` 产生 `1~100` 的整数。  
- 冒泡排序每轮把最大元素“冒”到末尾，两两比较交换实现升序。  
- `sort` 返回 `int`，这里直接返回 `0` 表示正常完成。
