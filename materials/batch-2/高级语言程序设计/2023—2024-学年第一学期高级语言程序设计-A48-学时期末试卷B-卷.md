### 选择 4

若 x 和 n 均是 int 型变量，且 x 的初值为 12，n 的初值为 5，则执行表达式 $x\% = (n\% = 2)$ 后 x 的值为 \_\_\_\_。

- A. 0
- B. 6
- C. 3
- D. 12

答案：A
参考解答：赋值运算符从右向左结合。
1. 先计算 $(n\% = 2)$：$n \% 2 = 5 \% 2 = 1$，将 1 赋给 n，此时 n=1，整个括号表达式的值为 1。
2. 再计算 $x\% = 1$：即 $x = x \% 1 = 12 \% 1 = 0$。
所以 x 的值为 0。

### 选择 10

下面程序段的输出结果是 \_\_\_\_。
```c
int i = 5;
while(i--); 
printf("%d", i);
```
- A. 0
- B. -1
- C. 1
- D. while 构成无限循环

答案：B
参考解答：
`i--` 是后置自减，先判断 i 的值，再减 1。
当 i=1 时，判断为真（非0），执行空语句，i 变为 0。
下一次循环，判断 i=0，为假，退出循环，但在判断前 i 并未变化？不对，后置自减是在表达式求值后执行。
让我们仔细追踪：
初始 i=5。
1. 判断 5 (真), i 变为 4。
...
5. 判断 1 (真), i 变为 0。
6. 判断 0 (假), 循环结束。注意：在判断条件时使用的是当前的 i 值。当 i=0 时，条件为假，循环终止。此时 i 已经是 0 了吗？
不，后置自减 `i--` 的副作用发生在序列点之后。
标准行为：
`while(i--)`
Step 1: check i(5), true, i becomes 4.
Step 2: check i(4), true, i becomes 3.
Step 3: check i(3), true, i becomes 2.
Step 4: check i(2), true, i becomes 1.
Step 5: check i(1), true, i becomes 0.
Step 6: check i(0), false, loop terminates. The decrement happens after the value is used for the condition. Since the value was 0, the condition is false. Does it decrement? Yes, but the loop exits immediately. Wait, strictly speaking, the expression evaluates to 0 (false), and then i is decremented to -1? Or does it exit before decrementing if the result is false?
Actually, `i--` returns the original value. If original value is 0, condition is false. The side effect `i = i - 1` still happens because the full expression is evaluated. So i becomes -1.
Let's verify with code logic.
If i=1: check 1 (true), i becomes 0. Next check i=0 (false), i becomes -1. Loop ends. Print -1.
So output is -1.

知识点：[自增（++）、自减（--）运算符](../../../topics/C语言程序设计/自增自减运算符.md)、[关系运算符与关系表达式](../../../topics/C语言程序设计/关系运算符.md)

### 选择 11

以下程序段 \_\_\_\_。
```c
x=-1;
do
{
    !x
    x=x*x;
}while(!x);
```
- A. 是死循环
- B. 循环体执行二次
- C. 循环体执行一次
- D. 有语法错误

答案：C
参考解答：
初始 x=-1。
进入 do-while 循环。
1. `!x` 即 `!(-1)`，结果为 0（假），这是一个表达式语句，无副作用，仅计算。
2. `x = x * x` => `x = (-1) * (-1) = 1`。
3. 判断 `while(!x)`：此时 x=1，`!1` 为 0（假）。循环结束。
循环体只执行了一次。

### 选择 12

以下对二维数组 a 的初始化正确定义的是 \_\_\_\_，

- A. `int a[2][?] = {1, 2, 3, 4};` （注：原题选项A中第二维疑似缺失或乱码，根据常规题型推测可能为 `int a[][2]` 或其他，但看其他选项）
   *修正：观察图片及常见考题，A选项通常为 `int a[][2]` 或类似。此处根据上下文，A选项显示为 `int a[2][?]`，这显然是识别错误或原题印刷错误。让我们看其他选项。*
- B. `int a[3][%] = {{1, 2}, {5, 6}};` （% 也是乱码）
- C. `int a[2][3] = {1, 2, 3, 4, 5, 6, 7};`
- D. `int a[][3] = {1, 2, 3, 4};`

*分析：*
通常这类题目考察第一维可省略，第二维不可省略。
C: `int a[2][3]` 定义大小为 2x3。初始化列表有 7 个元素。C 语言允许初始化列表元素多于数组元素吗？不允许。或者它会将多余的部分截断？实际上，如果初始化列表的元素个数超过数组容量，编译器会报错。这里 2x3=6 个位置，给了 7 个值，错误。
D: `int a[][3]`，第二维为 3。初始化 `{1, 2, 3, 4}`。
第一行：1, 2, 3
第二行：4, 0, 0
这是合法的。编译器会根据第二维的大小自动推断第一维的大小为 2（因为提供了4个值，每行3个，至少需要2行）。

假设 A 和 B 中的 `?` 和 `%` 是识别错误的数字。
如果 A 是 `int a[][2] = ...`，4个元素刚好填满 2x2，合法。
如果 B 是 `int a[3][]`，非法，第一维不能省。

鉴于 D 是完全合法的标准写法，且没有乱码嫌疑（除了题干中的下划线），D 是最可能的正确答案。

答案：D
参考解答：定义二维数组时，可以省略第一维的长度，但不能省略第二维。D 选项中第二维为 3，初始化数据足够确定第一维长度为 2，语法正确。

### 选择 14

设有语句 `int *point, i=10;` 和 `point=&i;`，则下面全部代表地址的一组选项为 \_\_\_\_

- A. `i`, `point`, `&i`
- B. `&*i`, `&i`, `*point`

### 选择 15

- A. `a[4]`
- B. `*(p+4)`
- C. `a+5`
- D. `*p[5]`

答案：B

A: `a[4]` 值为 4。
C: `a+5` 是地址，不是元素值。
D: `p[5]` 等价于 `*(p+5)` 即 `a[6]`，再加 `*` 运算优先级问题，`*p[5]` 会被解析为 `*(p[5])`，即 `*(a[6])`，而 `a[6]` 是 int，不能解引用，编译错误。即使理解为 `(*p)[5]` 也不对。

## 五、编程题 1（10 分）

如果一种数恰好等于它的因子（包括 1 但是不包括它自身）之和，这个数就称为“完数”。例如 $6=1+2+3$ ，6就是完数。编写程序输出 1~n 范围内的所有完数，n 由输入确定，必须是大于 1 的正整数。如果该范围内没有完数，则输出提示信息：“无完数”。

```c
#include <stdio.h>

int main() {
    int n, i, j, sum, found = 0;
    
    printf("Enter n: ");
    scanf("%d", &n);
    
    if (n <= 1) {
        printf("n must be greater than 1.\n");
        return 1;
    }
    
    for (i = 2; i <= n; i++) {
        sum = 0;
        // 计算因子之和
        for (j = 1; j < i; j++) {
            if (i % j == 0) {
                sum += j;
            }
        }
        
        // 判断是否为完数
        if (sum == i) {
            printf("%d ", i);
            found = 1;
        }
    }
    
    if (!found) {
        printf("无完数");
    }
    printf("\n");
    
    return 0;
}
```

## 六、编程题 2（15 分）

编写一个程序，要求：

① 定义 input 函数完成数组 array 中 n 个元素的输入。函数原型：`void input(int array[], int n);` 主函数中调用该函数完成输入数组的 n 个元素；

② 定义 output 函数完成数组 array 中 n 个元素值的输出。函数原型：`void output(int *array, int n);` 主函数中调用该函数完成输出数组的 n 个元素;

③ 定义 isPalindrome 函数判断数组元素是否满足回文数组的条件，回文数组是指正反排列后的元素顺序相同的数组，具有中心对称的特点。如数组【1 2 3 2 1】即是一个回文数组，而【1 2 3 4】就不是回文数组。函数原型为：`int isPalindrome(int array[], int n);` 主函数中调用该函数得到判断结果;

④ 在 main 函数中定义长度为 20 的一维 int 型数组 array 和表示实际输入元素个数的 int 型变量 n，从键盘上获得 n 的值（要求此值在 [1,20] 之间），然后调用 input 完成数组元素的输入，调用 output 输出所有元素，根据调用 isPalindrome 函数的结果输出是或不是回文数组的结论。

```c
#include <stdio.h>

// 1. 输入函数
void input(int array[], int n) {
    int i;
    for (i = 0; i < n; i++) {
        scanf("%d", &array[i]);
    }
}

// 2. 输出函数
void output(int *array, int n) {
    int i;
    for (i = 0; i < n; i++) {
        printf("%d ", *(array + i));
    }
    printf("\n");
}

// 3. 判断回文函数
int isPalindrome(int array[], int n) {
    int i;
    for (i = 0; i < n / 2; i++) {
        if (array[i] != array[n - 1 - i]) {
            return 0; // 不是回文
        }
    }
    return 1; // 是回文
}

int main() {
    int array[20];
    int n;
    
    printf("Enter number of elements (1-20): ");
    scanf("%d", &n);
    
    if (n < 1 || n > 20) {
        printf("Invalid n value.\n");
        return 1;
    }
    
    input(array, n);
    output(array, n);
    
    if (isPalindrome(array, n)) {
        printf("Yes, it is a palindrome array.\n");
    } else {
        printf("No, it is not a palindrome array.\n");
    }
    
    return 0;
}
```
