### 选择 1

下列字符中 ASCII 码值最小的是\_\_\_\_。

- A. a
- B. Z
- C. f
- D. A

参考解答：**结论：D**

ASCII 码值大小顺序为：大写字母 < 小写字母；字母顺序越靠前，码值越小。  
A～Z 的码值为 65～90，a～z 为 97～122。  
因此 A(65) < Z(90) < a(97) < f(102)，最小的是 **A**。

### 选择 2

将二进制数 $101101$ 转换成十进制数是\_\_\_\_。

- A. 45
- B. 90
- C. 49
- D. 91

参考解答：**答案：A. 45**

按权展开计算：


$$
(101101)_2 = 1\times2^5 + 0\times2^4 + 1\times2^3 + 1\times2^2 + 0\times2^1 + 1\times2^0
$$



$$
= 32 + 0 + 8 + 4 + 0 + 1 = 45
$$


- **A 正确**：计算结果为 45。
- **B 错误**：90 是 45 的两倍，相当于多左移了一位。
- **C、D 错误**：均不符合上述按权展开的结果。

### 选择 3

下面四个选项中, 均是合法浮点数的选项是\_\_\_\_。

- A. $+1e+1$, $5e-9.4$, $03e2$
- B. $-.60$, $12e-4$, $-8e5$
- C. $123e$, $1.2e-.4$, $+2e-1$
- D. $-e3$, $8e-4$, $5.e-0$

参考解答：**B**

在 C 语言等高级语言中，浮点数（科学计数法）的合法格式要求为：`[符号]数字部分 e/E [符号]整数指数`。关键规则是指数部分必须为**整数**，且 `e` 前后必须有有效的数字部分（除非使用小数点形式如 `.5` 或 `5.`）。

*   **A 错误**：`5e-9.4` 的指数 `-9.4` 是小数，非法；`03e2` 虽语法可能通过（视作八进制前缀的十进制解析或单纯数字），但通常标准浮点字面量不推荐以 0 开头混淆，且 `5e-9.4` 已确定其错误。
*   **B 正确**：`-.60` 是合法的小数形式浮点数；`12e-4` 和 `-8e5` 均符合“底数 e 整数指数”的规范，均为合法浮点数。
*   **C 错误**：`123e` 缺少指数部分；`1.2e-.4` 的指数 `-.4` 是小数，非法。
*   **D 错误**：`-e3` 缺少底数部分（e 前面没有数字），非法。

知识点：[实型数据的合法表示形式](../../../topics/C语言程序设计/实型数据的合法形式.md)、[常量与变量的概念](../../../topics/C语言程序设计/常量与变量.md)

### 选择 4

设变量均已正确定义并且赋值，以下与其他三组输出结构不同的一组语句是\_\_\_\_。

- A. `x++; printf("%d\n", x);`
- B. `n=++x; printf("%d\n", n);`
- C. `++x; printf("%d\n", x);`
- D. `n=x++; printf("%d\n", n);`

参考解答：**结论：D**

**推理过程：**

设变量 `x` 初始值为 $a$。

- **A**：`x++;` 先使用后自增，语句结束后 $x = a+1$；输出 `x`，即 $a+1$。
- **B**：`n = ++x;` 前置自增，先令 $x = a+1$，再赋给 `n`，故 $n = a+1$；输出 $n$，即 $a+1$。
- **C**：`++x;` 语句结束后 $x = a+1$；输出 `x`，即 $a+1$。
- **D**：`n = x++;` 后置自增，先把原值 $a$ 赋给 `n`，再令 $x = a+1$，故 $n = a$；输出 $n$，即 $a$。

A、B、C 均输出自增后的值 $a+1$，D 输出自增前的值 $a$，故输出结构不同的是 **D**。

知识点：[自增（++）、自减（--）运算符](../../../topics/C语言程序设计/自增自减运算符.md)、[赋值运算符及复合赋值运算符](../../../topics/C语言程序设计/赋值及复合赋值运算符.md)、[表达式中及赋值中的自动类型转换原则](../../../topics/C语言程序设计/自动类型转换.md)

### 选择 5

为表示关系 $x \ge Y$ 且 $Y \ge z$ ，应使用 C 语言表达式\_\_\_\_。

- A. `(x>=Y) && (Y>=z)`
- B. `(x>=Y) AND (Y>=z)`
- C. `(x>=Y>=z)`
- D. `(x>=Y) & (Y>=z)`

参考解答：结论：**A**

C 语言中，逻辑“与”运算符是 `&&`，而 `AND` 不是 C 的关键字（排除 B）。选项 C `(x>=Y>=z)` 是按结合性等价于 `((x>=Y)>=z)`，即先比较得出 0 或 1，再与 `z` 比较，语义错误。选项 D 使用位运算符 `&`，虽然在此处碰巧能得到正确逻辑值，但语义上表示按位与，不宜用于逻辑关系表达。因此，正确的表达式为 `(x>=Y) && (Y>=z)`。

### 选择 6

设有语句: `int a=7; float x=2.5, y=4.7;`，则表达式 `x+a%3*(int)(x+y)%2/4` 的值是\_\_\_\_。

- A. 2.5
- B. 2.75
- C. 2.0
- D. 0.0

参考解答：结论：**A. 2.5**

**推理过程：**

按运算符优先级和结合性，先计算 `a%3`，再处理类型转换 `(int)(x+y)`，接着从左到右进行乘、模、除运算，最后与 `x` 相加。

1. `a%3` → `7 % 3 = 1`
2. `(int)(x+y)` → `(int)(2.5 + 4.7) = (int)7.2 = 7`
3. 原表达式变为：`x + 1 * 7 % 2 / 4`
4. 乘、模、除从左向右结合：  
   `1 * 7 = 7`  
   `7 % 2 = 1`  
   `1 / 4 = 0` （整数相除，结果取整）
5. 最后：`x + 0 = 2.5 + 0 = 2.5`

**选项简析：**

- A：正确，计算结果为 2.5。  
- B：2.75，误将 `1/4` 当成浮点运算得到 0.25 再相加。  
- C：2.0，可能误认为 `(int)(x+y)` 是 7.0 且除法保留了小数部分后计算错误。  
- D：0.0，可能把整个表达式误解为整数运算或被 0 除等错误。

知识点：[算术运算符及其优先级说明](../../../topics/C语言程序设计/算术运算符.md)、[表达式中及赋值中的自动类型转换原则](../../../topics/C语言程序设计/自动类型转换.md)、[强制类型转换的语法与应用](../../../topics/C语言程序设计/强制类型转换.md)

### 选择 7

if 语句的基本形式是: `if(表达式)语句`, 以下关于 “表达式” 值的叙述中正确的是\_\_\_\_。

- A. 必须是逻辑值
- B. 必须是整数值
- C. 必须是正数
- D. 可以是任意合法的数值

参考解答：**结论**：D

**推理过程**：
在 C 语言等高级语言中，`if` 语句括号内的表达式并不局限于布尔类型或特定的整数范围。其判断规则如下：
1.  **合法性**：表达式必须是语法上合法的，且能计算出一个确定的值。
2.  **真假判定**：系统将该表达式的值视为逻辑真或假。规定为：**非零值（Non-zero）为真，零值（Zero）为假**。
3.  **类型兼容性**：该值可以是整型、浮点型、指针等任意合法数值类型。例如 `if(3.14)`、`if(-5)`、`if(ptr)` 均合法。

**选项分析**：
*   **A 错**：C 语言标准早期没有内置布尔类型，且即使有，表达式也可以是整型或浮点型，不“必须”是逻辑值。
*   **B 错**：表达式可以是浮点数（如 `if(0.5)`），不“必须”是整数。
*   **C 错**：负数（如 `-1`）是非零值，代表“真”，因此不“必须”是正数。
*   **D 对**：只要表达式合法且能求出数值（用于判断零或非零），即可作为 `if` 的条件。

知识点：[if单分支与双分支选择语句](../../../topics/C语言程序设计/if语句.md)

### 选择 8

关于 switch 语句，下列说法中不正确的是\_\_\_\_。

- A. case 语句必须以 break 结束
- B. default 分支可以没有
- C. switch 后面的表达式可以是整型或字符型
- D. case 后面的常量值必须唯一

参考解答：**答案：A**

**解析：**

- **A 错误**：`case` 分支**不必须**以 `break` 结束；若省略 `break`，程序会继续执行后续分支（即“贯穿”/fall-through 现象）。
- **B 正确**：`default` 分支是可选的，用于处理所有 `case` 均未匹配的情况。
- **C 正确**：`switch` 后的表达式必须是整型（包括 `char`、枚举等离散类型），不能是浮点型或字符串。
- **D 正确**：各 `case` 后的常量表达式值必须互不相同，否则编译器无法确定入口，会报错。

知识点：[switch多分支选择语句及其说明](../../../topics/C语言程序设计/switch语句.md)

### 选择 9

下列循环的执行结果是\_\_\_\_。

```c
int i,sum=0;
for(i=1;i<=3;sum++) sum+=i;
```

- A. 6
- B. 3
- C. 死循环
- D. 0

参考解答：**C. 死循环**

`for(i=1; i<=3; sum++)` 中，循环变量 `i` 从未被修改，始终为 $1$，条件 $1 \le 3$ 恒真。

每次循环体 `sum+=i` 使 `sum` 加 $1$，更新表达式 `sum++` 又使 `sum` 再加 $1$，即每轮 `sum` 增加 $2$，但 `i` 保持不变，循环无法终止。

- A：错误，`sum` 会无限增长，不会停在 $6$。
- B：错误，循环不会结束并返回某个值。
- D：错误，`sum` 初值为 $0$ 但循环体不断累加。

知识点：[for循环语句及表达式省略规则](../../../topics/C语言程序设计/for循环.md)、[赋值运算符及复合赋值运算符](../../../topics/C语言程序设计/赋值及复合赋值运算符.md)、[表达式中及赋值中的自动类型转换原则](../../../topics/C语言程序设计/自动类型转换.md)

### 选择 11

若有以下程序：

```c
#include <stdio.h>
void f(int n);
int main()
{
    void f(int n);
    f(5);
    return 0;
}
void f(int n)
{
    printf("%d\n",n);
}
```

则以下叙述中不正确的是\_\_\_\_。

- A. 若只在主函数中对函数f进行说明，则只能在主函数中正确调用函数f
- B. 若在主函数前对函数f进行说明，则在主函数和其后的其它函数中都可以正确调用函数f
- C. 对于以上程序，编译时系统会提示出错信息：提示对f函数重复说明
- D. 函数f无返回值，所以可用void将其类型定义为无类型

参考解答：**选 C**

---

### 各选项分析

- **A 正确**：函数声明的作用域从其声明处开始到所在块结束。若只在 `main` 内部声明 `f`，则只有 `main` 中可见该声明，其他函数无法调用（除非另有声明）。
- **B 正确**：在所有函数外部（文件作用域）声明 `f`，则该声明对后续所有函数均可见，均可正确调用。
- **C 不正确（即本题答案）**：C 语言**允许**对同一函数进行多次兼容的声明（重复声明），只要不冲突就不会报错。本程序中文件作用域的 `void f(int n);` 与 `main` 内部的 `void f(int n);` 是合法的重复声明，编译**不会**提示出错。
- **D 正确**：`void` 用于修饰无返回值的函数，表示该函数不返回值，描述无误。

知识点：[函数的定义格式与函数体](../../../topics/C语言程序设计/函数的定义.md)、[函数的原型声明及其位置](../../../topics/C语言程序设计/函数原型声明.md)

### 选择 12

关于 return 语句的理解, 下列哪一种说法是错误的\_\_\_\_\_\_。

- A. 当函数具有非 void 的返回值类型时, 函数体中一定要有 return 语句
- B. 当函数的返回值类型为 void 时, 函数体中可以没有 return 语句
- C. return 后的表达式若与函数返回类型不一致时, 一定会在编译时出错
- D. 当执行 return 语句时, 系统自动生成一个无名变量获取 return 后的表达式的值

参考解答：结论：**C 是错误的。**

- **D 正确**：`return` 执行时会用返回值初始化一个临时对象（无名变量），再将该临时对象传回调用处。

### 选择 16

以下程序的输出结果是\_\_\_\_。

```c
# include <stdio.h>
int main()
{
    int n[2] = {0}, i, j, k = 2;
    for (i = 0; i < k; i++)
        for (j = 0; j < k; j++)
            n[j] = n[i] + 1;
    printf("%d\n", n[k - 1]);
    return 0;
}
```

- A. 不确定的值
- B. 3
- C. 2
- D. 1

参考解答：**结论：B. 3**

**过程：**

初始 `n[0]=0, n[1]=0`，`k=2`。

- `i=0, j=0`：`n[0] = n[0] + 1 = 1`  
- `i=0, j=1`：`n[1] = n[0] + 1 = 2`  
- `i=1, j=0`：`n[0] = n[1] + 1 = 3`  
- `i=1, j=1`：`n[1] = n[1] + 1 = 3`

- D. `*&x`

1.  **变量定义分析**：
    `int x, *p=&x;` 定义了一个整型变量 $x$ 和一个指向整型的指针 $p$，且 $p$ 被初始化为 $x$ 的地址，即 $p = \&x$。

2.  **表达式解析**：
    表达式 `&*p` 包含两个运算符：解引用运算符 `*` 和取地址运算符 `&`。根据 C 语言运算符优先级，这两个运算符结合方向均为从右向左，但在此语境下逻辑如下：
    -   `*p`：取出指针 $p$ 所指向的内容。因为 $p$ 指向 $x$，所以 `*p` 等价于变量 $x$（作为左值，代表 $x$ 这个存储单元）。
    -   `&(*p)`：对 `*p` 的结果取地址。即取变量 $x$ 的地址。

3.  **结论推导**：
    $\&(*p) \equiv \&x$。

**选项分析：**

-   **A. `&x`**：正确。`&*p` 先解引用得到 $x$，再取地址得到 $x$ 的地址，即 `&x`。
-   **B. `*p`**：错误。`*p` 是 $x$ 的值（或左值），而 `&*p` 是地址，类型不同。
-   **C. `x`**：错误。同上，这是整数值，不是地址。
-   **D. `*&x`**：错误。`*&x` 等价于 `*(&x)`，即对 $x$ 的地址解引用，结果是 $x$ 本身，而不是 $x$ 的地址。

# 六、编程题2（10分）

参考解答：```c
#include <stdio.h>

int main()
{
    int x, y, z;
    for (x = 1; x <= 50; x++)
        for (y = x + 1; y <= 50; y++)
            for (z = y + 1; z <= 50; z++)
                if (x * x + y * y == z * z)

}

### 编程 2

从键盘输入任意一个整数 $m (< 1000)$ , 编写函数 fun 实现查找小于或等于 $m$ 的所有素数并放在 array 数组中, 函数返回所求出的素数的个数。

参考解答：**结论**

核心逻辑是遍历 $[2, m]$ 区间内的每个整数，通过试除法判断其是否为素数，若是则存入数组并计数。时间复杂度为 $O(m\sqrt{m})$。

**推理与实现过程**

1.  **素数判定算法**：
    对于任意整数 $n$，若 $n < 2$，则不是素数。若 $n \ge 2$，只需检查从 $2$ 到 $\lfloor\sqrt{n}\rfloor$ 之间是否存在能整除 $n$ 的因子。若存在，则 $n$ 为合数；否则为素数。
    数学依据：若 $n$ 有因子 $d$ 且 $d > \sqrt{n}$，则必存在另一因子 $n/d < \sqrt{n}$，故只需检查至 $\sqrt{n}$。

2.  **函数设计**：
    *   **输入**：整数 $m$，整型数组 `array`（用于存储结果）。
    *   **输出**：素数个数 `count`。
    *   **流程**：
        1. 初始化计数器 `count = 0`。
        2. 循环变量 $i$ 从 $2$ 遍历至 $m$。
        3. 对每个 $i$ 调用素数判断逻辑。
        4. 若 $i$ 是素数，执行 `array[count] = i` 并 `count++`。
        5. 返回 `count`。

3.  **关键代码结构（C语言示例）**：

```c
#include <math.h>

// 辅助函数：判断是否为素数
int isPrime(int n) {
    if (n < 2) return 0;
    for (int k = 2; k <= (int)sqrt(n); k++) {
        if (n % k == 0) return 0;
    }
    return 1;
}

// 主功能函数
int fun(int m, int array[]) {
    int count = 0;
    for (int i = 2; i <= m; i++) {
        if (isPrime(i)) {
            array[count] = i;
            count++;
        }
    }
    return count;
}
```

**注意事项**
*   边界条件：若 $m < 2$，循环不执行或判断失败，返回 0，数组为空，符合逻辑。
*   数组空间：调用者需确保 `array` 有足够的空间容纳最多 $\pi(m)$ 个素数（对于 $m<1000$，素数个数不超过 168 个）。
