### 填空 2

题干：给一个不多于 5 位的正整数，要求：①求出它是几位数；②分别打印出每一位数字；③按逆顺序打印出各位数字，例如原来为 12345，应输出 54321。
```c
#include <stdio.h>
int main() {
    int num, temp, digit, count = 0;
    long reversed_num = 0;
    scanf("%d", &num);
    temp = num;
    while (temp != 0) {
        digit = temp % 10;
        reversed_num = reversed_num * 10 + digit;
        temp /= 10;
        count++;
    }
    printf("位数: %d\n", count);
    printf("逆序: %ld\n", reversed_num);
    // 正向打印每位需要额外逻辑或栈，此处省略详细代码填充
```

### 填空 3

题干：请编写函数 fun，其功能是：计算并输出 3 到 n 之间所有素数的平方根之和。
```c
double fun(int n) {
    double sum = 0.0;
    int i, j, is_prime;
    for (i = 3; i <= n; i++) {
        is_prime = 1;
        for (j = 2; j * j <= i; j++) {
            if (i % j == 0) {
                is_prime = 0;
                break;
            }
        }
        if (is_prime) {
            sum += sqrt(i);
        }
    }
    return sum;
}
```

## 六、编程题 2（15分）

题干：利用 do…while 循环语句，模拟简单用户登录。具体要求：登录时需要输入用户名和密码，当用户和密码都输入正确时，正常登录；当输错任意一项或两项时，均不能正常登录；输错三次，则退出系统。

参考代码：
```c
#include <stdio.h>
#include <string.h>

int main() {
    char username[20], password[20];
    const char correct_user[] = "admin";
    const char correct_pass[] = "123456";
    int attempts = 0;
    int max_attempts = 3;
    int success = 0;

    do {
        printf("Enter username: ");
        scanf("%s", username);
        printf("Enter password: ");
        scanf("%s", password);

        attempts++;

        if (strcmp(username, correct_user) == 0 && strcmp(password, correct_pass) == 0) {
            success = 1;
            break;
        } else {
            printf("Login failed.\n");
        }
    } while (attempts < max_attempts);

    if (success) {
        printf("Login successful!\n");
    } else {
        printf("System locked due to too many failed attempts.\n");
    }

    return 0;
}
```
