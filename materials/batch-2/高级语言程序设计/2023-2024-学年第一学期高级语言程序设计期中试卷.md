### 选择 7
有 int 型变量 x、y、z，语句 `if(x > y) z = 0; else z = 1;` 等价于
- A. `z = (x > y) ? 1 : 0`
- B. `z = x > y`
- C. `z = x <= y`
- D. `z = x <= y ? 0 : 1`

答案：D。
参考解答：
原代码：若 x>y，z=0；否则（x<=y），z=1。
A: 若 x>y，z=1（错）。
B: 逻辑值 1 或 0，但顺序反了（x>y 时为 1，原题为 0）。
C: 只是赋值，没有三元运算符的逻辑分支，且逻辑相反。
D: 若 x<=y 为真，z=0？不对。
重新推导：
原逻辑：`x > y` -> `z=0`; `else` -> `z=1`.
A: `(x>y)?1:0` -> `x>y` 时 `z=1` (错)。
B: `x>y` -> 1, else 0. (错)。
C: `x<=y` -> 1, else 0. (错)。
D: `x<=y?0:1` -> 若 `x<=y` 为真，`z=0`。但原题是 `x<=y` 时 `z=1`。
**再次检查题目与选项**：
原题：`if(x>y) z=0; else z=1;`
即：`x>y` 为真 -> 0；`x>y` 为假 -> 1。
A: `z=(x>y)?1:0` -> `x>y` 为真 -> 1 (错)。
B: `z=x>y` -> `x>y` 为真 -> 1 (错)。
C: `z=x<=y` -> `x>y` 为假 -> 1 (对)，`x>y` 为真 -> 0 (对)。
   因为 `x>y` 为假 等价于 `x<=y` 为真。
   当 `x>y` 为真时，`x<=y` 为假 (0)，`z=0`。符合。
   当 `x>y` 为假时，`x<=y` 为真 (1)，`z=1`。符合。
所以 C 是正确的逻辑等价。
D: `z=x<=y?0:1` -> `x<=y` 为真 -> 0 (错)。

**订正**：原题选项 C 的 LaTeX 识别可能有误，原文显示为 `$. { z } { = } \mathbf { x } { < } { = } \mathbf { y }$`。
答案：C。

### 选择 8
有以下程序段，while 循环执行的次数是______。
```c
int i = 0;
while(i != 2)
    i++;
```
- A. 执行 2 次
- B. 有语法错，不能执行
- C. 执行 0 次
- D. 无限次

答案：D。
参考解答：
i 从 0 开始，每次加 1。
第一次：i=0!=2，执行 i++ -> i=1。
第二次：i=1!=2，执行 i++ -> i=2。
第三次：i=2!=2 为假，循环结束。
**等等，题目问的是“执行次数”**。
i=0, 进入循环，i 变为 1。
i=1, 进入循环，i 变为 2。
i=2, 不进入循环。
总共执行了 2 次。
**再检查选项**：
如果题目是 `while(i != 2)`，确实是 2 次。
但是，如果是 `while(i != 2)` 且 `i` 初始为 0，步长为 1，确实会经过 0->1->2。
难道题目有陷阱？比如 `i` 是局部变量未初始化？不，题目写了 `int i=0`。
或者是题目印刷错误，原题可能是 `while(i!=2) i--;` 或者 `i` 初始值不同？
看选项 D“无限次”，通常对应死循环。
如果题目是 `while(i != 2)`，且 `i` 初始为 0，每次 `i++`，那就是 2 次。
**重新审视 OCR**：
原文：`$_ \mathrm { i n t } \quad \mathrm { i = } 0 ;$ $\mathrm { w h i l e } ( \mathrm { i } ! { = } 2 )$ i++;`
确实是 2 次。
**但是**，有些题库中这类题的陷阱是 `i` 的类型溢出或者题目其实是 `while(i!=2)` 但 `i` 初始化为其他值？
或者，题目其实是 `while(i != 2)` 且 `i` 初始为 0，但 `i` 是 `unsigned`？不，声明是 `int`。
让我们再看一眼选项 A。
如果答案是 A，那么 D 就是干扰项。
如果答案是 D，说明题目逻辑是死循环。
有没有可能题目是 `while(i != 2) i--;`？那样就是死循环。但 OCR 显示 `i++`。
有没有可能题目是 `while(i != 2)` 且 `i` 初始为 2？那样是 0 次。
**另一种可能**：题目是 `while(i != 2)`，但 `i` 的定义有问题？
**最可能的解释**：这是一道经典题，原题通常是 `while(i!=2)` 且 `i` 初始为 0，答案是 2 次。
**但是**，如果题目是 `while(i!=2)` 且 `i` 是 `short` 或其他？
**再仔细看选项**：A. 执行 2 次。
**结论**：按标准逻辑，答案是 2 次。选 A。
*(注：若原题意图是考察死循环，通常会将 `i` 设为 2 或改变方向，此处按 OCR 文本逻辑作答)*

知识点：[while当型循环语句（含赋值与比较陷阱）](../../../topics/C语言程序设计/while循环.md)、[自增（++）、自减（--）运算符](../../../topics/C语言程序设计/自增自减运算符.md)、[顺序、选择、循环三种基本控制结构](../../../topics/C语言程序设计/三种基本控制结构.md)

### 选择 9
下列程序段执行后，m 的值为
```c
int i,j,m;
for(i=1;i<=4;i++) {
    m=0;
    for(j=i;j<=4;j++)
        m=m+i*j;
}
printf("%d\n",m);
```
- A. 5
- B. 6
- C. 16
- D. 36

答案：D。
参考解答：
外层循环 i 从 1 到 4。
i=1: m=0; j=1..4. m = 0 + 1*1 + 1*2 + 1*3 + 1*4 = 1+2+3+4 = 10.
i=2: m=0; j=2..4. m = 0 + 2*2 + 2*3 + 2*4 = 4+6+8 = 18.
i=3: m=0; j=3..4. m = 0 + 3*3 + 3*4 = 9+12 = 21.
i=4: m=0; j=4..4. m = 0 + 4*4 = 16.
最后输出 m 的值，即最后一次循环结束后的 m 值，为 16。
**等等**，题目问的是 `m` 的值。
循环结束后，m 保留的是最后一次 i=4 时的结果，即 16。
选项中有 16 (C) 和 36 (D)。
让我重新算一下总和？
题目是 `m=m+i*j`。
i=1: sum(1..4) * 1 = 10.
i=2: sum(2..4) * 2 = (2+3+4)*2 = 9*2 = 18.
i=3: sum(3..4) * 3 = (3+4)*3 = 7*3 = 21.
i=4: sum(4..4) * 4 = 4*4 = 16.
最终 m=16。
**难道我理解错了？**
是不是题目问的是所有 m 的和？不，变量 m 被重置了。
是不是题目代码不一样？
`for(j=i;j<=4;j++) m=m+i*j;`
是的，每次外层循环 m 归零。
所以结果是 16。
**检查选项**：C 是 16。
**为什么会有 36？**
如果题目是 `m` 不归零？
如果 `m=0` 在外层循环之前？
代码明确写着 `{ m=0; ... }`。
所以答案应该是 16。
**订正**：如果标准答案是 36，那可能是题目代码 `m=0` 在 `for(i...)` 外面。但根据给出的代码块，`m=0` 在内部。
按现有代码，答案为 16。

### 选择 14
以下正确的函数的形式是
- A. `double fun(int x,int y) {z=x+y ;return z}`
- B. `fun(int x, y) {int z ;return z ;}`
- C. `fun(x,y) {double z ;z=x+y ;return z ;}`
- D. `double fun(int x,int y) {int x,y ;double z ;z=x+y ;return z ;}`

答案：C。
参考解答：
A: 缺少变量 z 的定义（在 C 语言中，局部变量需先定义后使用，虽然某些编译器允许，但标准 C 要求定义）。且 `z` 未定义类型。
B: 函数名前缺少返回类型（默认为 int，但 `x, y` 未指定类型，C89 允许隐式声明但现代 C 不允许，且 `fun` 返回类型未显式给出，通常视为错误或不规范）。
C: 旧式函数定义（K&R C），参数类型省略，默认 int。这是合法的旧式写法。
D: 形参 `x, y` 重复定义（`int x,y` 在参数列表中又定义了？不，参数列表是 `int x,int y`，函数体内又写了 `int x,y`，这是重复定义，错误）。
**对比**：
A: 缺少 `int z;`。
B: 缺少返回类型（默认为 int），但参数无类型，C99 以后报错。
C: K&R 风格，合法。
D: 变量重复定义。
**但是**，题目说“正确的函数形式”。
在现代 C 考试中，通常考察标准 C。
A 缺定义。
B 缺返回类型（或隐式）。
C 是旧式。
D 重复定义。
**再看 A**：`{z=x+y ;return z}`。如果上下文没定义 z，编译错。
**再看 C**：`fun(x,y)` 这种写法在 C 中是合法的（虽然不推荐），只要参数默认是 int。
**再看 D**：`int x,y` 在函数体内重复了参数名，错误。
**结论**：C 是最可能的正确选项（尽管是旧式）。
**订正**：如果题目隐含是 C99 或 C11，可能没有正确答案，但 C 是唯一语法上“能跑”的（在宽松模式下）。
**实际上**，很多教材仍视 C 为正确（兼容模式）。
**或者**，A 选项其实有 `int z`？OCR 漏了？
原文 A: `double fun(int x,int y) {z=x+y ;return z}`。确实没看到定义。

**结论：** 使用 `do...while` 循环配合计数器实现最多 3 次登录尝试，用户名和密码均匹配才成功。

```c
#include <stdio.h>

}
```

```c
    temp = x;
    printf("正序：");
    while(power > 0) {
        digit = temp / power;
        printf("%d ", digit);
        temp %= power;
        power /= 10;
    }
    printf("\n");
    return 0;
}
```
*(注：由于题目要求填空，具体空缺位置未知，此处提供完整逻辑)*

参考解答：**结论**  
程序需要实现三个功能：  
1. 求正整数 $x$ 是几位数；  
2. 按从高位到低位的顺序输出每一位数字；  
3. 按逆序输出整个数字。

**关键步骤**：  
- 设输入的正整数为 $x$。  
- 用循环 `while(temp > 0){ temp /= 10; count++; }` 统计位数。  
- 逆序输出：不断取 `x % 10` 得到个位，然后 `x /= 10` 去掉个位，直到 $x=0$。  
- 正序输出：先算出最高位的权值 `power = 10^(位数-1)`，然后每次用 `x / power` 取出最高位，再用 `x %= power` 去掉最高位，`power /= 10` 直到 `power` 为 0。

**注意**：逆序与正序需要分别用原始输入值的副本，避免修改原值影响后续操作。

## 六、编程题 2（15 分）

利用 do…while 循环语句，模拟简单用户登录。具体要求：登录时需要输入用户名和密码，当用户和密码都输入正确时，正常登录；当输错任意一项或两项时，均不能正常登录；输错三次，则退出系统。

```c
#include <stdio.h>
#include <string.h>

        printf("请输入用户名：");

        printf("请输入密码：");

        correct_user = (strcmp(username, real_user) == 0);
```

## 六、编程题 2

**结论：** 使用 `do...while` 循环配合计数器实现最多 3 次登录尝试，用户名和密码均匹配才成功。

```c
#include <stdio.h>
#include <string.h>

int main() {
    char username[50], password[50];
    int attempts = 0;

    do {
        printf("请输入用户名：");
        scanf("%s", username);
        printf("请输入密码：");
        scanf("%s", password);

        if (strcmp(username, "admin") == 0 && strcmp(password, "123456") == 0) {
            printf("登录成功！\n");
            break;
        } else {
            attempts++;
            printf("用户名或密码错误！\n");
            if (attempts >= 3) {
                printf("输错三次，退出系统。\n");
                break;
            }
        }
    } while (1);

    return 0;
}
```

**关键步骤：**
1. `do...while(1)` 保证至少执行一次输入流程，通过内部 `break` 控制退出。
2. 字符串比较**必须用 `strcmp()`**，不能用 `==`（`==` 比较的是指针地址而非内容）。
3. `attempts` 记录失败次数，达到 $3$ 次时输出提示并 `break` 退出循环。
