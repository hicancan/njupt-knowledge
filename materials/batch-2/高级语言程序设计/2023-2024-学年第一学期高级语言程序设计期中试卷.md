### 填空 2
若有变量定义：`double a=13.6; int b=8;` 则表达式 `a + b^0 / 03 * (int)(a - b) / 4` 结果为 ______。
**注意**：OCR 识别 `b^0` 可能是 `b` 的某种运算？
原文：`$\mathbf { a } { + } \mathbf { b } ^ { 0 } / 0 3 ^ { * } ( \mathrm { i n t } ) ( \mathbf { a } { - } \mathbf { b } ) / 4$`
这里的 `^` 在 C 语言中是异或，但 `b` 是 int，`0` 是 int。
`03` 是八进制 3。
表达式解析：
`a + (b^0) / 03 * (int)(a-b) / 4`
`b=8` (1000), `0` (0000). `8^0 = 8`.
`03` 是 3。
`a-b` = 13.6 - 8 = 5.6. `(int)5.6` = 5.
表达式：`13.6 + 8 / 3 * 5 / 4`。
运算顺序：`/`, `*`, `/` 从左到右。
1. `8 / 3` (整数除法) = 2。
2. `2 * 5` = 10。
3. `10 / 4` (整数除法) = 2。
4. `13.6 + 2` = 15.6。
答案：`15.6`。

给一个不多于 5 位的正整数，要求：①求出它是几位数；②分别打印出每一位数字；③按逆顺序打印出各位数字，例如原来为 12345，应输出 54321。
**分析**：这是典型的“水仙花数”或“位数处理”题目。
**代码框架**：
```c
#include <stdio.h>
int main() {
    int x, count = 0, temp, digit;
    scanf("%d", &x);
    temp = x;
    // 求位数
    while(temp > 0) {
        temp /= 10;
        count++;
    }
    printf("位数：%d\n", count);
    
    // 打印每一位
    temp = x;
    // 需要倒序处理才能按位打印？或者直接除10取余
    // 题目要求：分别打印出每一位数字（通常指从左到右）
    // 以及逆序打印
    
    // 逆序打印
    printf("逆序：");
    temp = x;
    while(temp > 0) {
        printf("%d", temp % 10);
        temp /= 10;
    }
    printf("\n");
    
    // 正向打印每一位
    // 需要先求最高位权值
    temp = x;
    int power = 1;
    while(temp >= 10) {
        temp /= 10;
        power *= 10;
    }
    temp = x;
    printf("正序：");
    while(power > 0) {
        digit = temp / power;
        printf("%d ", digit);
        temp %= power;
        power /= 10;
    }
    printf("\n");
    return 0;
}
```

int main() {
    double sum = 0.0;
    int sign = 1;
    for (int i = 1; i <= 1000; i++) {

## 六、编程题 2（15 分）

利用 do…while 循环语句，模拟简单用户登录。具体要求：登录时需要输入用户名和密码，当用户和密码都输入正确时，正常登录；当输错任意一项或两项时，均不能正常登录；输错三次，则退出系统。

**代码实现**：
```c
#include <stdio.h>
#include <string.h>

int main() {
    char username[20], password[20];
    int attempts = 0;
    int correct_user = 0, correct_pass = 0;
    
    // 预设账号密码
    const char *real_user = "admin";
    const char *real_pass = "123456";
    
    do {
        printf("请输入用户名：");
        scanf("%s", username);
        printf("请输入密码：");
        scanf("%s", password);
        
        correct_user = (strcmp(username, real_user) == 0);
        correct_pass = (strcmp(password, real_pass) == 0);
        
        if (correct_user && correct_pass) {
            printf("登录成功！\n");
            break;
        } else {
            printf("用户名或密码错误！\n");
            attempts++;
            if (attempts >= 3) {
                printf("错误次数过多，系统退出。\n");
                return 0;
            }
        }
    } while (1); // do-while 循环，通过 break 跳出
    
    return 0;
}
```
