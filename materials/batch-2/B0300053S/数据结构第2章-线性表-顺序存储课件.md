线性结构的特点

• 存在唯一的”第一个”数据元素;

### 分析：

![第 14 页](数据结构第2章-线性表-顺序存储课件.assets/第14页.webp)

原文：

分析：

设顺序表长度为n，则在位置i $( \mathrm { i } { = } { } \mathbf { - } 1 , 0 , \cdots , \mathbf { n } { - } 1 )$ 后插入一个元素要移动 n-i-1个元素。

设 $\mathbf { P _ { i } }$ 是在位置i 之后插入一个新元素的概率，并设在任意位置处插入元素的概率是相等的， 即 $\mathbf { P _ { i } } { = } 1 / ( \mathbf { n } { + } 1 )$ 。设 $\mathbf { { E _ { i } } }$ 是在长度为n 的顺序表中插入一个新元素时所需移动元素的平均次数，则：

$$
E _ {i} = \sum_ {i = - 1} ^ {n - 1} \frac {1}{n + 1} (n - i - 1) = \frac {n}{2}
$$

渐近时间复杂度： ${ \mathrm { O } } ( { \mathfrak { n } } )$

### 线性表的顺序存储表示的优缺点：

![第 22 页](数据结构第2章-线性表-顺序存储课件.assets/第22页.webp)

原文：

线性表的顺序存储表示的优缺点：

（1）优点：

随机存取；

存储空间利用率高。

（2）缺点：

插入、删除效率低；

必须按事先估计的最大元素个数分配连续的存储空间，难以临时扩大。
