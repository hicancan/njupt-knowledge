### 一元整系数多项式

![第 29 页](数据结构第2章-线性表链接存储与多项式计算.assets/第29页.webp)

原文：

一元整系数多项式

$$
\mathbf {p} (\mathbf {x}) = 3 \mathbf {x} ^ {1 4} - 8 \mathbf {x} ^ {8} + 6 \mathbf {x} ^ {2} + 2
$$

要求:(1)按降幂排列

(2)做 $\mathsf { q } ( \mathbf { x } ) { \gets } \mathsf { q } ( \mathbf { x } ) { + } \mathsf { p } ( \mathbf { x } )$

分析:

1. 数据元素

该多项式是由一项一项组成的。我们忽略掉各项具体数字的细节，即每一项就是由系数(coef)和指数(exp)组成的：coef·x<sup>exp</sup> 。

每一项就是一个要处理的数据元素，即(coef,exp) 。

### 2. 元素间的逻辑关系

![第 30 页](数据结构第2章-线性表链接存储与多项式计算.assets/第30页.webp)

原文：

2. 元素间的逻辑关系

由于多项式按降幂排列，因此每一项都有一个指数比它高的项，有一个比它低的项，除了最高项没有比它高的项，最后一项没有比它低的项外。这样，多项式的每一项就组成了一个线性表，线性表中的每个数据元素是多项式的一项(coef,exp)。

因此，一元整系数多项式可以视为线性表。

### 3. 存储表示

![第 31 页](数据结构第2章-线性表链接存储与多项式计算.assets/第31页.webp)

原文：

3. 存储表示

$$
\mathbf {q} (\mathbf {x}) = 2 \mathbf {x} ^ {1 0} + 4 \mathbf {x} ^ {8} - 6 \mathbf {x} ^ {2}, \mathbf {p} (\mathbf {x}) = 3 \mathbf {x} ^ {1 4} - 8 \mathbf {x} ^ {8} + 6 \mathbf {x} ^ {2} + 2
$$

做 $\mathsf { q } ( \mathbf { x } ) { + } \mathsf { p } ( \mathbf { x } ) { \Rightarrow } \mathsf { q } ( \mathbf { x } )$ 9

结果为： $\mathsf { q } ( \mathbf { x } ) { = } 3 \mathbf { x } ^ { 1 4 } { + } 2 \mathbf { x } ^ { 1 0 } { - } 4 \mathbf { x } ^ { 8 } { + } 2$

线性表有顺序和链接存储：

1.用顺序存储：q(x) (2,10) (4,8) (-6,2)

<table><tr><td>p(x)</td><td>(3,14)</td><td>(-8,8)</td><td>(6,2)</td><td>(2,0)</td></tr></table>

<table><tr><td>结果q(x)</td><td>(3,14)</td><td>(2,10)</td><td>(-4,8)</td><td>(2,0)</td></tr></table>

从结果中可以发现，在q(x)上做了插入和删除运算，因此不宜采用顺序存储。
