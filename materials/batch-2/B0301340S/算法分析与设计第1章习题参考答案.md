## 第一章习题

### 习题 1

确定划线语句的执行次数，计算它们的渐近时间复杂度。

（1）

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j++)
        k = k + 10 * i;  // 划线语句
```

答案：划线语句的执行次数为 $n^2$，$O(n^2)$。

（2）

```c
i = 1;
do {
    x++;          // 划线语句
    i = 3 * i;
} while (i < n);
```

答案：划线语句的执行次数为 $t = \lceil \log_3 n \rceil$，渐近时间复杂度为 $O(\log_3 n)$。

（3）

```c
for (i = 0; i < n; i++)
    for (j = 0; j < n; j++)
        a[i][j] = 0;  // 划线语句
```

答案：划线语句的执行次数为 $n^2$，$O(n^2)$。

（4）

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        for (k = 1; k <= j; k++)
            y++;  // 划线语句
```

答案：划线语句的执行次数为 $\frac{n(n+1)(n+2)}{6}$，渐近时间复杂度为 $O(n^3)$。
