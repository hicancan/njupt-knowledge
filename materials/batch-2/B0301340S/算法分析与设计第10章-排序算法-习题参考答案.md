#### D. 快速排序

**结论：** 取首元素为枢轴（pivot），一趟划分后枢轴就位，再递归处理左右子序列。下面用 $\{\,\}$ 标记待排序的子区间，每趟对所有当前子区间同时划分。

| 趟数 | 序列状态 |
| :--- | :--- |

| 一 | $\{26 \quad 35 \quad 21 \quad 30 \quad 57 \quad 7\} \quad 65 \quad \{79 \quad 80 \quad 78\}$ |
| 二 | $\{7 \quad 21\} \quad 26 \quad \{30 \quad 57 \quad 35\} \quad 65 \quad \{78\} \quad 79 \quad \{80\}$ |

| 四 | $7 \quad 21 \quad 26 \quad 30 \quad 57 \quad 35 \quad 65 \quad 78 \quad 79 \quad 80$ |
| 五 | $7 \quad 21 \quad 26 \quad 30 \quad 35 \quad 57 \quad 65 \quad 78 \quad 79 \quad 80$ |

**关键步骤说明（第一趟划分）：**
- 枢轴 $=65$。左右指针向中间扫描：
  - 右指针找到 $26<65$，左指针找到 $78>65$，交换；
  - 继续：右指针找到 $57<65$（左指针已到 $30$，停止），将 $57$ 移到左侧空位；
  - 最终左侧 $\{26,35,21,30,57,7\}$，右侧 $\{79,80,78\}$，枢轴 $65$ 就位。

参考解答：## 1）输出关键字最小的前 $k$ 个元素

**结论：** 采用**小根堆（Min-Heap）**，时间复杂度为 $O(n + k\log n)$。

**关键步骤：**
1. **建堆**：将数组原地调整为小根堆，耗时 $O(n)$。
2. **取元素**：执行 $k$ 次"取出堆顶元素 → 将末尾元素移至堆顶 → 向下调整堆"，每次调整耗时 $O(\log n)$，共 $O(k\log n)$。
3. 总时间复杂度 $O(n + k\log n)$。当 $k \ll n$ 时远优于全排序的 $O(n\log n)$。

| 两路合并排序 | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n)$ | 稳定 | 不能 |
| 堆排序 | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(n\log_2 n)$ | $O(1)$ | 不稳定 | 能 |

**推理说明：**
- **时间**：插入/冒泡在有序时只需一趟扫描故最好 $O(n)$；选择排序无论何种情况都需双重循环故恒为 $O(n^2)$；快排划分均匀时 $O(n\log n)$，退化为链时 $O(n^2)$；归并和堆排序始终 $O(n\log n)$。
- **空间**：快排递归栈深度平均 $O(\log_2 n)$、最坏 $O(n)$（表中取平均情形）；归并需辅助数组 $O(n)$；其余原地操作 $O(1)$。
- **稳定性**：选择排序交换会跨越相同元素、快排分区交换同理、堆排序父子节点交换均破坏相对顺序，故不稳定；插入、冒泡、归并在相等时不交换或按序归并，故稳定。
- **确定最终位置**：选择排序每趟选出的极值、冒泡每趟浮到端点的极值、快排枢轴划分后、堆排序每趟取出的堆顶，其位置即最终有序位置；插入排序后续元素可能插入前面改变已有元素位置，归并排序中间过程局部有序但全局未定，故二者不能。

## 3）带表头结点单链表上的稳定排序

### 稳定的简单选择排序

**结论：** 每趟遍历未排序部分找到最小值**首次出现**的结点，将其从原链表摘下并尾插到已排序链表之后。

```c
// head 为带头结点的单链表
void StableSelectionSort(Node *head) {
    Node *sorted_tail = head; // 已排序部分的尾结点（初始为头结点）
    while (sorted_tail->next != NULL) {
        // 在未排序部分找最小值第一次出现的结点
        Node *p = sorted_tail->next;
        Node *min_prev = sorted_tail; // min结点的前驱
        Node *prev = sorted_tail;
        Node *min_val_node = p;
        int min_val = p->data;
        
        while (p != NULL) {
            if (p->data < min_val) { // 严格小于才更新，保证稳定性
                min_val = p->data;
                min_val_node = p;
                min_prev = prev;
            }
            prev = p;
            p = p->next;
        }
        
        // 若最小结点不是未排序部分的第一个，则摘下并插入到 sorted_tail 之后
        if (min_val_node != sorted_tail->next) {
            min_prev->next = min_val_node->next;          // 摘下
            min_val_node->next = sorted_tail->next;       // 插入
            sorted_tail->next = min_val_node;
        }
        sorted_tail = sorted_tail->next; // 已排序尾部前移
    }
}
```

**稳定性说明：** 查找时用严格 `<` 而非 `<=`，确保相同关键字中取最前面的结点，从而保持相对顺序不变。

### 稳定的直接插入排序

**结论：** 从未排序部分依次取下首结点，在已排序部分从头向后找到第一个**大于**它的结点之前插入。

```c
void StableInsertionSort(Node *head) {
    if (head->next == NULL || head->next->next == NULL) return;
    
    Node *unsorted = head->next->next; // 未排序部分的首结点
    head->next->next = NULL;           // 已排序部分初始仅含第一个元素
    
    while (unsorted != NULL) {
        Node *cur = unsorted;
        unsorted = unsorted->next;     // 先摘下待插入结点
        
        // 在已排序链表中找插入位置：找到第一个 data > cur->data 的结点之前
        Node *p = head;
        while (p->next != NULL && p->next->data <= cur->data) {
            p = p->next;               // <= 保证相等元素不被越过，维持稳定性
        }
        
        // 插入到 p 之后
        cur->next = p->next;
        p->next = cur;
    }
}
```

**稳定性说明：** 比较条件用 `<=` 向后扫描，使相等关键字的新结点总是插在旧结点之后，保证稳定性。

## 计算过程

外层循环变量 `i` 从 1 递增到 n，每次翻倍（`i *= 2`），因此外层循环执行次数为：

$$
\log_2 n + 1
$$

即外层复杂度为 **O(log n)**。

内层循环：

```c
for (j = 1; j <= n; j += i)
```

当外层循环变量为 `i` 时，内层循环执行次数约为：

$$
\frac{n}{i}
$$

因此总执行次数为：

$$
\sum_{k=0}^{\lfloor \log_2 n \rfloor} \frac{n}{2^k}
= n \sum_{k=0}^{\lfloor \log_2 n \rfloor} \frac{1}{2^k}
$$

等比数列求和：

$$
\sum_{k=0}^{\infty} \frac{1}{2^k} = 2
$$

所以：

$$
T(n) \approx 2n = O(n)
$$

故总时间复杂度为 **O(n)**，而不是 O(n²)。

## 选项分析

- 若选项中有 **O(n)**，则正确，理由：外层 log n 次、内层 n/i 次，求和后收敛于 2n。
- **O(n²)** 不对：内层并非每次执行 n 次，而是随 i 增大而线性减少。
- **O(n log n)** 不对：虽然外层是 log n，但内层代价递减，求和后数量级降为 n。
- **O(log n)** 不对：只考虑外层而忽略内层循环的线性工作量。
