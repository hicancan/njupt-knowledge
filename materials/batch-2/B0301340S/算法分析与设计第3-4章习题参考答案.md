## 第 3 章

### 一 基础题

参考解答：## 一、基础题

---

**1. 下列函数中，哪个的增长速度最快？**

A. $n \log n$  
B. $n^2$  
C. $2^n$  
D. $n!$

**结论：D**

**理由：**  
增长速度排序为 $n! > 2^n > n^2 > n\log n$，阶乘增长速度超过指数，其余均为多项式或更低阶。

---

**2. 若 $T(n) = 3T(n/2) + n$，则 $T(n)$ 的渐进复杂度为：**

A. $\Theta(n)$  
B. $\Theta(n^{\log_2 3})$  
C. $\Theta(n\log n)$  
D. $\Theta(n^2)$

**结论：B**

**关键步骤：**  
主定理（Master Theorem）：$a=3, b=2, f(n)=n$，  
$\log_b a = \log_2 3 \approx 1.585$，  
因为 $f(n) = n = O(n^{\log_2 3 - \varepsilon})$，所以 $T(n) = \Theta(n^{\log_2 3})$。

其他选项不对的原因：A 低估了递归分支的增长，C 是 $\log_2 3 = 1$ 时的结果，D 明显偏高。

---

**3. 二分查找算法的时间复杂度是：**

A. $O(n)$  
B. $O(n\log n)$  
C. $O(\log n)$  
D. $O(1)$

**结论：C**

**理由：** 每次将搜索区间折半，最多执行 $\log_2 n$ 次比较。

---

**4. 下列哪个算法是稳定的排序算法？**

A. 快速排序  
B. 堆排序  
C. 归并排序  
D. 选择排序

**结论：C**

**理由：** 归并排序在合并时保持相同元素的相对顺序；快排和堆排的交换过程会打乱稳定顺序，选择排序的交换也不保证稳定性。

---

**5. 若一个问题能用贪心算法得到全局最优解，则它必须满足：**

A. 最优子结构性质  
B. 贪心选择性质和最优子结构性质  
C. 无后效性  
D. 重叠子问题性质

**结论：B**

**理由：** 贪心算法成立需要“贪心选择性质”（局部最优导致全局最优）和“最优子结构性质”（最优解包含子问题最优解）。无后效性多用于动态规划，重叠子问题也是动态规划的特征。

知识点：[算法的概念与基本特性（确定性、有限性等）](../../../topics/算法分析/算法概念与特性.md)、[问题和问题求解方法与系统生命周期](../../../topics/算法分析/问题求解过程.md)、[算法的时间复杂度定义（最好、最坏、平均情况）](../../../topics/算法分析/时间复杂度定义.md)

### 简答 3

堆栈遵循先进后出原则，队列遵循先进先出原则，都属于线形结构。

参考解答：该说法正确。

堆栈和队列均为线性结构，其数据元素之间存在一对一的前后关系；区别仅在于操作受限方式不同：堆栈限制在表尾（栈顶）进行插入和删除，满足先进后出（LIFO）；队列限制在表尾插入、表头删除，满足先进先出（FIFO）。两者逻辑结构均为线性表，因此都属于线性结构。

知识点：[问题和问题求解方法与系统生命周期](../../../topics/算法分析/问题求解过程.md)

### 简答 7

递归算法的优点是程序非常简洁和清晰，且易于分析。但它的缺点是费时间、费空间。非递归算法的优缺点与之相反。

参考解答：**结论：**递归算法与非递归算法各有优缺点，应根据问题的规模和递归结构特点选择。

- **递归算法**：程序简洁、清晰，易于编码和分析，但通常存在重复计算，运行时的时间和空间开销较大。
- **非递归算法**：执行效率较高，可减少时间和空间开销，但程序结构可能较复杂，且不如递归直观。

因此，简单且递归关系明确的问题适合采用递归；性能要求较高或递归深度较大的问题更适合采用非递归算法。

知识点：[递归概念与归纳证明（斐波那契数列、Hanoi塔问题）](../../../topics/算法分析/递归与归纳证明.md)、[算法的概念与基本特性（确定性、有限性等）](../../../topics/算法分析/算法概念与特性.md)

### 二 扩展题

参考解答：1966 年。

- Floyd 算法的状态转移基于三层循环：
  $d_{ij}^{(k)}=\min\left(d_{ij}^{(k-1)},\ d_{ik}^{(k-1)}+d_{kj}^{(k-1)}\right)$
- 1962 年 Floyd 提出了**三重循环、不含路径重建数组 $next$** 的版本。
- 1966 年 Floyd 又发表了更完整的形式：在更新最短路的同时维护一个中转点/后继矩阵（常记作 $next$、$path$ 或 $succ$），用于结束后重构任意两点之间的最短路径。
- 教材中说“Floyd 在 **1966** 年提出图论中求任意两点间最短路径的算法并允许重建最优解路径”，指的是这个**带路径重建数组版本的完整提出年份**，因此对应 **1966 年**。

## 第 4 章

参考解答：## 结论

下三角矩阵采用一维数组压缩存储，索引映射公式为：

$$k = \frac{i(i-1)}{2} + (j-1) \quad (i \geq j)$$

核心运算实现如下（C++）：

```cpp
class LowerTriMatrix {
private:
    int *data;
    int n;  // 矩阵阶数
public:
    // 查找：O(1)
    int Get(int i, int j) {
        if (i >= j)
            return data[i * (i - 1) / 2 + (j - 1)];
        return 0;  // 上三角元素恒为 0
    }
    
    // 赋值：O(1)
    void Set(int i, int j, int val) {
        if (i >= j)
            data[i * (i - 1) / 2 + (j - 1)] = val;
        // 上三角位置不能赋值
    }
    
    // 输出矩阵：O(n²)
    void Print() {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++)
                cout << Get(i, j) << " ";
            cout << endl;
        }
    }
};
```

## 推理过程

**1. 存储映射推导**

下三角矩阵共有 $\frac{n(n+1)}{2}$ 个非零元素，采用行优先方式存入一维数组 $B[0 \dots \frac{n(n+1)}{2}-1]$。元素 $a_{ij}$（$i \geq j$）的存储位置 $k$ 为：

- 前 $i-1$ 行共有元素数：$\frac{i(i-1)}{2}$
- 第 $i$ 行中，$a_{ij}$ 是该行第 $j$ 个元素（下标从 $j=1$ 开始）

因此 $k = \frac{i(i-1)}{2} + (j-1)$，其中 $i,j$ 从 1 开始计数，$k$ 从 0 开始计数。

**2. 查找运算（Get）**

- 若 $i \geq j$，直接按公式计算物理下标，返回 `data[k]`，时间复杂度 $O(1)$
- 若 $i < j$，该位置处于上三角，下三角矩阵中该处元素恒为 0，直接返回 0

**3. 元素赋值（Set）**

- 若 $i \geq j$，按公式计算物理下标，执行 `data[k] = val`，时间复杂度 $O(1)$
- 若 $i < j$，应忽略或抛出异常，因为上三角位置不应存储非零值

**4. 矩阵输出（Print）**

- 两层循环遍历所有 $n \times n$ 位置，每次调用 Get 方法获取元素值
- 时间复杂度 $O(n^2)$，这是输出完整矩阵不可避免的代价

**5. 空间复杂度分析**

存储下三角元素需要 $\frac{n(n+1)}{2}$ 个单元，额外空间为 $O(1)$，总空间复杂度 $O(n^2)$（实际仅存非零元，相比完整存储节省约一半空间）。

知识点：[算法的概念与基本特性（确定性、有限性等）](../../../topics/算法分析/算法概念与特性.md)、[使用程序步分析算法的时间复杂度](../../../topics/算法分析/程序步分析法.md)
