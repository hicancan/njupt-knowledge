# 南京邮电大学《Python程序设计》期末复习提纲

原件经识别和整理；“参考解答”是我们补的。

## 一、题型分值分布

- 选择：20 * 1 分
- 填空：10 * 2 分
- 程序阅读：6 * 5 分
- 程序改错：5 * 2 分
- 编程：2 * 5 分 + 10 分

## 二、复习要点

### 1. Python 基础概念

- Python 是一门高级编程语言
- Python2 和 Python3 互不兼容
- 续行符 `\`
- 标识符的命名规则是什么？
- `is` 的作用是进行身份比较
- 如何撰写注释

### 2. 数据类型与运算符

- Python 的基本数据类型有哪些？
- 转义字符，比如 `\n`
- 各种运算符
- `not`、`and`、`or` 的运算优先级
- 数据类型的转换
- 字符串的运算符：`+` 和 `*`
- 集合运算符
- 字典的常用函数

### 3. 字符串与序列操作

- `format` 函数的格式控制符
- 单引号和双引号和三引号的区别
- 序列数据的切片操作

### 4. 流程控制与函数

- 结合循环结构程序理解 `range` 函数
- 学会阅读三种不同结构的程序：顺序结构、选择结构、循环结构
- `break`、`continue`、`pass` 等特殊语句的作用
- 函数的定义和调用
- 建议自己写一个代码实现冒泡排序
- 编写函数实现判断一个整数是否为质数

### 5. 文件处理与异常处理

- `open` 函数的打开文件的方式有哪些？
- 如何进行异常处理 `try…except…finally`

### 6. 图形化与随机数

- 小海龟（turtle）的基本操作方法
- `random` 函数库中的各种随机函数的用法

### 7. 综合编程练习

- 编写程序实现以下功能，将输入的整数按照从小到大的顺序构造一个新的整数
- 水仙花数
- 打印由 `*` 组成的各类形状
- 认真复习实验四的大程序
