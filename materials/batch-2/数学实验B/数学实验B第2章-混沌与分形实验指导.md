## 一、实验题目

### 实验 1

下面函数的迭代是否会产生混沌？

$$
f (x) = \left\{ \begin{array}{l l} 2 x & 0 \leq x \leq \frac {1}{2} \\ 2 (1 - x) & \frac {1}{2} <   x \leq 1 \end{array} \right.
$$

(注意: 为了使结果精确, 应该使用符号计算, 初始值可取小于 1 的正分数)

代码为:

```matlab
f = inline('1 - 2 * abs(x - 1/2)');
x = [ ];
y = [ ];
x(1) = kazo_c_o_0.123; % 注：原文此处识别有误，推测为具体初始值赋值，如 x(1)=0.123
y(1) = 0; 
x(2) = x(1); 
y(2) = f(x(1));
for i = 1:1000
    x(1 + 2*i) = y(2*i);
    x(2 + 2*i) = x(1 + 2*i);
    x(2 + 2*i) = f(x(2 + 2*i));
end
plot(x, y, 'r');
hold on;
syms x;
ezplot(f(x), [0, 1]);
axis([0, 1, 0, 1]);
hold off
```

结论：上面函数的迭代产生混沌。
