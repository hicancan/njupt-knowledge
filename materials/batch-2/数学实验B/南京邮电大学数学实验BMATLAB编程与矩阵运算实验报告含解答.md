## 1.5 数列生成实验

### 选择 1

题干：
数列 $\{x_{n}\}$ 定义为

$$
x = \text { randint } (1, 2, [ 1, m ]), \quad x (n) = x (n - 1) + x (n - 2), \quad n = 3, 4, \dots
$$

其中 `randint(1,2,[1,m])` 命令的含义是一个 $1 \times 2$ 的随机矩阵（注：根据上下文及 MATLAB 旧版本语法，此处通常指生成初始项或特定范围的随机整数，原题描述可能存在歧义，但依题意需生成前10项），其元素都是介于 1 与 m 之间的随机整数。试用循环语句编程给出该数列的前 10 项（要求将结果用向量的形式给出）。

```matlab
X = randint(1, 2, [1, 331]); 
for n = 3 : 10 
    x(n) = x(n - 1) + x(n - 2); 
end 
x
```

答案：
```text
Columns 1 through 8
     2     6     3     3     1     8     5     8
     1     8     9     9     1     4     8     0
     2     3     7     9     3     8     5     9
     6     2     3     8

Columns 9 through 10
     1     0
     0     9
     7     1
     6     3
     3     5
```

## 1.6 矩阵运算实验

### 计算 1

题干：
已知 $A = \begin{pmatrix} 4 & -2 & 2 \\ -3 & 0 & 5 \\ 1 & 5 & 3m \end{pmatrix}, B = \begin{pmatrix} 1 & 3 & 4 \\ -2 & 0 & -3 \\ 2 & -1 & 1 \end{pmatrix}$ ，在 MATLAB 命令窗口中建立矩阵 A、B 并计算 A 的行列式，逆矩阵，特征值，特征向量， $AB^{-1}, A^{-1}B$ 。

代码与输入：
```matlab
% 注意：原题中 A 的元素 3m 在后续输出中显示为 993，推测 m=331 或类似赋值，
% 但根据标准矩阵定义及下方输出反推，A 的具体数值如下：
A = [4, -2, 2; -3, 0, 5; 1, 5, 993]; 

% 计算特征值和特征向量
[p, d] = eig(A);

B = [1, 3, 4; -2, 0, -3; 2, -1, 1];
```

结果展示：

1. **矩阵 B 的建立**
   ```text
   B =
        1     3     4
       -2     0    -3
        2    -1     1
   ```

2. **A 的特征向量 P 和特征值 d**
   ```text
   P =
      0.8653   -0.3613    0.0020
     -0.5012   -0.9324    0.0050
      0.0017    0.0051    1.0000

   d =
      5.1624         0         0
             0   -1.1895         0
             0         0   993.0272
   ```
   *(注：P 的列向量为特征向量)*

3. **其他中间计算结果片段**

4. **计算 $A/B$ (即 $A \cdot B^{-1}$)**
   ```text
   A/B
      0.0020         0    -2.7430
   -280.4286   -987.0000  -846.2857
   ```
   *(注：原题输出格式较为混乱，此处保留原始识别出的主要数值结构)*
