# 《数学实验B》实验：利用 MATLAB 进行函数大小比较实例

原件经识别和整理；“参考解答”是我们补的。

实验名称 利用 MATLAB 进行函数大小比较实例

## 实验目的

用图形的方法比较超越函数的取值大小，这两个值分别是：$e^{\pi}$ 和 $\pi^{e}$，此过程通过 MATLAB 实现。

## 实验要求

要比较两个值的大小，首先要了解 $z = x^{y} - y^{x}$ 的空间形状。为了绘制出 $z$ 的形状，有必要利用 meshgrid 函数将 $x-y$ 面网格化。最后通过绘出 $e$ 和 $\pi$ 的位置，就得到两个值的大小了。

## 实验方法

首先用代码作出 $z = x^{y} - y^{x}$ 的图像。

代码：

```matlab
x = 1 : 0.01 : 4;
y = x;
```

```
ezplot(f(x), f(x))
-vis([0,20,0,20]);
```

$f(x)=\frac{25x-85}{x+3}$ 的咖啡网的其他收益
