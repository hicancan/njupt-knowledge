## 实验内容：方程求根与函数绘图

### 题目 1

**题目描述：**
对于方程 $e^x - 3\frac{m}{m + 100} x^2 = 0$，先画出左边的函数在合适的区间上的图形，借助于软件中的方程近似求根的命令求出所有的实根，找出函数的单调区间，结合高等数学的知识说明函数为什么确实只有你求出的这些实根。

**解题过程与代码：**

1.  **画图代码：**
    设定参数 $m=331$，则系数为 $3 \times \frac{331}{331+100}$。
    MATLAB 代码如下：
    ```matlab
    x = -1:0.001:4;
    y = exp(x) - 3 * 331 / (331 + 100) * x.^2;
    plot(x, y);
    ```
    *(注：原识别文本中公式书写有误，此处根据上下文逻辑修正为 `x.^2` 以符合方程定义)*

2.  **求根命令与结果：**
    通过观察图形后，使用 `fzero` 命令进行近似求根：
    ```matlab
    fzero('exp(x)-3*331/(331+100)*x^2', -0.5)
    fzero('exp(x)-3*331/(331+100)*x^2', 1)
    fzero('exp(x)-3*331/(331+100)*x^2', 3.1)
    ```
    得到该方程的实根为：
    $$a_1 = -0.5104$$
    $$a_2 = 1.2011$$
    $$a_3 = 3.0927$$

3.  **单调区间分析：**
    -   增区间：$(-\infty, 0.2900)$ 和 $(2.4055, +\infty)$
    -   减区间：$(0.2900, 2.4055)$

**参考解答：**
这是因为在增区间内，$e^x$ 的增长速率快于 $\frac{3 \times 331}{431}x^2$ 的增长速率；而在减区间内，二次项的增长速率暂时超过指数项，导致函数值下降。由于函数先增后减再增，且极限行为符合指数增长主导的特性，因此方程确实只有这三个实根。
