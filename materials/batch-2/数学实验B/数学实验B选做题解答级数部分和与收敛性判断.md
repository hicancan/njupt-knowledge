# 《数学实验B》选做题解答（级数部分和与收敛性判断）

本资料由识别工具读取并整理，包含关于级数 $\sum_{n=1}^{\infty} \frac{1}{n^2} \sin^m n$ 及 $\sum_{n=3}^{\infty} \frac{1}{\ln^\alpha n}$ （其中 $\alpha = \frac{m}{1000}$）的部分和计算、散点图绘制及收敛性判断的代码与结论。

## 一、选做题

### 选择 1

题干：考察级数 $\sum_{n=1}^{\infty} \frac{1}{n^2} \sin^m n$ 及 $\sum_{n=3}^{\infty} \frac{1}{\ln^\alpha n}$ ，其中 $\alpha = \frac{m}{1000}$ 。

(1) 编程求上述两个级数的部分和, 画出部分和的散点图, 并观察部分和序列的变化趋势;

(2) 判断上述级数是否收敛。若收敛，请从散点图观测其和的值。

代码：
```matlab
% 针对第一个级数 sum(1/n^2 * sin(n)^3) 的部分和计算示例
syms n;
S = 0;
for n = 3:1:500
    S = S + (1 / n^2) * (sin(n))^3; % 注意：原题代码中指数部分识别可能存在歧义，此处根据上下文推测为3或m
    plot(n, S, 'r');
    hold on;
end
```

```matlab
% 针对第二个级数 sum(1/ln(n)^alpha) 的部分和计算示例
syms s;
s = 0;
for n = 3:1:5000;
    s = s + (1 / ((log(n))^(331/1000))); % 注意：原题代码中指数部分识别可能存在歧义，此处根据上下文推测为特定值
    plot(n, s, 'b');
    hold on;
end
```

答案：由图可知 $\sum_{n=1}^{\infty}\frac{1}{n^{2}}\sin^{m}n$ 和序列逐渐趋向于一个值，而 $\sum_{n=3}^{\infty}\frac{1}{\ln^{2}n}$ 和序列逐渐以固定的速率增大。

参考解答：
(2): 级数 $\sum\limits_{n=1}^{\infty}\frac{1}{n^{2}}\sin^{m}n$ 收敛，由图知收敛于 $-6.9292\times10^{-3}$。
级数 $\sum\limits_{n=3}^{\infty}\frac{1}{\ln^{2}n}$ 不收敛。
