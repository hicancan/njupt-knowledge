## 一、求满足 $c - b = 2$ 的勾股数

### 题目描述

**教学要求**：会利用软件求勾股数，并且能够分析勾股数之间的关系。会解简单的近似计算问题。

**题目**：求满足 $c - b = 2$，$c \leq 1000$ 的所有勾股数，能否类似于（11.8），把它们用一个公式表示出来？

### 程序代码

```matlab
for b = 1:998
    a = sqrt((b + 2)^2 - b^2);
    if (a == floor(a))
        fprintf('a = %i, b = %i, c = %i\n', a, b, b + 2)
    end
end
```

### 理论推导

**解：**

由勾股定理 $a^2 + b^2 = c^2$ 及条件 $c = b + 2$，代入得：
$$ a^2 + b^2 = (b + 2)^2 $$
展开右边：
$$ a^2 + b^2 = b^2 + 4b + 4 $$
消去 $b^2$：
$$ a^2 = 4b + 4 $$
$$ a^2 = 4(b + 1) $$
由此可知 $a$ 必须为偶数，设 $a = 2u$（其中 $u$ 为正整数），则：
$$ (2u)^2 = 4(b + 1) $$
$$ 4u^2 = 4(b + 1) $$
$$ u^2 = b + 1 $$
$$ b = u^2 - 1 $$
进而求得 $c$：
$$ c = b + 2 = (u^2 - 1) + 2 = u^2 + 1 $$

因此，当 $c - b = 2$ 时，勾股数可以表示为：
$$
\begin{cases}
a = 2u \\
b = u^2 - 1 \\
c = u^2 + 1
\end{cases}
$$
其中 $u$ 为大于 1 的整数。

*注：原文中出现的 $\{a,b,c\} = c$ 及 $b = u^2 + 2u$ 等表述存在识别错误或逻辑混乱，上述推导为基于标准数学逻辑的修正。*
