### 例题－数字签名

![第 30 页](密码学复习课件.assets/第30页.webp)

原文：

例题－数字签名

例、 用户A发送给用户B一份密文，用户A向发送m＝02签名保密消息。用户A知道下列三个密钥：

A

B

公开密钥(e，n) ( 7，123) (13，51)

秘密密钥(d，n) (23，123) （5，51）

A计算他的签名： $s = m ^ { d _ { A } }$ mod $n _ { _ A } = ( 0 2 ) ^ { 2 3 } ( m o d 1 2 3 ) = 8$

再次加密签名： $c = s ^ { e _ { B } }$ mod $n _ { B } = 8 ^ { 1 3 } ( m o d 5 1 ) = 2 6$

### 例题－数字签名（续）

![第 31 页](密码学复习课件.assets/第31页.webp)

原文：

例题－数字签名（续）

接收者B必须恢复出02＝B认证他接收的密文。接收者也知道三个密钥：

公开密钥(e，n) (7，123) (13，51)

秘密密钥(d，n) （23，123） (5，51)

B用户用自己的秘密解密密钥一次解密：

$$
s = S ^ {d _ {B}} \mod n _ {B} = 2 6 ^ {5} (\mod 5 1) = 8
$$

再用A用户的公开密钥解密：

$$
m = s ^ {e _ {A}} \mod n _ {A} = 8 ^ {7} (\mod 1 2 3) = 2
$$

B用户可以确认：该签名是由A发出——用A公钥可解读；

该签名是发给自己的——用了B的公钥。
