# 《线性代数与解析几何》第三章复习题（含解答）

原件经识别和整理；“参考解答”是我们补的。

### 选择 6

直线 $\frac{x - a_1}{a_2 - a_3} = \frac{y - b_1}{b_2 - b_3} = \frac{z - c_1}{c_2 - c_3}$ 的位置关系为 ( )

- A. 相交于一点
- B. 重合
- C. 平行但不重合
- D. 异面

答案：A。

知识点：[空间直线的点向式（对称式）、参数式与一般式方程及转换](../../../topics/线性代数/空间直线方程.md)、[点到平面/直线的距离，两平面、两直线、线面间的夹角与位置关系](../../../topics/线性代数/位置关系与距离夹角.md)、[行列式的性质（换行变号、提取公因子、成比例为零等）](../../../topics/线性代数/行列式性质.md)

### 选择 7

直线 $L: \begin{cases} x+3y+2z+1=0 \\ 2x-y-10z+3=0 \end{cases}$ 与平面 $\pi:2x+13y+18z+1=0$ 的位置关系为 ( )

- A. $L \parallel \pi$
- B. $L \subset \pi$
- C. $L \perp \pi$
- D. $L$ 与 $\pi$ 斜交

答案：B。
知识点：[空间直线的点向式（对称式）、参数式与一般式方程及转换](../../../topics/线性代数/空间直线方程.md)、[点到平面/直线的距离，两平面、两直线、线面间的夹角与位置关系](../../../topics/线性代数/位置关系与距离夹角.md)

### 选择 8

双曲线 $\left\{\begin{aligned}\frac{x^{2}}{4}-\frac{z^{2}}{5}&=1\\ y=0\end{aligned}\right.$ 绕 $z$ 轴旋转一周所形成的曲面为 ( )

- A. $\frac{x^{2}}{4}+\frac{y^{2}}{5}-\frac{z^{2}}{5}=1$
- B. $\frac{x^{2}}{4}-\frac{y^{2}}{5}-\frac{z^{2}}{5}=1$
- C. $\frac{(x+y)^{2}}{4}-\frac{z^{2}}{5}=1$
- D. $\frac{x^{2}}{4}+\frac{y^{2}}{4}-\frac{z^{2}}{5}=1$

答案：D。

知识点：[常见二次曲面（椭球面、双曲面、抛物面）、旋转曲面、柱面及投影曲线](../../../topics/线性代数/曲面与空间曲线.md)

### 选择 9

方程 $x^{2}+4y^{2}-9z^{2}=-1$ 表示 ( )

- A. 椭球面
- B. 双曲抛物面
- C. 单叶双曲面
- D. 双叶双曲面

答案：D。
