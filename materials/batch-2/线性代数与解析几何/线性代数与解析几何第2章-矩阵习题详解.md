(3) $|A^*| = |A|^{3-1} = 2^2 = 4$

(4) $|BA^{-1}| = \frac{|B|}{|A|}$。原题未给 $|B|$，但给出了结果 $-\frac{1}{8}$。若结果正确，则 $|B| = -1/4$。此处仅列出公式和结果。
$$
|BA^{-1}| = \frac{|B|}{|A|} = -\frac{1}{8}
$$

(5)
$$
|(\boldsymbol{AB})^T| = |\boldsymbol{AB}| = |\boldsymbol{A}||\boldsymbol{B}| = 2 \times (-\frac{1}{4}) = -\frac{1}{2}
$$

(6)
$$
|(\boldsymbol{P}^{-1}\boldsymbol{A}\boldsymbol{P})^k| = |\boldsymbol{P}^{-1}|^k |\boldsymbol{A}|^k |\boldsymbol{P}|^k = |\boldsymbol{P}^{-1}\boldsymbol{P}|^k |\boldsymbol{A}|^k = 1^k |\boldsymbol{A}|^k = |\boldsymbol{A}|^k = 2^k
$$

(7)
$$
|\boldsymbol{A}^{-1} + 2\boldsymbol{A}^*| = |\boldsymbol{A}^{-1} + 2|A|\boldsymbol{A}^{-1}| = |\boldsymbol{A}^{-1} + 4\boldsymbol{A}^{-1}| = |5\boldsymbol{A}^{-1}|

$$
= 5^3 |\boldsymbol{A}^{-1}| = 125 \frac{1}{|\boldsymbol{A}|} = \frac{125}{2}

## 习题 4

$\because A^{2} - 2A + 4E = (A + E)(A - 3E) + 7E \Rightarrow (A + E)\left[-\frac{1}{7}(A - 3E)\right] = E$，$\therefore (A + E)^{-1} = -\frac{1}{7}(A - 3E)$。同样，有：$(A - 3E)^{-1} = -\frac{1}{7}(A + E)$。

## 习题 5

（1）$\because |A| \neq 0, |B| \neq 0 \Rightarrow |AB| = |A||B| \neq 0$，即 $AB$ 也可逆；

（2）$\because |AB| \neq 0 \Rightarrow |A||B| \neq 0 \Rightarrow |A| \neq 0, |B| \neq 0$，故矩阵 $A$，$B$ 均可逆。

## 习题 6

（1）$\because AB = AC$，$A$ 可逆，则 $A^{-1}AB = A^{-1}AC \Rightarrow B = C$；

（2）$\because AB = O$，$A$ 可逆，则 $A^{-1}AB = A^{-1}O \Rightarrow B = O$。
