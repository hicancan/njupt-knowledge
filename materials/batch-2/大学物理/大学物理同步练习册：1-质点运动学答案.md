# 质点运动学 第一节 质点运动的描述（1）

本节内容整理自《大学物理》同步练习册答案部分，主要涉及质点运动学中位置、位移、路程、速度、加速度及轨迹方程的计算与分析。

## 一、计算与解析题

### 计算 1

已知运动方程： $x = 4 t - t ^ { 2 }$

**求解前3s内的位移和路程：**

- **位移计算**
  - $t = 0$ 时， $x _ { 0 } = 0$ ；
  - $t = 3 \mathrm { s }$ 时， $x = 1 2 - 9 = 3 \mathrm { m }$
  - 前3s 内的位移： $\Delta x = x - x _ { 0 } = 3 \mathrm { m }$ ， ⇒ 前3s 内位移的大小： $\left| \Delta x \right| = 3 \mathrm { m }$

- **路程计算**
  - 质点运动速度： $v _ { x } = \frac { d x } { d t } = 4 - 2 t$
  - 速率： $\left| v _ { x } \right| = \frac { d s } { d t } = \left| 4 - 2 t \right|$
  - **注意**：质点在 $t = 2 \mathrm { s }$ 后反向运动！
  - 前3s内通过的路程：
    $$
    \Delta s = \int _ { 0 } ^ { 3 } \lvert v _ { x } \rvert d t = \int _ { 0 } ^ { 3 } \lvert 4 - 2 t \rvert d t = \int _ { 0 } ^ { 2 } ( 4 - 2 t ) d t + \int _ { 2 } ^ { 3 } - ( 4 - 2 t ) d t = 5 \mathrm { m }
    $$

### 填空 1

表达式中位置矢量是： $\vec{r}$ ，位移矢量是： $\Delta \vec { r }$

知识点：[位矢及其坐标表示（直角坐标与自然坐标）](../../../topics/大学物理/位矢与坐标表示.md)

### 计算 2

已知运动方程： $\vec { r } = 4 t ^ { 2 } \vec { i } + ( 2 t + 3 ) \vec { j }$

**求轨迹方程：**

$$
\left\{ \begin{array} { c } { { x = 4 t ^ { 2 } } } \\ { { y = 2 t + 3 } } \end{array} \right.
$$

消去时间 $t$，得轨迹方程： $y = \sqrt { x } + 3$ （注：由 $x=4t^2 \ge 0$ 可知定义域限制）

知识点：[位矢及其坐标表示（直角坐标与自然坐标）](../../../topics/大学物理/位矢与坐标表示.md)、[速度、加速度的定义与微分关系](../../../topics/大学物理/速度与加速度定义.md)

### 简答 1

**重点分析：质点沿 x 轴做直线运动，一维运动问题中的符号约定。**

在一维运动中，常把分量 $v _ { x }$ 和 $a _ { x }$ 的下标 $x$ 省去不写，用 $v$ 和 $a$ 表示。
- **注意**：此处 $v$ 不是速率；$a$ 不是加速度的大小。
- **方向判断**：用 $v$ 和 $a$ 的正负来表示方向。
  - 若 $v > 0$ ，表示沿 $x$ 轴正方向；
  - 若 $v < 0$ ，表示沿 $x$ 轴负方向。

相关公式推导：
- 位置矢量： ${ \vec { r } } = x { \vec { i } }$
- 速度： $\vec { v } = \frac { d \vec { r } } { d t } = \frac { d x } { d t } \vec { i } = v _ { x } \vec { i}$
  $$
  v _ {x} = \frac {d x}{d t}
  $$
- 加速度： $\vec {a} = \frac {d \vec {v}}{d t} = \frac {d v _ {x}}{d t} \vec{i} = a _ {x} \vec{i}$
  $$
  a _ {x} = \frac {d v _ {x}}{d t} = \frac {d ^ {2} x}{d t ^ {2}} \quad \Rightarrow \quad a = \frac {d v}{d t} = \frac {d ^ {2} x}{d t ^ {2}}
  $$

知识点：[位矢及其坐标表示（直角坐标与自然坐标）](../../../topics/大学物理/位矢与坐标表示.md)、[速度、加速度的定义与微分关系](../../../topics/大学物理/速度与加速度定义.md)

### 简答 2

**已知 $x \sim t$ 曲线，分析速度与加速度。**

- **速度的几何意义**：由一维运动速度 $v = { \frac { d x } { d t } }$ ，对应 $x \sim t$ 曲线上切线的斜率。
- **瞬时速度为零**：即 $v = \frac { d x } { d t } = 0$ ，对应在 $x \sim t$ 曲线上切线斜率为零时的位置。
  - 由图得， $t = 3 \mathrm { s }$ 时 $v = \frac { d x } { d t } = 0$ 。
- **第3秒至第6秒间的分析**：
  - 对应点切线斜率小于零， $v = \frac { d x } { d t } < 0$ （表示速度方向沿 $x$ 轴负方向）。
  - 且速度大小变大（切线越来越陡峭），说明这段时间内加速度方向与速度方向相同（均为负方向），质点做加速运动。

知识点：[速度、加速度的定义与微分关系](../../../topics/大学物理/速度与加速度定义.md)

### 计算 3

已知运动方程： $\vec { r } = a t ^ { 2 } \vec { i } + b t ^ { 2 } \vec { j }$

**分析运动性质：**

1.  **轨迹方程**：
    $$
    \left\{ { \begin{array} { l } { x = a t ^ { 2 } } \\ { y = b t ^ { 2 } } \end{array} } \right.
    $$
    消去时间 $t$，得轨迹方程： $y = { \frac { b } { a } } x$ ，$(x \geq 0)$。运动轨迹为直线。

2.  **速度**：
    $$
    \vec { v } = \frac { d \vec { r } } { d t } = 2 a t \vec { i } + 2 b t \vec { j}
    $$
    速度随时间变化，非匀速。

3.  **加速度**：
    $$
    \vec { a } = \frac { d \vec { v } } { d t } = 2 a \vec { i } + 2 b \vec { j}
    $$
    加速度保持不变。

**结论**：质点做匀变速直线运动。

知识点：[速度、加速度的定义与微分关系](../../../topics/大学物理/速度与加速度定义.md)

### 选择 1

**辨析速度、速率与位矢的变化率概念。**

已知位置矢量： $\vec { r } = x \vec { i } + y \vec { j }$
速度： ${ \vec { v } } = { \frac { d { \vec { r } } } { d t } } = { \frac { d x } { d t } } { \vec { i } } + { \frac { d y } { d t } } { \vec { j } }$

则速度大小（速率）：
$$
v = \left| { \vec { v } } \right| = \sqrt { ( \frac { d x } { d t } ) ^ { 2 } + ( \frac { d y } { d t } ) ^ { 2 } }
$$
或写作 $v = \left| { \vec { v } } \right| = \left| { \frac { d { \vec { r } } } { d t } } \right| = { \frac { \left| d { \vec { r } } \right| } { d t } } = { \frac { d s } { d t } }$

**重点注意**：
- $\left| d \vec { r } \right| = d s$ （弧长微元等于位移矢量的模）
- $d r = d { \left| \vec { r } \right| }$ （位矢大小的微分）
- 一般情况下 $\left| d { \vec { r } } \right| \neq d r$

选项分析：
- 选项（A）和（C）中的 ${ \frac { d r } { d t } } = { \frac { d | { \vec { r } } | } { d t } } \neq v$ （这是位矢大小变化的速率，不等于速度大小）。
- 选项（B）： $\frac { d \vec { r } } { d t } = \vec { v }$ 表示速度矢量。

*(注：原题未给出完整选项文字，此处根据解析还原逻辑)*

答案：需根据具体选项判断，通常考察 $\frac{d\vec{r}}{dt} = \vec{v}$ 与 $\frac{dr}{dt} \neq v$ 的区别。

知识点：[速度、加速度的定义与微分关系](../../../topics/大学物理/速度与加速度定义.md)、[位矢及其坐标表示（直角坐标与自然坐标）](../../../topics/大学物理/位矢与坐标表示.md)

### 计算 4

**根据 $v \sim t$ 曲线求位置。**

根据 $v \sim t$ 曲线，分段速度函数为：
$$
v = \left\{ \begin{array}{l l} 2 t & (0 \leq t < 1) \\ 2 & (1 \leq t < 2) \\ - 4 t + 1 0 & (2 \leq t < 2.5) \\ - 2 t + 5 & (2.5 \leq t < 3) \\ - 1 & (3 \leq t < 4) \\ 2 t - 9 & (4 \leq t \leq 4.5) \end{array} \right.
$$

由 $v = \frac { d x } { d t } \implies d x = v d t$，得 $\int _ { 0 } ^ { x } d x = \int _ { 0 } ^ { t } v d t$。假设初始位置 $x(0)=0$。

1.  **若 $t _ { 1 } = 2 . 5 \mathrm { s }$ 时，位置为 $x _ { 1 }$**：
    $$
    \begin{array}{r l} x _ {1} & = \int_ {0} ^ {2.5} v d t = \int_ {0} ^ {1} 2 t d t + \int_ {1} ^ {2} 2 d t + \int_ {2} ^ {2.5} (- 4 t + 1 0) d t \\ & = [t^2]_0^1 + [2t]_1^2 + [-2t^2 + 10t]_2^{2.5} \\ & = 1 + 2 + (-12.5 + 25 - (-8 + 20)) \\ & = 1 + 2 + (12.5 - 12) = 3.5 \mathrm{m} \end{array}
    $$
    *(注：原答案计算结果为 3.5m，此处复核积分过程)*
    $\int_ {2} ^ {2.5} (- 4 t + 1 0) d t = [-2t^2 + 10t]_2^{2.5} = (-2(6.25)+25) - (-2(4)+20) = (-12.5+25) - (-8+20) = 12.5 - 12 = 0.5$
    总和：$1 + 2 + 0.5 = 3.5 \mathrm{m}$。结果一致。

2.  **若 $t _ { 2 } = 4 . 5 \mathrm { s }$ 时，位置为 $x _ { 2 }$**：
    $$
    \begin{array}{l} x _ {2} = \int_ {0} ^ {4.5} v d t = x_1 + \int_ {2.5} ^ {3} (- 2 t + 5) d t + \int_ {3} ^ {4} (-1) d t + \int_ {4} ^ {4.5} (2 t - 9) d t \\ = 3.5 + [-t^2 + 5t]_{2.5}^3 + [-t]_3^4 + [t^2 - 9t]_4^{4.5} \end{array}
    $$
    分段计算：
    - $\int_ {2.5} ^ {3} (- 2 t + 5) d t = (-9 + 15) - (-6.25 + 12.5) = 6 - 6.25 = -0.25$
    - $\int_ {3} ^ {4} -1 d t = -1$
    - $\int_ {4} ^ {4.5} (2 t - 9) d t = (4.5^2 - 9\times4.5) - (4^2 - 9\times4) = (20.25 - 40.5) - (16 - 36) = -20.25 - (-20) = -0.25$
    
    总位移增量：$-0.25 - 1 - 0.25 = -1.5 \mathrm{m}$
    $x_2 = 3.5 - 1.5 = 2 \mathrm{m}$

答案：$t=2.5s$ 时 $x=3.5m$；$t=4.5s$ 时 $x=2m$。

### 计算 5

**已知加速度求运动方程。**

已知加速度： $a = 4t$ 和初始条件： $t = 0$ 时， $x _ { 0 } = 1 0 , v _ { 0 } = 0$ ，求位置 $x$ 和时间 $t$ 的关系式（运动方程）。

1.  **求速度**：
    $$
    a = { \frac { d v } { d t } } = 4 t \implies d v = 4 t d t
    $$
    $$
    \int _ { v _ { 0 } } ^ { v } d v = \int _ { 0 } ^ { t } 4 t d t \implies v - v _ { 0 } = 2 t ^ { 2}
    $$
    其中 $v _ { 0 } = 0$，故速度与时间的关系： $v = 2 t ^ { 2}$

2.  **求位置**：
    $$
    v = \frac { d x } { d t } = 2 t ^ { 2} \implies d x = 2 t ^ { 2} d t
    $$
    $$
    \int_ {x _ {0}} ^ {x} d x = \int_ {0} ^ {t} 2 t ^ {2} d t \implies x - x _ {0} = \frac {2}{3} t ^ {3}
    $$
    其中 $x _ {0 } = 1 0$

位置和时间的关系式： $x = ( \frac { 2 } { 3 } t ^ { 3 } + 1 0 ) \mathrm { m }$

知识点：[速度、加速度的定义与微分关系](../../../topics/大学物理/速度与加速度定义.md)

### 计算 6

**已知运动方程求某段时间内的平均速度。**

已知运动方程： $x = 4 . 5 t ^ { 2 } - 2 t ^ { 3 }$

1.  **计算特定时刻的位置**：
    - $t = 1 \mathrm { s }$ 时， $x _ { 1 } = 4 . 5 { \times } 1 ^ { 2 } - 2 { \times } 1 ^ { 3 } = 4 . 5 - 2 = 2 . 5 \mathrm { m }$
    - $t = 2 \mathrm { s }$ 时， $x _ { 2 } = 4 . 5 { \times } 2 ^ { 2 } - 2 { \times } 2 ^ { 3 } = 4 . 5 { \times } 4 - 2 { \times } 8 = 1 8 - 1 6 = 2 \mathrm { m }$

2.  **计算第2s内的平均速度**：
    - 第2s内的位移： $\Delta x = x _ { 2 } - x _ { 1 } = 2 - 2 . 5 = - 0 . 5 \mathrm { m }$
    - 时间间隔： $\Delta t = 2 - 1 = 1 \mathrm { s }$
    - 平均速度： ${ \overline { { v } } } = { \frac { \Delta x } { \Delta t } } = \frac { - 0 . 5 } { 1 } = - 0 . 5 \mathrm { m / s }$

答案：第2s内的平均速度为 $-0.5 \mathrm{m/s}$。

（2）瞬时速度：$v = \frac{dx}{dt} = 9t - 6t^2 \quad \Longrightarrow$ 第 2 s 末的瞬时速度：$v = 9 \times 2 - 6 \times 4 = -6\ \mathrm{m/s}$

（3）速率：$\left| v \right| = \frac{ds}{dt} = \left| 9t - 6t^2 \right|$ 注意：质点在 $t = 1.5\ \mathrm{s}$ 后反向运动！

第 2 s 内的路程：$\Delta s = \int_1^2 \lvert v \rvert \, dt = \int_1^2 \lvert 9t - 6t^2 \rvert \, dt = \int_1^{1.5} (9t - 6t^2) \, dt + \int_{1.5}^2 -(9t - 6t^2) \, dt = \frac{9}{4}\ \mathrm{m}$

### 计算 10

竖直向下为 $y$ 轴正方向，重力加速度：$\vec{a} = g\vec{j}$，即 $a_x = 0,\ a_y = g$

（1）水平方向匀速运动：$x = v_0 t$

竖直方向匀加速运动：$y = \frac{1}{2} g t^2$

任一时刻 $t$ 的位置坐标 $\left( v_0 t,\ \frac{1}{2} g t^2 \right)$

$$\begin{cases} x = v_0 t \\ y = \frac{1}{2} g t^2 \end{cases}$$

消去时间 $t$，得轨迹方程：$y = \frac{g}{2 v_0^2} x^2,\ (x \ge 0)$，轨迹为抛物线。

（2）水平方向匀速运动：$v_x = v_0$

竖直方向匀加速运动：$v_y = g t$，（竖直向下为 $y$ 轴正方向）

子弹在 $t$ 时刻的速度：$\vec{v} = v_0 \vec{i} + g t \vec{j}$；$\quad \Rightarrow$ ① 子弹在 $t$ 时刻的速率：$v = \sqrt{v_0^2 + g^2 t^2}$

② 子弹在 $t$ 时刻的切向加速度：$a_t = \frac{dv}{dt} = \frac{g^2 t}{\sqrt{v_0^2 + g^2 t^2}}$；

③ 子弹在 $t$ 时刻的法向加速度：$a_n = \sqrt{a^2 - a_t^2} = \sqrt{g^2 - \frac{g^4 t^2}{v_0^2 + g^2 t^2}} = \sqrt{\frac{g^2 v_0^2}{v_0^2 + g^2 t^2}} = \frac{g v_0}{\sqrt{v_0^2 + g^2 t^2}}$。
