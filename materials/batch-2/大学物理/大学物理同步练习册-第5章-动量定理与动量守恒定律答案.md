## 一、选择题

### 选择 1

题干涉及冲量的定义及性质。由冲量定义： $\vec { I } = \int _ { t _ { 1 } } ^ { t _ { 2 } } \vec { F } d t$ ，冲量不仅与力的大小有关，还与力的方向及力的作用时间有关，所以小力的冲量有可能比大力的冲量大。

- A. ……
- B. ……
- C. ……
- D. ……

答案：B。
参考解答：由动量定义： ${ \vec { P } } = m { \vec { v } }$ ，动量 $\vec { P }$ 不仅与速度 $\vec { v }$ 有关，还与物体的质量 $m$ 有关。本题选（B）。

知识点：[动量定理与动量守恒定律](../../../topics/大学物理/动量定理与动量守恒.md)、[牛顿三定律与惯性系](../../../topics/大学物理/牛顿三定律.md)

### 选择 2

题干涉及匀速圆周运动中的动量守恒与冲量问题。物体做匀速圆周运动，必定受到向心力作用，向心力由合外力提供： $F _ { n } = m { \frac { v ^ { 2 } } { r } } \neq 0$ ，方向指向圆心；由于在匀速圆周运动中物体所受合外力不为零，则物体的动量不守恒；运动一周回到原处，末速度 $\vec { v }$ 和初速度 $\vec { v } _ { 0 }$ 相等，即 $\vec { v } = \vec { v } _ { 0 }$ ，则动量改变为零： $\Delta \vec { P } = \vec { P } - \vec { P } _ { 0 } = m \vec { v } - m \vec { v } _ { 0 } = 0$ 。由动量定理： $\vec { I } = \int _ { 0 } ^ { t } \vec { F } d t = \vec { P } - \vec { P } _ { 0 } = m \vec { v } - m \vec { v } _ { 0 } = 0$ ，即合外力的冲量 $\vec { I }$ 为零。

- A. ……
- B. ……
- C. ……
- D. ……

答案：C。
参考解答：本题选（C）。

知识点：[动量定理与动量守恒定律](../../../topics/大学物理/动量定理与动量守恒.md)、[圆周运动的角量描述（角速度、角加速度）](../../../topics/大学物理/圆周运动描述.md)、[牛顿三定律与惯性系](../../../topics/大学物理/牛顿三定律.md)

### 选择 3

题干涉及冲量的矢量性及平衡状态下的冲量计算。（A）（B）冲量不仅与力的大小有关，还与力的方向及力的作用时间有关，所以作用在物体上的力大，力的冲量不一定大。（C）冲量是矢量，不仅有大小，还有方向。大小相等的冲量不一定相同。（D）水平方向上，物体在推力 $\vec { F }$ 和摩擦力 $\vec { f }$ 的作用下保持静止，则由动量定理： $\int _ { 0 } ^ { t } ( \vec { F } + \vec { f } ) d t = \vec { P } - \vec { P } _ { 0 } = 0$ ⇒水平推力的冲量： $\int _ { 0 } ^ { t } { \vec { F } } d t = - \int _ { 0 } ^ { t } { \vec { f } } d t \neq 0$ 。

### 选择 4

题干涉及子弹打摆球模型的动量守恒应用。由子弹和摆球构成的系统，系统外力为重力和绳的拉力，外力均沿竖直方向，水平方向合外力为零，则水平方向动量守恒：若设子弹和摆球共同运动时在水平方向的速度大小为 $v$ ，得 $m v _ { 2 } \sin 3 0 ^ { \circ } = ( m + M ) v \Rightarrow 2 0 \times 4 0 0 \times \sin 3 0 ^ { \circ } = ( 2 0 + 9 8 0 ) v \Rightarrow v = 4 { \mathrm { m / s } }$ 。竖直方向：由于摆线长度不可伸缩，绳上有应力作用，动量不守恒，竖直方向共同运动速度为零；所以子弹和摆球共同运动的速率（速度大小）为： $v = 4 \mathrm { m } / \mathrm { s }$ 。

## 二、计算题

知识点：[动量定理与动量守恒定律](../../../topics/大学物理/动量定理与动量守恒.md)、[牛顿定律在变力问题中的应用（如 ma_t = -mg sinθ）](../../../topics/大学物理/牛顿定律应用.md)

### 计算 6

小球运动一周后，末动量等于初动量， $\vec { P } = \vec { P } _ { 0 }$ ，动量增量： $\Delta \vec { P } = \vec { P } - \vec { P } _ { 0 } = 0$ ，动量增量的大小等于零；

（2）重力 $m \vec { g }$ 是恒力，则小球运动一周所受重力的冲量： $\vec { I } _ { \text {重力}} = m \vec { g } \cdot \Delta t = m \vec { g } \cdot \frac { 2 \pi } { \omega }$ ，冲量大小： $I _ { \text {重力}} = m g \frac { 2 \pi } { \omega }$ 。

（3）小球在重力 $mg$ 和绳拉力 $\vec { T }$ 的作用下做匀速圆周运动，由动量定理： $\int _ { 0 } ^ { \Delta t } ( m \vec { g } + \vec { T } ) d t = \vec { P } - \vec { P } _ { 0 } = 0$ ⇒小球所受绳子拉力的冲量： $\vec { I } _ { \text {拉力}} = \int _ { 0 } ^ { \Delta t } \vec { T } d t = - \int _ { 0 } ^ { \Delta t } m \vec { g } d t = - m \vec { g } \cdot \frac { 2 \pi } { \omega }$ ，拉力的冲量大小： $I _ { \text {拉力}} = m g \frac { 2 \pi } { \omega }$ 。

答案：见参考解答。

知识点：[动量定理与动量守恒定律](../../../topics/大学物理/动量定理与动量守恒.md)、[牛顿三定律与惯性系](../../../topics/大学物理/牛顿三定律.md)、[圆周运动的角量描述（角速度、角加速度）](../../../topics/大学物理/圆周运动描述.md)

### 计算 7

人和小船构成的系统在水平方向不受外力，则系统在水平方向动量守恒。设在运动过程中任一时刻 $t$ ，小船相对地面的速度大小为 $v$ ，方向水平向右；人相对地面的速度大小为 $v ^ { \prime }$ ，方向水平向左。又设整个过程中船相对地面移动距离为 $s$ ，人相对地面移动距离为 $s ^ { \prime }$ 。

$$
0 = M v - m v ^ {\prime} \Rightarrow M v = m v ^ {\prime} \Rightarrow M v d t = m v ^ { \prime } d t
$$

$$
\Rightarrow \int_ {0} ^ {T} M v d t = \int_ {0} ^ {T} m v ^ { \prime } d t \Rightarrow M \int_ {0} ^ {T} v d t = m \int_ {0} ^ {T} v ^ { \prime } d t \Rightarrow M s = m s ^ { \prime};
$$

又由图可知： $s + s ^ { \prime } = L$ ，联立上述两式，解得 $s = \frac { m } { M + m } L , s ^ { \prime } = \frac { M } { M + m } L ;$

![人和船相对运动示意图](<资料名>.assets/图7.png)

代入数据计算：
$$
s = \frac {m}{M + m} L = \frac {5 0}{1 0 0 + 5 0} \times 3. 6 \mathrm{m} = 1. 2 \mathrm{m}
$$

答案：船相对地面移动距离为 $1.2 \mathrm{m}$ 。

知识点：[动量定理与动量守恒定律](../../../topics/大学物理/动量定理与动量守恒.md)、[质心与质心运动定理](../../../topics/大学物理/质心运动定理.md)、[相对运动与伽利略变换](../../../topics/大学物理/相对运动.md)

### 计算 8

建立如图所示坐标系，小球碰撞前入射速度： $\vec { v } _ { 0 } = v \cos \alpha \vec { i } - v \sin \alpha \vec { j }$ ，碰后速度： $\vec { v } = - v \cos \alpha \vec { i } - v \sin \alpha \vec { j }$ 。由动量定理，小球受到墙壁作用力的冲量：

$$
\vec {I} = \int_ {0} ^ {\Delta t} \vec {F} d t = \overline {{\vec {F}}} \cdot \Delta t = m \vec {v} - m \vec {v } _ { 0} = - 2 m v \cos \alpha \vec {i},
$$

⇒ 小球受到墙壁的平均作用力： ${ \overline { { \vec { F } } } } = - { \frac { 2 m v \cos \alpha } { \Delta t } } { \vec { i } }$

根据牛顿第三定律，作用力与反作用力大小相等，方向相反，

![小球碰撞墙壁示意图](<资料名>.assets/图8.png)

⇒ 墙壁受到小球的平均冲力： $\overline { { \vec { F } } } ^ { \prime } = \frac { 2 m v \cos \alpha } { \Delta t } \vec { i }$

答案：墙壁受到小球的平均冲力为 $\frac { 2 m v \cos \alpha } { \Delta t } \vec { i }$ 。

知识点：[动量定理与动量守恒定律](../../../topics/大学物理/动量定理与动量守恒.md)、[牛顿三定律与惯性系](../../../topics/大学物理/牛顿三定律.md)

### 计算 9

（1）由于子弹穿透物体的时间极短，子弹和物体构成的系统在水平方向动量守恒：

$m v _ { 0 } = m v + M v ^ { \prime }$ ⇒ 子弹刚穿出时，物体的速度大小： $v ^ { \prime } = { \frac { m } { M } } ( v _ { 0 } - v ) = { \frac { 4 7 } { 1 5 } } \mathrm { m / s }$

物体获得速度 $v ^ { \prime }$ 后，在重力 $M g$ 和绳拉力T 的作用下将绕悬挂点做圆周运动，向心力： $T - M g = M { \frac { v ^ { \prime 2 } } { l } }$

⇒ 子弹刚穿出时绳中拉力： $T = M ( g + { \frac { v ^ { \prime 2 } } { l } } ) = 2 6 . 5 \mathrm { N }$

（2）设水平方向为ox轴，子弹入射前动量： $\vec { P } _ { 0 } = m \vec { v } _ { 0 } = m v _ { 0 } \vec { i }$ ，刚穿出时动量： ${ \vec { P } } = m { \vec { v } } = m v { \vec { i } }$

由动量定理，子弹在穿透过程中受到的冲量： $\vec { I } = \int _ { 0 } ^ { \Delta t } \vec { F } d t = \vec { P } - \vec { P } _ { 0 } = m v \vec { i } - m v _ { 0 } \vec { i } = - 4 . 7 \mathrm { N } \cdot \mathrm { s } \vec { i }$

答案：（1）绳中拉力为 $26.5 \mathrm { N }$ ；（2）子弹受到的冲量为 $- 4 . 7 \mathrm { N } \cdot \mathrm { s } \vec { i }$ 。

### 计算 10

如图，设水平方向为ox轴，忽略水对船的阻力，人和船构成的系统在水平方向上动量守恒。

人跳离第一条船的过程： $m v - M u _ { \scriptscriptstyle 1 } = 0$ ，

$\Rightarrow \ u _ { 1 } = \frac { m } { M } v$ ，方向水平向左，

⇒ 第一条船的速度： $\vec { u } _ { 1 } = - \frac { m } { M } \vec { v }$

![人跳船过程示意图](<资料名>.assets/图10.png)

人跳上第二条船的过程： $m v = ( m + M ) u _ { 2 } \ \Rightarrow \ u _ { 2 } = { \frac { m } { m + M } } v$ ，方向水平向右，

⇒ 第二条船的速度： $\vec { u } _ { 2 } = \frac { m } { m + M } \vec { v }$

答案：第一条船速度大小为 $\frac { m } { M } v$ ，方向向左；第二条船速度大小为 $\frac { m } { m + M } v$ ，方向向右。
