# 四级词汇词根+联想记忆法（乱序版核心词缀与词根构词规律）

## 词根词缀：词汇的“偏旁部首”

背四级单词最怕什么？**记不住、易混淆、忘得快**。但你可能发现，汉字“清、晴、睛、情”都带“青”，意思虽不同，却都与“青”的声旁或形旁有关。英语同理——==单词不是随机的字母组合，而是由有意义的“零件”拼装而成的==。

试着从下面这个词里拆一拆：

> **unpredictable** — 不可预测的

如果你认识 **dict**（说），那你就能猜出 **predict**（预先说→预测），加上 **-able**（可…的）变成“可预测的”，再冠上 **un-**（不）——整个词的意思就自己浮出来了。

这就是**词根词缀构词规律**：词根决定核心意思，前缀改变方向/否定，后缀标明词性。

[!IMPORTANT]
> 掌握一个高频词根，往往能帮你撬动十几甚至几十个四级词汇，而不是孤立地死记硬背。

---

## 为什么需要它？

四级词汇表里存在大量“长得像、意思想”的词，比如：

*   **sustain / contain / detain / retain**
*   **proceed / exceed / succeed**
*   **inspect / prospect / respect / spectacle**

如果只盯着拼写一个一个啃，很容易在考试时“看着眼熟，想不起来”。但如果你知道 **-tain-** 来自拉丁语“拿、握”，以上所有词就能串成一条线：

| 单词 | 词根词缀拆解 | 核心含义 |
| :--- | :--- | :--- |
| **sustain** | sus-(下) + tain(握) | 从下面握住→支撑、维持 |
| **contain** | con-(共同) + tain(握) | 握在一起→包含、容纳 |
| **detain** | de-(离开) + tain(握) | 握住使之离开→拘留、耽搁 |
| **retain** | re-(回) + tain(握) | 握回来→保留、保持 |

回到你真题里那道“欧洲早期工业增长”的选择题：

> Europe's earlier industrial growth was ______ by the availability of key resources...

*   A) constrained (con- 一起 + strict 拉紧 → 限制)
*   D) sustained (sus- 下 + tain 握 → ==从下方支撑→维持==)

题干说的是“关键资源可用性”对“工业增长”的正面作用，选 **sustained** 才符合逻辑。一旦你用词根理解了“-tain-”的“握、支撑”之意，就不会被 **constrained** 的拼写迷惑。

## 常见词根词缀速览

以下是四级乱序版词汇中最高频、最核心的一批构词零件：

### 高频前缀

| 前缀 | 含义 | 例词 |
| :--- | :--- | :--- |
| **un-/in-/im-/dis-** | 不、相反 | unable, incorrect, impossible, dislike |
| **re-** | 再次、回 | review, return, recycle |
| **pre-** | 在…之前 | preview, predict, preface |
| **inter-** | 在…之间 | internet, international, interact |
| **trans-** | 跨越、转移 | transfer, transform, transit |
| **sub-/sup-/sus-** | 下 | subway, support, sustain |

### 高频后缀（定词性）

| 后缀 | 词性 | 例词 |
| :--- | :--- | :--- |
| **-tion / -sion** | 名词 | education, decision |
| **-ment** | 名词 | development, movement |
| **-able / -ible** | 形容词 | comfortable, possible |
| **-al / -ive** | 形容词 | personal, active |
| **-ate / -ize** | 动词 | activate, modernize |

### 高频词根（定核心意思）

| 词根 | 含义 | 例词 |
| :--- | :--- | :--- |
| **-spect-** | 看 | inspect(检查), respect(尊敬), prospect(前景) |
| **-dict-** | 说 | predict(预言), dictionary(字典), contradict(反驳) |
| **-tain-** | 握、持 | contain, maintain, sustain, detain |
| **-ced-/ceed-** | 走 | proceed(前进), exceed(超过), succeed(成功) |
| **-scend-** | 爬 | ascend(上升), descend(下降), transcend(超越) |
| **-fin-** | 界限 | final, finish, define(下定义→划定界限) |

## 怎么做：用“拆-联-用”三步法记单词

碰到一个四级新词，不要马上查，先自己“解剖”它：

1.  **拆**：去掉前缀、后缀，找出裸词根。
    *   比如 **disrespectful** → dis- (不) + respect (尊重) + -ful (形容词) → 不尊重的。
2.  **联**：把同一个词根的家族词串起来，建立网络。
    *   **-spect-** 家族：inspect(往里看→检查), respect(回头看→尊重), prospect(向前看→前景), spectator(看的人→观众)。
3.  **用**：放到具体场景、真题句子里验证。
    *   “The light is too **dim** for me to read by.”
        *   **dim** 不用死记，它本身就是词根，指“暗淡、模糊”。
        *   对比：**mild**(温和)、**minute**(微小)、**slight**(轻微) → 只有 **dim** 专门形容光线不足。

[!WARNING]
> **不要望文生义！**
> 词根词缀是推导工具，不是万能公式。有些词在历史演变中含义已偏离。比如 **succeed**：suc-(从下) + ceed(走) → 从下面走上来 → 成功（不是“一直走下去”）。所以，**拆解后必须对照词典验证**，并在真实例句里内化。

## 真题实战拆解

> Slavery was ______ in Canada in 1833...
> A) abolished B) resigned C) diluted D) dissipated

*   **abolish**：ab-(离开) + ol(生长→滋养) + -ish → 让某物不再生长→废除。
*   **resign**：re-(回) + sign(标记) → 把标记/印章交回→辞职。
*   **dilute**：di-(分开) + lute(冲洗) → 冲淡、稀释。
*   **dissipate**：dis-(分开) + sip(扔、撒) → 挥霍、驱散。

题干谈“奴隶制在1833年的加拿大…”，历史常识与动词搭配都指向 **abolished（废除）**，而不是其他三个。用词根拆解可以帮你快速分辨词义方向，而非在四个陌生拼写中盲目猜测。
