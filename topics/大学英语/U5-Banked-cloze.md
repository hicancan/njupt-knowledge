# Unit 5 Banked cloze（选词填空）

## 选词填空的本质

Banked cloze（选词填空）要求从题首给出的备选词中，选择最合适的词填入空格。它既考查**词义辨析**，也考查**词性、搭配、上下文逻辑和固定用法**。通常每个备选词使用一次，也可能有多余干扰项。

> [!IMPORTANT]
> 先判断空格在句中承担的成分，再结合前后文确定词义；不能只看到中文意思相近就填。

## 解题步骤

可以按以下顺序思考：

1. **确定词性**：空格前有冠词、形容词、介词或不定代词时，先判断所需词性。
2. **寻找线索**：关注前后文中的同义解释、因果关系、转折和固定搭配。
3. **比较选项**：把意思相近的词放在一起比较，如 *acquaint*、*introduction*、*acquisition*。
4. **代回验证**：填入后分别检查语法是否自然、句意是否连贯。

例如：

> It is the **transition** period, during which we move from adolescence to adulthood.

*transition* 在这里作定语，表示“过渡的”；句意是从青少年阶段进入成年阶段，因此应选 *transition*，而不是表示“介绍”的 *introduction*。

## 常见词义辨析

| 备选词 | 常见含义 | 本题语境 |
|---|---|---|
| *anxiety* | 焦虑、担忧 | 父母对学业和未来感到担忧 |
| *acquaint* | 使熟悉、结识 | 了解并熟悉外部世界 |
| *acquisition* | 获得、收购 | 与 *acquaint* 的“熟悉”义不同 |
| *saddled* | 使背上负担、受累 | 承受父母施加的压力 |
| *expressed* | 表达 | *express feelings of anxiety* |
| *resent* | 怨恨、反对 | 对“大学期间结婚”的想法不满 |
| *acceptable* | 可接受的 | 女性收养孩子逐渐被接受 |
| *reinforce* | 加强、强化 | 加强学业方面的积累 |
| *equivalent* | 相等的、等同于 | *be equivalent to* 表示“等同于” |
| *shifting* | 转移、转换 | 从学业转向婚姻生活 |

## 语法和搭配信号

- **名词前**：空格可能填名词，如 *acquaint*（使熟悉的人或经历）与 *acquaintance*（熟人）不同；*acquaint oneself with* 是固定结构。
- **系动词后**：常用形容词或分词，如 *be equivalent to*、*be acceptable to/for*。
- **介词后**：注意介词搭配，如 *be worried about*、*be interested in*。
- **过去分词作定语**：如 *expressed feelings of anxiety*，表示“已经表达出来的担忧”。

## 易错点

> [!WARNING]
> 不要只依据单词的中文释义。同一单词在具体语境中可能对应不同词义，答案必须同时满足语法和逻辑。

常见问题包括：

- 把 *acquaint* 误当成名词“熟人”，忽略句中需要的是动词。
- 忽略 *be equivalent to* 中的介词搭配。
- 看到 *anxiety* 就直接填，却没发现前面有 *feelings of*，形成不自然的表达。
- 填完后不再通读全文，导致局部通顺但整体逻辑错误。

## 完整示例

原段落中的十个空格依次为：

1. *transition*：人生阶段的过渡期。  
2. *saddled*：承受父母的压力。  
3. *anxiety*：父母对未来的焦虑。  
4. *acquaint*：*acquaint oneself with the world*，意为“使自己熟悉世界”。  
5. *equivalent*：*be equivalent to lack of ambition*，表示“等同于没有抱负”。  
6. *expressed*：过去分词作定语，修饰“担忧”。  
7. *resent*：对母亲强迫自己寻找对象的想法感到不满。  
8. *acceptable*：女性收养孩子越来越“为社会所接受”。  
9. *reinforce*：加强自己的学术训练。  
10. *shifting*：*shift to marriage*，从学业转向婚姻。

> [!TIP]
> 做题时在每个备选词旁标出词性和核心搭配，再逐句圈出定语、介词、系动词等线索，通常比反复通读全文更高效。
