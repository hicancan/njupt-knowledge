# 广域网基本概念与虚电路服务（X.25、帧中继、ATM）

> [!IMPORTANT]
> 广域网（WAN）覆盖范围通常是几十到几千公里。其网络层为主机提供两大类服务：==无连接的数据报服务==和==面向连接的虚电路服务==。

## 虚电路服务 vs 数据报服务

**为什么需要虚电路？** 在广域网中，若每个分组都独立选路（数据报），虽然灵活，但难以保证资源。虚电路的思路是：**先建路，再传数**。通信前先发"连接建立请求"分组寻找路由，并在沿途交换结点==预留资源（带宽、缓存）==，从而对 QoS 有较好保证。

```mermaid
flowchart LR
    A[建立连接] --> B[数据传输] --> C[释放连接]
```

> [!WARNING]
> 虚电路 ≠ 电路交换！虚电路基于==存储转发==的分组交换，分组断续地占用一段段链路，物理链路被**动态复用**；而电路交换是独占整条物理通路。

| 特点 | 数据报服务 | 虚电路服务 |
| :--- | :--- | :--- |
| **思路** | 可靠通信由用户主机保证 | 可靠通信由网络保证 |
| **连接建立** | 不需要 | **必须有** |
| **目的地址** | 每个分组带全地址 | 仅建立阶段用，分组用**短的虚电路号** |
| **分组转发** | 独立选路 | 同一条虚电路走**同一路由** |
| **结点故障** | 丢失分组，后续改路由 | 经过该结点的**所有虚电路均失效** |
| **分组顺序** | 不一定按序到达 | **总是按序到达** |
| **差错/流量控制** | 用户主机负责 | 网络或用户主机负责 |

## 三种广域网技术

### X.25 分组交换网
- 70 年代 CCITT 制订，定义 **DTE 与 DCE** 之间的接口。
- 规定三层：**物理层、数据链路层、分组层**；分组层向高层提供虚电路服务。
- 在链路带宽低、误码率高的年代优势明显；链路条件改善后，其复杂的链路层和分组层协议显得**冗余**。

### 帧中继（Frame Relay）
- 对 X.25 的改进，称为"第二代 X.25"（1992 年），提供**虚电路服务**。
- **快速分组交换**：交换机一查完帧首部目的地址就==边接收边转发==；收完后再校验，出错则**中止传输并丢弃**。
- 工作流程示意：

```mermaid
flowchart LR
    H1[主机] -->|MAC帧| R1[路由器]
    R1 -->|剥MAC加FR首部| FR[帧中继网]
    FR -->|按虚电路号转发| R2[路由器]
    R2 -->|剥FR加MAC| H2[主机]
```

> [!NOTE]
> 帧中继把差错控制推给端系统：目的主机发现差错，报告上层 TCP 处理。

### ATM（异步传递方式）
- 建立在电路交换与分组交换基础上，面向连接的**快速分组交换**。
- 采用==定长 53 字节信元==（首部 5 字节），利于硬件高速交换；"异步"指信元可异步插入同步 SDH 比特流。
- 网络元素：**ATM 端点** + **ATM 交换机**。
- 连接标识：VPI（虚通道）+ VCI（虚通路）。

## 常考的坑

> [!CAUTION]
> - X.25、帧中继、ATM **都采用快速分组交换**？❌ 只有帧中继和 ATM 是，X.25 不是。
> - 三者**都提供虚电路服务**？✅ 正确。

**真题示例**：以下关于广域网的描述正确的是（ ）
- A. 广域网一般采用平面编址 ❌（广域网用层次结构编址）
- B. 三者都采用快速分组交换 ❌（X.25 不是）
- C. 三者都提供虚电路服务 ✅
- D. 广域网传输速率更高 ❌（通常局域网速率更高）

**答案：C**
