# Y86-64 指令集架构（ISA）定义

## 它是什么：处理器能看懂的“指令合同”

**Y86-64 ISA（Instruction Set Architecture，指令集架构）**是这门课为了讲清处理器实现而定义的一套简化指令系统：它仿照 x86-64，但指令更少、编码更规整。ISA 规定的是==程序员可见的机器状态、指令语义和指令编码==，不规定具体用几级流水线、电路怎样画。

可以把 Y86-64 理解成一份“合同”：汇编器按它把指令变成字节，CPU 按它取指、译码并更新状态；同一条指令无论用顺序实现还是流水线实现，外部结果都必须一致。

```mermaid
flowchart LR
    A["汇编指令"] --> B["指令编码"]
    B --> C["取指译码"]
    C --> D["执行运算"]
    D --> E["更新状态"]
```

## 为什么需要它

有了明确的 ISA，才能把“指令做什么”和“硬件怎样做”分开：前者用于写汇编、分析数据相关，后者用于设计 SEQ、PIPE 等处理器。考试中的插入 `nop`、数据相关和控制相关，前提都是先弄清每条指令==读什么、写什么、何时写==。

## 程序员可见状态与指令语义

| 可见状态 | Y86-64 中的内容 | 作用 |
|---|---|---|
| 程序寄存器 | 15 个 64 位寄存器，如 `%rax`、`%rsp` | 保存操作数、地址等 |
| 条件码 | `ZF`、`SF`、`OF` | 反映最近算术或逻辑运算结果 |
| 程序计数器 | `PC` | 指示下一条指令地址 |
| 内存 | 字节编址 | 保存指令和数据 |
| 状态码 | `AOK`、`HLT`、`ADR`、`INS` | 表示正常、停机或异常 |

主要指令可分成四类：

- **数据传送**：`irmovq`、`rrmovq`、`mrmovq`、`rmmovq`。
- **整数运算**：`addq`、`subq`、`andq`、`xorq`，目的寄存器同时是一个源操作数，并设置条件码。
- **控制转移**：`jmp`、条件跳转 `jXX`，以及 `call`、`ret`。
- **其他**：条件传送 `cmovXX`、`pushq`、`popq`、`halt`、`nop`。

例如：

```asm
irmovq $10, %rax
addq %rax, %rbx
```

第二条执行的是 $\%rbx \leftarrow \%rbx+\%rax$，并更新条件码；它不会把结果写进 `%rax`。

## 指令编码：先定操作，再定操作数

Y86-64 指令长度为 **1～10 字节**。首字节通常拆成高 4 位 `icode` 和低 4 位 `ifun`；需要寄存器时，下一字节给出 `rA:rB`；带常数的指令还含 8 字节立即数或目标地址。内存地址按 **基址加位移**计算：

$$
\text{有效地址}=R[rB]+D
$$

其中 $D$ 是指令中的位移常数。多字节数据采用==小端方式==：低位字节放低地址，高位字节放相邻高地址。

> [!TIP]
> 编码时按“首字节 → 寄存器字节 → 8 字节常数”检查；没有寄存器操作数的指令，不要凭空添加寄存器字节。

## 一个算对的编码例子

编码：

```asm
rmmovq %rsi, 0x1234(%rbx)
```

`rmmovq` 的首字节为 `40`；寄存器字节中 `rA=%rsi=6`，`rB=%rbx=3`，所以为 `63`。位移 `0x1234` 占 8 字节，按小端写为：

```text
34 12 00 00 00 00 00 00
```

因此完整编码是：

```text
40 63 34 12 00 00 00 00 00 00
```

共 $1+1+8=10$ 字节，语义为 $M_8[R[\%rbx]+0x1234]\leftarrow R[\%rsi]$。

## 相近概念与常见坑

| 概念 | 关注内容 | 不要混淆 |
|---|---|---|
| ISA | 指令语义、编码、可见状态 | 不等于硬件实现 |
| 微体系结构 | SEQ、PIPE、流水寄存器等 | 不改变 ISA 规定的结果 |
| 寻址方式 | 如何得到操作数位置 | 不是指令编码本身 |
| 数据相关 | 后条指令依赖前条结果 | 不等于控制相关 |

> [!WARNING]
> `%rsp` 指向栈顶；`pushq` 会先减小栈指针再写内存，`popq` 则先读内存再增大栈指针。`%rsp` 不是普通数据寄存器的同义替代品。

> [!NOTE]
> Y86-64 没有 `%rip` 寄存器，寄存器编号 `0xF` 表示“无寄存器”；`rrmovq` 与 `cmovXX` 共用 `icode=2`，靠 `ifun` 区分。
