# 算术与逻辑指令（add、sub、imul、sal、sar、xor等及对条件码的影响）

## 算术与逻辑指令：是什么、为什么、怎么用

在机器级，一切“计算”最终都落到 `add`、`sub`、`imul`、`sal`、`sar`、`xor` 这类指令上。它们按操作数长度区分后缀：`b/w/l/q` 对应 1/2/4/8 字节；按操作数位置区分形式：`addq %rcx,(%rax)` 是“寄存器 → 内存”，`addq (%rax),%rcx` 是“内存 → 寄存器”，**x86-64 不允许两个操作数都在内存**。

> [!IMPORTANT]
> 这些指令执行后都会**隐式改写条件码**（CF、OF、ZF、SF），这是后续 `Jcc` 条件跳转和 `cmov` 的依据。

## 条件码：两套解释，两套溢出

| 标志 | 含义 | 何时置 1 |
| :--- | :--- | :--- |
| CF | 进位/借位 | 无符号运算最高位产生进位或借位 |
| OF | 溢出 | 带符号运算结果超出表示范围 |
| ZF | 零 | 结果为 0 |
| SF | 符号 | 结果最高位为 1 |

关键区别：**同一个二进制结果，无符号看 CF，带符号看 OF**。`addw %bx,%ax` 中 `FFFA + FFF0 = FFEA`：

- 无符号解释：65530 + 65520 = 131050 > 65535，**CF=1 溢出**；
- 带符号解释：(-6) + (-16) = -22，**OF=0 正确**。

> [!WARNING]
> 不要看到“结果最高位变了”就断言 OF=1。OF 的判定标准是：**两个同号数相加，结果变号**；`sal`（算术左移）时若移位前后符号位不变，则 OF=0。

## 移位与乘法：用移位拼出常数乘法

`sal`（左移）低位补 0，`sar`（算术右移）高位补符号位；`shr` 才是高位补 0 的逻辑右移。对 short 变量 `x`，`x<<2` 等价于 `4x`，因此：

```assembly
movw %ax, %dx        ; dx = x
salw $2, %ax         ; ax = 4x
addl %dx, %ax        ; ax = 5x
sarw $1, %ax         ; ax = 5x/2（向零取整）
```

这就是编译器把 `5*x/2` 翻译成移位+加法的实例。`lea` 指令同样承担这类“算术”角色：`leaq 7(%rdx,%rdx,4),%rax` 直接计算 `%rax = 5*%rdx + 7`，**不访存、不改条件码**。

> [!TIP]
> 看到 `lea` 不要只想到“取地址”。当 Dst 不是地址而是普通寄存器时，它就是一个“乘法+加法”的算术指令。

## 完整算例：内存操作数与条件码

给定 `%rax=0x100`，`%rcx=0x1`，`%rdx=0x3`，内存 `0x100=0xFF`，`0x108=0xAB`，`0x110=0x13`，`0x118=0x11`：

| 指令 | 计算过程 | 目的 | 新值 |
| :--- | :--- | :--- | :--- |
| `addq %rcx,(%rax)` | 0xFF + 0x1 | 地址 0x100 | 0x100 |
| `subq %rdx,8(%rax)` | 0xAB − 0x3 | 地址 0x108 | 0xA8 |
| `imulq $16,(%rax,%rdx,8)` | 0x11 × 16 | 地址 0x118 | 0x110 |
| `incq 16(%rax)` | 0x13 + 1 | 地址 0x110 | 0x14 |
| `subq %rdx,%rax` | 0x100 − 0x3 | %rax | 0xFD |

> [!CAUTION]
> `imulq $16, mem` 是“单操作数乘法”的变体，结果直接写回内存，**不会**像双操作数 `imul` 那样可能截断到源操作数长度；计算有效地址时，`(%rax,%rdx,8)` 的缩放比例只能是 1、2、4、8。

## 常见坑速查

- **后缀与操作数长度不匹配**：`addw` 只改 16 位，高位 48 位保持不变，条件码只反映这 16 位的结果。
- **混淆 `sar` 与 `shr`**：对负数 `FF80H`，`sar` 得 `FFC0H`（仍负），`shr` 得 `7FC0H`（变正）。
- **误以为 `lea` 改标志**：`lea` 纯粹算地址，CF/OF/ZF/SF 保持原值。
- **内存-内存操作**：x86-64 算术/逻辑指令至少有一个操作数在寄存器或立即数中，遇到 `addq (%rax),(%rbx)` 是非法指令。

> [!NOTE]
> 逆向工程时，看到连续的 `sal`/`add`/`sar` 组合，应反推出高级语言里的常数乘除表达式，如 `((x<<2)+x)>>1` 即 `5x/2`。
