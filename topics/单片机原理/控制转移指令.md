# 控制转移类指令（LJMP、AJMP、SJMP、JZ、CJNE、DJNZ、LCALL等）

## 控制转移类指令

程序默认按顺序执行：CPU 每取出一条指令，PC 自动加 1（或加 2、加 3，取决于指令长度），指向下一条。但实际程序里到处是分支、循环、子程序调用，这些都需要**改变 PC 的值**。控制转移类指令干的就是这件事。

> [!IMPORTANT]
> 控制转移的本质：==所有转移指令最终都是在修改 PC==。理解了这一点，判断转移范围、计算目标地址就都有了统一的思路。

### 无条件转移：LJMP / AJMP / SJMP

三条都能跳，区别在于**跳多远**和**指令占几个字节**：

| 指令 | 转移范围 | 指令长度 | 目标地址怎么算 |
|---|---|---|---|
| `LJMP addr16` | 64 KB 全空间（$0000H\sim FFFFH$） | 3 字节 | 直接把 16 位地址送 PC |
| `AJMP addr11` | 与当前 PC 高 5 位相同的 2 KB 页内 | 2 字节 | $(PC_{15\sim11})$ 不变，低 11 位来自指令 |
| `SJMP rel` | 当前 PC 向前/向后各约 128 B（$-128\sim+127$） | 2 字节 | $(PC)+2+rel$ |

**一个容易踩的坑**：`SJMP rel` 里 rel 是**有符号偏移量**，以执行完该指令后的 PC 为基准。若 rel 为负（大于 $80H$ 视为负数），则目标在回跳方向；若为正，则前跳。

`AJMP addr11` 也是==坑点密集区==：它只能跳在与 **“PC+2 后”** 的高 5 位相同的 2 KB 空间内。跨页就会出错。

**例**：设 `AJMP 0A00H` 所在地址为 $1FFEH$，则该指令执行后 PC = $2000H$，高 5 位为 $00100$，而目标 $0A00H$ 对应高 5 位为 $01010$，不同——==此指令无法正确转移==。

### 条件转移：JZ / JNZ / CJNE / DJNZ

条件转移都是**相对转移**，目标地址 = 当前 PC（指令执行后的值）+ rel。转移范围仅为 $-128\sim+127$。程序中若条件转移距离不够，需用“条件转移 + LJMP”接力：

```assembly
      JZ   NEXT      ; 若 A=0 跳近处
      LJMP FAR_LABEL ; 否则远跳
NEXT: ...
```

`CJNE OP1, OP2, rel` 是最“多功能”的一条：**先比较，不等则转**；同时影响进位标志 $C$——若 $OP1 < OP2$ 则 $C \leftarrow 1$，否则 $C \leftarrow 0$。常配合 `JC`/`JNC` 实现大小比较跳转。

`DJNZ Rn/direct, rel` 的核心是：**先减 1，再判断**。若减后为 0，顺序执行；否则转移。循环次数 $N$ 次就要把初值设为 $N$，而非 $N+1$。

> [!WARNING]
> `DJNZ direct, rel` 中 direct 可以是 SFR 地址，但要注意：若操作数指向**只读或不存在**的地址，运行时不会报错，但结果不可预期。考试中需认准题目给出的 RAM 地址范围。

`JZ rel` 的执行过程可拆成三步：

1. $(PC) \leftarrow (PC)+2$，先指向下一条；
2. 若 $(A) = 0$，则 $(PC) \leftarrow (PC)+rel$；
3. 否则 PC 不变，继续顺序执行。

### LCALL 与子程序返回

`LCALL addr16` 分两步：

1. 先将返回地址（当前 PC 加 3 后的值）压入堆栈：先压低 8 位，再压高 8 位；
2. 再把 16 位目的地址送 PC。

对应的 `RET` 从堆栈弹出高、低字节恢复 PC。**必须成对使用**，且调用前 SP 需初始化。

```mermaid
flowchart LR
    A["主程序执行"] --> B["LCALL 子程序"]
    B --> C["SP+2 压入返回地址"]
    C --> D["PC ← 子程序入口"]
    D --> E["执行子程序体"]
    E --> F["RET 弹出返回地址"]
    F --> G["返回主程序继续"]
```

### 计算示例

设 `R0 = 05H`，执行以下循环：

```assembly
      MOV   R2, #03H
LOOP: DJNZ  R2, LOOP
```

初始 $R2 = 3$。第一次执行 `DJNZ`：$R2-1=2 \neq 0$，转 LOOP；第二次：$2-1=1\neq 0$，转 LOOP；第三次：$1-1=0$，==顺序执行==。循环体共执行 **3** 次，之后 `R2 = 00H`。

> [!TIP]
> 记“DJNZ 循环次数就是初值”，不用做加减法；而 `CJNE` 的关键是“不相等才转移”，等于则直落。
