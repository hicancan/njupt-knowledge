# 汇编伪指令（ORG、EQU、DB、DW、BIT、END等）

## 伪指令是什么

汇编语言程序里有两类“指令”：

- **指令**：如 `MOV A,#30H`、`SJMP LOOP`，汇编后生成机器码，下载到单片机后由 CPU 执行。
- **伪指令**：如 `ORG`、`EQU`、`DB`，==只告诉汇编器如何汇编，本身不生成可执行机器码，CPU 不会执行它们==。

为什么需要伪指令？因为程序除了“让 CPU 做什么”，还要说明“代码放在哪里、数据怎样存放、符号代表什么、汇编到哪里结束”。

## 常用伪指令

| 伪指令 | 作用 | 示例及含义 |
|---|---|---|
| `ORG` | 指定后续程序或数据的起始地址 | `ORG 0000H`：后续内容从 ROM 的 `0000H` 开始 |
| `EQU` | 给符号赋值，便于修改和阅读 | `LED EQU P1`：程序中 `LED` 代表 `P1` |
| `DB` | 定义字节数据，每项占 1 个 ROM 单元 | `DB 12H,34H`：依次存入 `12H`、`34H` |
| `DW` | 定义字数据，每项占 2 个 ROM 单元 | `DW 1234H`：存入 `12H`、`34H` |
| `BIT` | 给位地址定义符号名 | `KEY BIT P3.2`：`KEY` 表示位地址 `P3.2` |
| `END` | 表示源程序汇编结束 | 通常放在源程序末尾 |

`DB` 和 `DW` 定义的数据存放在**程序存储器 ROM**中，常用于表格、常量和显示段码，不等于在 RAM 中申请变量。

## 一个完整的小例子

```asm
        ORG 0000H
        LJMP START

        ORG 0030H
START:  MOV DPTR,#TAB
        MOV A,#1
        MOVC A,@A+DPTR
        MOV P1,A
        SJMP $

TAB:    DB 3FH,06H,5BH
        END
```

执行过程如下：

1. `ORG 0030H` 使 `START` 从 `0030H` 开始。
2. `MOV DPTR,#TAB` 把表首地址送入 `DPTR`。
3. `A=1`，查表指令读取 `TAB+1` 单元。
4. 表中第 0、1、2 项分别为 `3FH`、`06H`、`5BH`，所以最终 $A=06H$，$P1=06H$。

这里 `ORG`、`DB`、`END` 只参与汇编和存储安排；真正被查表指令读取的是 `DB` 已经放入 ROM 的数据。

## `DB` 与 `DW` 的地址计算

```asm
        ORG 0100H
BUF:    DB 11H,22H
        DW 1234H,5678H
        DB 0AAH
```

各字节的存放结果为：

| ROM 地址 | 内容 | 来源 |
|---|---|---|
| `0100H` | `11H` | 第一个 `DB` |
| `0101H` | `22H` | 第一个 `DB` |
| `0102H` | `12H` | `1234H` 高字节 |
| `0103H` | `34H` | `1234H` 低字节 |
| `0104H` | `56H` | `5678H` 高字节 |
| `0105H` | `78H` | `5678H` 低字节 |
| `0106H` | `AAH` | 最后一个 `DB` |

因此，==`DW` 按高字节在前、低字节在后的顺序存放==。若问 `BUF` 后共占多少字节，则 $2+2\times2+1=7$ 字节，下一可用地址为 `0107H`。

## 相近概念与常见坑

| 易混内容 | 区别 |
|---|---|
| `EQU` 与 `BIT` | `EQU` 可定义一般数值或地址符号；`BIT` 专门定义可位寻址的位符号 |
| `DB` 与 `DW` | `DB` 每项 1 字节；`DW` 每项 2 字节，适合地址、16 位常量 |
| `DB` 与 RAM 变量 | `DB` 把常量写入 ROM；不能直接当作运行时可随意修改的 RAM 变量 |
| `ORG` 与 `END` | `ORG` 可多次使用以安排不同代码段；`END` 只表示汇编结束，不是 CPU 的停机指令 |

> [!WARNING]
> `ORG 0000H` 后若直接放主程序，可能覆盖中断入口区域。常见写法是在 `0000H` 放跳转指令，再用 `ORG 0030H` 等安排主程序。

> [!CAUTION]
> `SJMP $` 才是原地等待；只写 `END` 不会让 CPU 停止执行。`END` 后面的内容不再属于本次汇编的源程序。

> [!TIP]
> 做存储地址题时，按“`ORG` 定起点，`DB` 加 1，`DW` 加 2”逐项推地址；遇到 `DW`，立即检查高低字节顺序。
