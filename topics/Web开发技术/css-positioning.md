# 元素定位（绝对定位、相对定位、静态定位）与堆叠元素

## 元素定位与堆叠

在 CSS 中，要精确控制元素的位置，需要理解定位机制。页面上的盒子如果不做特别设置，默认按文档流排列——块级元素从上到下，行内元素从左到右。但很多时候我们需要打破这种默认排列，比如让导航栏固定在顶部、让弹窗居中显示、或者在角落放一个悬浮按钮。这时就需要用到 `position` 属性。

### 静态定位：默认的文档流

```css
div {
  position: static;
}
```

静态定位是元素的默认定位方式，也就是“没有定位”。元素按照 HTML 出现的顺序在文档流中依次排列，`top`、`right`、`bottom`、`left` 和 `z-index` 属性对它**无效**。

> [!NOTE]
> 几乎所有元素默认都是 `position: static`，除非你主动修改它。考试中如果问“未设置 position 的元素属于什么定位”，答案就是静态定位。

### 相对定位：相对于自己原来的位置偏移

```css
.box {
  position: relative;
  top: 20px;
  left: 30px;
}
```

相对定位的元素**仍然占据文档流中的原始空间**，但视觉上可以相对于原位置偏移。它有两个关键特征：

1. 偏移的参照点是元素**原本应该在的位置**。
2. 元素移走后，原来的空间不会被其他元素填充。

这意味着如果你设置 `top: 20px`，元素会向下移动 20 像素，但上方会留下一块空白。相对定位常用于微调位置，或者作为绝对定位元素的**定位父级**。

### 绝对定位：脱离文档流，相对于定位父级

```css
.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

绝对定位会让元素**完全脱离文档流**——它不再占用原来的空间，后面的元素会顶上来，就像这个元素不存在一样。它的偏移参照点是**最近的已定位祖先元素**（即 `position` 不为 `static` 的祖先）。如果找不到，则相对于 `<html>`（初始包含块）定位。

> [!IMPORTANT]
> ==“绝对”这个名字容易让人以为它总是相对于浏览器窗口定位，实际上它是相对于最近的定位祖先，只有找不到定位祖先时才退回到 `<html>`。==

典型的组合用法是**父相子绝**：父元素设 `position: relative`（保持文档流占用），子元素设 `position: absolute` 实现相对父元素的精确定位。

### 堆叠顺序：谁压在上面

当元素重叠时，`z-index` 决定谁显示在上层。规则很简单：

- `z-index` 只在**定位元素**（非 `static`）上生效。
- 数值越大，元素越靠上。
- 同级定位元素且 `z-index` 相同或未设置时，==后来者居上==（HTML 中后出现的覆盖先出现的）。

> [!WARNING]
> 如果父元素的 `z-index` 已经限制了层级上下文，子元素再高也翻不出父元素的“层”。这是考试中常见的坑——子元素 `z-index: 999` 在一个 `z-index: 1` 的父元素里，仍然可能被 `z-index: 2` 的外部元素盖住。

### 常见的坑

1. **设置绝对定位后忘记指定偏移**：元素会留在原地但脱离文档流，导致布局错乱。
2. **绝对定位父级不设 `position`**：元素会一路找上去，最终相对窗口定位，不是你想要的效果。
3. **`z-index` 加在静态元素上**：完全不生效，需要同时设置 `position: relative/absolute/fixed`。
4. **浮动 vs 绝对定位混淆**：浮动能让文字环绕，绝对定位则是完全盖住，文字不会避开。

### 算对了一道题

回到开头提到的考试题：左侧边距嵌入小文本框，主文本环绕它。

**思路分析**：题目要求“主文本围绕小框流动”，这会用到 `float` 而不是绝对定位——因为绝对定位会让文字无视盒子直接穿过。`float: left` 让盒子靠左，后续文本环绕；配合 `overflow: auto` 建立块级格式化上下文，防止文字钻入浮动区域下方。

**CSS 关键代码**：

```css
.sidebar {
    float: left;               /* 左浮动，脱离文档流但文字环绕 */
    width: 20%;                /* 限定宽度 */
    background-color: #f0f0f0;
    padding: 10px;
    margin-right: 10px;        /* 留出间距让主文本不贴边 */
    font-size: 0.8em;          /* 较小字体 */
    font-style: italic;        /* 斜体 */
}

.main-content {
    overflow: auto;            /* 清除浮动影响，防止高度塌陷 */
}
```

> [!TIP]
> 考试中如果同时出现“侧边栏 + 定位”的需求，先判断是否需要文字环绕。需要环绕 → 用浮动；需要层叠或固定位置 → 用绝对定位。两者不要混用在同一需求上。
