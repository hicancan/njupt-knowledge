# 转移指令（JMP、条件转移、CALL、RET）

## 转移指令概述

8086 指令系统中的转移指令用于改变程序的执行顺序，使其从当前指令转到指定位置继续执行。主要包括无条件转移指令 `JMP`、条件转移指令、子程序调用指令 `CALL`、子程序返回指令 `RET`，以及与中断配合使用的 `INT n` 和 `IRET`。

| 指令 | 基本作用 | 是否带返回地址 |
|---|---|---|
| `JMP` | 无条件转移 | 否 |
| 条件转移 | 条件成立时转移 | 否 |
| `CALL` | 调用子程序 | 是 |
| `RET` | 从子程序返回 | — |
| `INT n` | 产生软件中断 | 是 |
| `IRET` | 从中断服务程序返回 | — |

> [!IMPORTANT]
> `JMP` 只改变执行位置，不保存返回地址；`CALL` 会保存返回地址，因此必须与 `RET` 配合使用。

## JMP：无条件转移

`JMP` 将程序执行权转交给目标地址，不要求任何条件，也不改变标志寄存器。

```asm
JMP  CHECK       ; 段内直接转移
JMP  SHORT NEXT  ; 段内短转移
JMP  BX          ; 段内间接转移
JMP  WORD PTR [SI]
JMP  FAR PTR LABEL ; 段间直接转移
JMP  DWORD PTR [SI] ; 段间间接转移
```

按地址形成方式可分为段内直接、段内间接、段间直接和段间间接转移。`JMP SHORT LABEL` 是短转移，偏移范围通常为 $-128\sim+127$；缺省的 `JMP LABEL` 是段内近转移，可采用 16 位相对位移。

## 条件转移

条件转移是否执行，取决于前一条指令产生的标志位。所有条件转移都是短转移。

| 条件 | 指令 | 判断依据 |
|---|---|---|
| 等于、不等于 | `JE/JZ`、`JNE/JNZ` | `ZF=1/0` |
| 无符号数高于、高于等于 | `JA/JNBE`、`JAE/JNB` | `CF=0` 且 `ZF=0`；`CF=0` |
| 无符号数低于、低于等于 | `JB/JNAE`、`JBE/JNA` | `CF=1`；`CF=1` 或 `ZF=1` |
| 有符号数大于、大于等于 | `JG/JNLE`、`JGE/JNL` | `ZF=0` 且 `SF=OF`；`SF=OF` |
| 有符号数小于、小于等于 | `JL/JNGE`、`JLE/JNG` | `SF≠OF`；`ZF=1` 或 `SF≠OF` |
| 有进位、无进位 | `JC`、`JNC` | `CF=1/0` |

例如，比较两个无符号数：

```asm
MOV AL, 35H
CMP AL, 20H
JA  GREATER       ; 35H＞20H，转入 GREATER
```

`JA` 判断的是无符号数大小，不能用 `JG` 代替；`JG` 依据 `SF` 和 `OF` 判断有符号数。

## CALL 与 RET

`CALL` 用于调用子程序。执行时，CPU先把返回地址压入堆栈，再转入子程序入口；`RET` 从栈顶弹出返回地址，使程序返回调用处。

```asm
MAIN:
    CALL DISPLAY
    CALL PRINT
    RET

DISPLAY PROC
    MOV AH, 02H
    INT 21H
    RET
DISPLAY ENDP
```

在实模式中，返回地址由段地址和偏移地址组成。调用同一代码段内的过程时，`CALL` 通常压入返回偏移地址；若进行远调用，则压入返回偏移地址和返回段地址。`RET` 根据栈中内容完成相应返回。

`RET n` 还可在返回时额外释放 $n$ 字节参数：

```asm
CALL  PROC1
...
PROC1 PROC
    PUSH AX
    ...
    RET 2
PROC1 ENDP
```

这里的 `RET 2` 会先弹出返回地址，再释放调用者在栈上保留的 2 字节参数。

## 中断调用与返回

`INT n` 用于发出软件中断。CPU根据中断类型码 $n$ 查找中断向量，进入相应的中断服务程序。实模式下，中断向量表位于内存最低端 $1\text{ KB}$，每个中断向量占4字节，其地址为：

$$
4n\sim 4n+3
$$

其中低地址的两个字节保存入口偏移地址，高地址的两个字节保存入口段地址。

`IRET` 是中断返回指令。它从堆栈依次弹出 `IP`、`CS` 和 `FLAGS`，恢复中断前的程序现场和标志状态。

> [!IMPORTANT]
> 在8086实模式中，`IP`、`CS`、`FLAGS` 均为16位，因此执行 `IRET` 共从栈中弹出 $2+2+2=6$ 字节，分别恢复为 `IP`、`CS` 和 `FLAGS`。

```asm
SERVICE PROC FAR
    PUSHA
    PUSH DS
    ; 中断处理
    POP DS
    POPA
    IRET
SERVICE ENDP
```

`CLI` 和 `STI` 分别用于关闭、开放可屏蔽中断；它们只影响可屏蔽中断请求。硬件可屏蔽中断服务程序结束前，通常还要向对应8259A发送结束命令 `EOI`。若中断源连接主片，命令写到 `20H`；若连接从片，则应写到从片的命令端口 `A0H`。

> [!WARNING]
> 常见错误是把 `IRET` 写成只恢复 `IP` 和 `CS`。在实模式中，`IRET` 还会恢复 `FLAGS`，所以总共弹出6字节。另一个易错点是：对从片8259A的硬件中断结束时，把 `EOI` 错写到主片端口 `20H`。

## 典型计算

若题目给出从地址 `0000H:0048H` 开始的4个连续字节依次为 `00H、38H、30H、50H`，则：

$$
\frac{0048H}{4}=12H
$$

所以中断类型码为 `12H`。入口偏移地址为 `3800H`，入口段地址为 `5030H`，故中断服务程序入口地址为：

$$
5030H:3800H
$$

判断中断类型码时，应抓住“==中断向量地址等于类型码乘4==”这一核心关系。
