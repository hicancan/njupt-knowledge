# 微处理器的工作模式（实模式、保护模式、虚拟8086模式）

## 三种工作模式：实模式、保护模式、虚拟 8086 模式

80486 有三种工作方式：**实模式**、**保护模式**、**虚拟 8086 模式**。理解它们的关键在于：CPU 复位后从哪种模式起步？每种模式能访问多大的地址空间？中断向量表又该放在哪里？

### 实模式：复位后的起点

CPU 初始加电或复位后，自动进入==实模式==。此时：

- **物理地址形成**：由 16 位偏移量与段寄存器内容左移 4 位相加得到，即
  $$\text{物理地址} = \text{段基址} \times 16 + \text{偏移量}$$
  共 20 位，可用 `CS:IP` 表示。
- **地址空间**：只能访问第一个 1MB 内存（`00000H ~ FFFFFH`），I/O 地址范围为 64KB（`0000H ~ FFFFH`）。
- **特权级**：程序运行在最高特权级 0 级。

> [!IMPORTANT]
> 实模式下，**中断向量表**必须设置在系统 RAM 最低端的 1K 单元，即物理地址 `00000H ~ 003FFH`。

### 中断向量与中断向量表

**中断向量**是实模式下中断服务子程序的==入口地址==，由两部分组成：
- 服务程序所在代码段的**段基址**（2 字节）
- 服务程序入口的**偏移地址**（2 字节）

共 4 字节，即 `CS:IP`。

CPU 把 256 种中断向量组成一张表，称为**中断向量表**。每种中断类型码 $n$ 对应表中 4 个单元，表地址为：
$$\text{表地址} = 4 \times n$$

CPU 响应中断时，从 $4 \times n \sim 4 \times n+3$ 单元取出中断向量，分别送入 IP 和 CS，从而转向中断服务程序。

### 保护模式：最常用、最具特色

通过设置 CR0 的 PE 位（PE=1）可进入保护模式。此时：
- 可访问 **4GB**（$2^{32}$）物理存储空间
- 逻辑空间（虚拟空间）可达 $2^{46} = 64\text{T}$
- 支持分页机制，CR0 的 PG 和 PE 位组合决定模式：
  - `00`：实模式
  - `01`：不分页保护
  - `11`：分页保护

> [!NOTE]
> 保护模式下，中断向量表改称为**中断描述符表**（IDT），其结构与实模式的中断向量表不同。

### 虚拟 8086 模式

在保护模式下，通过设置 EFLAGS 的 VM 位，可使 CPU 以虚拟 8086 方式运行，允许多个 8086 程序在保护模式环境下并行执行，同时保持与实模式兼容的地址形成机制。

### 三种模式对比

| 特性 | 实模式 | 保护模式 | 虚拟 8086 模式 |
|------|--------|----------|----------------|
| 物理地址空间 | 1MB | 4GB | 1MB（虚拟） |
| 中断向量表 | 中断向量表（1KB） | 中断描述符表 | 同保护模式 |
| 特权级 | 0 级 | 0~3 级 | 3 级 |
| 分页支持 | 无 | 有 | 有 |

### 典型例题解析

> **题目**：实模式下，9CH 型中断服务程序的入口地址为 `1240H:56DEH`，则 9CH 型中断向量被安排在内存物理地址____H 至____H 四个单元中，第一个单元的内容是____H，这片存放 256 个中断向量共有____个单元的内存区域被称为中断向量表。

**解答**：

中断类型码 $n = 9\text{CH} = 156$

表地址计算：
$$4 \times n = 4 \times 156 = 624 = 270\text{H}$$

所以：
- 物理地址范围：`270H ~ 273H`
- 中断向量低 2 字节为偏移地址 `56DEH`，高 2 字节为段基址 `1240H`
- 第一个单元（270H）的内容是 `DEH`（偏移地址低字节）
- 256 个中断向量共占 $256 \times 4 = 1024 = 1\text{K}$ 个单元

> [!TIP]
> 计算中断向量表地址时，记住公式 $4 \times n$，注意是**十六进制**运算。9CH 的 4 倍是 270H，不是 36H。

> [!WARNING]
> 实模式下中断向量表的 1KB 固定放在 RAM 最低端（`00000H~003FFH`），不可随意移动。保护模式下则使用中断描述符表，位置由 IDTR 指定。
