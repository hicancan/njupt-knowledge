# 数制转换（二进制、十进制、十六进制互转）

数制转换是微机接口技术的基础技能。在 8254 定时器编程、端口地址计算、中断向量设置等场景中，经常需要在二进制、十进制、十六进制之间快速转换，还要理解 BCD 码的特殊性。

## 四种数制的表示与转换

**二进制（B）**：逢二进一，只有 0、1 两个数码，是计算机硬件直接处理的形式。  
**十进制（D）**：日常计数方式，便于人们理解数值大小。  
**十六进制（H）**：逢十六进一，用 0～9、A～F 表示，==4 位二进制数恰好对应 1 位十六进制数==，因此书写简洁，常用于表示地址、控制字和计数初值。  
**BCD 码**：用 4 位二进制数表示 1 位十进制数字（0～9），分为压缩 BCD（1 字节存 2 位）和非压缩 BCD（1 字节存 1 位）。

| 转换类型 | 方法 | 示例 |
|---------|------|------|
| 二→十 | 按权展开求和 | $1011B = 1×2^3+0×2^2+1×2^1+1×2^0 = 11$ |
| 十→二 | 除 2 取余，逆序排列 | $129 ÷ 2$ 反复取余得 $10000001B$ |
| 二→十六 | 4 位一组，不足补 0 | $10000001B → 1000\ 0001 → 81H$ |
| 十六→二 | 每位展成 4 位 | $3AH → 0011\ 1010B$ |
| BCD→十 | 直接读出各位数字 | $10010111_{BCD} → 97$ |
| BCD→二 | 先转十进制，再转二进制 | $97 → 1100001B$ |

> [!IMPORTANT]
> ==BCD 码不是二进制数==，它只是用二进制形式"编码"了十进制数字。$(10010111)_{BCD}$ 表示十进制 97，而不是二进制 $10010111B$（后者等于十进制 151）。

## 8254 计数初值中的数制选择

8254 的控制字 D0 位决定计数初值的解释方式：
- **D0=0**：二进制计数，初值范围 $0～65535$（写入 0000H 表示 65536）
- **D0=1**：BCD 码计数，初值范围 $0～9999$（写入 0000H 表示 10000）

> [!WARNING]
> 当计数初值 $> 9999$ 时，==只能选二进制方式==，因为 BCD 码无法表示超过 4 位十进制数。例如初值 40000 必须用二进制，而 2000 两种方式均可。

**编程时的区别**：
- 二进制方式：直接写入数值的二进制形式，如 2000 → `MOV AX, 2000`（实际为 07D0H）
- BCD 方式：写入的是"看起来像十进制"的十六进制数，如 2000 → `MOV AX, 2000H`

## 典型例题解析

**例**：将 $(129)_{10}$ 转换为二进制和十六进制；将 $(10010111)_{BCD}$ 转换为十进制和二进制。

**解**：
1. $129 = 128 + 1 = 2^7 + 2^0 = (10000001)_2 = (81)_{16}$
2. $(10010111)_{BCD}$：高 4 位 $1001$ 表示 9，低 4 位 $0111$ 表示 7，故为 $(97)_{10}$
3. $97 = 64 + 32 + 1 = 2^6 + 2^5 + 2^0 = (1100001)_2$

**例**（8254 综合题）：8254 的 0 号计数器，控制字 36H，初值 2000，CLK=2MHz。若改用 BCD 计数，控制字和初值如何修改？

**解**：
- 原控制字 $36H = 00110110B$，D0=0 为二进制；改 BCD 需 D0=1，即 $00110111B = 37H$
- 原初值指令 `MOV AX, 2000`（二进制）；BCD 方式应写 `MOV AX, 2000H`（表示十进制 2000）

> [!TIP]
> 快速判断技巧：看到 `MOV AX, 2000` 是十进制 2000（二进制方式），看到 `MOV AX, 2000H` 在 BCD 方式下也表示十进制 2000，但两者的机器码完全不同。

## 常见错误与注意事项

1. **混淆 BCD 与二进制**：$(10010111)_{BCD}=97$，而 $10010111B=151$，两者不相等。
2. **十六进制书写遗漏后缀**：`10H` 是 16，`10` 是 10，`10B` 是 2，考试和编程中务必带后缀。
3. **初值写入顺序**：8254 要求先低字节后高字节，与数制无关，但 BCD 方式下高低字节各自是 BCD 编码。
4. **范围判断失误**：16 位二进制无符号数范围是 $0～65535$，不是 $0～65536$；但初值 0 在 8254 中表示最大值 65536。

掌握这些转换方法后，面对 8254 初始化、端口地址译码、中断向量计算等题目时，就能迅速在数制间切换，避免低级错误。
