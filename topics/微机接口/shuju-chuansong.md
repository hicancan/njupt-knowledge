# 数据传送指令（MOV、PUSH、POP、XCHG等）

数据传送指令是程序中使用频率最高的一类指令，负责在 **CPU 寄存器、存储器、I/O 端口和堆栈**之间搬运信息。它们只负责“搬运”，一般不改变数据本身，也不进行算术运算。接口程序中常见的 `MOV DX,3F8H`、`MOV AL,'A'`、`OUT DX,AL`，就是在为访问串口准备端口地址和数据。

## MOV：最基本的数据传送

格式为：

```asm
MOV 目的操作数, 源操作数
```

执行结果是 **源 → 目的**，源操作数内容不变。例如：

```asm
MOV AL,'A'       ; AL←41H，立即寻址
MOV DX,BX        ; DX←BX，寄存器寻址
MOV DX,[BX]      ; 从 DS:BX 指向的内存取一个字，寄存器间接寻址
MOV AX,[BX+SI+6] ; 基址加变址寻址，并带位移量
```

`MOV DX,[BX]` 与 `MOV DX,BX` 的区别在于：前者把 **BX 当作内存地址**，后者直接传送 **BX 中的数值**。

> [!IMPORTANT]
> MOV 的核心限制是：==源、目的不能同时为存储器操作数，操作数字长必须一致==；MOV 不影响标志位。

此外还需注意：

- 目的操作数不能是立即数，也不能是 CS；
- 立即数不能直接送段寄存器，因此初始化 DS 要写成：

```asm
MOV AX,DATA
MOV DS,AX
```

- 两个段寄存器之间不能直接传送；
- IP 不能作为 MOV 的操作数；
- 内存操作数类型不明确时，要用 `BYTE PTR`、`WORD PTR` 等说明。

例如 `MOV BUF1,BUF2` 错在源、目的都是内存；`INC [BX]` 错在无法判断增减的是字节还是字，应写成 `INC BYTE PTR [BX]` 或 `INC WORD PTR [BX]`。`MOV AL,[DX]` 也不合法，因为 16 位寻址中 DX 不能作为这种内存寻址的间址寄存器。

## PUSH、POP 与 XCHG

堆栈用于保存现场、传递数据和暂存结果。8086 中一次通常压入或弹出一个字：

$$
PUSH:\ SP\leftarrow SP-2,\qquad POP:\ 先弹出数据，再 SP\leftarrow SP+2
$$

压栈时低字节放低地址、高字节放高地址。堆栈向低地址方向增长，因此 **栈底地址较高，栈顶由 SS:SP 指向**。

```asm
PUSH DS
; 中间修改 DS
POP DS        ; 恢复原来的 DS
```

`POP` 的目的操作数不能是立即数，通常也不能是 CS；`PUSH` 和 `POP` 必须成对、按相反顺序使用，否则容易恢复错现场或破坏返回地址。

`XCHG d,s` 用于 **交换两个操作数**，例如 `XCHG AL,AH` 后，两者内容互换。它与 MOV 的关键区别是：MOV 是单向复制，XCHG 是双向交换；XCHG 同样不允许两个操作数都在内存中，也不影响标志位。

| 指令 | 作用 | 典型用途 |
|---|---|---|
| MOV | 单向复制 | 初值、地址、数据传送 |
| PUSH/POP | 压栈/出栈 | 保存和恢复现场 |
| XCHG | 内容交换 | 交换寄存器或内存数据 |
| LEA | 取有效地址 | 获得变量偏移地址 |
| IN/OUT | 端口输入/输出 | 访问接口芯片 |

注意 `MOV DX,OFFSET SERVICE` 是把 SERVICE 的 **偏移地址**送入 DX，并不是把服务程序内容送入 DX。

## 一个完整的寻址计算例子

已知：

$$
BX=1200H,\quad SI=0002H,\quad DS=3000H
$$

且 $(31202H)=0F7H$，$(31203H)=90H$，执行：

```asm
MOV AX,WORD PTR [BX+SI]
```

源操作数采用 **基址加变址寻址**，有效地址为：

$$
EA=BX+SI=1200H+0002H=1202H
$$

物理地址为：

$$
PA=DS\times16+EA=30000H+1202H=31202H
```

AX 是字寄存器，所以连续读取两个单元：低地址 $31202H$ 的 $0F7H$ 送 AL，高地址 $31203H$ 的 $90H$ 送 AH，因此：

$$
\boxed{AX=90F7H}
$$

> [!TIP]
> 做这类题固定按“**先定寻址方式 → 算 EA → 算物理地址 → 按字长和低字节在低地址取值**”四步进行，最不容易把 `90F7H` 错写成 `F790H`。

> [!WARNING]
> 基址加变址寻址中，BX 与 BP 不能同时出现，SI 与 DI 不能同时出现；使用 BP 时还要特别留意默认段寄存器通常为 SS，而不是 DS。
