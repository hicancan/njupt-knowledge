# 算术、关系、逻辑、位运算、移位、条件及复合赋值运算符与优先级

在 Java 中，运算符是告诉编译器执行特定数学或逻辑操作的符号。简单来说，它就是你对变量进行运算的工具。比如，你想把两个数字加起来，就用 `+`；想比较大小，就用 `>` 或 `<`。

你可能会问：“这么多运算符，写在一起谁先算？” 这就引出了**优先级**的概念。你可以把它理解为“先乘除，后加减”的规则。当你不确定时，==最好的习惯是使用括号 `( )` 显式指定运算顺序==，这能让代码的可读性更好。

为了让你更直观地看清谁先谁后，下面这张表整理了常用的运算符优先级（由高到低）：

```mermaid

    B[一元运算符<br>++expr --expr + - ! ~]
    C[乘除运算<br>* / %]
    D[加减运算<br>+ -]
    E[移位运算<br><< >> >>>]

    A --> B --> C --> D --> E --> F --> G --> H --> I --> J --> K --> L --> M --> N
```

### 算术运算符：基础计算与“坑”

算术运算符处理的就是我们日常的加减乘除。

- **二元运算符**：`+`（加）、`-`（减）、`*`（乘）、`/`（除）、`%`（取余）。
- **一元运算符**：`++`（自增）、`--`（自减）。

> [!WARNING]
> 关键区别：前缀与后缀
> 这是考试和编程中极易出错的点。
> - **`++x`（前缀）**：先让 x 加 1，再拿新值去参与运算。
> - **`x++`（后缀）**：先拿 x 的旧值去参与运算，运算完了再给 x 加 1。

**动手算一算**：设 `x = 2`，那 `(x++) / 3` 的结果是多少？
- 因为是后缀 `++`，所以先做除法：`2 / 3`。Java 中整数相除结果还是整数（直接截断，不是四舍五入），所以结果是 `0`。
- 运算完后，x 才变成 3。

再看看组合的情况，设 `x = 1, y = 2, z = 3`，如何计算 `y += z-- / ++x`？
1.  先看右边的表达式：`z-- / ++x`
2.  `++x` 是前缀，先自增：x 变成 2，取值 2。
3.  `z--` 是后缀，先取值：z 取值为 3，参与除法。
4.  除法：`3 / 2 = 1`（整数截断）。
5.  此时 z 再自减变成 2，x 是 2。
6.  最后算赋值：`y += 1`，即 `y = y + 1 = 2 + 1 = 3`。

### 关系运算符与条件运算符：做出判断

关系运算符用来比较两个值，结果一定是布尔值：==`true` 或 `false`==。

- `==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）。

> [!NOTE]
> `=` 是赋值，`==` 才是比较是否相等。写错是新手最痛苦的 bug 之一。

条件运算符也叫三元运算符，是 `?:`。它是写简单判断的快捷方式。
结构：`条件 ? 表达式1 : 表达式2`
如果条件为 `true`，执行表达式1；为 `false`，执行表达式2。

### 逻辑运算符：连接复杂条件

当你要同时判断多个条件时（比如“x 大于 0 并且 y 小于 10”），就需要逻辑运算符。

| 运算符 | 含义 | 说明 |
| :--- | :--- | :--- |
| `&` | 逻辑与 | 两边都算，两边都真才为真 |
| `\|` | 逻辑或 | 两边都算，两边都假才为假 |
| `&&` | 短路与 | 左边为假则右边不算，直接得假 |
| `\|\|` | 短路或 | 左边为真则右边不算，直接得真 |
| `!` | 逻辑非 | 取反 |
| `^` | 逻辑异或 | 两边真假不同时才为真 |

> [!IMPORTANT]
> 核心考点：短路现象
> `&&` 和 `||` 具有短路特性，效率更高，也更常用。
> 例如：`(a > 10) && (b++ > 5)`，如果 `a > 10` 为 `false`，那么 `b++` 根本就不会执行。这是一个高频考点。

### 移位运算符与位运算符：直接操作二进制

这些运算符直接对整数的二进制位（0 和 1）进行操作。

- **移位运算符**
  - `<<`：左移，右边补0。左移 n 位相当于乘以 $2^n$。
  - `>>`：右移，左边补原来最高位的值（正数补0，负数补1）。
  - `>>>`：无符号右移，左边永远补0。

- **位逻辑运算符**
  - `&`（按位与）、`|`（按位或）、`^`（按位异或）、`~`（按位取反）。

### 复合赋值运算符：化简你的代码

当我们对一个变量进行运算后又赋值给自己时，可以用复合赋值运算符让代码更简洁。

`x = x + 5` 可以简写为 `x += 5`。
常见的有：`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`<<=`、`>>=`、`>>>=`。

> [!TIP]
> 复合赋值运算隐含了一个**强制类型转换**。比如 `byte b = 1; b += 1;` 是合法的，但 `b = b + 1;` 会因为类型提升为 int 而报错。
