# Martin迭代参数图形探索

## 它是什么

Martin 迭代是一种二维离散动力系统迭代格式。给定初值 $(x_0,y_0)$ 和参数 $a,b,c$，反复计算

$$
\begin{cases}
x_{n+1}=y_n-\sin(a x_n)\\[2mm]
y_{n+1}=b-x_n-\cos(c y_n)
\end{cases}
$$

在平面上把 $(x_n,y_n)$ 描成点。随着迭代次数 $N$ 增大，点集可能收敛到有限个点、周期軌道，或形成==分形图形（Martin 吸引子）==。

为什么需要它？它是“第三章 迭代、混沌与分形”里用来观察“参数变化 $\Rightarrow$ 图形突变”的典型实验：不用解微分方程，只靠迭代便能看到混沌与分形。

## 怎么做

实验 2.5 要求改参数 $a,b,c$，看图形。取 $m=10000,\;N=20000$，调用 `Martin(a,b,c,N)` 即可。

| 原表参数 | 代入 $m=10000$ 后实际调用 |
| :--- | :--- |
| $-m,\;m/1000,\;-m$ | `Martin(-10000, 10, -10000, 20000)` |
| $m/100,\;m/10,\;-10$ | `Martin(100, 1000, -10, 20000)` |
| $m/1000,\;m,\;-m$ | `Martin(10, 10000, -10000, 20000)` |
| $-m/10,\;17,\;4$ | `Martin(-1000, 17, 4, 20000)` |

```mermaid
flowchart LR
  A["选 m=10000"] --> B["代入 a,b,c"]
  B --> C["Martin(a,b,c,N)"]
  C --> D["描 20000 点"]
  D --> E["看分形/周期"]
```

> [!IMPORTANT]
> 表中 `m/1000` 等是记号：$m=10000$ 时 `m/1000=10`，不是保留字母 `m` 去算。

## 和相近概念的区别

- **Logistic 迭代**：一维，看 $x_{n+1}=rx_n(1-x_n)$ 的分岔；Martin 是二维。
- **Julia 集**：复平面 $z_{n+1}=z_n^2+c$；Martin 用三角函数与实数对 $(a,b,c)$。
- 二者都能出分形，但 ==Martin 靠三个可调参数扫图形==，实验味更浓。

## 常见的坑

> [!WARNING]
> 初值常取 $(0,0)$ 或 $(1,1)$；若迭代不够（$N$ 太小），只看到零散点而非完整吸引子。

> [!CAUTION]
> 把 `m/1000` 误当变量名原样传给代码，会得到 `Martin(m/1000,...)` 报错——必须先数值代入。

## 一个算对了的例子

取表中第 3 行 $-m,\;m/1000,\;-m$，$m=10000$：

$$
a=-10000,\quad b=10,\quad c=-10000,\quad N=20000
$$

执行 `Martin(-10000, 10, -10000, 20000)`，平面描出 Martin 型分形：细丝缠绕、自相似结构明显。对照第 4 行 `Martin(100, 1000, -10, 20000)` 又是另一类图案——说明==微小参数改动就换吸引子形状==，这正是本题要写的“得到什么图形”。
