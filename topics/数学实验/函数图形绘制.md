# 函数图形绘制（plot/fplot）

## 为什么需要函数绘图

数学实验的第一步往往是"先看图，再分析"。面对 $x^5 - \frac{m}{200}x - 0.1 = 0$ 这样的高次方程，解析求解困难，但画出函数图像后，实根的个数与大致位置立刻可见。MATLAB 提供两类核心绘图工具：`plot` 处理**离散采样数据**，`fplot` 处理**连续函数句柄**。

## plot：先采样，再连线

`plot` 的本质是"描点连线"：给定一组离散的 $x$ 坐标，计算对应的 $y$ 值，再用线段顺次连接。

```matlab
x = -1.7:0.02:1.7;                    % 步长 0.02 采样
y = x.^5 - 1001/200*x - 0.1;          % 注意点运算 .^ 和 .*
plot(x, y); grid on;                  % grid on 显示网格便于读数
```

> [!IMPORTANT]
> **plot 的关键是"点运算"**：`x.^5` 与 `1001/200*x` 必须带 `.`，否则 MATLAB 会尝试矩阵幂/矩阵乘而报错或给出错误结果。

## fplot：直接画函数

当函数用 M 文件定义时，`fplot` 可直接接受**函数句柄**，无需手动指定采样点，MATLAB 会自动在关键区间加密采样。

以分段函数为例：

```matlab
% 函数文件 f.m
function y = f(x)
    if 0 <= x && x <= 1/2
        y = 2.0 * x;
    else
        y = 2.0 * (1 - x);
    end
end

% 主程序
fplot(@f, [0, 1])                     % @f 是函数句柄，[0,1] 是区间
```

> [!WARNING]
> **fplot 调用 M 文件函数时，M 文件中的逻辑判断（如 `if`）必须能处理标量输入**。若写成 `x >= 0 & x <= 1/2`（逻辑与），而 `x` 为向量时会报错；此处因 `fplot` 逐点计算，用 `&&` 即可。

## plot 与 fplot 的区别

| 特性 | `plot` | `fplot` |
|------|--------|---------|
| **输入** | 离散向量 `x, y` | 函数句柄 `@f` 或字符串表达式 |
| **采样** | 手动指定（步长影响精度） | 自动自适应加密 |
| **适用场景** | 实验数据、显式计算结果 | 已知函数表达式、快速草图 |
| **多图叠加** | 多次 `plot` + `hold on` | 同一坐标系多次调用或 `fplot(vector)` |

## 常见坑与技巧

> [!CAUTION]
> **向量运算必须带 `.`**：`x.^2` 而非 `x^2`，`2.*x` 而非 `2*x`（标量乘向量可省略点，但习惯统一加点更安全）。

> [!TIP]
> **正态分布曲线族**：画 $\mu = 0, -1, 1$ 三条曲线时，用 `hold on` 叠加，或用 `fplot` 同时传入多个函数句柄，配合 `legend('μ=0','μ=-1','μ=1')` 标注。

> [!NOTE]
> **三维曲面**：`z = mx^2 + y^4$ 需用 `meshgrid` 生成网格，再用 `surf(X,Y,Z)` 绘制（见选择 13），这是 `plot` 的二维扩展。

**验证实例**：对 $f(x)=x^3+kx$，用 `fplot(@(x) x.^3+k.*x, [-3,3])` 分别取 $k=-0.6,0,0.3$，可见 $k<0$ 时出现"减-增-减"三单调区间，$k\ge0$ 时单调递增——图像直观验证了导数判别式 $\Delta=-12k$ 的理论。
