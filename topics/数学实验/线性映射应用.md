# 线性映射与特征值应用

线性映射与特征值的真正威力，在于把「迭代」变成「幂运算」，再把幂运算交给特征值。下面从概念、方法到 MATLAB 实现，串起这节课的核心。

## 什么是线性映射迭代

给定矩阵 $A$ 与初值 $x^{(0)}$，定义序列

$$x^{(n+1)} = A\,x^{(n)}$$

则 $x^{(n)} = A^n x^{(0)}$。天气预报、人口迁移、马尔可夫链都归结为这种「==用一个矩阵反复乘同一个向量==」的模型。为什么需要特征值？直接连乘 $n$ 次要 $O(n)$ 步，而把 $x^{(0)}$ 拆成特征向量的组合后，$A^n$ 就只剩 $n$ 次标量幂。

```mermaid
flowchart LR
    A["初值 x(0)"] --> B["拆成特征向量"]
    B --> C["各分量乘 lambda^n"]
    C --> D["线性组合"]
    D --> E["x(n) 通项"]
```

## 怎么做：对角化求通项

若 $A$ 可对角化，$A = PDP^{-1}$，其中 $D = \mathrm{diag}(\lambda_1,\lambda_2)$，$P = (p_1, p_2)$。把 $x^{(0)} = u\,p_1 + v\,p_2$ 解出 $u,v$，则

$$x^{(n)} = u\lambda_1^n p_1 + v\lambda_2^n p_2$$

对 $A = \begin{pmatrix} 4 & 2 \\ 1 & 3 \end{pmatrix}$，MATLAB 中 `[P,D]=eig(A)` 给出 $\lambda = 5, 2$，对应 $p_1 = (2,1)^T$、$p_2 = (-1,1)^T$。由 $(1,2)^T = u(2,1)^T + v(-1,1)^T$ 解得 $u = 1$，$v = 1$，于是

$$x^{(n)} = 5^n\binom{2}{1} + 2^n\binom{-1}{1} = \binom{2\cdot 5^n - 2^n}{5^n + 2^n}$$

> [!TIP]
> 解 $u,v$ 时不必手算：MATLAB 里 `c = P \ x0` 一步到位，因为 $Pc = x^{(0)}$。

## 与「直接迭代」的区别

| 方法 | 适用 | 代价 | 能否给出通项 |
|---|---|---|---|
| 直接迭代 $x^{(n+1)}=Ax^{(n)}$ | 任意矩阵 | 每步一次矩阵乘 | 否 |
| 特征值法 | 可对角化 | 一次分解 | ==是== |

直接迭代适合用 `for` 循环观察趋势；==只有特征值法能写出 $x^{(n)}$ 的封闭表达式==。

## MATLAB 实现要点

```matlab
A = [4,2;1,3]; x0 = [1;2];
[P,D] = eig(A);          % P：特征向量，D：对角阵
c = P \ x0;              % x0 在特征向量基下的坐标
n = 10;
xn = P * (diag(D).^n) .* c   % 验算
```

幂运算 $A^6$ 用 `A^6` 即可，==不必自己写循环连乘==；验证对角化用 `norm(A - P*D/P)`（应接近 0）。

## 常见的坑

> [!WARNING]
> - `eig(A)` 给出的特征值==顺序与特征向量列==一一对应，$P$ 的第 $j$ 列属于 $D$ 的第 $j$ 个对角元。
> - 特征向量可任意缩放，MATLAB 归一化后与手算的 $(2,1)^T$ 可能差常数倍，比较时先除以第一分量。
> - 遇到复特征值（如考试题里的 $-0.5\pm 1.32i$）不代表算错，$A$ 实矩阵也可有复共轭特征值。

> [!IMPORTANT]
> 在天气等马尔可夫模型中，当 $n\to\infty$ 时 $x^{(n)}$ 趋于==绝对值最大特征值（$\lambda = 1$）对应的特征向量==方向；若把该向量缩放到各分量和为 1，就得到稳定分布 $P^*$，如 $(0.6087, 0.2174, 0.1739)^T$。
