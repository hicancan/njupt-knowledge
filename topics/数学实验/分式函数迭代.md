# 分式函数迭代收敛性与初值关系

---

## 分式线性函数的不动点

### 什么是不动点

对于迭代过程 `x_{n+1} = f(x_n)`，如果一个数 `x*` 满足 `f(x*) = x*`，就称 `x*` 为函数 `f` 的**不动点**。从几何上看，不动点是函数曲线 `y = f(x)` 与直线 `y = x` 的交点。

分式线性函数的一般形式为：
```math
f(x) = \frac{ax + b}{cx + d}
```
其不动点通过求解方程 `x = (ax + b) / (cx + d)` 得到，化简后是一个一元二次方程，通常最多有两个不动点。

> [!TIP]
> 求不动点就是解方程 `f(x) = x`，这是连通迭代终点与函数参数的桥梁。

---

### 为什么需要关注收敛性

迭代序列是否收敛、收敛到哪个值，在数值计算中决定了算法的有效性。我们希望通过设计函数 `f(x)`，让它的不动点恰好是我们想计算的数（如 `√2`、`∛m`），然后从一个初始值出发反复迭代来逼近这个数。

但并非所有不动点都能被迭代序列稳定地趋近——这引出了吸引与排斥的概念。

---

## 收敛性与初值的关系

### 局部收敛的条件

对于一个不动点 `x*`，如果 `|f'(x*)| < 1`，则它是**吸引的**：在 `x*` 附近的初值产生的迭代序列会收敛到它。  
如果 `|f'(x*)| > 1`，则它是**排斥的**：迭代序列会远离它，哪怕初值离它很近。

这就是判断收敛性的核心依据：==迭代在某点收敛的局部条件，由该点导数的绝对值决定。==

> [!IMPORTANT]
> 数值实验中，初值选在吸引不动点附近，迭代就会稳定收敛；选在排斥不动点附近，则会发散或收敛到其他不动点。

### 全局行为与初值敏感性

分式线性函数至多有两个不动点，可能出现**一个吸引、一个排斥**的情况。这时整个实数轴会被某个特殊点分割成两大区域——迭代序列要么落到吸引不动点，要么发散到无穷。这个“分割点”正是排斥不动点或使得分母为零的奇点。

初值一旦跨过这个分界线，迭代的终点就完全不同。这就是**初值敏感性**的体现：两个相差很小的初值，可以收敛到完全不同的结果。

---

## 常见误区与常见坑

> [!WARNING]
> 1. **混淆不动点与近似解**：不动点是理论方程的精确根；迭代终点是数值逐步逼近的近似值。实验时要看序列是否稳定在一个值附近。
> 2. **误以为所有不动点都能收敛**：必须检查导数绝对值！
> 3. **分母为零的坑**：迭代中如果出现分母 `cx_n + d = 0`，会导致计算中断，这个点就是函数的奇点。

## 算对一个例子（来自实验 2.2）

考虑函数
```math
f(x) = \frac{x - 1}{x + m}
```
取 `m=1000`，初值 `x0=3`，进行迭代：

**1. 求不动点**  
解方程 `x = (x - 1) / (x + 1000)` ⟹ 化简得 `x^2 + 1000x = x - 1` ⟹ `x^2 + 999x + 1 = 0`。  
解得 `x1 ≈ -0.001001`，`x2 ≈ -998.999`。

**2. 判断收敛性**  
求导：`f'(x) = (1000 + 1) / (x + 1000)^2`。  
在 `x1 ≈ -0.001` 处，`|f'(x1)| ≈ 0.001 < 1`，是**吸引点**。  
在 `x2 ≈ -999` 处，`|f'(x2)| ≈ 1000 > 1`，是**排斥点**。

**3. 迭代行为模拟**  

```mermaid
flowchart LR
  A["初值 x0=3"] -->|f(x)| B["x1 ≈ -0.0005"]
  B -->|f(x)| C["x2 ≈ -0.001"]
  C -->|f(x)| D["x3 ≈ -0.001001"]
  D -.->|收敛| E["不动点 -0.001001<br>（吸引点）"]
```
初值 3 在吸引不动点的“引力范围”内，因此序列迅速收敛到 `-0.001001`，这就是数值实验显示的结果。

若初值取 `-999` 附近（如 `-999.5`），迭代则会迅速远离该点，因为那里导数的绝对值远大于1。

## 拓展到非线性分式函数

对于 `f(x) = (ax + b) / (cx² + dx + e)`，收敛性与初值的关系更复杂，可能出现多个吸引不动点（多稳态），形成不同的**吸引域**。初值落在哪个吸引域，就收敛到对应的不动点。这时，初值不再仅仅是“靠近”，而是要落在正确的收敛“盆地”中。
