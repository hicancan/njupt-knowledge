# MATLAB基本操作与命令补充

## 符号计算与泰勒展开

MATLAB 中做符号运算是数学实验的起点。与数值计算不同的是，==符号计算得到的是精确的数学表达式，而不是近似的小数==。要使用符号功能，需要用 `syms` 声明符号变量。

泰勒展开能把复杂函数在某个点附近“翻译”成多项式，研究局部行为。MATLAB 提供了 `taylor` 函数完成这个任务。

### 基本用法

```matlab
syms x                    % 声明 x 为符号变量
f = sqrt(1 + x);          % 定义符号表达式
T = taylor(f, 'Order', 5) % 在 x=0 处展开到 4 次幂
```

> [!IMPORTANT]
> `'Order', 5` 指的是截断阶数为 5，意味着展开式中最高次幂是 4。这是新手最容易记错的地方——想得到 $x^4$ 项，就要设 `Order` 为 `5`。

运行结果是：
$$ T = 1 + \frac{1}{2}x - \frac{1}{8}x^2 + \frac{1}{16}x^3 - \frac{5}{128}x^4 $$

### 为什么用符号计算而不用数值近似？

试想 $\sqrt{1+x}$ 在 $x=0.01$ 附近，直接用 `sqrt(1.01)` 只能得到一个数。而泰勒展开给的是一个多项式，能看清函数变化的“结构”：一阶项占主导，二阶项做微小修正。做误差分析、灵敏度讨论时，这个结构比一个数值重要得多。

## 分段函数的定义与画图

有些函数不能用一个公式写下来，比如三角波。MATLAB 需要用 **函数文件** 把逻辑描述清楚，再用 `fplot` 画出。

### 为什么需要函数文件？

命令窗口只能写一行指令，分段逻辑（`if...else`）必须写在独立的 `.m` 文件里。

`f.m` 的内容：
```matlab
function y = f(x)
    if 0 <= x && x <= 1/2
        y = 2.0 * x;
    else
        y = 2.0 * (1 - x);
    end
end
```

主程序调用：
```matlab
fplot(@f, [0, 1])         % @f 是函数句柄，把函数“指给”fplot
```

> [!WARNING]
> 函数文件保存为 `f.m` 后，必须放在当前工作目录下，否则 MATLAB 找不到。`fplot` 的第一个参数要用 `@f`，而不是 `f`——少了 `@` 会报错。

## 三维空间曲线

画空间曲线用 `plot3`，用法和二维的 `plot` 几乎一样，只是多了一维坐标。

```matlab
t = -10:0.01:10;          % 参数范围
x1 = cos(t);
y1 = sin(t);
z1 = t;
plot3(x1, y1, z1, 'k')   % 'k' 表示黑色
hold on                   % 保持图像，叠加下一条曲线

x2 = 2*cos(t);
y2 = 2*sin(t);
z2 = t;
plot3(x2, y2, z2, 'r')   % 'r' 表示红色
hold off
```

这段代码画出了两条螺旋线：黑色半径为 1，红色半径为 2。`hold on` 让两条曲线出现在同一个坐标系里，`hold off` 解除叠加状态。

## 矩阵运算的易错点

MATLAB 的矩阵运算符分为“按线性代数算”和“逐元素算”两类，混淆了结果完全不对。

| 运算 | 数学含义 | MATLAB 写法 |
| :--- | :--- | :--- |
| 矩阵乘法 | 行乘以列 | `A * B` |
| 逐元素相乘 | 对应位置相乘 | `A .* B` |
| 矩阵的逆乘 | $AB^{-1}$ | `A * inv(B)` 或 `A / B` |
| 矩阵乘方 | $A^2 = A \times A$ | `A^2` |
| 转置 | $A^T$ | `A'` |

> [!CAUTION]
> `A .* B` 和 `A * B` 只差一个点，结果维度可能一样，但数值完全不同。不检查是否点乘是考试最大的丢分点。

以题目中 $A = \begin{pmatrix} 4 & -2 & 2 \\ -3 & 0 & 5 \\ 1 & 5005 & 3 \end{pmatrix}$，$B = \begin{pmatrix} 1 & 3 & 4 \\ -2 & 0 & -3 \\ 2 & -1 & 1 \end{pmatrix}$ 为例：

- `A * B` 的 (1,1) 位置是 $4\times1 + (-2)\times(-2) + 2\times2 = 12$。
- `A .* B` 的 (1,1) 位置是 $4 \times 1 = 4$，完全是两回事。

行列式 `det(A)` 在本题中结果是 $-130158$。只要矩阵输入正确，一个命令即可得出。
