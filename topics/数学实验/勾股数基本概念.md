# 勾股数定义与基本性质

> [!IMPORTANT]
> 满足 $a^2 + b^2 = c^2$ 的==正整数组== $(a, b, c)$ 称为**勾股数**（Pythagorean triple）。

## 它是什么与为什么需要

提到直角三角形，你最先想到哪组边长？大概率是 $3, 4, 5$。但除了这组，还有多少？它们有没有规律可循？

在《数学实验B》中，探究勾股数不仅是重温几何定理，更是为了练习用编程手段解决数论问题：通过构造算法批量生成、筛选并验证满足特定丢番图方程的整数解。

## 基本性质与怎么做

并非所有勾股数都是“新”的。例如 $(6, 8, 10)$ 只是 $(3, 4, 5)$ 各乘 $2$。因此我们需要区分两类：

| 类型 | 定义 | 示例 |
| :--- | :--- | :--- |
| **本原勾股数** | $\gcd(a,b,c)=1$ | $(3,4,5),\ (5,12,13)$ |
| **派生勾股数** | 本原组同乘正整数 $k$ | $(6,8,10),\ (9,12,15)$ |

> [!NOTE]
> 对本原勾股数 $(a,b,c)$，必有 $\gcd(a,b)=\gcd(b,c)=\gcd(a,c)=1$。三者两两互素。

怎么系统地造出所有本原勾股数？靠枚举太慢，可以用参数化公式。取正整数 $m > n > 0$，令：

$$
a = m^2 - n^2,\quad b = 2mn,\quad c = m^2 + n^2
$$

只要 $m, n$ 满足两个附加条件，生成的就是本原勾股数：
1. ==$\gcd(m, n) = 1$==（互素）
2. $m, n$ 一奇一偶

> [!TIP]
> 记忆口诀：**大减小平方差，二倍积作直边，平方和当斜边；互素且奇偶异，本原才出现。**

## 一个算对了的例子

**任务**：取 $m=3, n=2$，求对应的勾股数并判断是否本原。

**步骤**：
1. 检查条件：$\gcd(3,2)=1$，且一奇一偶，满足。
2. 代入公式：
   $$a = 3^2 - 2^2 = 5$$
   $$b = 2 \times 3 \times 2 = 12$$
   $$c = 3^2 + 2^2 = 13$$
3. 验证：$5^2 + 12^2 = 25 + 144 = 169 = 13^2$。成立。
4. 结论：$(5, 12, 13)$ 是一组本原勾股数。

## 相近概念的区别

- **勾股数 vs 实数解**：方程 $x^2+y^2=z^2$ 有无穷多实数解，但勾股数特指**正整数解**。
- **本原 vs 派生**：实验中若要求“找出所有本质不同的勾股数”，只需生成本原组，再按需乘倍数即可，避免重复计算。

## 常见的坑

> [!WARNING]
> 忘记“一奇一偶”条件！若取 $m=3, n=1$（同为奇数），算得 $(8, 6, 10)$，虽满足方程，但 $\gcd(8,6,10)=2 \neq 1$，得到的是派生而非本原勾股数。

> [!CAUTION]
> 在 MATLAB/Python 编程实现时，循环边界极易写错。注意条件是 $m > n > 0$，切勿让 $n$ 从 $0$ 开始（会导致 $a=c$，退化为非三角形），也勿漏掉上限导致死循环或超时。
