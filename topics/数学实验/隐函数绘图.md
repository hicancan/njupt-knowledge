# 隐函数绘图与网格数据可视化

---
requires: [MATLAB基础/矩阵运算与点运算]
---

如果方程 $F(x,y)=0$ 无法解出 $y=f(x)$，怎么画出它的曲线？如果想看 $z = f(x,y)$ 在三维空间里的起伏，只给一堆离散的 $(x,y,z)$ 点够吗？这两个问题分别对应本节的两项核心技能。

## 隐函数绘图

`ezplot` 能直接根据方程字符串绘制隐函数图形，无需手动求解或离散化。

**基本语法：**

```matlab
ezplot('F(x,y)=0')                          % 默认范围 [-2π, 2π]
ezplot('F(x,y)=0', [xmin,xmax,ymin,ymax])   % 指定范围
```

> [!IMPORTANT]
> 传入的表达式必须是==字符串==，且等式需移项写成 `...=0` 的形式。

以真题为例，设学号后三位 $m=331$，画 $\sin\!\left(x^{2}+\frac{m}{1000}y^{2}\right)=\cos(xy)$：

```matlab
% 将 m=331 代入，移项使右边为 0
ezplot('sin(x^2+331/1000*y^2)-cos(x*y)=0', [-20,20,-20,20])
```

> [!CAUTION]
> 真题给出的参考代码中第二项误写为 `331/1000*x^2`（把 $y^2$ 错写成 $x^2$），考试时务必仔细核对题目原式！

## 网格数据可视化

要画三维曲面，必须先有“网格”。`meshgrid` 负责把一维向量变成二维网格矩阵，再用 `mesh` 或 `surf` 渲染。

```mermaid
flowchart LR
A["定义x,y向量"] --> B["meshgrid生成网格"]
B --> C["计算Z矩阵"]
C --> D["mesh/surf绘图"]
```

**标准流程（结合真题解答）：**

```matlab
x = -5 : 0.1 : 5;
y = -5 : 0.1 : 5;
[X, Y] = meshgrid(x, y);       % 生成网格坐标矩阵
Z = 331 * X.^2 + Y.^4;         % 逐元素计算高度
mesh(X, Y, Z);                 % 绘制网格曲面
```

> [!WARNING]
> 计算 `Z` 时，矩阵乘法必须用==点运算==（`.^`、`.*`），否则 MATLAB 会按线性代数矩阵乘法报错。

## 易混概念辨析

| 对比项 | `ezplot` | `meshgrid` + `mesh`/`surf` |
| :--- | :--- | :--- |
| **用途** | 二维隐函数 / 显函数 | 三维网格曲面 |
| **输入** | 方程字符串 | 数值矩阵 `X, Y, Z` |
| **是否需网格** | 否（内部自动处理） | ==是（必须先生成）== |
| **输出维度** | 二维平面曲线 | 三维空间曲面 |

> [!NOTE]
> `mesh` 画的是线框图（能看到背面），`surf` 画的是着色表面图（不透明）。两者都需要 `meshgrid` 提供网格骨架。

> [!TIP]
> 记忆口诀：**隐函字符串，三维先铺网；算Z用点乘，ez不用管。**
