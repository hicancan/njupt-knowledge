# CPI（每条指令平均时钟周期数）

> [!IMPORTANT]
> CPI（Cycles Per Instruction）即==每条指令平均时钟周期数==，表示 CPU 执行一条指令平均需要消耗多少个时钟周期。它是衡量处理器效率的核心指标：CPI 越小，说明执行单条指令越快。

## 它是什么与为什么需要

不同指令的复杂程度不同，所需的时钟周期数也不同。例如加法可能只需 1 个周期，而访存乘法可能需要多个周期。如果只看主频，无法反映程序真实的运行快慢。因此我们需要一个“加权平均值”来描述整段程序的执行代价，这就是有效 CPI。

有了 CPI，就能把**硬件参数**（时钟频率）和**软件特征**（指令混合比例）联系起来，进而求出 MIPS 速率和程序执行时间 $t_{CPU}$。

## 怎么做：核心公式链

先理清三个时间尺度的层级关系：

```mermaid
flowchart LR
    A["时钟周期"] -->|"×4"| B["机器周期"]
    B -->|"×k"| C["指令周期"]
```

> [!NOTE]
> **时钟周期**是主频的倒数；**机器周期**通常包含若干个时钟周期；**指令周期**包含若干个机器周期。CPI 关注的是最底层的“时钟周期”总数。

计算时遵循以下公式链：

$$ \mathrm{CPI} = \frac{\sum (\text{第 } i \text{ 类指令条数} \times \text{该类指令的时钟周期数})}{\text{总指令条数}} $$

$$ t_{CPU} = \text{总指令数} \times \mathrm{CPI} \times \text{时钟周期} $$

$$ \mathrm{MIPS} = \frac{\text{主频 (MHz)}}{\mathrm{CPI}} $$

下面用课件中的例子算一次有效 CPI：

| 指令类型 | 执行条数 | 每条所需时钟周期 |
| :---: | :---: | :---: |
| 类型 A | 45000 | 1 |
| 类型 B | 32000 | 2 |
| 类型 C | 15000 | 2 |
| 类型 D | 8000 | 2 |

代入公式：

$$ \mathrm{CPI} = \frac{45000 \times 1 + 32000 \times 2 + 15000 \times 2 + 8000 \times 2}{45000 + 32000 + 15000 + 8000} = \frac{155000}{100000} = 1.55 $$

## 易混概念辨析

考试中常将 CPI、MIPS、FLOPS 放在一起考查，它们的侧重点完全不同：

| 指标 | 含义 | 侧重点 |
| :--- | :--- | :--- |
| CPI | 每条指令平均时钟周期数 | ==体系结构效率== |
| MIPS | 每秒百万条指令数 | 标量处理速度 |
| FLOPS | 每秒浮点运算次数 | 科学计算性能 |
| 吞吐量 | 单位时间内完成的任务量 | 系统整体处理能力 |

> [!WARNING]
> MIPS 高不代表程序跑得快！如果编译器生成了大量简单但冗余的指令，MIPS 会升高，但 $t_{CPU}$ 反而变长。因此评估性能必须看 $t_{CPU}$。

## 综合题实战拆解

思考一个问题：已知主频和 MIPS，怎么反推 CPI？再结合机器周期，怎么求指令周期的构成？以真题综合 1 为例：

**已知**：主频 $f=10\text{ MHz}$，1 个机器周期含 4 个时钟周期，平均指令执行速度为 1 MIPS。

1. **求平均指令周期及所含机器周期数**
   - 时钟周期 $T_c = 1/f = 0.1\mu\text{s}$。
   - 机器周期 $T_m = 4 \times T_c = 0.4\mu\text{s}$。
   - 1 MIPS 意味着每秒执行 $10^6$ 条指令，故平均指令周期 $T_i = 1 / 10^6 = 1\mu\text{s}$。
   - 每个指令周期含机器周期数 $k = T_i / T_m = 1 / 0.4 = 2.5$ 个。

2. **换用 $T_c' = 0.4\mu\text{s}$ 的芯片，求新 MIPS**
   - 新机器周期 $T_m' = 4 \times 0.4 = 1.6\mu\text{s}$。
   - 假设指令集不变，$k$ 仍为 2.5，则新指令周期 $T_i' = 2.5 \times 1.6 = 4\mu\text{s}$。
   - 新速度 $V' = 1 / 4\mu\text{s} = 0.25\text{ MIPS}$。

3. **要达到 80万次/秒（0.8 MIPS），求所需主频**
   - 目标 $T_i'' = 1 / 0.8\text{ MIPS} = 1.25\mu\text{s}$。
   - 目标 $T_m'' = 1.25 / 2.5 = 0.5\mu\text{s}$。
   - 目标 $T_c'' = 0.5 / 4 = 0.125\mu\text{s}$。
   - 所需主频 $f'' = 1 / 0.125\mu\text{s} = 8\text{ MHz}$。

> [!CAUTION]
> 线下考试不允许使用计算器！遇到带小数的除法（如 $1/0.4$、$1.25/2.5$），务必先转化为分数 $\frac{10}{4}$、$\frac{5/4}{5/2}$ 进行约分，避免手算出错。
