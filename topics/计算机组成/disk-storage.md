# 磁盘存储设备（磁性材料物理特性、磁表面存储器读写原理、盘片分类）

## 磁盘存储设备

磁盘是计算机最常用的外存储器。先想一个问题：内存断电就丢数据，那程序、文档、操作系统本身要长期保存，靠什么？答案就是磁盘这类**磁表面存储器**——它用电信号改变磁性材料的磁化状态来记录信息，断电后磁化状态依然保留。

### 磁性材料与读写原理

磁表面存储器的核心是一层很薄的**磁性材料**，涂敷或镀在非磁性基体（盘片）上。读写靠**磁头**完成。

写入时，磁头线圈通入不同方向的电流，产生不同方向的磁场，使磁层上对应微小区域的**剩磁方向**发生翻转或保持。两种剩磁方向就代表二进制的 **0 和 1**。

读出时，磁头相对磁层运动，磁层上剩磁方向的变化会在磁头线圈中感应出电动势，经放大、整形后还原成原来的数据。

> [!IMPORTANT]
> 磁盘驱动器向盘片磁层记录数据时采用==串行==方式写入。磁头相对于盘片的读写本质上是磁层上一个点一个点顺序经过磁头，所以数据是一位一位串行写入的，不是并行。

### 盘片分类

按基体材料（盘片）的不同，磁盘分为**软磁盘**和**硬磁盘**两大类。

| | 软磁盘（软盘） | 硬磁盘（硬盘） |
|---|---|---|
| 基体 | 聚酯薄膜，柔软 | 铝合金/玻璃，刚性 |
| 转速 | 低（如 300 rpm） | 高（如 5400/7200 rpm） |
| 磁头 | 接触式 | 浮动式（气垫） |
| 容量 | 小，固定 | 大，可很大 |
| 能否更换 | 可更换 | 一般密封固定 |

3.5 英寸软盘采用**双面高密度**记录方式，标准容量为 ==1.44 MB==，每个扇区存储的固定数据是 ==512 B==。软、硬盘的==存储原理==和==记录方式==基本相同，但在==结构==和==性能==上差别很大。

一个算对了的例子：一张 3.5 英寸软盘容量 $1.44\text{ MB}$，每个扇区固定 $512\text{ B}$，则总扇区数为：

$$
\frac{1.44 \times 1024 \times 1024}{512} = 2880
$$

> [!WARNING]
> 单位坑：$1.44\text{ MB}$ 中的 MB 按 $1\text{ MB}=1024\text{ KB}$、$1\text{ KB}=1024\text{ B}$ 计算。考试遇到容量题，默认用二进制换算；题中若给出“扇区数 × 512 B”反推容量，也用二进制。

> [!TIP]
> 记忆要点：软盘“双面高密度、1.44 MB、每扇区 512 B”；磁盘写入是“串行”；软硬磁盘“原理相同、结构性能不同”。
