# 角动量定理与角动量守恒定律

## 从“力推不动门”说起

为什么用同样大小的力推门，推在门边比推在门轴附近更容易把门推开？为什么花样滑冰运动员把手臂收拢，转速会突然变快？这两个现象背后，都藏着同一个物理量——**角动量** $\vec{L}$。

对质点，角动量定义为

$$\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$$

它描述的是“动量绕某点旋转的趋势”。对刚体绕定轴转动，所有质点的角动量沿轴方向叠加，得到

$$L = J\omega$$

其中 $J$ 是转动惯量，$\omega$ 是角速度。这正是“平动中 $p=mv$”的转动版类比。

## 角动量定理：力矩的时间累积

回忆质点的动量定理：合力的冲量等于动量增量。角动量也有完全平行的结论。由牛顿第二定律可以推出

$$\vec{M} = \frac{d\vec{L}}{dt} \quad \text{——角动量定理（微分形式）}$$

其中 $\vec{M} = \vec{r} \times \vec{F}$ 是合外力矩。两边对时间积分，得到**积分形式**：

$$\int_{t_0}^{t} \vec{M}\,dt = \vec{L} - \vec{L}_0$$

对刚体定轴转动，标量形式为

$$\int_{t_0}^{t} M\,dt = J\omega - J\omega_0$$

> [!IMPORTANT]
> 角动量定理说的是：**外力矩的时间累积（冲量矩）等于角动量的增量**。它与动量定理 $\int F\,dt = p - p_0$ 地位完全对等，只是把“力”换成了“力矩”，“动量”换成了“角动量”。

```mermaid
flowchart LR
    A["外力矩 M"] --> B["时间累积<br/>冲量矩 ∫Mdt"]
    B --> C["角动量改变<br/>ΔL = L - L₀"]
    C --> D["转动状态变化<br/>ω 改变"]
```

## 角动量守恒定律

如果合外力矩 $\vec{M} \equiv 0$，那么

$$\vec{L}_2 = \vec{L}_1 \quad \text{或} \quad J_1\omega_1 = J_2\omega_2$$

这就是**角动量守恒定律**。回到开头的问题：滑冰运动员收臂时，$J$ 减小，为保持 $L$ 不变，$\omega$ 必然增大。

> [!TIP]
> 判断角动量是否守恒，关键看**合外力矩是否为零**，而不是看外力是否为零。例如卫星绕地球做圆周运动，引力本身很大，但引力始终指向地心，对地心的力矩为零，所以角动量守恒。

## 与相近概念的区别

| 对比项 | 动量定理 | 角动量定理 |
|--------|----------|------------|
| 研究对象 | 质点/系统平动 | 质点/刚体转动 |
| 累积量 | 力的时间累积（冲量） | 力矩的时间累积（冲量矩） |
| 状态量 | 动量 $p=mv$ | 角动量 $L=J\omega$ |
| 守恒条件 | 合外力为零 | 合外力矩为零 |
| 典型应用 | 碰撞、火箭推进 | 天体运动、刚体变速转动 |

> [!WARNING]
> 常见错误：把 $L=J\omega$ 当成角动量的唯一定义。注意 $L=J\omega$ 只适用于**刚体定轴转动**；对单个质点或一般运动，必须用叉积定义 $\vec{L}=\vec{r}\times\vec{p}$，且 $\vec{L}$ 的方向由右手定则确定，不一定沿转轴。

## 典型例题：细杆在摩擦力作用下停转

在摩擦系数为 $\mu$ 的桌面上，有一质量为 $m$、长度为 $l$ 的细杆，以初始角速度 $\omega_0$ 绕垂直于杆的质心轴转动。求细杆经过多长时间停止转动。

**解：** 杆上距质心 $x$ 处取微元 $dm = \frac{m}{l}dx$，所受摩擦力为 $\mu g\,dm$，方向与运动方向相反。该微元对质心轴的力矩大小为

$$dM = \mu g \cdot x \cdot dm = \frac{\mu mg}{l}x\,dx$$

两侧对称，总力矩为

$$M = 2\int_0^{l/2} \frac{\mu mg}{l}x\,dx = \frac{\mu mgl}{4}$$

方向与 $\omega_0$ 相反。细杆绕质心轴的转动惯量 $J = \frac{1}{12}ml^2$。由角动量定理积分形式，取 $t_0=0$，末态 $\omega=0$：

$$\int_0^t (-M)\,dt = J\omega - J\omega_0 \Rightarrow -Mt = -J\omega_0$$

代入 $M$ 与 $J$：

$$t = \frac{J\omega_0}{M} = \frac{\frac{1}{12}ml^2 \cdot \omega_0}{\frac{1}{4}\mu mgl} = \frac{l\omega_0}{3\mu g}$$

> [!CAUTION]
> 本题若误用 $M=\mu mg \cdot \frac{l}{2}$（把摩擦力当成集中作用在杆端），会得到错误结果。分布力必须先取微元积分求总力矩，这是刚体问题的常见陷阱。
