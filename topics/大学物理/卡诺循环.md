# 卡诺循环的效率与致冷系数

## 它是什么：理想热机的极限

卡诺循环是由两个**等温过程**和两个**绝热过程**组成的理想可逆循环。它是热力学中效率最高的循环模型，定义了热机将热能转化为功的理论上限，以及制冷机消耗功转移热量的理论下限。

```mermaid

    B --> C(绝热膨胀)

    D --> E(等温压缩)
    E --> F(绝热压缩)
```

> [!IMPORTANT]
> 核心公式（温度必须用**热力学温标 K**）：
> - 卡诺热机效率：$\eta_c = 1 - \frac{T_2}{T_1}$
> - 卡诺致冷系数：$w_c = \frac{T_2}{T_1 - T_2}$
> 其中 $T_1$ 为高温热源温度，$T_2$ 为低温热源温度。

## 为什么需要：衡量实际设备的标尺

实际热机受摩擦、非准静态过程等影响，效率永远低于卡诺效率。卡诺循环提供了==理论最大值==，用于判断设计方案是否违背热力学第二定律。若某设计声称的效率超过同温限下的卡诺效率，则该设计不可行。

## 怎么做：解题关键步骤

1.  **单位换算**：看到摄氏度 ($^\circ \mathrm{C}$) 必须立即转换为开尔文 ($\mathrm{K}$)。公式：$T(\mathrm{K}) = t(^\circ \mathrm{C}) + 273.15$。
2.  **识别角色**：
    *   **热机**：关注效率 $\eta = \frac{W}{Q_1}$。
    *   **制冷机**：关注致冷系数 $w = \frac{Q_2}{W}$。
3.  **关联变量**：利用 $\eta_c$ 或 $w_c$ 建立 $Q_1, Q_2, W$ 之间的关系。

> [!TIP]
> p-V 图中，卡诺循环两条绝热线下的面积代表绝热过程做的功。由于绝热过程内能变化仅取决于温差，且始末温差相同，故==两条绝热线下的面积相等==（即 $\Delta U$ 大小相等）。

## 常见陷阱与辨析

| 概念 | 易错点 | 正确理解 |
| :--- | :--- | :--- |
| **温度单位** | 直接代入 $^\circ \mathrm{C}$ 计算 | 必须使用绝对温度 $\mathrm{K}$ |
| **效率比较** | 认为循环包围面积大效率就高 | 效率只取决于 $T_1, T_2$，与工质、面积无关 |
| **可行性判断** | 仅检查能量守恒 ($Q_1=Q_2+W$) | 还需检查是否满足 $\eta \le \eta_c$ |

> [!WARNING]
> 卡诺效率 $\eta_c$ 仅由热源温度决定。若两个卡诺循环工作在相同的 $T_1$ 和 $T_2$ 之间，无论其 p-V 图形状如何（只要由两等温两绝热构成），其效率必然相等。

## 算例演示

**题目**：一台卡诺热机工作于 $327^{\circ} \mathrm{C}$ 和 $27^{\circ} \mathrm{C}$ 之间，每循环吸热 $2000 \mathrm{~J}$，求对外做功。

**解析**：
1.  **换算温度**：
    $T_1 = 327 + 273 = 600 \, \mathrm{K}$
    $T_2 = 27 + 273 = 300 \, \mathrm{K}$
2.  **计算效率**：
    $\eta_c = 1 - \frac{T_2}{T_1} = 1 - \frac{300}{600} = 0.5$
3.  **计算做功**：
    由 $\eta = \frac{W}{Q_1}$ 得：
    $W = \eta Q_1 = 0.5 \times 2000 \, \mathrm{J} = 1000 \, \mathrm{J}$

故答案为 **B**。此例展示了标准解题流程：先换单位，再求效率，最后求功。
