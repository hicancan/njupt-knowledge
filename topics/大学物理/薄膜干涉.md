# 等倾干涉与等厚干涉（劈尖、牛顿环）

## 薄膜干涉的核心：光程差与半波损失

为什么同样的薄膜，有时反射加强（增反），有时反射减弱（增透）？关键在于两束反射光相遇时的==总光程差==。计算时不能只看几何路程，必须回答一个前置问题：反射时是否存在**半波损失**？

> [!IMPORTANT]
> 当光从波疏媒质射向波密媒质（$n_小 \to n_大$）反射时，相位突变 $\pi$，相当于附加光程 $\lambda/2$。若上下表面反射均有或均无半波损失，则附加项抵消；若仅有一次，则总光程差需加 $\lambda/2$。

对于折射率为 $n_2$、厚度为 $e$ 的薄膜，置于 $n_1$ 和 $n_3$ 介质之间，垂直入射时总光程差为：

$$
\delta = 2n_2 e + \delta'
$$

其中 $\delta'$ 由折射率关系决定：当 $n_1 < n_2 > n_3$ 或 $n_1 > n_2 < n_3$ 时，$\delta' = \lambda/2$；否则 $\delta' = 0$。明纹条件 $\delta = k\lambda$，暗纹条件 $\delta = (2k+1)\lambda/2$。

## 等厚干涉：劈尖与牛顿环

当薄膜厚度 $e$ 不均匀时，同一级条纹对应相同厚度，称为==等厚干涉==。

```mermaid
flowchart LR
    A["平行光垂直入射"] --> B{"膜厚是否均匀?"}
    B -- 是 --> C["等倾干涉"]
    B -- 否 --> D["等厚干涉"]
    D --> E["劈尖/牛顿环"]
    E --> F["条纹定域于膜面"]
```

> [!TIP]
> 劈尖相邻明（暗）纹对应的==厚度差恒为== $\Delta d = \dfrac{\lambda}{2n}$，面间距 $l = \dfrac{\lambda}{2n\theta}$。条纹越密，说明劈尖角 $\theta$ 越大或介质折射率 $n$ 越大。

牛顿环本质是空气劈尖的变体，中心接触点 $e=0$。若存在半波损失，中心为暗斑；将装置从空气移入水中，因 $n$ 增大导致 $\Delta d$ 减小，==条纹变密==但中心明暗性质不变。

## 易错辨析与典型计算

| 对比维度 | 等倾干涉 | 等厚干涉（劈尖/牛顿环） |
| :--- | :--- | :--- |
| 膜厚特征 | 均匀 | 不均匀 |
| 条纹形状 | 同心圆环 | 直条纹 / 同心圆环 |
| 级次分布 | 中心级次高 | 薄处级次低 |
| 光源要求 | 扩展光源 | 平行光垂直入射 |

> [!WARNING]
> 求“最小厚度”时务必注意 $k$ 的取值！增透膜（反射相消）满足 $2ne + \lambda/2 = (2k+1)\lambda/2$，化简得 $2ne = k\lambda$。当 $k=0$ 时 $e=0$ 无物理意义，故==最小非零厚度取 $k=1$==，即 $e_{min} = \lambda/(4n)$。切勿盲目代入 $k=0$。

以填空题为例：玻璃（$n=1.60$）上镀 $MgF_2$（$n=1.38$）增透膜，$\lambda=500\ \text{nm}$。因 $n_{空气}<n_{MgF_2}<n_{玻璃}$，仅上表面有半波损失，反射相消条件为 $2ne = (2k+1)\lambda/2$。取 $k=0$ 得最小厚度：

$$
e_{min} = \frac{\lambda}{4n} = \frac{500}{4 \times 1.38} \approx 90.6\ \text{nm}
$$

此题验证了==增透膜最小厚度公式== $e=\lambda/(4n)$ 的适用前提：单层膜且仅一次半波损失。若折射率关系改变，公式需重新推导，切忌死记硬背。
