# 相对论中的质量与动量

> [!IMPORTANT]
> 在经典力学中，动量 $\boldsymbol{P} = m\boldsymbol{v}$ 里的质量 $m$ 是常数。但如果物体速度接近光速 $c$，动量还能这样算吗？

## 它是什么与为什么需要

狭义相对论要求物理定律在所有惯性系中形式相同（相对性原理），且光速不变。如果继续沿用经典动量 $p = m_0 v$，在洛伦兹变换下碰撞过程的动量将不再守恒！为了让动量守恒定律在高速下依然成立，必须重新定义动量和质量。

由此引入：
- **相对论质量**：$m = \frac{m_0}{\sqrt{1 - v^2/c^2}}$，其中 $m_0$ 为静止质量。
- **相对论动量**：$p = mv = \frac{m_0 v}{\sqrt{1 - v^2/c^2}}$。

```mermaid
flowchart LR
A["静止质量 m0"] -->|"乘以洛伦兹因子"| B["相对论质量 m"]
B -->|"乘以速度 v"| C["相对论动量 p"]
C -->|"代入"| D["能量动量关系"]
```

> [!NOTE]
> 相对论动量与能量的核心关系式为：$E^2 = E_0^2 + p^2c^2$，它将总能量 $E=mc^2$、静止能量 $E_0=m_0c^2$ 和动量统一在一个方程中。

## 怎么做与相近概念的区别

解题时，==核心步骤是先通过速度求出洛伦兹因子 $\gamma = \frac{1}{\sqrt{1-v^2/c^2}}$，再计算质量或动量==。

| 对比项 | 经典力学 | 狭义相对论 |
| :--- | :--- | :--- |
| **质量** | 恒定不变 $m_0$ | 随速度增大 $m = \gamma m_0$ |
| **动量** | $p = m_0 v$ | $p = \gamma m_0 v$ |
| **动能** | $E_K = \frac{1}{2}m_0 v^2$ | $E_K = mc^2 - m_0c^2$ |
| **适用范围** | $v \ll c$ | 任意 $v < c$ |

> [!WARNING]
> 千万不要把相对论动能写成 $\frac{1}{2}mv^2$ 或 $\frac{1}{2}\gamma m_0 v^2$！相对论动能只能由总能量减去静止能量得到：$E_K = mc^2 - m_0c^2$。

## 常见的坑

> [!CAUTION]
> 1. **混淆符号**：题目给的“电子质量”通常指静止质量 $m_0$。若未说明，需根据语境判断是 $m_0$ 还是 $m$。
> 2. **单位混用**：粒子物理常以 $\text{MeV}$ 为单位给出能量，此时可直接利用 $E = mc^2$ 算出 $m$（单位为 $\text{MeV}/c^2$），无需换算成千克。
> 3. **忘记开根号**：求速度时从 $\gamma$ 反推 $v$，公式为 $v = c\sqrt{1 - 1/\gamma^2}$，极易漏掉平方或根号。

## 一个算对了的例子

**题目**：已知粒子 A 以 $v_A = 2.9 \times 10^8 \text{ m/s}$ 运动，粒子 B 以 $v_B = 2.7 \times 10^8 \text{ m/s}$ 运动，两者静止质量均为 $m_0$，取 $c = 3.0 \times 10^8 \text{ m/s}$。求两者的相对论质量。

**解析**：

直接套用相对论质量公式 $m = \frac{m_0}{\sqrt{1 - v^2/c^2}}$。注意这里可以先算比值 $v/c$ 以简化运算。

对于粒子 A：
$$
m_A = \frac{m_0}{\sqrt{1 - \frac{v_A^2}{c^2}}} = \frac{m_0}{\sqrt{1 - \frac{2.9^2}{3.0^2}}} = \frac{m_0}{\sqrt{1 - 0.934}} \approx 3.9 m_0
$$

对于粒子 B：
$$
m_B = \frac{m_0}{\sqrt{1 - \frac{v_B^2}{c^2}}} = \frac{m_0}{\sqrt{1 - \frac{2.7^2}{3.0^2}}} = \frac{m_0}{\sqrt{1 - 0.81}} = \frac{m_0}{\sqrt{0.19}} \approx 2.3 m_0
$$

> [!TIP]
> 考试时遇到 $v$ 非常接近 $c$ 的情况（如本题的 $2.9/3.0$），分母根号内的值会很小，导致相对论质量急剧增大。这正是“有质量的物体无法达到光速”的数学体现——当 $v \to c$ 时，$m \to \infty$，需要无限大的能量才能继续加速。
