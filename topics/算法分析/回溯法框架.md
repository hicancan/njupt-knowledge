# 回溯法的递归回溯与迭代回溯算法框架

## 递归回溯与迭代回溯

回溯法的本质是：在解空间树中 **深度优先** 搜索，每到一个结点先判断“这条路还有没有希望”，有希望就继续向下走，没希望就立刻回头。这个“判断 + 回头”的动作就是**剪枝**，而剪枝的依据通常来自约束条件或限界函数。

### 递归回溯框架

递归写法最贴近回溯的直观含义——**走到哪算哪，不行就 return**。以课件中的程序 8-1 为原型，其核心结构如下：

```c
void Backtrack(int t)
{
    if (t > n) {
        Output(x);          // 到达叶结点，输出一个可行解
    } else {
        for (int i = 0; i < m; i++) {
            x[t] = i;                    // 尝试第 t 层取第 i 个候选值
            if (Constraint(t) && Bound(t))  // 满足约束且还有希望
                Backtrack(t + 1);         // 进入下一层
        }
    }
}
```

`t` 表示当前搜索深度，`x[t]` 记录第 `t` 步的选择。约束函数 `Constraint` 与限界函数 `Bound` 共同决定是否继续递归。两者的区别在于：**约束函数**判断当前部分解是否满足问题的硬性条件（如皇后不冲突、子集和不超过 M），**限界函数**判断当前部分解是否还有可能扩展出最优解（多用于最优化问题）。

递归回溯的优点是结构清晰、易写易读；缺点是每次进入下一层都产生函数调用开销，且受系统递归深度限制。

### 迭代回溯框架

迭代写法把递归调用改成**显式循环 + 回退**，对应课件中的程序 8-2：

```c
void IterativeBacktrack(void)
{
    int t = 0;
    while (t >= 0) {
        if (t < n) {
            // 尝试为第 t 层找下一个候选值
            while (!NextValue(t) && t >= 0)
                t--;          // 第 t 层所有值都试完，回退
            if (t >= 0) t++;  // 找到候选值，进入下一层
        } else {
            Output(x);        // 到达叶结点，输出可行解
            t--;              // 回退继续找下一个解
        }
    }
}
```

`NextValue(t)` 负责为第 `t` 层取下一个候选值，并在取到时同时完成约束与限界检查。若该层所有候选值均已试过，则返回“失败”，`t` 减 1 回退。

> [!IMPORTANT]
> 递归回溯靠“函数调用栈”保存现场；迭代回溯靠“显式的 `t` 增一 / 减一”实现前进与回退。二者遍历解空间树的**顺序完全相同**，区别仅在实现机制。

### 一个典型应用：求第一个可行解

考题中要求修改 n-皇后程序，在求得第一个可行解后终止。递归版本只需在叶结点处输出后**直接退出整个搜索**，最干净的方式是加一个全局标志：

```c
int found = 0;

void Backtrack(int t)
{
    if (found) return;         // 已找到，直接剪掉所有后续搜索
    if (t > n) {
        Output(x);
        found = 1;
        return;
    }
    for (int i = 0; i < n && !found; i++) {
        x[t] = i;
        if (Place(t))
            Backtrack(t + 1);
    }
}
```

迭代版本则在叶结点输出后 `break` 跳出外层循环，或直接将循环条件改为 `while (t >= 0 && !found)`。

> [!TIP]
> “求全部可行解”和“求第一个可行解”的唯一区别：前者到达叶结点后**回退继续**，后者到达叶结点后**立即终止**。

### 回溯法的时间分析：蒙特卡罗估计

回溯算法的时间取决于状态空间树中**实际生成的结点数**。最坏情况下它可能达到 $O(m^n)$，但剪枝通常能大幅减少实际结点数。若树太大无法精确统计，可用**蒙特卡罗方法**估计：随机沿一条可行路径下走，每到一层统计该结点的儿子数 $m_i$，则估计结点总数为：

$$
1 + m_0 + m_0 m_1 + m_0 m_1 m_2 + \cdots
$$

以考题为例，4-皇后问题中随机路径 $(0,2)$ 的结点数：

$$
1 + 4 + 4\times 2 = 13
$$

路径 $(1,3,0,2)$ 的结点数：

$$
1 + 4 + 4\times 1 + 4\times 1\times 1 + 4\times 1\times 1\times 1 = 17
$$

二者平均得估计结点数 $15$。随机取多条路径求均值，估计更可靠。

> [!WARNING]
> 蒙特卡罗估计假设每个结点被选中的概率均匀。如果实际剪枝极不均匀，一次随机路径可能偏离较大，应取多条路径平均。

### 常见的坑

1. **回退时忘记“恢复现场”** ：候选值改变后，若约束检查需要依赖之前的 `x` 值，回退时必须把 `x[t]` 恢复到“未赋值”状态，否则会“污染”下一次尝试。
2. **约束函数与限界函数混为一谈**：前者判断“合不合法”，后者判断“有没有可能更优”。可行解问题通常只写约束函数。
3. **迭代回溯中 `t` 的边界处理**：回退到 `t = -1` 表示搜索结束，循环终止条件务必写 `t >= 0`。
4. **子集和数问题要求输入有序**：课件中的 `SumOfSub` 依赖递增有序的 `w` 序列做剪枝；数据无序时**得不到全部可行解**，这是考过的计算题易错点。
