# 群的定义、有限群的判定条件及子群的判定定理

## 群是什么：从代数系统到群

先想一个问题：如果给你一个集合配上一个二元运算，你怎么一步步检查它“够不够格”叫群？

在南京邮电大学《离散数学》第五章“代数结构”里，我们从**代数系统** $\langle S, * \rangle$ 出发：若 $*$ 在 $S$ 上封闭，就是广群；再加结合律，是**半群**；半群有幺元 $e$，是**独异点**；独异点中每个元素都有逆元，才升级为==群==。

> [!IMPORTANT]
> 群的定义：$\langle G, *\rangle$ 满足——（1）**封闭性** $\forall a,b\in G, a*b\in G$；（2）**结合律** $(a*b)*c=a*(b*c)$；（3）**有幺元** $e$，$a*e=e*a=a$；（4）**每元有逆元** $a*a^{-1}=a^{-1}*a=e$。

```mermaid
flowchart LR
  A["代数系统"] --> B["封闭"]
  B --> C["半群:结合律"]
  C --> D["独异点:有幺元"]
  D --> E["群:每元可逆"]
```

## 为什么需要子群判定

我们常要在大群里找小块，看它自己是不是也成群。一个一个验四条太慢，于是有：

> [!IMPORTANT]
> 子群判定定理：$H\subseteq G$ 且 $H\neq\varnothing$，则 $H\le G$ 当且仅当 $\forall a,b\in H$，$a*b^{-1}\in H$（一步搞定封闭+逆+幺元）。

## 有限群怎么快速判定

有限半群更简单：

| 条件 | 结论 |
|---|---|
| 有限半群 + 左右消去律都成立 | 它是群 |
| 运算表每行每列都是全体元素的置换 | 它是群 |

> [!WARNING]
> 群中不能有零元（除平凡单元素群外）。若有零元 $z$，会导致 $z=e$ 从而群只剩一个元素，常考判断题==“群中不可能有零元”是对的==。

## 和相近概念的区别

| 概念 | 比群少什么 | 例子 |
|---|---|---|
| 半群 | 无幺元、无逆元 | $\langle \mathbb{N},+\rangle$ |
| 独异点 | 无逆元 | $\langle \mathbb{N},+\rangle$ |
| 交换群 | 多条件：可交换 | $\langle\mathbb{R},+\rangle$ |

## 一步步算对的例子

取讲义题：设 $\langle\mathbb{R}, *\rangle$，$a*b=a+b+1$，证它是群。

1. **封闭**：实数的加仍实数，$a+b+1\in\mathbb{R}$。
2. **结合**：$(a*b)*c=a+b+c+2$，$a*(b*c)=a+b+c+2$，相等。
3. **幺元**：令 $a*e=a$，即 $a+e+1=a$，得 $e=-1\in\mathbb{R}$。
4. **逆元**：令 $a*x=-1$，即 $a+x+1=-1$，得 $x=-2-a\in\mathbb{R}$。

四条齐备，故 $\langle\mathbb{R}, *\rangle$ 是群。

> [!TIP]
> 解题模板：==先封结，再寻幺，后解逆==；自定义运算题把“等于幺元”的等式直接解出 $e$ 与逆元即可。
