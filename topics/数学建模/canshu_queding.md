# 模型参数的确定（基于数据拟合或实验选择）

## 模型参数的确定

在数学建模中，我们建立了模型结构（如微分方程、统计回归式），但如果参数没选对，模型依然无法工作。**模型参数的确定**就是为模型中未知的常量找到合理数值的过程，它决定了模型预测的准确性。

> [!IMPORTANT]
> ==模型结构决定“关系”，参数决定“尺度”。== 同一个 SEIR 方程，参数不同，预测的感染人数可以相差数十倍。

### 为什么需要参数确定

模型的参数往往代表现实世界中的关键特征，例如传播率、发病率、衰减速率等。我们无法直接“发明”这些数值，只能通过**数据拟合**或**实验选择**来获得：

- **使模型与现实匹配**：参数来自真实数据，预测才有参考价值。
- **支撑决策**：药物需求量预测、出行政策制定都依赖参数。
- **探索“如果…会怎样”**：改变参数值，可以模拟不同干预效果。

```mermaid
flowchart LR
  A[真实数据] --> B(模型结构)
  B --> C{参数估计}
  C --> D[拟合的模型]
  D --> E[预测 / 决策]
```

### 两种主要方式

| 数据拟合 | 实验选择 |
| :--- | :--- |
| 用历史数据“反推”参数值 | 从现有文献、实验或已知事实直接取值 |
| 例子：最小二乘拟合发病率 | 例子：参考病毒潜伏期 $1/\sigma = 5.3$ 天 |
| 适合：无法直接测量的参数 | 适合：公认的生物学、物理常数 |
| 常见于：$\beta$、$k$ 等模型特定参数 | 常见于：$\sigma$、$\gamma$ 等文献已有值 |

> [!TIP]
> 解题时先把能从文献或题设直接搬来的参数（如 $N$、$1/\sigma$、$1/\gamma$）填上，再集中精力拟合 $\beta$、$k$ 等需要优化的参数。

### 逐步确定参数：以埃博拉疫情为例

**第一步**：厘清已知和未知。

- 已知参数（可直接引用）：总人口 $N$、平均潜伏期 $1/\sigma = 5.3$ 天、平均传染期 $1/\gamma = 5.61$ 天。
- 需拟合的参数：$\beta_0$（无干预传播率）、$k$（干预后的衰减速率）。

**第二步**：模型校准。

利用 CDC/WHO 发布的累计病例数据，以 SEIR 模型计算出理论曲线，通过最小二乘法调整 $\beta_0$ 和 $k$，使理论值与实际数据点吻合。

**第三步**：分析不同地区的参数差异。

通过拟合得到三国的参数如表所示：

| 参数 | 几内亚 | 塞拉利昂 | 利比里亚 |
| :--- | :--- | :--- | :--- |
| 无干预传播率 $\beta_0$ | 0.27 | 0.45 | 0.28 |
| 降低传播率 $k$ | 0.048 | 0.048 | 0.048 |
| 基本再生数 $R_0$ | 1.51 | 2.53 | 1.59 |

> [!WARNING]
> 即使使用同一个模型结构（如 SEIR），不同地区必须独立拟合参数。塞拉利昂的 $R_0$ 高达 2.53，远大于利比里亚的 1.59，==若照搬他国参数会造成严重低估或高估==。

### 一个算对了的例子

**题目要求**：预测几内亚、塞拉利昂、利比里亚的药物需求量。

**思路分析**：

- 疫情规模 → 取决于累积病例和增长速度；
- 药物量 = $f($当前病例累积量 $CUM_p$，发病率$)$。

**确定的关键参数**：

1. **当前累计患者数量 $CUM_p$**：从模型或实际数据获取。
2. **疾病的发病率（增长率）**：可由 $R_0$ 和 $\beta$ 换算得出。

公式表示为：

$$
\text{Medicine Quantity} = f(CUM_p, \text{Increasing Rate})
$$

> [!TIP]
> 在模型里，发病率常与 $\beta$ 和 $I(t)$ 直接相关；而 $CUM_p$ 正是方程中 $CUM(t)$ 的输出值，把它们设为参数便于根据统计数据动态修正预测。

### 常见的坑

- **把拟合出来的参数当成普适的**：一国疫情参数不能直接用于另一国或另一病毒（如埃博拉与新冠完全不同）。
- **忽略参数的单位量纲**：$\beta$ 定义常为“每人每天传播率”，与 $N$ 是否归一化直接相关，代入模型需保持量纲一致。
- **混淆 $\beta_0$ 和 $R_0$**：$R_0 = \beta_0 / \gamma$，基本再生数是一个比值，而非传播率本身。调整干预措施时，$R_0$ 会衰减，体现为 $\beta(t)$ 的指数下降。

掌握参数确定的思考路径，你就可以自信地回答：参数从哪来、为何这样设、误差可能在哪。这正是数学建模中从方程走向实际的关键一步。
