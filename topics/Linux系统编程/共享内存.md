# 共享内存的创建shmget、映射shmat、脱离shmdt与控制shmctl

## 共享内存是什么

System V 共享内存让多个进程把**同一段物理内存**映射到各自的虚拟地址空间。一个进程写入，另一个进程直接读取，不必像管道、消息队列那样在用户空间与内核之间反复复制数据，因此适合交换大量数据。

> [!IMPORTANT]
> 共享内存只解决“数据共享”，**不自动解决互斥与同步**。多个进程同时读写时，通常还要配合信号量等机制。

## 创建与获取：shmget

```c
#include <sys/ipc.h>
#include <sys/shm.h>

int shmget(key_t key, size_t size, int shmflg);
```

`key` 标识共享内存对象，可由 `ftok()` 生成，也可使用 `IPC_PRIVATE`；`size` 是请求的字节数；成功返回共享内存标识符 `shmid`，失败返回 `-1`。

常用标志：

| 标志 | 作用 |
|---|---|
| `IPC_CREAT` | 不存在则创建，存在则获取 |
| `IPC_CREAT \| IPC_EXCL` | 不存在则创建，已存在则报错 |
| 权限位，如 `0666` | 设置访问权限 |

例如：

```c
int shmid = shmget(IPC_PRIVATE, 4096, IPC_CREAT | 0666);
if (shmid == -1) {
    perror("shmget");
    exit(1);
}
```

注意：`shmget()` 返回的是 `shmid`，不是内存地址；`IPC_PRIVATE` 常用于创建新的私有对象，有亲缘关系的进程可继承该标识符，无亲缘进程通常使用约定好的 `key`。

## 映射与脱离：shmat、shmdt

```c
void *shmat(int shmid, const void *shmaddr, int shmflg);
int shmdt(const void *shmaddr);
```

一般将 `shmaddr` 设为 `NULL`，让系统选择映射地址；`shmflg` 通常设为 `0`，传入 `SHM_RDONLY` 可只读映射。

```c
char *p = shmat(shmid, NULL, 0);
if (p == (void *)-1) {
    perror("shmat");
    exit(1);
}

strcpy(p, "Hello, shared memory!");
printf("%s\n", p);

if (shmdt(p) == -1) {
    perror("shmdt");
}
```

`shmat()` 成功返回映射首地址，失败返回 `(void *)-1`；`shmdt()` 只是解除当前进程的映射，==不会删除共享内存对象==。

```mermaid
flowchart LR
    A["shmget 创建"] --> B["得到 shmid"]
    B --> C["shmat 映射"]
    C --> D["指针读写"]
    D --> E["shmdt 脱离"]
    E --> F["shmctl 删除"]
```

## 控制与删除：shmctl

```c
int shmctl(int shmid, int cmd, struct shmid_ds *buf);
```

常见命令：

| 命令 | 用途 |
|---|---|
| `IPC_STAT` | 获取共享内存状态，写入 `buf` |
| `IPC_SET` | 修改部分属性 |
| `IPC_RMID` | 标记删除共享内存 |

```c
if (shmctl(shmid, IPC_RMID, NULL) == -1) {
    perror("shmctl");
}
```

执行 `IPC_RMID` 后，对象被标记删除；已经映射它的进程仍可继续使用，待相关映射脱离后，系统才真正释放。因此，==`shmdt()` 负责“我不再使用”，`shmctl(IPC_RMID)` 负责“这个对象应当删除”==，两者不能互相替代。

## 完整通信例子

进程 A 创建、映射并写入：

```c
int id = shmget(IPC_PRIVATE, 1024, IPC_CREAT | 0666);
char *p = shmat(id, NULL, 0);
strcpy(p, "NJUPT");
/* 将 id 告知进程 B，并保证同步 */
```

进程 B 使用同一个 `id`：

```c
char *q = shmat(id, NULL, 0);
printf("%s\n", q);   /* 输出 NJUPT */
shmdt(q);
```

A 确认 B 已读完后执行：

```c
shmdt(p);
shmctl(id, IPC_RMID, NULL);
```

这里传递的是字符串 `"NJUPT"`，无需计算共享内存大小；若题目要求存放 $n$ 个 `int`，则至少申请 $n \times \texttt{sizeof(int)}$ 字节，例如 $100$ 个 `int` 在 `sizeof(int)=4` 时需要 $400$ 字节。

> [!WARNING]
> 常见错误：把 `shmat()` 的返回值直接与 `NULL` 比较；只调用 `shmdt()` 却忘记 `IPC_RMID`；进程退出后误以为系统必定自动删除对象；未做同步便同时读写。共享内存若不再使用，应明确脱离并删除，避免长期残留。
