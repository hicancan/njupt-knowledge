# 数学期望的性质

## 数学期望的性质

如果直接按分布列或概率密度求 $E[X]$，计算量往往巨大。能否将复杂随机变量拆解为简单变量的组合来求解？这正是数学期望线性性质存在的意义。它允许我们在==不知道联合分布==的情况下，仅凭边缘期望就能算出和的期望。

> [!IMPORTANT]
> 核心性质：对任意常数 $a, b$ 及随机变量 $X, Y$（无论是否独立），恒有
> $$E[aX + bY] = aE[X] + bE[Y]$$
> 推广至 $n$ 个变量：$E\left[\sum_{i=1}^n c_i X_i\right] = \sum_{i=1}^n c_i E[X_i]$。

### 为什么它是解题利器

面对“设备元件调整数”“样本均值”等复合变量时，直接求分布律极其繁琐。引入示性变量（0-1变量）并利用线性性质，可将复杂问题转化为若干个简单期望的加法运算。

```mermaid
flowchart LR
    A["复杂变量 X"] --> B["拆解为 ΣXi"]
    B --> C["利用线性性质"]
    C --> D["ΣE[Xi]"]
    D --> E["快速得结果"]
```

### 怎么做：指示变量法四步走

以真题“三元件设备调整数”为例：

1.  **定义指示变量**：令 $X_i=1$ 表示第 $i$ 个元件需调整，否则为 0。
2.  **表达目标变量**：总调整数 $X = X_1 + X_2 + X_3$。
3.  **求分量期望**：$E(X_i) = P(X_i=1)$，分别为 0.1, 0.2, 0.3。
4.  **叠加得结果**：$E(X) = 0.1+0.2+0.3 = 0.6$。

> [!TIP]
> 遇到“计数型”随机变量（如成功次数、故障数、匹配对数），优先尝试==指示变量分解法==，避免硬凑分布列。

### 与方差性质的关键区别

这是考试中最容易混淆的点，务必通过下表区分：

| 性质 | 数学期望 $E[\cdot]$ | 方差 $D[\cdot]$ |
| :--- | :--- | :--- |
| 线性性 | ==无条件成立== | 仅当变量==相互独立==时成立 |
| 常数提取 | $E[cX] = cE[X]$ | $D[cX] = c^2 D[X]$ |
| 和的运算 | $E[X+Y]=E[X]+E[Y]$ | $D[X+Y]=D[X]+D[Y]$（需独立） |

> [!WARNING]
> 期望的线性性质==不要求独立性==！但方差的加法公式必须验证独立性。上例中若误用 $D(X)=\sum D(X_i)$ 而未确认独立条件，虽本题碰巧正确，但在非独立场景下必错。

### 在统计推断中的应用

线性性质是证明无偏估计量的基石。例如验证加权估计量 $\hat{\mu} = \frac{\sum a_i X_i}{\sum a_i}$ 的无偏性：

$$
E(\hat{\mu}) = \frac{\sum a_i E(X_i)}{\sum a_i} = \frac{\sum a_i \mu}{\sum a_i} = \mu
$$

此处仅依赖 $E(X_i)=\mu$ 和线性性质，无需知道总体具体分布。同理，样本均值 $E(\overline{X})=\mu$、样本方差 $E(S^2)=\sigma^2$ 的证明均源于此。

> [!CAUTION]
> $E[g(X)] \neq g(E[X])$！线性性质仅对==线性函数==成立。例如 $E[X^2] \neq (E[X])^2$，这正是方差 $D(X)=E[X^2]-(E[X])^2$ 不为零的原因。切勿将期望符号随意穿过非线性函数。
