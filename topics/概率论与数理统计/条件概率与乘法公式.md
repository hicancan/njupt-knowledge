# 条件概率与乘法公式

## 条件概率：在“已知”之后重新分配概率

随机事件的概率刻画的是“事前”对事件发生可能性的度量。但现实中我们常常在获得新信息后重新评估概率——例如，已知某职工透视结果呈阳性，他患肺结核的概率是多少？这种“在事件 $B$ 已经发生的条件下，事件 $A$ 发生的概率”就是**条件概率**，记作 $P(A \mid B)$。

直观上，条件概率做了一件事：**把样本空间从 $\Omega$ 缩减为 $B$**。既然已经知道 $B$ 发生了，那么真正“有效”的样本点全都落在 $B$ 内。此时 $A$ 发生的部分，只能是 $A$ 与 $B$ 的公共部分 $AB$。

> [!IMPORTANT]
> 条件概率的定义：设 $P(B) > 0$，则 $P(A \mid B) = \dfrac{P(AB)}{P(B)}$。分母 $P(B)$ 本质上是一个标准化因子，保证在“新样本空间 $B$”上概率仍归一。

**条件概率本身也满足概率的三条公理**：非负性（$P(A|B) \ge 0$）、规范性（$P(\Omega|B)=1$）、可列可加性。这意味着所有对普通概率成立的运算规则（加法公式、对立事件公式等）在条件概率框架下同样适用，只是每一项后都要附上“$|B$”。

---

## 乘法公式：把“联合”拆成“条件 × 边缘”

由条件概率定义直接变形，即得**乘法公式**：

$$P(AB) = P(B)\,P(A \mid B) = P(A)\,P(B \mid A)$$

它回答的问题是：**两个事件同时发生，可以分两步走**——先让 $B$ 发生（概率 $P(B)$），再在 $B$ 已发生的前提下让 $A$ 发生（概率 $P(A|B)$）。这一公式在多事件情形下可递推推广：

$$P(A_1 A_2 \cdots A_n) = P(A_1)\,P(A_2 \mid A_1)\,P(A_3 \mid A_1 A_2)\cdots P(A_n \mid A_1\cdots A_{n-1})$$

> [!TIP]
> 判断何时用乘法公式：题目出现“**已知……求……且……**”的连续条件表述，或者要你求 $P(AB)$，但只给了 $P(B)$ 和 $P(A|B)$。抓住关键句：“在……发生的条件下”。

---

## 条件概率 vs. 乘法公式：别把箭头方向搞反

初学最容易混淆的是这两个公式的**使用方向**：

| 公式 | 已知 | 求 | 本质 |
|:---:|:---:|:---:|:---:|
| 条件概率公式 $P(A \mid B) = \frac{P(AB)}{P(B)}$ | $P(AB)$、$P(B)$ | $P(A \mid B)$ | 求“条件”下的概率 |
| 乘法公式 $P(AB) = P(B)\,P(A \mid B)$ | $P(B)$、$P(A \mid B)$ | $P(AB)$ | 由条件反推“联合” |

> [!WARNING]
> $P(A \mid B)$ 与 $P(AB)$ 是两个完全不同的量：前者是“在 $B$ 已发生后 $A$ 的概率”，后者是“$A$ 与 $B$ 同时发生的概率”。二者只在 $P(B)=1$ 时数值相等的极端情形下才相同。

---

## 从条件概率到全概率与贝叶斯：一图理清

条件概率和乘法公式是两大“进阶公式”的基石。它们的关系可以这样组织：

```mermaid
flowchart LR
    A["条件概率定义"] --> B["乘法公式"]
    B --> C["全概率公式"]
    B --> D["贝叶斯公式"]
    C -. "完备事件组分割 B" .-> D
```

- **全概率公式**：把 $B$ 拆到互不相容的“原因” $A_1, \dots, A_n$ 上，用乘法公式算每一块的贡献再求和。
- **贝叶斯公式**：在全概率公式的基础上“逆推”——已知结果 $B$ 已发生，反求某个“原因”$A_i$ 的后验概率 $P(A_i \mid B)$。

## 一道算对的例子

**题目**：已知 $P(A)=\frac14$，$P(B \mid A)=\frac13$，$P(A \mid B)=\frac12$，求 $P(A \cup B)$。

**解**：

由乘法公式，
$$P(AB) = P(A)\,P(B \mid A) = \frac14 \times \frac13 = \frac{1}{12}.$$

再由条件概率定义 $P(A \mid B) = \dfrac{P(AB)}{P(B)}$，变形得
$$P(B) = \frac{P(AB)}{P(A \mid B)} = \frac{\frac{1}{12}}{\frac12} = \frac16.$$

最后由加法公式，
$$P(A \cup B) = P(A) + P(B) - P(AB) = \frac14 + \frac16 - \frac{1}{12} = \frac{3+2-1}{12} = \frac13.$$

> [!NOTE]
> 解题时**先看题目给了哪种“条件”**：给了 $P(B|A)$ 就先用乘法公式求 $P(AB)$；给了 $P(A|B)$ 就用条件概率公式反解 $P(B)$。两类公式交替使用是典型考法。

## 常见的坑

1. **分母张冠李戴**：$P(A|B)$ 的分母永远是 $P(B)$，$P(B|A)$ 的分母永远是 $P(A)$。把 $P(AB)$ 放在分子上是共同的，区别只在分母。
2. **把 $P(A|B)$ 与 $P(B|A)$ 混为一谈**：除非 $P(A)=P(B)$，否则二者不相等。贝叶斯公式正是用来刻画这种“正向条件”与“逆向条件”的换算关系。
3. **忽视 $P(B)>0$ 的前提**：条件概率定义要求分母事件概率非零。题目若给出 $P(B)=0$，则 $P(A|B)$ 无定义。
