# 估计量的评选标准（无偏性、有效性、相合性）

## 估计量的评选标准

在参数估计中，我们得到了未知参数 $\theta$ 的估计量 $\hat{\theta}$。但不同的估计方法（如矩估计、最大似然估计）可能给出不同的结果。如何判断哪个估计量“更好”？我们需要三个核心标准：**无偏性**、**有效性**和**相合性**。

### 无偏性：没有系统偏差

想象你在打靶，如果子弹的平均落点正好是靶心，说明你没有“系统性”的偏差。
数学上，若估计量 $\hat{\theta}$ 的期望等于真值，即：
$$ E(\hat{\theta}) = \theta $$
则称 $\hat{\theta}$ 是 $\theta$ 的==无偏估计量==。

> [!IMPORTANT]
> 无偏性的实际意义是指**没有系统性的偏差**。它只保证长期平均来看是准的，不代表单次估计一定接近真值。

### 有效性：波动越小越好

如果有两个无偏估计量 $\hat{\theta}_1$ 和 $\hat{\theta}_2$，谁的方差更小，谁就更“有效”。因为方差小意味着估计值在真值附近摆动幅度小，更稳定。
若 $D(\hat{\theta}_1) < D(\hat{\theta}_2)$，则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ ==更有效==。

### 相合性：大样本下的稳定性

当样本容量 $n$ 无限增大时，估计量依概率收敛于真值：
$$ \lim_{n \to \infty} P\{|\hat{\theta} - \theta| < \varepsilon\} = 1 $$
这保证了只要数据够多，估计结果就会稳定在真值附近。

### 常见误区与辨析

| 概念 | 关注点 | 常见误解 |
| :--- | :--- | :--- |
| **无偏性** | 期望值 $E(\hat{\theta})$ | 误以为无偏就是每次估计都准确 |
| **有效性** | 方差 $D(\hat{\theta})$ | 忽略前提：必须在**无偏**估计之间比较 |
| **相合性** | 极限行为 ($n \to \infty$) | 误认为小样本下也一定精确 |

> [!WARNING]
> **易错坑**：比较有效性时，必须先验证两者都是**无偏**的。如果一个有偏一个无偏，不能直接通过方差比较有效性。此外，样本方差 $S^2 = \frac{1}{n-1}\sum(X_i-\bar{X})^2$ 是 $\sigma^2$ 的无偏估计，而 $\frac{1}{n}\sum(X_i-\bar{X})^2$ 是有偏的。

### 典型例题解析

**题目**：设 $X_1, \dots, X_n$ 来自总体 $X$， $E(X)=\mu, D(X)=\sigma^2$。确定常数 $c$，使 $\bar{X}^2 - cS^2$ 是 $\mu^2$ 的无偏估计量。

**思路引导**：
要使它是无偏估计，需满足 $E(\bar{X}^2 - cS^2) = \mu^2$。利用公式 $E(Y^2) = D(Y) + [E(Y)]^2$ 展开计算。

**解题步骤**：
1.  已知 $E(\bar{X})=\mu, D(\bar{X})=\frac{\sigma^2}{n}$，故 $E(\bar{X}^2) = \frac{\sigma^2}{n} + \mu^2$。
2.  已知 $S^2$ 是 $\sigma^2$ 的无偏估计，故 $E(S^2) = \sigma^2$。
3.  代入期望公式：
    $$ E(\bar{X}^2 - cS^2) = \left(\frac{\sigma^2}{n} + \mu^2\right) - c\sigma^2 = \mu^2 $$
4.  整理得 $\frac{\sigma^2}{n} - c\sigma^2 = 0$，解得 ==$c = \frac{1}{n}$==。

> [!TIP]
> 记忆技巧：无偏看期望，有效看方差，相合看极限。遇到 $\bar{X}^2$ 想方差公式，遇到 $S^2$ 想无偏性质。
