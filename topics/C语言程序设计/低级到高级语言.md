# 由低级语言到高级语言的演变
### 为什么需要高级语言

计算机只认识 0 和 1。最早的程序员直接用机器指令写程序，比如让 CPU 做一次加法可能要写 `10110000 00000001`。显然，这种写法效率极低、极易出错，换一台机器（指令集不同）程序就要全部重写。于是人们逐步发明了汇编语言、高级语言，把“给人看的符号”翻译成“给机器看的二进制”。

> [!NOTE]
> 语言“高”“低”不是指好坏，而是指**离机器的远近**：离机器越近越“低级”，离人越近越“高级”。

### 三代语言的对比

| | 机器语言 | 汇编语言 | 高级语言 |
|---|---|---|---|
| 书写形式 | 0/1 二进制串 | 助记符（如 `ADD`） | 接近自然语言/数学式 |
| 可读性 | 极差 | 较差 | 好 |
| 可移植性 | 不可移植 | 很差 | 好（需编译器） |
| 硬件依赖 | 强 | 强 | 弱 |
| 执行前是否需要翻译 | 不需要 | 需要汇编器 | 需要编译器/解释器 |

**翻译方式**是把高级语言变成机器语言的关键一环：

- **编译**：把整个源程序一次性翻译成目标代码，再执行。C 语言属于编译型。
- **解释**：逐句翻译、逐句执行，不产生独立目标文件。BASIC 早期版本、Python 常见实现属于解释型。

### 结构化程序设计语言

早期 BASIC、FORTRAN 允许大量使用 `GOTO` 随意跳转，程序一长就成了“意大利面条代码”，难以阅读和维护。

==结构化程序设计==的核心主张是：任何程序逻辑都能用**顺序、选择、循环**三种基本结构组合表达，**尽量避免无限制的 GOTO**。

> [!IMPORTANT]
> ==第一个结构化程序设计语言是 PASCAL==。这是南邮常考的一个事实性考点。
> C 语言也支持结构化程序设计，但它不是“第一个”。

PASCAL 由 Niklaus Wirth 于 1970 年前后设计，强制较好的程序结构，广泛应用于教学。C 语言诞生稍晚（1972 年前后），兼具高级语言的可读性和汇编语言般的灵活控制能力。

### 一个常考的小题

例题：第一个结构化程序设计语言是（　）。

- A. PASCAL　B. C　C. BASIC　D. FORTRAN

**答案：A。**

解析：BASIC 和 FORTRAN 早期版本都不是结构化语言；C 虽然支持结构化，但并非第一个；PASCAL 是**第一个**结构化程序设计语言。

### 常见的坑

[!WARNING]
- 汇编语言**不是机器语言**，它用助记符，需要汇编器翻译，不可直接执行。
- 高级语言**不等于解释型语言**。C 是高级语言，但它是编译型。
- PASCAL 是第一个**结构化**程序设计语言，不是第一个高级语言——第一个广泛应用的高级语言一般认为是 FORTRAN。

[!TIP]
记忆口诀：**“FORTRAN 最早，PASCAL 第一个结构化，C 最广泛系统用”**。考试中“第一个”和“最早”的问法要仔细区分。
