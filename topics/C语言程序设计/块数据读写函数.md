# fread和fwrite函数的原型及块数据读写

## 它是什么

`fread` 和 `fwrite` 是 C 语言提供的==**块数据读写**函数==，专门用于一次性读取或写入一大段连续字节，主要面向二进制文件（也可用于文本文件）。前文学过的 `fgetc`/`fputc` 一次只处理一个字符，`fgets`/`fputs` 一次处理一个字符串——但如果你要保存一个结构体数组、一张图片、一段音频呢？逐字符读写既慢又容易把二进制数据中的 `\0` 误当作结束标记。这时块读写就派上用场：它把内存中的一整块数据按字节原样搬到文件，或从文件搬到内存。

> [!IMPORTANT]
> `fread` / `fwrite` 是文件读写四对函数中唯一以"数据块"为单位操作的一对，是二进制文件读写的主力。

## 函数原型

```c
int fread ( void *buffer, int size, int n, FILE *fp );
int fwrite(const void *buffer, int size, int n, FILE *fp);
```

| 参数 | 含义 |
| :-- | :-- |
| `buffer` | 内存缓冲区起始地址（`fread` 存放读入数据，`fwrite` 提供待写数据） |
| `size` | 单个数据项的字节大小，如 `sizeof(struct Student)` |
| `n` | 数据项的个数 |
| `fp` | 文件指针，由 `fopen` 打开 |
| **返回值** | ==实际成功读/写的数据项个数（不是字节数）== |

> [!TIP]
> 记忆：参数顺序是"**缓冲区 → 单项大小 → 个数 → 文件**"，`fread` 和 `fwrite` 完全一致，写函数只是把 `const` 加在 buffer 前，避免误改。

## 与相近函数的区别

| 函数 | 单位 | 典型场景 |
| :-- | :-- | :-- |
| `fgetc`/`fputc` | 1 个字符 | 逐字符处理文本 |
| `fgets`/`fputs` | 一个字符串（遇 `\n`/`\0`） | 行式文本 |
| `fscanf`/`fprintf` | 格式化字段 | 文本数值 |
| `fread`/`fwrite` | ==**整块内存**== | 二进制、结构体数组 |

文本格式函数遇到 `\0` 会截断，块读写则把 `\0` 当普通字节处理，这正是二进制文件所需。

## 文件操作五步走

```mermaid
flowchart LR
    A["定义 FILE*"] --> B["fopen 打开"]
    B --> C["fread/fwrite"]
    C --> D["fclose 关闭"]
    D --> E["结束"]
```

注意 `fopen` 二进制方式应写成 `"rb"`、`"wb"`、`"ab"` 等（Windows 下需显式加 `b`）。

## 一个算对了的例子

```c
#include <stdio.h>
struct Student {
    int no;
    char name[10];
};
int main(void) {
    FILE *fp;
    struct Student s[2] = {{1, "Li"}, {2, "Wang"}};
    struct Student t[2];
    int cnt;

    fp = fopen("stu.dat", "wb");            // 二进制写
    cnt = fwrite(s, sizeof(struct Student), 2, fp);
    fclose(fp);
    printf("写入 %d 个\n", cnt);            // 输出 2

    fp = fopen("stu.dat", "rb");            // 二进制读
    cnt = fread(t, sizeof(struct Student), 2, fp);
    fclose(fp);
    printf("读出 %d 个：%d %s\n", cnt, t[1].no, t[1].name); // 2 Wang
    return 0;
}
```

==`fwrite` 写入 2 项、`fread` 读回 2 项，返回值都是"项数"而非字节数==。

## 常见的坑

> [!WARNING]
> - **返回值是项数不是字节数**：写 `fwrite(s, 4, 5, fp)` 成功时返回 5，不是 20。
> - **忘记 `fclose`**：数据可能滞留在缓冲区未落盘，尤其小文件更易出现"读不到刚写的内容"。
> - **`fread` 读的项数超出文件剩余数据**：返回值会小于 `n`，必须检查返回值，不能想当然认为全读到了。
> - **文本方式打开二进制文件**（Windows 下少了 `b`）：`\n` 与 `\r\n` 转换会破坏数据。

> [!CAUTION]
> `fread`/`fwrite` 操作的是内存的**原样字节**，跨平台（不同字节序、结构体内存对齐、`int` 位宽）直接写结构体往往不可移植，考试只需注意==**必须成对使用、检查返回值**==即可。
