# 字符串常量的存储及'\0'结束标志

## 字符串常量与结束标志

字符串常量是用一对双引号 `""` 括起来的字符序列，例如 `"Hello"`、`"123"` 和 `""`。它可以包含普通字符，也可以包含转义字符，如 `"Hello\"Accp\""`。

在 C 语言中，字符串常量末尾会自动附加一个空字符 `'\0'`。`'\0'` 不是可见字符，而是值为 0 的字符，用于==标记字符串结束==。

> [!IMPORTANT]
> 字符串长度只统计 `'\0'` 之前的字符数；字符串实际占用的字节数比长度多 1。

| 内容 | 字符串长度 | 实际占用字节数 |
|---|---:|---:|
| `""` | 0 | 1 |
| `"a"` | 1 | 2 |
| `"abc"` | 3 | 4 |
| `"117"` | 3 | 4 |

例如，字符串 `"a"` 在内存中实际保存为：

```text
'a'  '\0'
```

因此它占用 $1+1=2$ 个字节，而不是 1 个字节。

## 为什么需要结束标志

很多字符串处理函数并不是根据数组容量判断长度，而是从指定地址开始逐个读取字符，直到遇到 `'\0'` 才停止。因此，把字符串放进字符数组时，必须保证其中存在结束标志。

```c
char a[10] = {'h', 'e', 'l', 'l', 'o'};
```

初始化后，数组前 5 个元素为 `'h'`、`'e'`、`'l'`、`'l'`、`'o'`，剩余元素自动初始化为 `'\0'`。其内存内容可表示为：

```text
h e l l o \0 \0 \0 \0 \0
```

所以：

```c
puts(a + 2);
```

`a + 2` 指向第三个元素 `'l'`，`puts` 从这里输出，直到遇到 `'\0'`，结果为：

```text
llo
```

## 字符数组与字符串

C 语言没有专门的字符串变量，通常使用字符数组保存字符串。字符数组与字符串的主要区别在于末尾是否具有 `'\0'`。

```c
char s1[6] = {'h', 'e', 'l', 'l', 'o'};
char s2[6] = "hello";
char s3[] = "hello";
```

`s1` 的末尾元素也是 `'\0'`，因为未显式初始化的数组元素会被置为 0；但如果数组所有位置都被显式赋值，就没有自动留下结束标志。

```c
char s[5] = {'h', 'e', 'l', 'l', 'o'};
puts(s); // 可能越界读取，结果不确定
```

而下面的写法能够正确保存字符串：

```c
char s[6] = "hello";        // 自动添加 '\0'
char s[]  = "hello";        // 数组长度自动确定为 6
```

> [!TIP]
> 记忆口诀：**双引号是字符串，单引号是字符；字符串自带“尾巴”，长度不含尾巴。**

## 常见易错点

> [!WARNING]
> `"117"` 是字符串常量，不是字符常量；字符常量必须使用单引号，例如 `'1'`。`'B'` 才是字符常量。

`'\x41'`、`'\104'` 都是合法的字符常量写法，分别表示十六进制和八进制形式对应的字符；而 `"x41"` 只是由字符 `x`、`4`、`1` 组成的字符串。

另外，字符串末尾的 `'\0'` 不计入字符串长度，却必须计入存储空间。看到“字符串占多少字节”时，通常应按“长度 $+1$”计算。
