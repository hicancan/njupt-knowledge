# 计算机硬件组成（CPU、存储器等）及工作过程

## 计算机硬件五大部件

计算机硬件由==运算器、控制器、存储器、输入设备和输出设备==组成。其中，运算器与控制器合称 **CPU（Central Processor Unit，中央处理器）**，负责“运算 + 控制”，是计算机最核心的部件。

```mermaid
flowchart LR
    I["输入设备"] --> M["存储器"]
    M --> C["CPU"]
    C --> M
    M --> O["输出设备"]
    C -. "控制信号" .-> I
    C -. "控制信号" .-> O
```

| 部件 | 主要作用 | 典型例子 |
|---|---|---|
| 运算器 | 算术运算、逻辑运算 | 加法器 |
| 控制器 | 取指令、分析指令、发出控制信号 | 指令控制电路 |
| 存储器 | 存放程序和数据 | 内存、外存 |
| 输入设备 | 将外部信息送入计算机 | 键盘、鼠标 |
| 输出设备 | 将处理结果送出 | 显示器、打印机 |

## CPU 与寄存器

CPU 内部设有寄存器，用来保存数据、地址或计算的中间结果。访问寄存器时，==不必通过地址总线和数据总线访问内存==，因此速度更快。寄存器容量很小，不能代替存储器保存大量程序和数据。

| 概念 | 含义 | 不要混淆 |
|---|---|---|
| 字长 | CPU 一次能处理的二进制位数 | 不是存储容量单位 |
| 存储容量 | 存储器能保存的信息量 | 基本单位是字节 |
| 地址总线 | 指定要访问的存储单元 | 根数决定可寻址范围 |

存储器容量的基本单位是==字节（Byte，B）==，1 字节等于 8 位。常见换算为：

$$1\ \mathrm{KB}=2^{10}\ \mathrm{B},\quad 1\ \mathrm{MB}=2^{20}\ \mathrm{B},\quad 1\ \mathrm{GB}=2^{30}\ \mathrm{B}$$

> [!IMPORTANT]
> 若地址总线有 $n$ 根，且按字节编址，则可表示 $2^n$ 个不同地址，最大可寻址空间为 $2^n$ 字节。

## 计算机的工作过程

程序和数据先存入存储器，CPU 再按指令要求工作，基本过程可概括为“取指令—分析指令—执行指令”，并反复进行。

```mermaid
flowchart LR
    A["取指令"] --> B["分析指令"]
    B --> C["执行指令"]
    C --> D["保存结果"]
    D --> A
```

例如计算两个数之和：输入设备提供数据，数据存入存储器；控制器取出并分析加法指令，运算器完成运算；中间结果可暂存在寄存器中，最终结果写回存储器，再由输出设备显示。

## 从源程序到可执行文件

C 语言程序需要经过==编辑、编译、链接、运行==。编译把源文件变为目标文件，链接再把目标文件与所需库等组合成可执行文件。

| 阶段或文件 | 扩展名 |
|---|---|
| 源文件 | `.c` |
| 目标文件 | `.obj` |
| 可执行文件 | `.exe` |
| 头文件 | `.h` |

> [!WARNING]
> 编译后通常还不能直接运行，必须经过**链接**。不要漏写链接，也不要把目标文件当成可执行文件。

## 算对了的例子

**题目：若计算机有 32 根地址总线，则存储器的最大存储容量可达多少？**

按字节编址时，可寻址的字节数为：

$$2^{32}\ \mathrm{B}=2^2\times2^{30}\ \mathrm{B}=4\ \mathrm{GB}$$

所以答案是 **4GB**，不是 32GB。

> [!TIP]
> 做容量题先确认“按字节编址”，再算 $2^n$；看到“文本文件”则按字符计数。例如 `-12.34` 含 `-`、`1`、`2`、`.`、`3`、`4` 共 6 个字符，占 **6 字节**，不能按 `double` 的 8 字节计算。
