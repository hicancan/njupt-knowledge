# 字符数据的合法表示形式

## 字符数据的合法表示

在 C 语言中，字符数据主要有两种存在形式：**字符常量**和**字符串常量**。区分它们的关键在于**定界符**与**内存存储**。

> [!IMPORTANT]
> **核心定义**：字符常量是用**单引号** `' '` 括起来的单个字符；字符串常量是用**双引号** `" "` 括起来的字符序列。

### 1. 怎么判断是否合法？

判断一个字符表示是否合法，只需问自己两个问题：
1. **用了什么括号？** 单引号是字符，双引号是字符串。
2. **里面有几个“有效”字符？** 标准 C 中，单引号内通常只能包含**一个**字符（或一个转义序列）。

### 2. 与相近概念的区别

很多初学者容易混淆 `'0'`、`"0"` 和 `0`。它们在内存中的表现截然不同：

| 表示形式 | 类型 | ASCII 值/内容 | 占用字节 (典型) | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `'0'` | 字符常量 | 48 | 1 | 数字字符 0 |
| `"0"` | 字符串常量 | 48, 0 | 2 | 含结束符 `\0` |
| `0` | 整型常量 | 0 | 4 (int) | 数值零 / NULL |

> [!WARNING]
> **常见坑**：`"A"` 不是字符常量！它是字符串。在需要 `char` 类型的地方使用 `"A"` 会导致类型不匹配警告或错误。

### 3. 转义字符的特殊性

字符常量中可以包含**转义序列**，它们被视为**一个**字符。
- `\n`：换行符（1 个字符）
- `\x41`：十六进制 ASCII 码，对应 `'A'`（1 个字符）
- `\101`：八进制 ASCII 码，对应 `'A'`（1 个字符）

若写成 `"\x41"`（双引号），则变成包含 `'A'` 和 `\0` 的字符串。

### 4. 算对了的例子

回顾考题：**以下不正确的字符常量是？**

- A. `"117"`
- B. `"0"`
- C. `'\x41'` (假设原题意图为此合法形式)
- D. `'B'`

**解析**：
- **A (`"117"`)**：使用双引号，是**字符串常量**，不是字符常量。❌
- **B (`"0"`)**：使用双引号，是**字符串常量**。❌
- **D (`'B'`)**：单引号包裹单个字符，合法。✅
- **C (`'\x41'`)**：单引号包裹一个十六进制转义序列，代表字符 'A'，合法。✅

题目问“不正确”，且通常单选题中考察最明显的类型错误。若选项 A 为 `"117"`，它显然不是字符常量。若题目是多选或考察更细致的非法字符，需注意单引号内不能放多个普通字符（如 `'ab'` 在某些编译器虽不报错但属非标准行为）。

> [!TIP]
> **记忆口诀**：单引字符双引串，转义虽长算一个。看到双引直接排，莫把字符串当字符看。

### 5. 内存存储差异

为什么 `"a"` 占 2 个字节而 `'a'` 占 1 个字节？

$$ \text{"a"} = \{ \text{'a'}, \text{'\0'} \} $$

C 语言规定字符串必须以空字符 `\0` (ASCII 0) 结尾，以便函数（如 `printf`）知道字符串在哪里结束。而字符变量 `char c = 'a';` 仅存储该字符的 ASCII 码值。

> [!NOTE]
> 在文件操作或数组处理中，务必注意这一区别。例如读取文件时，`fgetc` 返回的是 `int` 类型的字符 ASCII 码，而非字符串。
