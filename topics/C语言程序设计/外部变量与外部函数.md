# 用extern声明外部变量与外部函数

## 外部变量与 extern 关键字

先想一个问题：一个工程拆成多个 `.c` 文件后，A 文件里的函数想用 B 文件里定义的全局变量，编译器在编译 A 文件时根本不认识这个变量，怎么办？

答案就是：在 A 文件里用 `extern` **声明**它，告诉编译器“这个变量在别的文件里已经定义过了，你放行，链接阶段会找到它”。

### 声明与定义的区别

这是理解 `extern` 的第一道坎：

| 操作 | 含义 | 是否分配内存 | 示例 |
|------|------|:---:|------|
| 定义 | 真正创建变量 | ✅ | `int g_count = 0;` |
| extern 声明 | 引用别处已定义的变量 | ❌ | `extern int g_count;` |

> [!IMPORTANT]
> `extern` 只做**声明**，不分配存储空间。==变量的定义必须且只能有一次==，而 extern 声明可以出现在每个需要用到它的文件中。

### 多文件工程中的基本用法

假设工程有两个文件：

**B 文件（定义方）**——`file_b.c`

```c
int g_total = 100;          // 定义全局变量
void print_total(void) { ... }
```

**A 文件（使用方）**——`file_a.c`

```c
#include <stdio.h>
extern int g_total;         // 声明：g_total 在别处定义
extern void print_total(void);  // 声明外部函数

int main(void) {
    printf("%d\n", g_total);    // 可以正常访问
    print_total();
    return 0;
}
```

> [!TIP]
> 通常把 `extern` 声明集中放在一个 `.h` 头文件里，哪个源文件要用就 `#include` 哪个头文件，避免到处手写声明。
>
> 注意：B 文件本身不要 `#include` 那个声明头文件，否则同一变量在 B 文件里既是“定义”又是“extern 声明”，某些编译器会直接报重复定义。

### 与 static 全局变量的区别

这也是一道常考的辨析题。

| 存储类别 | 作用范围 | 能否被其他文件 extern 引用 |
|---------|---------|:---:|
| 普通全局变量（外部变量） | 整个工程 | ✅ 能 |
| `static` 全局变量 | 仅本源文件 | ❌ 不能 |
| `extern` 声明 | 引用其他文件的外部变量 | —— |

所以题目问“定义一个只允许本源文件中所有函数使用的全局变量”，该选 **static**，而不是 extern。

### 外部变量一定不是局部变量

局部变量定义在函数体内或复合语句块内，而**外部变量定义在所有函数之外**，生命周期贯穿整个程序运行期。因此题目中“一定不是局部变量”的选项就是 **外部变量**。

### 一个完整的算例

**`share.c`**——定义外部变量与外部函数：

```c
int g_counter = 10;

void show_counter(void) {
    printf("counter = %d\n", g_counter);
}
```

**`main.c`**——extern 声明后使用：

```c
#include <stdio.h>
extern int g_counter;
extern void show_counter(void);

int main(void) {
    show_counter();        // 输出：counter = 10
    g_counter += 5;
    show_counter();        // 输出：counter = 15
    return 0;
}
```

运行后，`main.c` 成功访问并修改了 `share.c` 中定义的外部变量 `g_counter`。

### 常见的坑

> [!WARNING]
> **只声明不定义**：所有文件里都写 `extern int x;` 而没有一处 `int x;`，链接时直接报“未定义的引用”。
>
> **重复定义**：两个源文件都写了 `int x;` 又没有用 `static` 限制，链接时报“重复定义”。
>
> **extern 不初始化**：`extern int x = 0;` 在函数外写，编译器会视为定义而非声明，容易造成重复定义。声明时应写 `extern int x;`（不带初始值）。
>
> **static 变量不能跨文件引用**：这是最常考的边界条件，B 文件里 `static int s;`，A 文件里 `extern int s;` 是**链接错误**。
