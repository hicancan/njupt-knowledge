# 无参宏指令与带参宏指令的定义及使用

## 宏指令是什么

宏指令（宏定义）是 C 语言编译预处理的一种：在编译之前，预处理器把程序中所有出现的宏名**原样替换成对应的字符串**，替换完才开始真正的编译。它不占运行时间，只占编译时间。

```c
#define M 1+2        // 无参宏：M 就是字符串 "1+2"
#define N 2*M+1      // 无参宏可以嵌套使用已定义的宏
#define MUL(x,y) x*y // 带参宏：形参 x、y 在替换时被实参文本替换
```

> [!IMPORTANT]
> 宏替换是**纯文本替换**，不做任何计算、不做类型检查、不先求实参的值。宏定义行末**不要加分号**——分号会被一起替换进去，常常导致语法错误。

## 替换过程发生了什么

```mermaid
flowchart LR
    A["源程序 c"] --> B["预处理：宏替换"]
    B --> C["展开后的源程序"]
    C --> D["编译、运行"]
```

以 `#define M(x, y) x*y` 和调用 `M(2+8, 4)` 为例，预处理器只做一件事：

$$M(2+8,\ 4) \;\longrightarrow\; 2+8*4$$

替换后交给编译器，按运算符优先级计算：$2 + 8\times4 = 34$。

> [!WARNING]
> 如果答案想要 40，宏定义必须写成 `#define M(x, y) (x)*(y)`。==带参宏的整体和每个形参都要加括号==，否则实参是表达式时极易因优先级而出错。

## 无参宏与带参宏对比

| 对比项 | 无参宏 | 带参宏 |
|---|---|---|
| 形式 | `#define 宏名 串` | `#define 宏名(形参表) 串` |
| 作用 | 定义符号常量、简化书写 | 模拟简单函数功能 |
| 替换 | 宏名 → 串 | 形参 → 实参文本，再整体替换 |
| 典型坑 | 串没加括号 | 实参表达式未加括号 |

## 常见的坑

- **嵌套宏逐层展开**：`#define M 1+2`、`#define N 2*M+1`，则 `x = N;` 展开为 `x = 2*1+2+1;`，结果是 $5$，不是 $9$。
- **数组长度定义**：`#define N 3` 之后可以写 `int a[N*3];`，因为宏替换发生在编译期；而变量长度（如 `int n=3; int a[n];`）在 C89 中不允许，`#define N=3` 这种写法把等号也替换进去，同样错误。
- **带参宏不是函数**：`c = MUL(a+2, b+5)` 若宏为 `x*y`，展开是 `a+2*b+5`，当 $a=2,b=3$ 时结果为 $13$，而不是想象中的 $35$。

> [!TIP]
> 解题口诀：==先原样替换，再按优先级算==。把宏调用"抄"成展开式，每一步都写清楚，答案就不会错。

## 一个完整的例子

```c
#define A(x) x*x
#define B(x,y) A(x)-A(y)
```

执行 `z = B(3, 2-3);`：

$$B(3,\ 2-3) \rightarrow A(3)-A(2-3) \rightarrow 3*3-2-3*3 = 9-2-9 = -2$$

所以 $z=-2$。注意 `A(2-3)` 展开为 `2-3*2-3`，而不是 $(2-3)^2$——再次说明==文本替换不会先算实参==。
