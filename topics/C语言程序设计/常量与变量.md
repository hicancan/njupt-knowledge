# 常量与变量的概念

## 常量与变量

在编写程序时，我们处理的各种数据，有些是固定不变的，有些则会随着程序的运行而改变。这就引出了 C 语言中两个最基础的概念：==常量与变量==。

### 为什么需要区分它们？

想象一下，你正在编写一个计算圆面积的程序。圆周率 π 的值（3.14159...）在整个计算过程中永远不变，而圆的半径可能需要根据用户输入而变化。把 π 定义为“常量”，把半径定义为“变量”，能让程序逻辑更清晰、更安全。

> [!IMPORTANT]
> **常量**：程序执行过程中其值**不可改变**的量。
> **变量**：程序执行过程中其值**可以改变**的量。

### 常量：两种表现形式

在 C 语言中，常量有两种“打扮”方式：

1.  **字面常量**：直接写出值的常量，一看便知。
    *   `10`、`-5` 是整型常量。
    *   `3.14`、`-2.5` 是实型常量。
    *   `'A'`、`'6'` 是字符型常量。
    *   `"Hello"` 是字符串常量。

2.  **符号常量**：用一个名字（标识符）来代表一个常量，需用 `#define` 定义。这属于编译预处理，编译时会进行宏替换。
    ```c
    #define PI 3.14159  // 注意：行末没有分号
    ```

### 字面常量详解：种类与常见陷阱

C 语言中的字面常量看似简单，但格式要求严格，是考试的常客。

**1. 整型常量**
三种进制表示，必须合法。十进制就是普通数字，八进制和十六进制则需特殊前缀。
*   十进制：`137`
*   八进制：必须以 `0` 开头，如 `0211`。
*   十六进制：必须以 `0x` 或 `0X` 开头，如 `0xA3`。
*   后缀：可在常量后加 `L`(l) 或 `U`(u) 表示长整型或无符号型，如 `10L`、`10u`。

**2. 实型常量**
只能是十进制，有且仅有两种表示形式：
*   **小数形式**：==必须要有小数点==，但小数点前或后的数字可以省略。如 `123.`、`.456`。
*   **指数形式**：`E`(e) 前必须是合法的数字，`E` 后必须是==合法的整数==。如 `1.2e3`（表示 $1.2 \times 10^3$）是合法的，而 `e3`、`1.2e`、`1.2e3.4` 都是非法的。

> [!WARNING]
> 易错点
> `E` 后面必须是整数，不能是小数或变量。`1.2e3.4` 和 `1.2e` 都是非法的实型常量。

**3. 字符型常量**
用一对单引号 `' '` 括起来的单个字符，其值就是该字符的 ASCII 码。
*   普通字符：`'A'`（ASCII 码 65）、`'a'`（97）、`'0'`（48）。
*   转义字符：以反斜杠 `\` 开头，表示特殊含义。有三种合法形式：
    *   `'\n'`（换行，ASCII 码 10）
    *   `'\121'`（八进制转义，表示 ASCII 码值为 $1 \times 64 + 2 \times 8 + 1 = 81$ 的字符 `'Q'`）
    *   `'\xA5'`（十六进制转义，表示 ASCII 码值为 $10 \times 16 + 5 = 165$ 的字符 `'¥'`）

> [!TIP]
> 大小写转换公式
> *   小写转大写：`ch = ch - 32;`
> *   大写转小写：`ch = ch + 32;`
> 这个魔法数字 32 正是 `'a'`(97) 与 `'A'`(65) 的 ASCII 码差值。

**4. 字符串常量**
用一对双引号 `" "` 括起来的零个或多个字符序列。
*   ==字符串长度与所占字节数相差 1==。因为编译器会自动在字符串末尾添加一个空字符 `'\0'` 作为结束标志。
*   例如，字符串 `"Hello"` 的长度是 5，但它占了 6 个字节的存储空间。

### 一个算对了的例子

**填空 1**：整型常量 137 在 C 源程序中用八进制整型常量的表达形式是 ______。

**解题步骤**：
1.  明确目标：将十进制数 137 转换为八进制。
2.  使用“除 8 取余”法：
    *   $137 \div 8 = 17$ 余 **1**
    *   $17 \div 8 = 2$ 余 **1**
    *   $2 \div 8 = 0$ 余 **2**
3.  从下往上读取余数，得到 $(211)_8$。
4.  在 C 语言中，八进制常量必须加前缀 `0`。

**答案**：`0211`

### 如何正确命名标识符？

变量名、函数名、符号常量名等都属于用户自定义的标识符。命名必须遵守以下规则，否则无法通过编译：

1.  只能由**字母**(A-Z, a-z)、**数字**(0-9)和**下划线**(_)组成。
2.  ==第一个字符不能是数字==。
3.  ==不能是 C 语言的关键字==（如 `int`、`for`、`sizeof`、`return` 等）。
4.  严格区分大小写（如 `sum` 和 `Sum` 是两个不同的变量）。

合法的例子：`_count`、`data2`、`MaxValue`
非法的例子：`2data`（数字开头）、`my-data`（含减号）、`for`（关键字）
