# FILE结构体与文件指针的定义

## 为什么你打开文件前总得写 `FILE *fp`

编写程序处理数据时，我们通常从键盘读入、向屏幕输出。但如果数据量很大、或者需要反复使用，就不能只依赖终端——这时需要把数据存到磁盘的文件里。

C 语言操作文件时，必须先建立一个“管理通道”，这个通道的入口就是一个 **`FILE *` 类型的指针**。它不是文件内容本身，而是**文件在内存中的“身份证”**：记录了当前读写位置、缓冲区状态、文件结束标志等控制信息。

可以这样理解：  
- 磁盘上的文件 = 一栋大楼  
- `FILE *` 指针 = 前台给你的门禁卡  
- 后续 `fgetc`、`fread` 等操作 = 刷卡进入楼层进行具体操作  

```mermaid
flowchart LR
  A["磁盘文件"] -->|"fopen()"| B["FILE结构体（内存）"]
  B -->|"返回地址"| C["FILE *fp"]
  C -->|"传递给"| D["fread / fwrite 等"]
```

> [!IMPORTANT]
> `FILE` 结构体由 `<stdio.h>` 定义，我们**不需要手动创建或修改它的成员**，只需声明 `FILE *` 指针，然后通过 `fopen` 获得一个有效指针即可。

---

## 文件指针的定义与基本使用流程

```c
FILE *fp;                     // 1. 定义一个 FILE 指针
fp = fopen("d:\\data.txt", "r");  // 2. 打开文件，建立关联
// ...读写操作...
fclose(fp);                   // 3. 关闭文件，释放资源
```

`fopen` 根据你给出的路径和打开方式，在内存中分配一个 `FILE` 结构体并返回其地址；失败时返回 `NULL`。因此安全检查很关键：

```c
FILE *fp = fopen("d:\\data.txt", "r");
if (fp == NULL) {
    perror("打开失败");
    return -1;
}
```

> [!WARNING]
> 初学最常见的“段错误”之一：**对 `fopen` 返回的 `NULL` 指针直接进行读写**。路径不存在、权限不足、打开方式有误都会导致返回 `NULL`，必须判空。

## `FILE` 指针与“文件结束”判断

`FILE` 结构体中有一个文件结束标志。读完最后一字节后，标志被置位。`feof(fp)` 就是用来查询这个标志的：

- **还没读到末尾** → `feof(fp)` 返回 **0**  
- **已越过末尾** → `feof(fp)` 返回 ==非零值==（不是 `EOF`、不是 `NULL`）

常见坑：读循环写 `while (!feof(fp))` 会多执行一次。原因是读完最后一个数据时标志尚未置位，再读一次才触发置位。解决方案：**用读函数的返回值作为循环条件**。

```c
// 推荐写法：边读边判
while ((c = fgetc(fp)) != EOF) {
    putchar(c);
}
// 循环结束后再用 feof 判是因为读完还是出错
if (feof(fp))
    printf("\n正常结束\n");
```

> [!TIP]
> 记忆口诀：`fread` / `fwrite` 返回值是**成功读写的块数**；`fgetc` 失败返回 `EOF`；`feof` 返回 ==非零== 才表示读到末尾。

## 和“文件名”“打开方式”的关系

同一物理文件可以对应多个不同 `FILE *`，但日常操作中 **一个文件对应一个指针** 即可。打开方式决定了这个指针能做什么：

| 方式 | 含义 |
|------|------|
| `"r"` | 只读，文件必须存在 |
| `"w"` | 只写，新建或清空已有文件 |
| `"a"` | 追加，文件不存在则新建 |
| `"r+"` | 读写，文件必须存在 |
| `"w+"` | 读写，新建或清空 |
| `"rb"` / `"wb"` | 二进制读 / 写 |

不少同学混淆：**“读”用 `r`，“读写”旧文件选 `r+`，新建读写选 `w+`**。

> [!CAUTION]
> `"w"` 和 `"w+"` 都会把文件原有内容**立即清空**。仅仅想“打开并修改内容”要用 `"r+"`。

## 一个完整的例子：数据块读写并判末尾

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int score;
} Student;

int main() {
    FILE *fp;
    Student s = {"Alice", 90}, t;

    // 写入二进制数据块
    fp = fopen("record.bin", "wb");
    if (!fp) return -1;
    fwrite(&s, sizeof(Student), 1, fp);
    fclose(fp);

    // 读回并输出
    fp = fopen("record.bin", "rb");
    if (!fp) return -1;
    while (fread(&t, sizeof(Student), 1, fp) == 1) {
        printf("%s: %d\n", t.name, t.score);
    }
    if (feof(fp))
        printf("读完\n");
    fclose(fp);
    return 0;
}
```

`fread` / `fwrite` 的参数分别是：数据地址、每块字节数、块数、文件指针。它们返回成功读写的块数——用来控制循环比 `feof` 更可靠。
