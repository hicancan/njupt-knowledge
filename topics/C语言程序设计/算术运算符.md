# 算术运算符及其优先级说明

## 算术运算符是什么

算术运算符用来完成数值计算。C 语言中常见的算术运算符如下：

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加法或正号 | `3 + 2` | `5` |
| `-` | 减法或负号 | `3 - 5` | `-2` |
| `*` | 乘法 | `3 * 4` | `12` |
| `/` | 除法 | `7 / 2` | `3` |
| `%` | 求余数 | `7 % 2` | `1` |

其中，`+`、`-` 既可以作为二元运算符，也可以作为一元运算符，如 `+a`、`-a`。`%` 要求两个操作数通常都是整数，结果为除法后的余数。

> [!IMPORTANT]
> ==两个整数相除，结果仍为整数，小数部分直接舍去。==例如 `7 / 2` 等于 `3`，不是 `3.5`；若写成 `7.0 / 2`，结果才是 `3.5`。

## 为什么需要优先级

表达式中同时出现多个运算符时，必须确定计算顺序。例如：

```c
int a = 2 + 3 * 4;
```

先算加法还是乘法？根据优先级，`*` 高于 `+`，所以先算 `3 * 4`，再算加法，结果为 `14`，而不是 `20`。

常见相关运算符的优先级由高到低可概括为：

| 优先级层次 | 运算符 | 结合方向 |
|---|---|---|
| 高 | 圆括号 `()`、一元 `+`、一元 `-`、`!` | 一元运算符通常从右向左 |
| 较高 | `*`、`/`、`%` | 从左向右 |
| 较低 | 二元 `+`、`-` | 从左向右 |
| 更低 | 赋值及复合赋值，如 `=`、`+=`、`/=` | 从右向左 |
| 最低 | 逗号运算符 `,` | 从左向右 |

因此，在 `||`、`!`、`+=`、`&&` 中，优先级最高的是逻辑非 `!`。

> [!TIP]
> 记忆顺序：==括号优先，乘除取余高于加减，赋值靠后，逗号最后。==同级运算符通常按结合方向依次计算。

## 怎样正确计算表达式

先看优先级，再看同级的结合方向；有括号时先计算括号内的表达式。例如：

```c
int a = 6;
a += a - a * a;
```

计算过程如下：

1. `*` 优先：`a * a = 36`。
2. 括号意义上的右侧表达式为 `a - 36`，即 `6 - 36 = -30`。
3. `a += -30` 等价于 `a = a + (-30)`。
4. 所以 `a = 6 - 30 = -24`。

再看一个包含整数除法的例子：

```c
int a = 10, n = 7, b;
a /= (b = 4, n %= b) + 1;
```

括号内是逗号表达式：先执行 `b = 4`，再执行 `n %= b`，即 `n = 7 % 4 = 3`。逗号表达式的值是最后一个表达式的值，因此括号内结果为 `3`，加 `1` 得 `4`。最后：

```c
a = a / 4;   /* 10 / 4，整数除法，结果为 2 */
```

## 常见易错点

> [!WARNING]
> `a += b` 应理解为 `a = a + (b)` 的简洁形式，右侧整个表达式算完后再进行复合赋值，不能误算成只加上右侧第一项。

- `*` 不能省略：`2(a+b)` 不是合法表达式，应写成 `2 * (a + b)`。
- `%` 不是百分号：`7 % 4` 表示求余数，结果为 `3`。
- 整数除法会丢失小数：`10 / 4` 为 `2`，`10 / 4.0` 才为 `2.5`。
- 不要只背“先乘除后加减”：赋值、逗号、逻辑运算符也经常参与表达式，必须结合完整优先级判断。
- 对负整数使用 `/`、`%` 时，应特别留意具体语言标准规定的舍入和余数规则，不要直接套用数学直觉。

> [!NOTE]
> 优先级决定“谁先与谁结合”，括号则用于明确改变结合关系。复杂表达式中适当加括号，既能减少错误，也能提高程序可读性。
