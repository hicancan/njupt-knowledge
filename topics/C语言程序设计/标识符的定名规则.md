# 合法的用户标识符命名规则

## 标识符的本质与构成

在 C 语言中，**用户标识符**是程序员为变量、函数、数组等实体起的名字。编译器通过识别这些名字来定位内存中的数据或代码入口。你可以把它想象成变量的“身份证”，必须严格符合语法规范才能被系统认可。

一个合法的标识符必须同时满足以下三个硬性条件：
1. 由**字母**（A-Z, a-z）、**数字**（0-9）和**下划线**（_）组成。
2. **首字符**必须是字母或下划线，不能是数字。
3. 区分大小写，且不能与 C 语言的**关键字**（如 `int`, `if`, `auto` 等）重名。

> [!IMPORTANT]
> ==核心规则==：标识符只能包含 `[a-zA-Z0-9_]`，且**不能以数字开头**，**不能是关键字**。

## 常见陷阱与辨析

许多初学者容易在特殊符号和关键字上栽跟头。请观察以下对比，判断哪些是合法的：

| 候选项 | 是否合法 | 原因分析 |
| :--- | :---: | :--- |
| `_A` | ✅ | 以下划线开头，符合规则 |
| `$1*num` | ❌ | 包含非法字符 `$` 和 `*` |
| `auto` | ❌ | `auto` 是 C 语言关键字（存储类说明符） |
| `&a` | ❌ | 包含非法字符 `&` |
| `1num` | ❌ | 以数字开头 |

> [!WARNING]
> **易错点**：C 语言标准只允许字母、数字和下划线。任何其它符号（如 `$`, `@`, `#`, `&`, `*`）出现在标识符中均视为语法错误。此外，虽然大写字母（如 `G`, `K`）完全合法，但需注意 C 语言**区分大小写**，`Sum` 和 `sum` 是两个不同的标识符。

## 典型例题解析

回顾南邮考题中的经典案例：

**题目**：下列选项中，合法的用户自定义标识符是？
- A. `$1^{*}\mathrm{num}$`
- B. `auto`
- C. `_A`
- D. `&a`

**推导过程**：
1. 检查 A：含有 `$` 和 `*`，非法字符，排除。
2. 检查 B：`auto` 是 C 语言保留关键字，用于声明自动变量，不能作为用户标识符，排除。
3. 检查 D：含有 `&`，非法字符，排除。
4. 检查 C：由下划线和字母组成，以下划线开头，非关键字，**合法**。

因此，正确答案为 **C**。

再看另一道关于语法的题目，虽然主要考察函数声明，但也涉及标识符的使用语境：
```c
void prt_char(); // 声明返回 void
main(){
    int G=5, k;
    k = prt_char(G); // 试图接收返回值
}
```
这里 `prt_char` 本身是一个合法的标识符（字母+下划线）。错误不在于命名，而在于**语义矛盾**：声明为 `void`（无返回值）的函数，不能在赋值语句右侧使用。这提醒我们，标识符合法只是第一步，还需确保其使用方式符合类型系统规则。

> [!TIP]
> **记忆口诀**：字数下划可组合，数字打头绝不行；特殊符号全禁止，关键字里莫留名。
