# 结构体变量的定义方式（含直接定义）与初始化方法

## 什么是结构体变量

结构体用于把若干**相关但类型不同**的数据组织成一个整体。例如，学生信息通常包含学号、年龄和成绩，它们的数据类型不同，却共同描述一个学生。

结构体变量就是某个结构体类型的具体对象。先声明结构体类型，再定义变量：

```c
struct stud {
    int no;
    int age;
};

struct stud vs;
```

这里：

- `struct` 是结构体类型说明关键字；
- `stud` 是结构体标签名；
- `no`、`age` 是结构体成员名；
- `vs` 是结构体变量名。

> [!IMPORTANT]
> ==标签名不等于变量名==。`stud` 表示类型，`vs` 才表示可供使用的变量。

## 为什么需要结构体

如果处理多个学生，用独立数组保存学号、年龄等数据，会导致数据对应关系容易混乱。结构体可以把属于同一对象的数据放在一起：

```c
struct stud vs;
vs.no = 1;
vs.age = 20;
```

访问成员时使用成员运算符 `.`，格式为：

```c
变量名.成员名
```

因此，上题中的 A 应改为 `vs.no = 1;`，D 应改为 `vs.age = 20;`。

## 如何定义结构体变量

### 先定义类型，再定义变量

这是最常见、也最便于区分标签名和变量名的方式：

```c
struct stud {
    int no;
    int age;
};

struct stud va;
struct stud vb, vc;
```

同一种类型的多个变量可以共用一条定义语句，也可以分别定义。

### 定义类型的同时定义变量

在结构体声明结束后直接写出变量名：

```c
struct stud {
    int no;
    int age;
} vs;
```

此时 `vs` 在声明后立即被定义，适合后续需要立即使用的场合。

若暂时不需要 `stud` 这个标签，还可以使用匿名结构体：

```c
struct {
    int no;
    int age;
} vs;
```

> [!NOTE]
> 匿名结构体没有独立的类型名，之后不能再直接写 `struct stud va;`。本课程考试中通常优先采用“标签名 + 变量”的写法。

## 如何初始化结构体变量

结构体初始化使用初始化列表，各成员按声明顺序依次赋值：

```c
struct stud {
    int no;
    int age;
};

struct stud va = {1, 20};
```

含义是：

```c
va.no  = 1;
va.age = 20;
```

也可以在定义类型时直接定义并初始化变量：

```c
struct stud {
    int no;
    int age;
} vs = {1, 20};
```

> [!IMPORTANT]
> 初始化列表中的值必须与成员在结构体中的==声明顺序一致==，不能根据成员名称自动匹配。

## 结构体数组的初始化

结构体数组的每个元素都是一个结构体，初始化时按“元素顺序、成员顺序”依次填写：

```c
struct person {
    char name[9];
    int age;
};

struct person student[10] = {
    "John", 17,
    "Paul", 19,
    "Mary", 1,
    "Adam", 16
};
```

其中 `student[0]` 保存 `"John"` 和 `17`，`student[1]` 保存 `"Paul"` 和 `19`，依此类推。未显式初始化的元素，其成员会被初始化为对应类型的零值。

访问结构体数组元素的成员时，需要连续使用成员运算符：

```c
student[2].name[0]   // 'M'
student[2].name[1]   // 'a'
student[2].age      // 1
```

## 易混概念辨析

| 写法 | 含义 | 是否正确 |
|---|---|---|
| `struct stud va;` | 定义 `stud` 类型的变量 `va` | 正确 |
| `stud va;` | 把标签当类型名直接使用 | 标准 C 中不正确 |
| `stud.no = 1;` | 把标签名当成变量 | 错误，应为 `vs.no` |
| `vs.stud.age` | 把标签当成 `vs` 的成员 | 错误，应为 `vs.age` |
| `struct vt = {1, 20};` | 把结构体变量当成类型定义 | 错误 |

> [!TIP]
> 看到 `struct ex { ... } example;`，先划分三部分：`struct` 是关键字，`ex` 是标签，`example` 才是变量。因此“`example` 是结构体类型名”这一说法错误。

## 一个算对了的例子

```c
struct ex {
    int x;
    float y;
    char z;
} example;
```

若要定义并初始化该类型的变量，可以写：

```c
struct ex a = {1, 2.5f, 'A'};
```

若变量已在别处定义，则应写：

```c
a.x = 1;
a.y = 2.5f;
a.z = 'A';
```

其中，字符成员必须用单引号表示，浮点常量最好带 `f` 后缀，避免先按 `double` 类型转换再存入 `float` 成员。
