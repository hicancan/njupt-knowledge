# Gouraud Shading双线性光强插值 (Gouraud Shading)

## 它是什么，为什么需要

==Gouraud 着色（Gouraud Shading）== 是在**多边形内部**做明暗处理的一种方法：先在**每个顶点**用完整光照模型（如 Phong 模型）算出光强 $I$，然后在三角形内部对顶点光强做**双线性插值**，得到每一点的光强。它由 Henri Gouraud 于 1971 年提出，也叫 *intensity interpolation shading*（光强插值着色）。

上一章的**平面明暗处理**（flat shading）对整个多边形只用一个光强，多边形之间会有明显的"棱"。想一想：棱从哪来？来自多边形边界的**光强不连续**。如果让光强在顶点之间平滑过渡，棱就没了——这正是 Gouraud 的思路。

## 怎么做

以一个三角形 $P_1P_2P_3$ 为例：

1. **算顶点光强**：对每个顶点，用 Phong 模型计算 $I_i = I_aK_a + I_pK_d\cos\theta_i + I_pK_s\cos^n\phi_i$。注意 $\cos\theta_i$ 需要该顶点的**法向量**——如果面片是多边形，通常用周围共顶点多边形法向量的平均作为顶点法向量。
2. **边上插值**：给定扫描线与边的交点 $P$，按线段比例插值
   $$I = I_1 + (I_2 - I_1)\frac{y - y_1}{y_2 - y_1}$$
3. **面内插值**：在扫描线上，对左右两个交点的光强再做一次线性插值。

```mermaid
flowchart LR
    A["顶点法向量"] --> B["Phong 算 I"]
    B --> C["边上插值"]
    C --> D["扫描线插值"]
    D --> E["像素光强"]
```

> [!IMPORTANT]
> ==Gouraud 只插值光强 I，不插值法向量==；每点光强再乘上颜色分量得到最终颜色。

## 与相邻概念的区别

| 方法 | 插值对象 | 速度 | 效果 / 代价 |
|---|---|---|---|
| 平面着色 | 不插值，面内常数 | 最快 | 有棱角 |
| **Gouraud** | **光强 $I$** | **较快** | **有马赫带，无高光细腻度** |
| Phong 着色 | 法向量 $\mathbf N$ | 较慢 | 高光更真实 |

Phong 着色把插值对象从 $I$ 换成 $\mathbf N$，再对每点重算光照，高光形状更好，但每像素都要跑一遍 Phong 公式，代价高。

> [!WARNING]
> **马赫带（Mach band）**：人眼在光强一阶导数不连续处会"看到"亮带或暗带。Gouraud 在多边形边界处 $I$ 连续但 $\partial I/\partial x$ 不连续，因此仍有马赫带。
> **高光问题**：若高光区域只覆盖一个顶点，插值会把高光抹平甚至消失；若高光中心落在多边形内部，插值完全无法产生高光。

## 一个算对了的例子

三角形顶点 $P_1(0,0,I_1=10)$、$P_2(10,0,I_2=30)$、$P_3(0,10,I_3=20)$，求点 $P(3,4)$ 的光强。

重心坐标：$u=1-0.3-0.4=0.3,\ v=0.3,\ w=0.4$（沿 $P_1P_2$ 走 $0.3$，沿 $P_1P_3$ 走 $0.4$）。

$$I_P = uI_1 + vI_2 + wI_3 = 0.3\times10 + 0.3\times30 + 0.4\times20 = 3+9+8 = 20$$

> [!TIP]
> 三边形双线性插值 ==本质上是重心坐标插值==；扫描线算法里把它拆成"边上插值 + 扫描线上插值"两次线性插值，结果一致但更适合光栅化流水线。

> [!NOTE]
> 延伸辨析：Gouraud 的插值可以在**世界坐标系**或**屏幕坐标系**下做。透视投影下屏幕插值会有纹理/明暗畸变，严格做法是做 $w$ 加权的透视校正插值；明暗插值的畸变通常不如纹理明显，多数场合忽略。
