# RGB与HSV颜色模型 (RGB & HSV Color Models)

好的，我们开始讲解“RGB与HSV颜色模型”这个知识点。

先思考一个问题：给你一组 RGB 数值 (255, 0, 0)，你马上知道它是纯红色。但如果我问你“粉红色”或“暗红色”在 RGB 里该怎么调？你可能需要同时调整 R、G、B 三个值。对于人来说，这样描述颜色是不是有点反直觉？

这恰恰就是我们需要两种颜色模型的原因。

## 为什么需要两种模型

- **RGB 是“设备导向”的模型**
  它直接对应显示器、相机等电子设备的物理结构。通过混合==红、绿、蓝三基色光==来产生颜色，是一种**加色模型**。计算光照、纹理混合时，我们直接在 RGB 空间做线性运算，效率最高。但它不贴合人类对“色调”、“鲜艳度”、“明暗”的直觉。

- **HSV 是“用户导向”的模型**
  它将颜色描述为人类更易理解的三个维度：
  - **Hue (色调):** 颜色的种类，如红、绿、蓝，用角度 0°~360° 表示。
  - **Saturation (饱和度):** 颜色的纯度或鲜艳程度。S=0 是灰色，S=1 是纯色。
  - **Value (明度):** 颜色的明暗程度。V=0 是纯黑，V=1 是纯色/最亮。
  
  ==HSV 模型将颜色的色彩信息（H, S）与强度信息（V）分离开来。==

> [!IMPORTANT]
> 在真实感图形学的光照与着色计算中，必须使用 RGB 模型。但设计调色盘、进行颜色增强（如只让红色更鲜艳）等交互操作时，在 HSV 空间调整会更直观。

## RGB 与 HSV 的相互转换

在考试和实践中，你只需要掌握一种最典型的转换算法。

**转换的目标**：给定一个 RGB 值，其中 R, G, B 的范围均归一化到 $[0, 1]$，求对应的 H, S, V。

**算法步骤**:

1.  **计算明度 V**：取 RGB 中的最大值。
    $$V = \max(R, G, B)$$

2.  **计算饱和度 S**：根据最大值是否为 0 来判断。
    $$S = \begin{cases} 
    0, & \text{if } V = 0 \\
    \frac{V - \min(R, G, B)}{V}, & \text{otherwise}
    \end{cases}$$

3.  **计算色调 H**：根据饱和度是否为 0 和哪个通道是最大值分情况讨论。
    - 若 $S = 0$，则 H 无定义（约定为 0）。
    - 若 $S \neq 0$，先计算一个中间色调 $H'$。令 $\Delta = V - \min(R, G, B)$。
    $$H' = \begin{cases}
    \frac{G - B}{\Delta}, & \text{if } V = R \\
    \frac{B - R}{\Delta} + 2, & \text{if } V = G \\
    \frac{R - G}{\Delta} + 4, & \text{if } V = B
    \end{cases}$$
    - 最后将 $H'$ 转换到 $[0^\circ, 360^\circ)$ 范围：
    $$H = H' \times 60^\circ$$
    若计算结果 $H < 0$，则 $H = H + 360^\circ$。

## 一个算对了的例子

题目：将 RGB 颜色 (0.2, 0.4, 0.8) 转换为 HSV 模型。

1.  **找最值**
    $V = \max(0.2, 0.4, 0.8) = \mathbf{0.8}$
    $\min = 0.2$

2.  **计算饱和度 S**
    $\Delta = V - \min = 0.8 - 0.2 = 0.6$
    $S = \frac{\Delta}{V} = \frac{0.6}{0.8} = \mathbf{0.75}$

3.  **计算色调 H**
    因为 $V = 0.8 = B$ (蓝色通道值最大)，使用第三个公式：
    $H' = \frac{R - G}{\Delta} + 4 = \frac{0.2 - 0.4}{0.6} + 4 = \frac{-0.2}{0.6} + 4 \approx -0.333 + 4 = 3.667$
    $H = H' \times 60^\circ = 3.667 \times 60^\circ = \mathbf{220^\circ}$

**结果**：此颜色的 HSV 值为 **(220°, 0.75, 0.8)**。这在视觉上是一个饱和度较高、较明亮的蓝色。

> [!WARNING]
> **常见误区**：在做题时，一定要先归一化！如果题目给的 RGB 在 $[0, 255]$ 范围，必须先除以 255，转换到 $[0, 1]$ 区间，再进行上述计算，否则 S 和 H 的结果会是错的。

## 两种模型的对比总结

| 特性 | RGB颜色模型 | HSV颜色模型 |
| :--- | :--- | :--- |
| **描述方式** | 基于三基色光的混合量 | 基于色调、饱和度、明度 |
| **面向对象** | ==硬件设备（显示器、扫描仪）== | ==人类直觉（艺术家、设计师）== |
| **坐标轴意义** | 红、绿、蓝的强度 | 颜色的种类、纯度、明暗 |
| **几何形状** | 单位立方体 (Cube) | 六棱锥 (Hexcone) 或圆锥体 |
| **核心应用** | **光照计算、纹理存储、视频编码** | **调色板、颜色选择器、图像编辑** |
