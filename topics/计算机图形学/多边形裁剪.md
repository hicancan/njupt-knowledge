# Sutherland-Hodgman多边形裁剪算法 (Sutherland-Hodgman Polygon Clipping)

## 为什么要裁剪

在二维观察流水线中，世界坐标下的场景经过窗口到视区的变换后，有些图元会部分或全部落在视区之外。如果直接渲染这些超出边界的图元，不仅浪费计算资源，还可能破坏显示结果。Sutherland-Hodgman 算法就是对多边形进行边界裁剪的经典方法。

## 核心思想

==将多边形关于一条裁剪边界的裁剪，转化为将多边形的每条边依次送入一个“黑盒”，黑盒根据边与裁剪边界的关系输出 0、1 或 2 个顶点。==

对矩形裁剪窗口的四条边（左、右、下、上）依次执行这一过程：每次裁剪的输出顶点序列作为下一次裁剪的输入。

```mermaid
flowchart LR
    A["输入多边形"] --> B["左边界裁剪"]
    B --> C["右边界裁剪"]
    C --> D["下边界裁剪"]
    D --> E["上边界裁剪"]
    E --> F["输出裁剪后多边形"]
```

## 边的四种情况与顶点输出规则

将多边形的一条边从起点 S 到终点 P 送入裁剪器，S 和 P 各自可能在裁剪边界的内部或外部。记裁剪边界内侧为“可见侧”，则共有四种情况：

| 情况 | S 位置 | P 位置 | 输出顶点 |
|------|--------|--------|----------|
| Case 1 | 内侧 | 内侧 | P |
| Case 2 | 内侧 | 外侧 | 交点 I |
| Case 3 | 外侧 | 外侧 | 无 |
| Case 4 | 外侧 | 内侧 | 交点 I，P |

> [!IMPORTANT]
> 裁剪过程不是直接丢弃整个多边形，而是一条边一条边地处理。==每个裁剪阶段只关注当前边两端点相对于“当前这条裁剪边界”的位置关系。==

## 一步步推演

对于某条裁剪边界（例如左边界 x = x_min）：

1. 取多边形顶点序列中相邻两点构成有向线段 $P_i \to P_{i+1}$（注意闭合：最后一点与第一点相连）。
2. 判断起点 $P_i$ 是否在可见侧（x ≥ x_min）；终点 $P_{i+1}$ 是否在可见侧。
3. 若 $P_i$ 与 $P_{i+1}$ 一内一外，求线段与裁剪边界的交点 $I$：
   - 用参数方程 $P = P_i + t(P_{i+1} - P_i)$，$t \in [0,1]$
   - 对左边界 $x = x_{min}$：$t = \frac{x_{min} - x_i}{x_{i+1} - x_i}$
   - 交点坐标：$I = (x_{min},\ y_i + t(y_{i+1} - y_i))$
4. 按上表规则，将该输出的顶点追加到输出列表。

处理完多边形所有边后，得到的输出顶点序列就是关于该边界裁剪后的多边形。将它作为下一条边界的输入，重复直到四边裁剪完毕。

> [!TIP]
> 记忆口诀：==“内→内 留终点，内→外 留交点，外→外 全不要，外→内 交点到终点。”==

## 与 Liang-Barsky 算法的区别

| 算法 | 处理对象 | 裁剪策略 | 适用场景 |
|------|---------|---------|---------|
| Sutherland-Hodgman | 多边形 | 依次用裁剪窗口边界面裁剪 | 多边形裁剪 |
| Liang-Barsky | 线段 | 参数方程直接计算有效区间 | 线段裁剪 |

Sutherland-Hodgman 可用于对多边形填充区域的裁剪，而 Liang-Barsky 仅处理单条线段。

## 一个算对的例子

设裁剪窗口为 $x_{min}=1,\ x_{max}=4,\ y_{min}=1,\ y_{max}=4$。
多边形顶点序列：$A(0,0),\ B(3,0),\ C(3,3),\ D(0,3)$（一个正方形）。

**关于左边界 x=1 裁剪：**

依次处理边：
- $A(0,0) \to B(3,0)$：S 外 P 内 → Case 4 → 求交点 $I_1$，输出 $I_1, B$
  - $t = (1-0)/(3-0) = 1/3$，$I_1 = (1,\ 0+1/3×0) = (1,0)$
- $B(3,0) \to C(3,3)$：S 内 P 内 → Case 1 → 输出 $C$
- $C(3,3) \to D(0,3)$：S 内 P 外 → Case 2 → 求交点 $I_2$，输出 $I_2$
  - $t = (1-3)/(0-3) = 2/3$，$I_2 = (1,\ 3+2/3×(3-3)) = (1,3)$
- $D(0,3) \to A(0,0)$：S 外 P 外 → Case 3 → 无输出

左边界裁剪后顶点序列：==(1,0), (3,0), (3,3), (1,3)==。恰好是左边界截取后的矩形。

再依次通过右、下、上边界裁剪，该多边形完全在窗口内，结果不变。

> [!WARNING]
> 如果多边形顶点顺序不是逆时针或顺时针一致性环绕，裁剪结果可能在退化为一条边时出现重复顶点。此外，==对于凹多边形，Sutherland-Hodgman 会产生多余的重叠边界线段==，这时应改用 Weiler-Atherton 算法。
