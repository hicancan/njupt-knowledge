# 三次样条插值 (Cubic Spline Interpolation)

## 什么是三次样条插值

给定 $n+1$ 个数据点 $(x_i, y_i)$，能否找到一条曲线既穿过所有点，又保证整体光滑？如果用单个高次多项式，会出现剧烈振荡；如果用分段线性插值，转折点处不可导。==三次样条插值==正是解决这一矛盾的方案：它用**分段三次多项式**连接相邻点，并强制拼接处满足 $C^2$ 连续性（函数值、一阶导、二阶导均连续）。

> [!IMPORTANT]
> 核心定义：每段 $S_i(x) = a_i + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3$，全局 $C^2$ 连续且过所有控制点。

## 为什么需要它

对比其他插值方法，三次样条在“平滑度”与“计算稳定性”间取得了最佳平衡：

| 方法 | 连续性 | 缺点 |
| :--- | :--- | :--- |
| Lagrange | $C^\infty$ | 高次Runge现象，震荡严重 |
| 分段线性 | $C^0$ | 折线感强，不可导 |
| Hermite | $C^1$ | 需额外指定每个点的导数值 |
| ==Cubic Spline== | ==$C^2$== | ==无需预设导数，自然光滑== |

> [!NOTE]
> 图形学中相机路径、骨骼动画关键帧插值首选 Cubic Spline，因其加速度连续，运动无突变感。

## 如何构造

设 $h_i = x_{i+1} - x_i$，记 $M_i = S''(x_i)$ 为各节点二阶导数。利用 $C^2$ 条件可导出关于 $M_i$ 的三对角线性方程组：

$$
\frac{h_{i-1}}{6}M_{i-1} + \frac{h_{i-1}+h_i}{3}M_i + \frac{h_i}{6}M_{i+1} = \frac{y_{i+1}-y_i}{h_i} - \frac{y_i-y_{i-1}}{h_{i-1}}
$$

```mermaid
flowchart LR
    A["列出方程组"] --> B["补边界条件"]
    B --> C["解三对角阵"]
    C --> D["回代求系数"]
    D --> E["得各段Si(x)"]
```

> [!WARNING]
> 仅靠内部点只能列 $n-1$ 个方程，必须补充2个边界条件才能求解 $n+1$ 个未知量 $M_0 \sim M_n$。

常见边界类型：

- **Natural Spline**：$M_0 = M_n = 0$（端点曲率为零）
- **Clamped Spline**：指定 $S'(x_0)$ 和 $S'(x_n)$
- **Not-a-Knot**：$S'''$ 在 $x_1, x_{n-1}$ 处也连续

## 一个算对的例子

已知三点 $(0,0), (1,2), (2,1)$，求 Natural Cubic Spline。

1. $h_0=h_1=1$，右端差商：$\frac{2-0}{1}-\frac{0-?}{?}$ → 对 $i=1$：$\frac{1-2}{1}-\frac{2-0}{1}=-3$
2. Natural 边界：$M_0=M_2=0$，代入方程得 $\frac{1}{3}(2)M_1 = -3 \Rightarrow M_1 = -4.5$
3. 回代第一段系数：
   $$a_0=0,\quad b_0=\frac{2-0}{1}-\frac{1(-4.5)}{6}=2.75,\quad c_0=0,\quad d_0=\frac{-4.5-0}{6}=-0.75$$
4. 故 $S_0(x)=2.75x - 0.75x^3$，验证：$S_0(0)=0✓$，$S_0(1)=2✓$，$S_0''(1)=-4.5=M_1✓$

> [!TIP]
> 考试常考 Natural 或 Clamped 边界；务必先写清边界类型再列方程，否则方程组不封闭。

## 常见的坑

> [!CAUTION]
> 混淆“样条”与“Bézier/B-Spline”：Cubic Spline **必过所有控制点**；Bézier/B-Spline 一般只过首末点，中间点仅起牵引作用。题目问“interpolation”选 Spline，问“approximation”才考虑后者。

> [!WARNING]
> 等距节点时 $h_i$ 可约简，但不等距时必须保留 $h_i$ 参与运算，直接套用等距公式会出错。
