# 统计学习三要素（模型、策略、算法）

统计学习的核心公式可以概括为：$\text{方法} = \text{模型} + \text{策略} + \text{算法}$。面对海量数据，我们如何保证学到的规律既准确又泛化？这三要素正是构建任何机器学习系统的“骨架”。

## 三要素的内涵与关系

- **模型（Model）**：即==假设空间==，定义了我们要学习的函数形式。在监督学习中，它表现为决策函数 $Y=f(X)$ 或条件概率分布 $P(Y|X)$。
- **策略（Strategy）**：即==评价准则==，用于从假设空间中筛选最优模型。核心是最小化风险函数，包括经验风险最小化（ERM）和结构风险最小化（SRM）。
- **算法（Algorithm）**：求解最优化问题的具体计算步骤。若目标函数有解析解则直接求解，否则需迭代近似。

```mermaid
flowchart LR
    A["模型: 假设空间"] --> B["策略: 评价准则"]
    B --> C["算法: 最优化求解"]
    C --> D["最优模型 f*"]
```

> [!IMPORTANT]
> ==策略是连接模型与算法的桥梁==。没有策略，模型只是候选集合；没有算法，策略无法落地。三者缺一不可，共同构成完整的统计学习方法。

## 策略的选择：ERM 与 SRM

为什么不能只追求训练误差最小？因为经验风险最小化容易导致过拟合。结构风险最小化通过引入正则化项（罚项）来平衡拟合能力与模型复杂度：

$$
\min_{f \in \mathcal{F}} \left[ \frac{1}{N}\sum_{i=1}^{N} L(y_i, f(x_i)) + \lambda J(f) \right]
$$

其中 $L$ 为损失函数，$J(f)$ 为模型复杂度惩罚项，$\lambda$ 控制权衡。==SRM 等价于正则化==，是防止过拟合的关键策略。

> [!TIP]
> 记忆口诀：“经验看当下，结构顾长远”。ERM 只看训练集表现，SRM 兼顾泛化能力，实际应用中几乎总是优先选择 SRM。

## 生成模型 vs 判别模型

在模型层面，监督学习分为两类，其本质区别在于是否建模联合分布：

| 对比维度 | 生成模型 | 判别模型 |
| :--- | :--- | :--- |
| 学习目标 | 联合分布 $P(X,Y)$ | 条件分布 $P(Y\|X)$ 或 $f(X)$ |
| 典型方法 | 朴素贝叶斯、HMM | SVM、Logistic回归、决策树 |
| 收敛速度 | 样本少时更快 | 通常需要更多数据 |
| 隐变量处理 | 支持 | 不支持 |
| 还原能力 | 可还原 $P(X,Y)$ | 不可还原 |

> [!NOTE]
> 生成模型能还原联合分布，因此在存在隐变量或需要数据生成任务时不可替代；判别模型直接建模决策边界，通常在分类准确率上更具优势。

## 常见误区与正确示例

> [!WARNING]
> 混淆“模型”与“算法”：模型是函数的数学形式（如线性函数），算法是求解参数的过程（如梯度下降）。同一模型可用不同算法求解，同一算法也可用于不同模型。

**算对示例**：用逻辑回归做二分类。  
- 模型：$P(Y=1|X) = \sigma(w^Tx + b)$  
- 策略：结构风险最小化，损失为交叉熵 + L2正则 $\lambda \|w\|^2$  
- 算法：梯度下降迭代更新 $w, b$  

若仅用交叉熵（ERM）且特征维数高，易过拟合；加入 L2 项（SRM）后测试准确率提升，验证了策略选择的必要性。
