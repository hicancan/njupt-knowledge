# 数据结构的基本概念

数据结构研究数据元素之间的关系，以及这些关系在计算机中的表示和运算。Wirth 的概括是：**程序 = 算法 + 数据结构**。

- **逻辑结构**：与计算机无关，只看元素之间的关系。四类：集合、线性结构、树结构、图结构。
- **存储结构**（物理结构）：逻辑结构在计算机中的表示，主要有顺序存储和链接存储，另有索引、散列。
- **运算**：定义在逻辑结构上，实现依赖存储结构。
- **抽象数据类型（ADT）**：数据结构加上定义在它上面的一组运算，只规定“做什么”，不规定“怎么做”。

易错：逻辑结构**不依赖**存储结构；同一逻辑结构可以有不同的存储结构。
