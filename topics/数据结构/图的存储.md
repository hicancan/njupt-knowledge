# 图的基本概念与存储结构

- $n$ 个顶点的**无向完全图**有 $n(n-1)/2$ 条边，**有向完全图**有 $n(n-1)$ 条边。
- **连通图**：无向图任意两顶点有路径；**强连通图**：有向图任意两顶点互相可达，$n$ 个顶点至少 $n$ 条边（成环）。
- **邻接矩阵**：$A[i][j]$ 表示是否有边（或权值）。无向图的邻接矩阵**对称**；$n$ 个顶点的无向连通图至少有 $2(n-1)$ 个非零元。
- **邻接表**：每个顶点一个边结点链表（`adjVex`、`w`、`nextArc`）。有向图中顶点的**出度**是其链表长度，**入度**要扫描所有链表统计 `adjVex` 等于它的边结点数。有向完全图的邻接表有 $n(n-1)$ 个边结点。
