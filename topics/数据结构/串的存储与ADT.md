# 字符串的抽象数据类型（ADT）与顺序存储表示

## 字符串是什么，为什么要单独定义

字符序列在文本处理、模式匹配、编译原理中无处不在。C++ 的 `char[]` 或 `string` 只是**实现手段**，而数据结构关心的是"字符串上能做什么操作、操作满足什么约束"——这就是 ADT 的意义：==把"能做什么"和"怎么存"分开==。

先想一个问题：给你两个字符串 `s = "nanjing"` 和 `t = "you"`,你要拼接、求子串、比较大小——这些操作的**输入输出**是什么？哪些操作是"基本"的，哪些可以由基本操作组合出来？ADT 就是回答这套规范。

## 字符串 ADT

ADT 4.3 把字符串抽象为字符的有限序列，数据对象 $D=\{a_i \mid a_i \in \text{字符集}, i=1,2,\dots,n,\ n\ge 0\}$，数据关系 $R=\{\langle a_{i-1},a_i\rangle\}$。基本操作通常包括：

| 操作 | 含义 |
|---|---|
| `StrAssign(s, chars)` | 由常量生成串 |
| `StrCopy(s, t)` | 串复制 |
| `StrLength(s)` | 求串长 |
| `Concat(s, t)` | 串连接 |
| `SubString(sub, s, pos, len)` | 求子串 |
| `StrCompare(s, t)` | 按字典序比较 |
| `Index(s, t, pos)` | 模式匹配（定位子串） |
| `StrInsert / StrDelete` | 插入、删除子串 |

> [!IMPORTANT]
> 串长为 0 时称为**空串** `""`，它与**空格串** `" "`（长度为 1）完全不同；子串位置从 1 开始计数，这是数据结构教材与 C++ 下标（从 0 开始）的常见差异点。

## 顺序存储表示

串的顺序表示直接用 C++ 一维字符数组描述：

```cpp
#define MAXLEN 255
struct SString {
    char ch[MAXLEN + 1];  // ch[0] 闲置或存长度
    int length;
};
```

另一种方案是 `ch[0]` 存放串长（Pascal 风格），牺牲一个字符位置换取 $O(1)$ 取长度。动态分配则按需 `new`，避免定长数组截断。

## 和数组 ADT 的关系与区别

数组是"同类型元素的定长矩形块"，稀疏矩阵是其压缩特例；字符串可视为**元素类型固定为字符、长度可变的特殊线性表**。顺序串的插入删除需要移动元素，时间 $O(n)$，这是顺序存储的共性代价。

> [!WARNING]
> 易错点：`SubString(sub, s, pos, len)` 中必须检查 $1 \le pos \le StrLength(s)$ 且 $0 \le len \le n-pos+1$，否则子串越界；`StrCompare` 按 ASCII 逐字符比较，遇到不同字符立即返回，而非比较长度。

## 一个算对了的例子

设 `s = "STRUCTURE"`（长度 9），执行：

- `SubString(sub, s, 3, 4)`：从第 3 个字符起取 4 个，得 `sub = "RUCT"`；
- `Index(s, "TRU", 1)`：从位置 1 起找 `"TRU"`，首次出现在第 4 位，返回 4；
- `Concat("DATA", "STRUCTURE")` 得 `"DATASTRUCTURE"`，长度 13。

==记住：ADT 定义操作规范，顺序存储用字符数组落地，二者是"接口"与"实现"的分离。==
