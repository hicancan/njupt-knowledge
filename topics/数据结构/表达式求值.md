# 中缀表达式与后缀表达式

后缀表达式（逆波兰式）把运算符写在运算对象之后，不需要括号，用一个栈就能求值。

**中缀转后缀**：从左到右扫描，运算对象直接输出；运算符与栈顶比较优先级，栈顶优先级不低于当前运算符时先弹出输出，再把当前运算符进栈；左括号进栈，遇右括号弹出到左括号为止。

- `a*b+c/d` → `a b * c d / +`
- `(a+b)*c+d/(e+f)` → `a b + c * d e f + / +`

**后缀求值**：遇运算对象进栈，遇运算符弹出两个对象计算后把结果进栈，最后栈中只剩结果。
