# 堆栈

只允许在一端（栈顶）插入和删除的线性表，**后进先出**（LIFO）。

- 顺序栈：`top` 指向栈顶元素；空栈 `top == -1`，满栈 `top == maxSize-1`。
- 链式栈：在链表头部进出。

**出栈序列的判定**：进栈顺序固定为 1、2、…、n 时，若某元素出栈，比它先进栈且还在栈中的元素必须按逆序出栈。例如 1~5 依次进栈，14523 不可能（4 出栈后 2、3 都在栈中，3 必须先于 2 出栈），14532 可以。$n$ 个元素不同出栈序列的个数是卡特兰数 $\frac{1}{n+1}\binom{2n}{n}$。
