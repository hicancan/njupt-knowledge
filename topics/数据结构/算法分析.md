# 算法与算法分析

算法是解决问题的有限步骤，具有有穷性、确定性、可行性、输入、输出五个特性。好的算法还应正确、可读、**健壮**（非法输入不会产生莫名其妙的结果）、高效。

**时间复杂度**用渐近记号 $O(f(n))$ 表示语句执行次数随规模 $n$ 增长的量级，只保留最高阶项、去掉系数：

$$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n)$$

- 两层各 $n$ 次的嵌套循环：$O(n^2)$；三层（如矩阵乘法）：$O(n^3)$。
- 循环变量每次乘 2：$O(\log n)$。
- 计算“某语句执行次数”要精确数：例如 `for (i=1;i<=n;i++) if (2*i<n) y++;` 中 `y++` 执行 $\lceil n/2\rceil - 1$ 次。

**空间复杂度**是算法所需额外存储随 $n$ 的量级。算法的优劣与描述语言、机器环境**无关**。
