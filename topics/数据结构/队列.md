# 队列与循环队列

在一端（队尾）插入、另一端（队头）删除，**先进先出**（FIFO）。

**循环队列**把顺序存储看作首尾相接，下标按模 `maxSize` 运算：

- 入队：`rear = (rear + 1) % maxSize`；出队：`front = (front + 1) % maxSize`。
- 约定 `front` 指向队头元素的前一个位置时：**队空** `front == rear`；**队满** `(rear + 1) % maxSize == front`（空出一个单元来区分空和满）。
- 元素个数：`(rear - front + maxSize) % maxSize`。
