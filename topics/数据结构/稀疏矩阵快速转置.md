# 稀疏矩阵的快速转置算法（num数组与k数组的计算）

## 稀疏矩阵的快速转置算法

在稀疏矩阵的三元组顺序表存储中，普通转置算法需多次扫描三元组表，时间复杂度为 $O(\text{cols} \times \text{terms})$。为了提升效率，引入**快速转置算法**，其核心思想是：预先计算原矩阵每一列非零元的个数及在转置后三元组表中的起始位置，从而只需**一次扫描**即可完成转置。

> [!IMPORTANT]
> 快速转置的时间复杂度为 $O(\text{cols} + \text{terms})$。若矩阵列数为 $X$，非零元数为 $Z$，则复杂度为 $O(X+Z)$。注意南邮考题中有时行/列定义不同，需根据具体变量含义判断（如前文选择题答案 D 对应 $O(Y+Z)$，通常指列数+非零元数）。

### 核心数组：num 与 k

算法依赖两个辅助数组，长度均为原矩阵的列数（即转置后的行数）：

1.  **`num[col]`**：统计原矩阵第 `col` 列中**非零元素的个数**。
2.  **`k[col]`**：指示原矩阵第 `col` 列的第一个非零元素，在转置后的三元组表中应存放的**下标位置**（通常从 0 或 1 开始，依教材约定，此处以 0 起始为例，若题目要求 1 起始需相应调整）。

$$
\begin{aligned}
num[col] &= \sum_{i=0}^{rows-1} \text{count}(M[i][col] \neq 0) \\
k[0] &= 0 \\
k[col] &= k[col-1] + num[col-1] \quad (col > 0)
\end{aligned}
$$

> [!TIP]
> `k` 数组本质是 `num` 数组的**前缀和**。`k[col]` 表示在第 `col` 列之前（不含本列）共有多少个非零元，这些元素将占据转置表的前几个位置。

### 算法流程图解

```mermaid
flowchart TD
    Start([开始]) --> Init[初始化 num/k 全0]
    Init --> Scan1[扫描三元组表<br>统计 num[col]]
    Scan1 --> CalcK[计算 k[col]<br>k[col] = k[col-1]+num[col-1]]
    CalcK --> Scan2[再次扫描三元组表]
    Scan2 --> GetElem[取元素 e<i,j,v>]
    GetElem --> Pos[k[j] 即为目标位置]
    Pos --> Store[存入转置表 T[k[j]]]
    Store --> UpdateK[k[j]++]
    UpdateK --> Check{是否遍历完?}
    Check --否--> GetElem
    Check --是--> End([结束])
```

### 常见误区与坑

*   **[!WARNING] 下标越界**：计算 `k` 数组时，注意 `k[0]` 的初始值。若三元组下标从 1 开始，`k[1]=1`，递推公式不变，但最后存储位置需对应。
*   **[!CAUTION] k 的动态更新**：在第二次扫描填充转置矩阵时，每放置一个元素，对应的 `k[col]` 必须**自增 1** (`k[col]++`)，以确保同一列的下一个非零元能放到正确位置。这是“快速”的关键，避免了查找插入点。
*   **[!NOTE] 与普通转置区别**：普通转置对原矩阵每一列，都要遍历整个三元组表寻找该列元素；快速转置通过 `k` 数组直接定位，空间换时间。

### 实例演算（基于课件简答 10）

给定稀疏矩阵 $M$（6 行 6 列），非零元三元组如下（行,列,值）：
`(0,2,12), (1,1,19), (2,0,18), (2,3,-8), (3,5,-23), (4,0,36), (4,2,14), (6,2,15)`
*(注：原题图1有7行0-6，6列0-5)*

**第一步：计算 `num[col]`**
统计每列非零元个数：
*   Col 0: `(2,0,18), (4,0,36)` $\rightarrow$ num[0] = 2
*   Col 1: `(1,1,19)` $\rightarrow$ num[1] = 1
*   Col 2: `(0,2,12), (4,2,14), (6,2,15)` $\rightarrow$ num[2] = 3
*   Col 3: `(2,3,-8)` $\rightarrow$ num[3] = 1
*   Col 4: 无 $\rightarrow$ num[4] = 0
*   Col 5: `(3,5,-23)` $\rightarrow$ num[5] = 1

**第二步：计算 `k[col]`**
假设起始下标为 0：
*   $k[0] = 0$
*   $k[1] = k[0] + num[0] = 0 + 2 = 2$
*   $k[2] = k[1] + num[1] = 2 + 1 = 3$
*   $k[3] = k[2] + num[2] = 3 + 3 = 6$
*   $k[4] = k[3] + num[3] = 6 + 1 = 7$
*   $k[5] = k[4] + num[4] = 7 + 0 = 7$

| 列号 col | 0 | 1 | 2 | 3 | 4 | 5 |
| :--- | :-: | :-: | :-: | :-: | :-: | :-: |
| **num[]** | 2 | 1 | 3 | 1 | 0 | 1 |
| **k[]** | 0 | 2 | 3 | 6 | 7 | 7 |

> [!IMPORTANT]
> 最终转置矩阵的三元组表长度为 8。例如原矩阵中 `(0,2,12)`，列号为 2，查 `k[2]=3`，故转置后存放在下标 3 的位置，随后 `k[2]` 变为 4，供该列下一个元素使用。
