# 二叉树的遍历

- **先序**：根、左、右；**中序**：左、根、右；**后序**：左、右、根；**层次**：按层从左到右（用队列）。
- 由**先序 + 中序**或**后序 + 中序**可以唯一确定一棵二叉树：先序第一个（后序最后一个）是根，在中序中找到根即可分出左右子树，递归。只有先序和后序不能唯一确定。

**递归算法模式**（统计结点数、叶结点数、高度、释放结点）：

```c
int Leaves(BTNode *t) {
    if (t == NULL) return 0;
    if (t->lChild == NULL && t->rChild == NULL) return 1;
    return Leaves(t->lChild) + Leaves(t->rChild);
}
int Height(BTNode *t) {
    if (t == NULL) return 0;
    int l = Height(t->lChild), r = Height(t->rChild);
    return (l > r ? l : r) + 1;
}
```

释放整棵树要用**后序**：先释放左右子树，再释放根。
