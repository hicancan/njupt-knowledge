# 二叉树的定义、性质与存储

二叉树是每个结点至多有两棵子树、且子树有左右之分的树。

**性质**（根在第 1 层）：
1. 第 $i$ 层至多 $2^{i-1}$ 个结点；
2. 高度为 $h$ 的二叉树至多 $2^h-1$ 个结点；
3. 叶结点数 $n_0$ 与度为 2 的结点数 $n_2$ 满足 $n_0=n_2+1$；
4. $n$ 个结点的完全二叉树高度为 $\lceil\log_2(n+1)\rceil$（推广：完全 $k$ 叉树高度为 $\lceil\log_k((k-1)n+1)\rceil$，244 个结点的完全三叉树高 6）。

**存储**：完全二叉树可以顺序存储，编号 $i$ 的结点左孩子 $2i+1$、右孩子 $2i+2$（从 0 编号）；一般用**二叉链表**，结点含 `lChild`、`element`、`rChild`，结点 `p` 是叶结点的条件是 `p->lChild == NULL && p->rChild == NULL`。
