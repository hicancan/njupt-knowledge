# 空域平滑：均值滤波与中值滤波

一个像素突然变成满亮，而周围都在同一灰度附近。怎样判定它是干扰而不是细节？只看它自己做不到。空域平滑借助邻域估计中心值，依据是相邻像素常来自同一片表面；当邻域跨越真实边缘，这个依据就会变弱。

均值滤波让每个样本贡献相同的权重。若平坦区域内各样本的噪声独立、零均值、方差为 $\sigma^2$，$n$ 点平均的噪声方差为 $\sigma^2/n$。但一旦邻域混入两侧不同亮度，平均值就可能把应当清楚的边界变成过渡带。中值滤波按灰度排序，取奇数大小窗口的中间一项；它是基于排序的非线性滤波，单个极端值不容易把结果拉走。

**自编例。** 求下面 $3\times3$ 灰度窗口的中心输出，无需规定整幅图像的边界填充：

| | | |
|---:|---:|---:|
| 100 | 99 | 101 |
| 100 | 255 | 101 |
| 99 | 100 | 102 |

均值为 $1057/9\approx117.44$；排序为 $99,99,100,100,100,101,101,102,255$，中值为第 5 项 $100$。如果中心处本应与邻域同为约 100，且 255 是孤立的盐噪声，中值更接近这一区域的水平。

把条件改一下：若 255 不是噪声，而是一条一像素宽亮线中的点，居中的 $3\times3$ 窗内可能只有 3 个亮点，其余是暗背景；中值同样会把线抹掉。中值滤波保住的是**邻域排序中占优势的结构**，并不认识真正的边缘或目标。实际比较时，先看异常像素占比和待保留结构的宽度，再决定滤波方式和窗口大小。

参考：[OpenCV 的图像平滑文档](https://docs.opencv.org/3.4.15/d4/d13/tutorial_py_filtering.html)。
