# C++用I/O流（cin/cout）实现输入/输出

## 它是什么

在 C 语言中，我们用 `scanf` / `printf` 处理输入输出——格式控制串里要手写 `%d`、`%f`，类型写错就出乱码。C++ 则换了一套思路：==把输入和输出看作"流"（stream）==，数据像水一样从键盘"流"进程序、从程序"流"到显示器。

```mermaid
flowchart LR
    KB["键盘"] -->|cin >> 提取符| PROG["程序变量"]
    PROG -->|cout << 插入符| MON["显示器"]
```

`cin` 和 `cout` 是系统预定义的 ==流类对象==：`cin` 代表**标准输入设备（键盘）**，`cout` 代表**标准输出设备（显示器）**。它们在 `<iostream>` 中声明，使用前必须做文件包含：

```cpp
#include <iostream>
using namespace std;
// 或老式写法：#include <iostream.h>
```

## 怎么用

- **输入**：`cin` 配合提取符 `>>`，格式为 `cin >> 变量1 >> 变量2 ...;`，`>>` 右边**只能跟变量**，表示把流中的数据送入这些变量。
- **输出**：`cout` 配合插入符 `<<`，格式为 `cout << 表达式1 << 表达式2 ...;`，各表达式值依次送显示器。

```cpp
char c; int a; float f;
cin >> c >> a >> f;
cout << "c=" << c << " a=" << a << " f=" << f << endl;
```

输入 `A 90 289.4` 后，屏幕输出：

```
c=A a=90 f=289.4
```

## 与 C 语言写法的对比

| 对比项 | C：`scanf`/`printf` | C++：`cin`/`cout` |
|---|---|---|
| 格式控制符 | 需手写 `%d` `%f` 等 | 不需要，自动匹配类型 |
| 出错风险 | 格式符与变量类型不符 | 由编译器类型检查保护 |
| 可扩展性 | 固定格式集 | 可重载 `<<` `>>` 为自定义类型服务 |

## 常见的坑

> [!WARNING]
> 1. 忘记写 `#include <iostream>` 及 `using namespace std;` 会导致 `cin`/`cout` 无法识别。
> 2. `>>` 后面跟**表达式**而不是变量是错误的；`<<` 后面则可以跟任意表达式。
> 3. 默认输入输出格式是十进制、自动精度；如需 `true`/`false`、进制切换等格式控制，需用**操纵符**（见第 8 章），如 `boolalpha`/`noboolalpha`、`endl`。

## 小细节：换行符 `endl`

C++ 新增换行控制符 `endl`，与 `'\n'` 等效：

```cpp
cout << "a=" << a << endl;
cout << "a=" << a << "\n";   // 效果完全一样
```

> [!NOTE]
> `endl` 除了换行还会刷新输出缓冲区；`'\n'` 只换行不强制刷新。日常练习两者等价，不必深究。

## 一个完整的例子

下面的程序演示同时使用 `cin`/`cout` 与作用域运算符访问同名全局变量（也是常见考点）：

```cpp
#include <iostream>
using namespace std;

int sum = 100;               // 全局变量

int main()
{
    int sum = 5;             // 局部变量，遮蔽全局变量
    cout << "sum=" << sum << endl;        // 5
    cout << "全局sum=" << ::sum << endl;  // 100
    return 0;
}
```

输出：

```
sum=5
全局sum=100
```

> [!TIP]
> 遇到 `cout` 连续 `<<` 多个值时，按"从左到右依次输出"理解即可；若输出结果与预期不符，优先检查变量类型、作用域遮蔽以及是否遗漏了 `endl`/`'\n'`。
