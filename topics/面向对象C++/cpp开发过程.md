# C++程序的开发过程与VC++6集成开发环境

好的，我们开始讲解。

你想运行一个 C++ 程序，让计算机理解并执行你的指令，这中间需要经过一个“翻译”和“组装”的过程。这个过程，就是 C++ 程序的开发流程。

### 从源代码到可执行文件

你的程序最初只是一些人类能读懂的文本，我们称之为**源代码**。从源代码到最终可以运行的程序，需要经过一个流水线般的处理过程，一共四步。

我先把这四步放在一张流程图里，帮你建立一个宏观印象：

```mermaid
flowchart LR
    A["编辑<br>编写.cpp源文件"] --> B["编译<br>生成.obj目标文件"]
    B --> C["链接<br>生成.exe可执行文件"]
    C --> D["运行<br>执行程序"]
```

下面我们来逐步拆解。

#### 1. 编辑
这就是你写代码的过程。你在编辑器里写下符合 C++ 语法的文本，并保存为源文件。按照约定，C++ 源文件的扩展名是 ==`.cpp`==。这也是考试中的一个常见考点。

#### 2. 编译
编译器负责将 `.cpp` 源文件翻译成机器能懂的二进制指令。编译的结果称为**目标文件**，扩展名为 ==`.obj`==。这个阶段的翻译是“逐个文件”进行的，每个 `.cpp` 文件可以单独编译成一个 `.obj` 文件。

> [!WARNING]
> 编译阶段只检查**语法错误**，比如你写错了关键字，或者少了个分号。如果你的程序调用了一个在其他文件中定义的函数，编译器此时不会报错，它只是记下一笔“欠账”，留给下一步处理。

#### 3. 链接
链接器负责把编译生成的所有 `.obj` 文件，以及程序用到的库文件（如输入输出库）中的代码“组装”起来，解决掉上一步留下的“欠账”，最终生成一个完整的**可执行文件**，扩展名为 ==`.exe`==。

> [!IMPORTANT]
> 如果在编译时只是记下了“欠账”，到了链接阶段发现到处都找不到这个函数的实现，链接器就会报错，我们称之为**链接错误**（常见提示如 `unresolved external symbol`）。

#### 4. 运行
双击生成的 `.exe` 文件，程序就被加载到内存中执行了。无论你的程序有多复杂，它总是从 ==`main()` 函数的第一条语句开始运行==。

> [!NOTE]
> 一个常见的误解是以为某个“特别重要”的函数会先于 `main` 执行。请谨记：C++ 程序的执行入口是且仅是 `main` 函数。

### 在 VC++6 集成开发环境中的实践

理解了理论，我们来看看在一个具体的工具——VC++6.0 集成开发环境（IDE）中如何操作。IDE 把编辑、编译、链接、运行等功能集成在了一起，让你不用在命令行里敲复杂的指令。

#### 单文件程序的操作步骤
对于只包含一个 `.cpp` 文件的简单程序，操作非常直接：

1.  **创建文件**：`文件` -> `新建` -> `文件` -> `C++ Source File`，填写文件名（如 `hello`），系统会自动添加 `.cpp` 后缀。
2.  **编辑代码**：在编辑区输入你的 C++ 代码。
3.  **编译链接**：点击工具栏上的 `Build` 按钮（图标像一个齿轮），或按 `F7` 键。这一步会**自动完成编译和链接**。如果成功，下方的输出窗口会显示 `hello.exe - 0 error(s), 0 warning(s)`。
4.  **运行程序**：点击工具栏上的 `Execute Program` 按钮（图标像一个红色的感叹号），或按 `Ctrl+F5` 键。程序会在一个弹出的控制台窗口中运行，并显示 `Press any key to continue`。

#### 多文件程序的操作步骤
当一个程序功能复杂，代码被分散在多个 `.cpp` 和 `.h` 文件中时，我们必须先创建一个“项目”来管理它们：

1.  **创建项目**：`文件` -> `新建` -> `工程`（Projects）-> `Win32 Console Application`。填写“工程名称”，并选择一个“位置”存放。这步会创建一个 `.dsw` 工作空间文件。
2.  **添加文件**：`工程`（Project）-> `添加到工程`（Add to Project）-> `文件`（Files）。可以添加已有的 `.cpp` 和 `.h` 文件，也可以新建。
3.  **编写代码**：在各个文件中分别编写代码。
4.  **编译链接**：同样点击 `Build` 按钮或按 `F7`。IDE 会智能地编译所有被修改过的文件，然后将项目内所有 `.obj` 文件链接成一个 `.exe` 文件。
5.  **运行程序**：点击 `Execute Program` 按钮或按 `Ctrl+F5` 运行。

> [!TIP]
> 多文件编程时，务必通过创建**项目（Project）**来管理文件。直接打开多个独立的单文件进行编译链接，是无法让它们之间互相调用的。这是新手最常遇到的坑。

### 一个算对了的例子

我们来看**填空题**：“开发 C++ 程序与其他开发高级语言的程序一样，包括编辑、编译、① 和 ② 四个步骤。”

**分析与解答**：
回忆我们的“流水线”：
1.  编写代码并保存，这是**编辑**。
2.  将源文件转换为二进制指令，生成 `.obj` 文件，这是**编译**。
3.  `.obj` 文件结合库文件，生成 `.exe` 文件，这是**链接**。
4.  执行 `.exe` 文件查看结果，这是**运行**。

所以，① 应填写 `链接`，② 应填写 `运行`。

> [!NOTE]
> 完整的开发过程四步曲顺序不可颠倒：**编辑 → 编译 → 链接 → 运行**。其中，编译和链接两个概念及其产物的文件扩展名（`.obj`, `.exe`）是高频考点。
