# 引用的概念及使用（含引用作形参、返回值及与指针区别）

## 引用是什么

引用（reference）是某个已存在变量的别名。定义引用时使用 `&`，其格式为：

```cpp
类型 &引用名 = 原变量;
```

例如：

```cpp
int k = 1000;
int &x = k;
```

这里 `x` 不是新变量，而是 `k` 的另一个名字。通过 `x` 修改值，`k` 也会改变：

```cpp
x = 2000;
cout << k;  // 2000
```

> [!IMPORTANT]
> 引用必须在定义时初始化，并且初始化后不能改为引用其他变量。

## 为什么需要引用

引用可以避免复制较大的数据，也能在函数中直接修改实参。它常用于函数形参和返回值。

### 引用作函数形参

```cpp
void change(int &x) {
    x = 100;
}

int a = 10;
change(a);
```

形参 `x` 是实参 `a` 的别名，因此函数中对 `x` 的修改会直接影响 `a`。

如果形参写成普通值类型：

```cpp
void change(int x) {
    x = 100;
}
```

函数只修改形参副本，调用结束后 `a` 不变。

### 引用作函数返回值

函数可以返回某个变量的引用：

```cpp
int &getMax(int &a, int &b) {
    return (a > b) ? a : b;
}
```

调用时可通过返回的引用继续修改原变量：

```cpp
int x = 3, y = 8;
getMax(x, y) = 10;
```

此时 `y` 变为 `10`。

> [!WARNING]
> 不要返回局部变量的引用。函数结束后局部变量已经失效，返回的引用会产生未定义行为。

## 引用与指针的区别

| 比较项目 | 引用 | 指针 |
|---|---|---|
| 初始化 | 定义时必须初始化 | 可以暂时不初始化 |
| 能否改指 | 初始化后不能改指 | 可以随时改为指向其他对象 |
| 是否需要 `*` | 使用时不需要 | 通过 `*` 解引用 |
| 是否可为 `nullptr` | 不可以 | 可以 |
| 空指针检查 | 不需要 | 通常需要 |
| 典型用途 | 形参、返回值、运算符重载 | 地址保存、动态内存、链表等 |

引用更像是“变量的另一个名字”，使用更简洁；指针则显式保存地址，控制能力更强。

> [!TIP]
> 记忆：引用必须绑定，不能换；指针可以为空，也能换。

## 常见错误辨析

```cpp
int &a[4];      // 错误：不能定义引用数组
int &*p;        // 错误：不能定义指向引用的指针
int &&q;        // 错误：&& 用于右值引用
int i, &p = i;  // 正确：p 是 i 的引用
```

题目中 `int i, &p=i;` 的定义正确，因此选 D。

对于函数原型：

```cpp
void f(int *x, long &y);
```

调用时，指针形参需要地址，引用形参直接传变量：

```cpp
int a;
long b;
f(&a, b);
```

所以应选 B。

## 综合例子

```cpp
int &select(int &a, int &b) {
    return a > b ? a : b;
}

int main() {
    int x = 5, y = 9;
    select(x, y) = 20;
    return 0;
}
```

执行后，`y` 的值变为 `20`。因为 `select` 返回的是 `y` 的引用，而不是 `y` 的副本。
