# 函数模板的定义与模板函数的使用

## 为什么需要函数模板

写 `min(int,int)`、`min(double,double)`、`min(char,char)` 时，函数体几乎一样，只是类型不同。函数模板把“类型”也变成参数：编译器根据调用实参自动生成具体函数，避免重复抄写。

## 定义与调用

```cpp
template <class T>          // 模板参数表：声明未知类型 T
T min(T x, T y)             // 函数模板：返回类型、形参都可用 T
{
    return (x < y) ? x : y;
}
```

`template` 也可写 `typename T`；多个未知类型要分别说明，如 `template<class T1, class T2>`。调用 `min(3, 5)` 时，编译器由实参推得 `T=int`，生成并调用 `int min(int,int)`；这个具体函数叫**模板函数**，生成过程叫**实例化**。也可显式写 `min<double>(3, 5)`。

```mermaid
flowchart LR
    A["函数模板"] --> B["实参类型推导"]
    B --> C["实例化"]
    C --> D["模板函数"]
    D --> E["正常调用"]
```

> [!IMPORTANT]
> ==函数模板实例化得到模板函数；类模板实例化得到模板类。==“模板函数实例化后得到函数模板”方向写反，是错误说法。

> [!WARNING]
> `template` 语句与函数模板定义之间不能插入其他语句；模板参数表只作用于紧随其后的那个函数定义。

## 类型推导的坑

模板参数 `T` 要在整个调用中保持一致。已知 `int i,j; char c;`：

| 调用 | 推导结果 | 判断 |
|---|---|---|
| `min(i,j)` | `T=int` | 正确 |
| `min(c,c)` | `T=char` | 正确 |
| `min((int)c,i)` | 两个实参均为 `int` | 正确 |
| `min(i,c)` | 一个要求 `T=int`，一个要求 `T=char` | 错误 |

因此选择题的错误项是 `min(i,c)`。想混用类型，可显式转换，如 `min((int)c,i)`，或把模板改成两个独立类型参数；但返回类型与比较规则要另行设计。

## 一个算对的例子

```cpp
template<class T1, class T2>
void sum(T1 x, T2 y)
{ cout << sizeof(x + y); }
```

调用 `sum('1', 99.0)`：`T1=char`，`T2=double`。计算 `x+y` 时，`char` 经整型提升为 `int`，再按通常算术转换与 `double` 运算，表达式类型为 `double`。故 `sizeof(x+y)=sizeof(double)=8`，输出 **8**，选 C。这里 `sizeof` 看的是==表达式结果的类型==，不是两个实参大小相加，也不是字符 `'1'` 的数值。

> [!TIP]
> 做调用判断先问两句：每个 `T` 能否从全部实参推出同一个类型？若模板含运算，运算后的表达式类型是什么？前者定“能否实例化”，后者定 `sizeof`、返回值等结果。
