# 常数据成员（const数据成员）及初始化列表

## 常数据成员是什么

在类中，如果某个数据成员的值在对象创建后==绝不允许被修改==，就应将其声明为常数据成员。其定义形式为：

```cpp
const 类型名 成员名;
```

它属于对象级别，每个对象都拥有一份独立拷贝。与普通成员不同，它在整个生命周期内保持恒定，常用于表示该类特有的不变量（如圆周率 $\pi$、缓冲区大小等）。

## 为什么必须用初始化列表

能否在构造函数体内对常数据成员赋值？答案是否定的。因为 `const` 成员一旦创建便不可更改，而构造函数体执行时对象已构造完成，此时赋值等同于修改。因此，==常数据成员的初始化只能在构造函数的初始化列表中完成==。

> [!IMPORTANT]
> 初始化列表是常数据成员唯一合法的初始化途径，函数体内赋值会导致编译错误。

```mermaid
flowchart LR
    A["对象内存分配"] --> B["初始化列表执行"]
    B --> C["const成员初始化"]
    C --> D["构造函数体执行"]
    D --> E["对象就绪"]
```

## 正确示例：圆类中的 PI

参考课件例4.3，定义 `Circle` 类时使用常数据成员表示 $\pi$：

```cpp
class Circle {
private:
    const double PI;      // 常数据成员
    double radius;
public:
    // ✅ 正确：通过初始化列表初始化PI
    Circle(double r = 0) : PI(3.1415926), radius(r) {}
    
    double area() const { return PI * radius * radius; }
    double perimeter() const { return 2 * PI * radius; }
};
```

> [!TIP]
> 若多个对象共享同一个不变量（如 $\pi$），应改用 `static const` 避免数据冗余。普通 `const` 成员每个对象都存一份，浪费内存。

## 与相近概念的区别

| 特性 | 常数据成员 | 静态常数据成员 | 全局常量 |
|------|-----------|---------------|---------|
| 作用域 | 仅本类内 | 本类内，类共享 | 文件/全局 |
| 存储方式 | 每对象一份 | 全类共享一份 | 独立存储 |
| 初始化位置 | 构造函数初始化列表 | 类外定义或C++11类内 | 定义时直接初始化 |
| 是否依赖对象 | 是 | 否 | 否 |

> [!NOTE]
> 课件明确指出：常数据成员“跟着对象走”，造成数据冗余；改进方式是定义为静态常数据成员。

## 常见陷阱与注意事项

> [!WARNING]
> 忘记在初始化列表中初始化常数据成员，编译器会报错：“uninitialized const member”。

> [!CAUTION]
> 不要试图在构造函数体或其他成员函数中对 `const` 成员赋值，即使使用 `this->PI = ...` 也非法。

> [!TIP]
> 考试高频点：选择题常考“常数据成员的初始化方式”，务必记住==只能通过初始化列表==这一唯一途径。同时注意区分 `const` 成员与 `static const` 成员的初始化语法差异，后者在 C++11 起支持类内直接初始化。
