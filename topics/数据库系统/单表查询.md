# 单表查询（SELECT、WHERE、ORDER BY、聚集函数、GROUP BY、HAVING、LIMIT）

## 单表查询：SELECT 语句的骨架

SQL 的四大功能中，**数据查询**是核心操作，动词是 `SELECT`。一条完整的单表查询语句骨架如下：

```sql
SELECT [ALL|DISTINCT] <目标列表达式>[, ...]
FROM <表名或视图名>
[WHERE <条件表达式>]
[GROUP BY <列名1> [HAVING <条件表达式>]]
[ORDER BY <列名2> [ASC|DESC]]
[LIMIT <行数1> [OFFSET <行数2>]];
```

> [!IMPORTANT]
> 只有 `SELECT` 和 `FROM` 子句是每个 SQL 查询语句所必需的，其余子句均可省略。子句书写顺序固定，不能颠倒。

各子句职责：

| 子句 | 作用 | 类比关系代数 |
|------|------|-------------|
| `SELECT` | 指定要显示的属性列 | 投影 $\Pi$ |
| `FROM` | 指定查询对象（表/视图） | 关系 $R$ |
| `WHERE` | 筛选满足条件的元组 | 选择 $\sigma$ |
| `GROUP BY` | 按列值分组，配合聚集函数 | — |
| `HAVING` | 筛选满足条件的组 | — |
| `ORDER BY` | 结果排序（升序/降序） | — |
| `LIMIT` | 限制返回行数 | — |

## WHERE：行级筛选

`WHERE` 子句作用于**基表或视图**，从中选择满足条件的元组。常见条件形式：

```sql
-- 比较
SELECT Sname, Ssex FROM Student WHERE Smajor = '计算机科学与技术';

-- 范围（BETWEEN AND）
SELECT Sname FROM Student
WHERE extract(year from current_date) - extract(year from Sbirthdate) BETWEEN 18 AND 20;

-- 集合（IN / NOT IN）
SELECT Sname, Ssex FROM Student
WHERE Smajor IN ('计算机科学与技术', '信息安全');

-- 空值（IS NULL，不能用 = NULL）
SELECT Sno, Cno FROM SC WHERE Grade IS NULL;

-- 模糊匹配（LIKE）
SELECT Sname, SAGE FROM S WHERE SNAME LIKE 'L%';
```

> [!WARNING]
> 判断空值必须用 `IS NULL` / `IS NOT NULL`，写成 `Grade = NULL` 永远返回假。`NULL` 与任何值比较结果都是 `UNKNOWN`。

## 聚集函数与 GROUP BY

聚集函数用于统计，常见有：

| 函数 | 功能 |
|------|------|
| `COUNT(*)` | 统计元组个数 |
| `COUNT(DISTINCT 列名)` | 统计去重后的个数 |
| `AVG(列名)` | 平均值 |
| `MAX / MIN / SUM` | 最大 / 最小 / 求和 |

```sql
-- 未分组：作用于整个查询结果
SELECT COUNT(*) FROM Student;              -- 学生总人数
SELECT COUNT(DISTINCT Sno) FROM SC;        -- 选课人数（去重）

-- 分组后：分别作用于每个组
SELECT Sno, AVG(Grade) FROM SC GROUP BY Sno;   -- 每个学生的平均成绩
SELECT Cno, COUNT(Sno) FROM SC GROUP BY Cno;   -- 每门课的选课人数
```

> [!IMPORTANT]
> `GROUP BY` 细化聚集函数的作用对象：未分组时聚集函数作用于整个结果，分组后分别作用于每个组。`SELECT` 子句中只能取**聚集函数**或 **`GROUP BY` 子句指定的列**，二者之外的列不允许出现。

## HAVING 与 WHERE 的区别

如果分组后还要筛选组，使用 `HAVING`：

```sql
-- 查询选修了多门课的学生学号
SELECT Sno FROM SC
WHERE Semester = '20192'
GROUP BY Sno
HAVING COUNT(*) > 1;
```

| 对比项 | WHERE | HAVING |
|--------|-------|--------|
| 作用对象 | 基表/视图的元组 | 分组后的组 |
| 能否用聚集函数 | ==不允许== | ==允许== |
| 执行时机 | 分组前筛选 | 分组后筛选 |

> [!CAUTION]
> 聚集函数**不能**出现在 `WHERE` 子句中。想筛选"平均成绩大于 80 的学生"，必须先 `GROUP BY`，再 `HAVING AVG(Grade) > 80`，写成 `WHERE AVG(Grade) > 80` 是语法错误。

## ORDER BY 与 LIMIT

`ORDER BY` 对结果按指定列排序，`DESC` 降序、`ASC` 升序（默认）：

```sql
-- 按课程号升序、成绩降序
SELECT * FROM SC ORDER BY Cno, Grade DESC;
```

`LIMIT` 限制返回行数，常与 `ORDER BY` 搭配实现"前 N 名"：

```sql
-- 取成绩前 2 名
SELECT Sno FROM SC
WHERE Cno = '81003'
ORDER BY Grade DESC
LIMIT 2;

-- 跳过前 2 名，再取 2 名（即第 3、4 名）
SELECT Sno FROM SC
ORDER BY Grade DESC
LIMIT 2 OFFSET 2;
```

> [!TIP]
> 记忆口诀：**WHERE 选行、GROUP 分组、HAVING 选组、ORDER 排序、LIMIT 截断**。执行顺序：`FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`。

## 完整算例

统计每门课程的学生选修人数（超过 10 人的课程才统计），显示课程号和人数，按人数降序排列，人数相同按课程号升序：

```sql
SELECT C#, COUNT(S#)
FROM SC
GROUP BY C#
HAVING COUNT(S#) > 10
ORDER BY 2 DESC, 1 ASC;
```

解析：先 `GROUP BY C#` 分组，`COUNT(S#)` 统计每组人数；`HAVING` 筛掉人数 ≤ 10 的组；`ORDER BY 2 DESC, 1 ASC` 中 `2` 指 `SELECT` 中第 2 列（人数）降序，`1` 指第 1 列（课程号）升序。
