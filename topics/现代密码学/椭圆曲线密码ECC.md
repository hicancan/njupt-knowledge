# Elliptic Curve Cryptography (ECC) 的基本概念

## 什么是 ECC 及其核心价值

如果 RSA 需要 1024 位密钥才能达到某种安全强度，有没有一种算法能用更短的密钥实现同等安全？这就是椭圆曲线密码（ECC）解决的问题。ECC 由 Koblitz 和 Miller 于 1985 年提出，其安全性基于==椭圆曲线离散对数问题（ECDLP）的难解性==。

> [!IMPORTANT]
> ECC 的核心优势在于“短密钥、高安全”。在相同安全级别下，ECC 所需密钥长度远小于 RSA 或传统有限域离散对数体制，且目前尚无亚指数攻击方法。

| 安全级别 | RSA/DSA 密钥长 | ECC 密钥长 | 优势体现 |
| :--- | :--- | :--- | :--- |
| 80-bit | 1024 bit | 160 bit | 存储与带宽节省显著 |
| 128-bit | 3072 bit | 256 bit | 计算效率大幅提升 |
| 256-bit | 15360 bit | 512 bit | 适用于物联网等资源受限环境 |

## 数学基础与点运算

ECC 并非直接使用实数域上的曲线，而是定义在有限域 $GF(p)$ 或 $GF(2^n)$ 上。南邮考题常考察 $GF(p)$ 上的 Weierstrass 方程：$y^2 \equiv x^3 + ax + b \pmod p$，且需满足判别式 $\Delta = -16(4a^3+27b^2) \not\equiv 0 \pmod p$ 以保证曲线非奇异。

```mermaid
flowchart LR
    A["选取有限域"] --> B["定义曲线方程"]
    B --> C["验证判别式Δ≠0"]
    C --> D["枚举x求二次剩余"]
    D --> E["生成点集构成群"]
```

> [!WARNING]
> 求解 $y^2 \equiv k \pmod p$ 时，必须先判断 $k$ 是否为模 $p$ 的二次剩余。若 $k^{(p-1)/2} \equiv -1 \pmod p$，则该 $x$ 对应无解，切勿强行开方。

## 真题实战：确定椭圆曲线上的点

以历年真题为例：设 $E: y^2 \equiv x^3 + x + 1 \pmod{23}$，试确定其上 10 个点。

**解题步骤：**

1.  遍历 $x \in [0, 22]$，计算 $f(x) = x^3+x+1 \pmod{23}$。
2.  利用欧拉准则判断 $f(x)$ 是否为二次剩余：$f(x)^{11} \equiv 1 \pmod{23}$ 则有解。
3.  有解时求出 $y$，注意 $(x, y)$ 与 $(x, p-y)$ 成对出现。

> [!TIP]
> 模 23 下常用平方根记忆：$1^2=1, 2^2=4, 3^2=9, 4^2=16, 5^2=2, 6^2=13, 7^2=3, 8^2=18, 9^2=12, 10^2=8, 11^2=6$。遇到 $f(x)$ 值可直接查表反推 $y$。

**部分正确结果验证：**

-   $x=0$: $f(0)=1$, $y=\pm1 \Rightarrow (0,1), (0,22)$
-   $x=1$: $f(1)=3$, $3^{11} \equiv -1$，无解
-   $x=2$: $f(2)=11$, $11^{11} \equiv -1$，无解
-   $x=3$: $f(3)=31 \equiv 8$, $8=10^2 \Rightarrow (3,10), (3,13)$
-   $x=4$: $f(4)=69 \equiv 0 \Rightarrow (4,0)$（唯一解，因 $y=-y$）
-   $x=5$: $f(5)=131 \equiv 16$, $16=4^2 \Rightarrow (5,4), (5,19)$
-   $x=6$: $f(6)=223 \equiv 16 \Rightarrow (6,4), (6,19)$
-   $x=7$: $f(7)=351 \equiv 6$, $6=11^2 \Rightarrow (7,11), (7,12)$

至此已找到 10 个点：$(0,1),(0,22),(3,10),(3,13),(4,0),(5,4),(5,19),(6,4),(6,19),(7,11)$。

> [!CAUTION]
> 填空题常考 ECC 定义域为 $GF(2^n)$ 或 $GF(p)$，判断题强调安全基础是 ECDLP 而非普通离散对数。列举公钥算法时务必包含 ECC，勿与对称密码混淆。
