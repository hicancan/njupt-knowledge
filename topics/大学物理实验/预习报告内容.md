# 预习报告的编写内容与要求

## 它是什么与为什么需要

预习报告是你在进实验室之前，对本次实验“要做什么、依据什么原理、用什么仪器、先测什么后测什么”的书面准备。南邮《物理实验》明确要求：**课前带预习报告到课堂**，否则实验容易陷入被动。

为什么必须写？因为实验不是边看边做。课件里说“课前预习的好坏是实验能否取得主动的关键”。你不写预习报告，进实验室后很可能：仪器不会调、电路图不会画、数据表格没准备、测完才发现缺条件。预习报告就是帮你把“原理 → 条件 → 步骤 → 表格”提前理清。

## 预习报告要写哪些内容

根据复习提纲，至少包含这些部分：

| 内容 | 要求 |
|---|---|
| 实验目的 | 简明写出本次要测什么、验证什么 |
| 原理与公式 | 写清所用公式、各量含义、单位用 SI |
| 仪器设备 | 标注 ==型号、规格==，不能只写“电表” |
| 电路图/光路图 | 自拟线路图、光路图，提前画好 |
| 数据表格 | 根据实验任务画记录表格 |
| 关键与注意事项 | 主要实验条件、实验关键、注意事项 |

如果做的是设计性实验，还要在预习时**自拟实验方案**、提出仪器要求，并报请老师批准，才能进实验室操作。

## 怎么做：以电表改装为例

题干给出：表头内阻 $R_g = 2000\,\Omega$，量程 $I_g$，要改装成量程 $I_1$、$I_2$ 的电流表，且已贴出 $R_1$、$R_2$ 计算公式。

你预习时该想两个问题：
- 要并联还是串联电阻？改电流量程应**并联分流电阻**；
- 两个量程怎么实现？常用闭路式分流器，由 $R_1$、$R_2$ 与表头配合构成不同量程。

于是预习报告里你应提前画好电路图（表头、分流电阻、量程切换端），并按公式把 $R_1$、$R_2$ 用 $I_g, I_1, I_2, R_g$ 表达清楚，单位统一用 $\Omega$ 和 A。进课堂后老师要求“画电路图、画校正曲线取 4 个点并定级”，你因预习过公式，就能直接连线测量、取点、算校正值，而不必现场推导。

```mermaid
flowchart LR
  A["预习：原理公式"] --> B["画电路图"]
  B --> C["拟数据表格"]
  C --> D["课堂连接测量"]
  D --> E["校正曲线4点"]
```

## 和相近概念的区别

预习报告 ≠ 正式实验报告。前者是“课前计划”，重点是原理、图、表格；后者是实验后的书面总结，要求文字通顺、字迹端正、数据完备、结果正确且含误差分析。预习里的“自拟方案”也不同于课堂上的最终方案——它可能经老师批准后修改。

## 常见的坑

> [!WARNING]
> 常见丢分点：进实验室没带预习报告；仪器设备只写名称不写型号规格；数据表格没提前画；SI 单位漏写或写错。

> [!IMPORTANT]
> ==核心要求==：课前必须带预习报告，含原理、仪器型号规格、电路/光路图与原始数据表格。

> [!TIP]
> 记忆口诀：“目的—原理—仪器—图—表—注意”，六项齐全再进实验室。

一个算对方向的小例子：若已知 $R_g=2000\,\Omega$、$I_g$ 给出、公式已提供，你只需把数值代入并联分流关系，算出 $R_1, R_2$，并在预习报告标注单位 $\Omega$，这就是一份合格的公式准备；课堂再据此连线、取 4 个校正点定级即可。
